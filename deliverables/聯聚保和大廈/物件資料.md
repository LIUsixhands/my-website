# 聯聚保和大廈 — 買方銷售報告書 資料夾

| 檔案 | 用途 |
|:--|:--|
| `實登_市政路25號.xls` | 內政部實價登錄原始檔（101/01–115/10，查詢 2026-10-06，69 筆） |
| `analyze.py` | 走小登管線清洗 → `summary.json`、`transactions.csv`（有效 65 筆） |
| `listings.json` | 市售 7 戶：刊登資訊＋謄本校正坪數＋參考區間／出價建議（小登推估） |
| `build_report.py` | 產出 `聯聚保和大廈_銷售報告書.html／.pdf`（9 頁 A4） |
| `位置圖_七期三分區.png` | 七期三分區＋保和位置（小登依助哥 v4 圖重繪） |
| `QR_LINE.png`／`QR_網站.png` | 助哥聯絡 QR |

更新流程：換實登檔 → `python3 analyze.py` → 改 `listings.json` → `python3 build_report.py` → `pdftoppm` 逐頁看。

規則：
- 不使用他家刊登照片；市售來源在報告中不寫仲介品牌與物件編號。
- 謄本只取面積欄位，不記所有權人與他項權利。
- 單價一律含車／不含車並列；對外行情只用近三年中位（`headline()`）。
