# flux.md — 外觀與影像規格（小路 · Gemini 版）

> 檔名沿用 `flux.md`（系統固定欄位名），實際用 **Google Gemini** 生圖。
> Midjourney 版備份在 `備用_其他工具/flux_Midjourney版.md`，想換回去隨時可以。

---

## ⚠️ Gemini 跟 Midjourney 的三個關鍵差異

| | Midjourney | **Gemini** |
|---|---|---|
| 怎麼下指令 | 逗號分隔的英文標籤 | **完整的中文句子**，像在跟人講話 |
| 參數 | `--ar 9:16 --style raw` | **沒有參數**，用文字描述或介面選項 |
| 怎麼鎖臉 | `--cref 圖片網址` | **直接把基準臉圖片一起上傳**，然後說「用這張圖裡的同一個人」 |

> **最重要**：Gemini 不太吃「不要 XXX」這種否定句，講「不要美肌」有時反而會強化。
> 所以下面所有規格都改成**正面描述**：不是「不要塑膠臉」，是「保留真實的毛孔與皮膚紋理」。

## 🚀 先做這件事：建立基準臉

**階段一（只做一次，免費）**

1. 打開 **gemini.google.com**（用 Google 帳號登入，免費版就能生圖，有每日額度）
2. 貼上 §6 的「基準臉指令」
3. 生出來的圖不滿意就直接跟它講：「臉再圓一點」「年紀看起來太大」「頭髮要更亂一點」——**Gemini 可以用對話慢慢調**，這是它比 Midjourney 好用的地方
4. 調到滿意 → **下載那張圖** → 這就是小路的基準臉

**階段二（之後每一張）**

上傳基準臉 ＋ 貼上新的場景指令。Gemini 會保持同一個人。

## 📽️ 實際產線（助哥現有工具）

助哥手上只有 **HeyGen** 和 **開拍**，沒有 ChatGPT / Google One。所以分工是：

| 階段 | 用什麼 | 花錢嗎 |
|------|--------|--------|
| 1. 生小路的基準臉 | **Gemini 免費版** | 不用 |
| 2. 把臉變成會講話的主播 | **HeyGen**（已付費）Photo Avatar | 已付 |
| 3. 產口播影片 | **HeyGen**（播播 skill 自動化） | 已付 |
| 4. 剪接、上字幕、配 B-roll | **開拍**（已付費） | 已付 |
| 5. 生活感照片（IG 貼文用） | **Gemini 免費版** | 不用 |

**指令**（第 2 步只做一次）：
```bash
python3 .claude/skills/skill-bobo/scripts/upload_talking_photo.py 小路_基準臉.png
# 印出 talking_photo_id → 設成環境變數 HEYGEN_TALKING_PHOTO_ID
```

之後叫「播播」產片，就會用小路的臉，不是 HeyGen 的公版主播。

> **為什麼不用 HeyGen 現成主播就好？**
> 現成主播的臉是共用的，別人的頻道也在用。虛擬人物 IP 的價值在於「那張臉只有你有」，
> 用公版等於一開始就放棄辨識度。

> **可能會卡的地方**：Photo Avatar 不是每個 HeyGen 方案都有，
> 而且它可能要求人臉驗證。跑上面那個指令若失敗，把錯誤訊息貼給小魂，會判斷是方案問題還是圖的問題。

## 2. 影像風格（用白話文寫，正面描述）

<!-- BLOCK:STYLE -->
| 項目 | 設定 |
|------|------|
| 整體感覺 | 像用手機隨手拍的生活照，構圖有點隨性、不刻意 |
| 光線 | 只用現場的自然光，沒有打燈、沒有閃光燈，有時甚至偏暗 |
| 色調 | 顏色偏淡、微冷，不鮮豔 |
| 皮膚 | 保留真實的毛孔、紋理與細微瑕疵 |
| 對焦 | 前後景都算清楚，像手機拍的那種 |
| 構圖 | 人物不放正中間，畫面有一點點歪 |
| 比例 | 直式 9:16（手機全螢幕） |
<!-- /BLOCK:STYLE -->

> 比例：如果你用的介面有「長寬比」選項就直接選 9:16；沒有的話指令裡寫「直式 9:16」，
> 生出來若比例不對，用手機內建的裁切功能裁成直式即可。

## 6. 基準臉指令（第一次用，直接複製）

**這張圖有兩個用途，所以構圖有硬規格：**
1. 之後每張生活照的「同一個人」參考
2. 上傳到 HeyGen 做成會講話的 Photo Avatar ← **這個決定了構圖**

HeyGen 的 Photo Avatar 需要：**正面、上半身、臉佔畫面夠大、背景單純、雙眼睜開看鏡頭**。
站在路邊的全身照做不出來，所以基準臉要拍成「證件照的構圖 + 生活照的質感」。

不用附圖，直接貼進 Gemini：

```
幫我生成一張照片。

構圖：上半身正面照，從胸口以上入鏡，臉部佔畫面約三分之一，
她正面直視鏡頭，雙眼睜開，嘴巴閉著表情自然放鬆，頭沒有歪。

人物：24 歲台灣女生，圓臉、臉頰帶點肉感，單眼皮、眼尾微微下垂，深棕色眼睛，
鼻子小而圓潤，上唇薄下唇稍厚，眉毛平直且位置偏低，黑色及肩胛骨長髮綁成低馬尾、
鬢角有幾根散落的頭髮，皮膚偏白帶暖調、左臉頰有淡淡的痘疤痕跡，
右下巴有一顆小痣，身形偏瘦，素顏。

穿著：素面白色短袖襯衫。

背景：單純的淺灰色牆面，沒有雜物。

光線：柔和均勻的自然光從正面來，臉上沒有明顯陰影，沒有打燈也沒有閃光燈。

質感：像用手機拍的，顏色偏淡不鮮豔，保留真實的毛孔與皮膚紋理，
包含左臉頰那片淡淡的痘疤。

重點：她的長相要是路上會遇到的普通女生，不是明星臉，不是網美，沒有修圖感。

比例：直式 9:16。
```

**不滿意就直接跟 Gemini 對話調整**（這是 Gemini 比 Midjourney 好用的地方）：

| 你看到的問題 | 就跟它說 |
|---|---|
| 太漂亮、像網美 | 「臉再普通一點，不要這麼精緻，像路上會遇到的一般人」 |
| 看起來太成熟 | 「年紀再小一點，看起來像剛出社會兩年」 |
| 臉太長 | 「臉再圓一點，臉頰肉再多一點」 |
| 皮膚太光滑 | 「保留毛孔跟左臉的痘疤，不要磨皮」 |
| 頭髮太整齊 | 「馬尾綁鬆一點，鬢角要有幾根散落的頭髮」 |
| 妝太濃 | 「素顏，不要眼妝也不要口紅」 |
| 表情僵硬 | 「表情再放鬆一點，像剛睡醒被叫住拍的」 |

**驗收標準（過了才下載）**
- [ ] 正面、上半身、臉夠大
- [ ] 雙眼睜開看鏡頭、嘴巴閉著
- [ ] 背景乾淨
- [ ] **左臉痘疤還在**
- [ ] **右下巴的痣看得到**
- [ ] 混進你手機裡朋友的照片，不會一眼被認出是 AI

下載存成 `小路_基準臉.png`，丟給小魂上傳到 HeyGen。

## 8. 一致性檢查表（每批抽 3 張比對基準圖）

- [ ] 臉型圓度
- [ ] 眼型（單眼皮、眼尾微下垂）
- [ ] 鼻子大小
- [ ] 嘴唇厚度
- [ ] 髮型（低馬尾＋鬢角散髮）
- [ ] **右下巴的痣還在**
- [ ] **左臉痘疤還在（Gemini 最容易自動修掉這個）**
- [ ] 皮膚有毛孔質感
- [ ] 手部沒崩
- [ ] 沒有真實品牌 logo、沒有可辨識的真人

**任一項不過 → 重生，不要挑圖。**
