# 小登實價AI 🏠 — Claude × 內政部實價登錄 成交行情分析助理

「小登」是 Sixhands Studio 的**實登行情數據官**，用 AI 聊天的方式查詢和分析全台實價登錄成交行情。
問它「北屯區最近成交行情？」它會自動去抓內政部實價登錄的真實成交資料，算出平均總價、每坪單價、各區比較，再用白話文分析給你聽。

## 運作原理

```
你發問 → Claude 判斷要查什麼 → 呼叫工具下載內政部實價登錄 CSV（每季開放資料）
       → 程式篩選 + 統計 → Claude 根據真實數據寫出分析回覆
```

- **AI 大腦**：Anthropic Claude API（工具呼叫 tool use）
- **資料來源**：內政部「不動產成交案件實際資訊資料供應系統」開放資料（plvr.land.moi.gov.tw），涵蓋全台各縣市的買賣、預售屋、租賃成交資料
- **快取**：下載過的季度資料會存在 `cache/` 資料夾，之後查詢秒回，不會重複下載

## 安裝步驟（第一次使用）

### 1. 安裝 Node.js
到 https://nodejs.org 下載安裝 LTS 版（18 以上即可）。

### 2. 安裝套件
打開終端機（Terminal / 命令提示字元），進入這個資料夾：

```bash
cd price-ai
npm install
```

### 3. 設定 API 金鑰
到 https://platform.claude.com/ 註冊並建立 API Key，然後：

```bash
cp .env.example .env
```

用記事本打開 `.env`，把 `ANTHROPIC_API_KEY=` 後面換成你自己的金鑰。

### 4. 啟動

```bash
npm start
```

看到 `✅ 實價AI 已啟動` 之後，用瀏覽器打開 **http://localhost:3000** 就可以開始問了。

## 部署到網路上（讓別人也能用）

這個程式需要後端伺服器，**不能**放在 GitHub Pages（GitHub Pages 只能放靜態網頁）。推薦免費/低價方案：

| 平台 | 說明 |
|---|---|
| [Zeabur](https://zeabur.com) | 台灣團隊，中文介面，連 GitHub 即可部署 |
| [Render](https://render.com) | 免費方案可用，選 Web Service，Start Command 填 `npm start` |
| [Railway](https://railway.app) | 部署簡單，按用量計費 |

部署時記得在平台的環境變數設定裡加上 `ANTHROPIC_API_KEY`。

⚠️ **注意**：API 金鑰是要付費計量的，公開網址給別人用之前，建議加上密碼保護或用量限制，避免被濫用。

## 加上通關密碼（防止陌生人亂用、燒光你的額度）

在部署平台（Zeabur / Render）的環境變數設定裡，多加一筆：

```
ACCESS_CODE=你自己取的密碼
```

設定後，網頁會先顯示一個密碼輸入畫面，只有輸入正確密碼的人才能開始問問題。把這組密碼給你的客戶（例如簽約、預約看房的人）即可。

- **不設定 `ACCESS_CODE`** → 完全公開，任何人都能用（適合自己測試）
- **本機測試時**：在 `.env` 裡加同樣一行即可套用

## 常見問題

**Q：資料多久更新一次？**
實價登錄開放資料以「季」為單位發布（例如 114S4 = 民國114年第4季），每季結束後陸續補齊。程式會自動抓最新有資料的一季，並在回答中註明季別。

**Q：為什麼某些查詢筆數是 0？**
可能該區該季剛好沒有符合條件的成交，或最新一季資料還沒公布完整。可以請 AI 查上一季（例如「查 114S3 的資料」）。

**Q：想換模型？**
在 `.env` 加一行 `CLAUDE_MODEL=claude-sonnet-5` 可以省成本（分析力稍降）。預設是 `claude-opus-4-8`。
