# 台股短線進出候選股每日篩選器

每天盤後跑一次，從全上市＋上櫃普通股裡，依短線評分模型排出 **Top 10 候選股**，
價格區間預設鎖定 **20 ~ 59.95 元**。

資料全部取自證交所與櫃買中心的官方盤後開放資料，沒有第三方付費 API、不需要金鑰，
只用 Python 標準函式庫，`git clone` 下來就能跑。

> **這是研究工具，不是投資建議。** 輸出的是「符合條件的候選名單」，
> 不是「應該買的股票」。真正的進出決策、部位大小與風險承受度，由你自己判斷。

---

## 快速開始

```bash
cd stock-screener

# 篩選最近一個交易日（盤後才有資料）
python3 screener.py

# 指定日期
python3 screener.py --date 2026-08-17

# 同時輸出 Markdown 與 HTML 報表
python3 screener.py --out today.md --html today.html
```

第一次執行要向交易所抓約 32 個交易日的資料，含禮貌性間隔約需 **2~4 分鐘**。
抓過的資料會存進 `.cache/`，之後每天只補當天那一筆，通常 **10 秒內**跑完。

**執行時間很重要**：證交所盤後資料約 14:30 後更新、櫃買中心約 15:00 後。
太早跑會抓不到當天資料，程式會自動退回前一個交易日並在報表標示實際資料日期。

### 參數

| 參數 | 預設 | 說明 |
|------|------|------|
| `--date` | 今天 | 資料日期 `YYYY-MM-DD` |
| `--top` | 10 | 輸出檔數 |
| `--min-price` / `--max-price` | 20 / 59.95 | 價格區間 |
| `--min-avg-vol` | 3000 | 20 日均量下限（張），流動性門檻 |
| `--lookback` | 32 | 回補幾個交易日以建立均線 |
| `--out` / `--html` | 無 | 另存 Markdown / HTML 報表 |
| `--quiet` | 關 | 不印抓取進度 |

### 結束代碼

自動化腳本可據此判斷該不該告警：

| 代碼 | 意義 | 該不該當成故障 |
|------|------|----------------|
| `0` | 正常產出報表 | — |
| `1` | 沒有資料（假日休市或盤後尚未更新） | 否 |
| `2` | 有資料，但沒有個股通過篩選 | 否 |
| `3` | 連不上交易所 | **是** |

## 每天自動跑（GitHub Actions）

`.github/workflows/stock-screener-daily.yml` 已經設定好，**合併進 `main` 之後就會自己動**，
不需要任何金鑰或額外設定。

- **執行時間**：週一至週五 `07:40 UTC` = **台北時間 15:40**。
  台股 13:30 收盤、證交所約 14:30 更新、櫃買約 15:00，留了緩衝。
  GitHub 排程在尖峰時可能延遲數十分鐘 — 晚跑沒關係，早跑才會抓不到資料。
- **報表位置**：
  - `stock-screener/reports/latest.md` / `.html` — 永遠是最新一份
  - `stock-screener/reports/YYYY-MM-DD.md` / `.html` — 依**資料日期**歸檔的歷史報表
- **執行摘要**：每次 Actions 執行頁面直接看得到當日 Top 10 表格，不必翻檔案。
- **手動觸發**：Actions 頁面按 **Run workflow**，可指定日期與檔數補跑。

歸檔用的是報表裡的**資料日期**而不是執行日期 — 太早觸發時程式會自動退回前一個交易日，
檔名要跟著它的判斷走，才不會出現「8/18 的檔案裡裝 8/17 的資料」。

行情快取會透過 `actions/cache` 保留，所以每天只需要向交易所補當天那一筆。

### 三種收場，處理方式不同

| 情況 | 結果 | 行為 |
|------|------|------|
| 正常產出報表 | ✅ 成功 | commit 回 repo |
| 假日休市 / 資料未更新 | ⚠️ 警告 | 不 commit，**不**讓 build 失敗 |
| 沒有個股通過篩選 | ⚠️ 警告 | 不 commit，**不**讓 build 失敗 |
| 連不上交易所 | ❌ 失敗 | **讓 build 失敗並通知你** |

國定假日一年有二十幾天，每次都跳紅字沒有意義，所以假日只給警告。
但「連不上交易所」是真的故障 — 靜靜地失敗比吵你更糟，所以它會讓 build 紅掉。

### 疑難排解：連續多日出現連線失敗

代表交易所擋掉了 GitHub runner 的 IP（雲端 IP 段被擋是常見狀況）。可選：

1. 改用 **self-hosted runner**（放在你自己的機器或台灣的 VPS），workflow 只需把
   `runs-on: ubuntu-latest` 改成 `runs-on: self-hosted`。
2. 回到本機 cron：

   ```bash
   # crontab -e，週一至週五 15:40
   40 15 * * 1-5 cd /path/to/my-website/stock-screener && \
     /usr/bin/python3 screener.py --quiet --out reports/latest.md --html reports/latest.html
   ```

報表會逐日累積（一年約 250 個交易日，每份數 KB）。想控制數量的話，
在 workflow 的「歸檔報表」步驟後面加一行清理即可，例如
`find reports -name '2*.md' -mtime +90 -delete`。

## 評分模型（總分 100）

先套用**硬性過濾**，不符合的直接剔除，不進入評分：

| 條件 | 理由 |
|------|------|
| 收盤價落在 20 ~ 59.95 元 | 指定的操作區間 |
| 20 日均量 ≥ 3,000 張 | 短線進出必須出得掉，量太小會滑價吃掉價差 |
| 收盤價 ≥ MA20 | 只做站在月線之上的多方結構 |
| 當日跌幅 < 8.5% | 排除接近跌停的個股 |
| 至少 22 根日 K | 均線與 ATR 需要足夠樣本 |
| 四位數字代號、排除 00 開頭 | 濾掉 ETF、ETN、權證、特別股 |

通過的個股再計分：

### 1. 動能與均線結構（25 分）
收盤站上 MA5（6 分）＋ MA5 在 MA20 之上（6 分）＋ 乖離率位置（最高 13 分）。

乖離率（收盤對 MA20）給分刻意做成**倒 U 型**：`+2% ~ +12%` 是甜蜜區給滿分，
`+12% ~ +20%` 降到 6 分並標註「留意回測均線」，超過 +20% 給 0 分。
**漲太多不是加分項** — 短線在乖離過大時進場，等於幫前面的人抬轎。

### 2. 量能（25 分）
當日量 ÷ 20 日均量，`1.5 ~ 4 倍` 給 15 分為最佳；`4 ~ 6 倍` 降為 9 分；
超過 6 倍只給 4 分並標註「過熱」，因為爆量常是出貨或一日行情。
另加流動性分：20 日均量 ≥ 10,000 張給 10 分、≥ 5,000 張給 8 分、其餘 6 分。

### 3. 籌碼（20 分）
近 5 個交易日三大法人累計買賣超 ÷ 20 日均量。
≥ 1.0 倍給 20 分、≥ 0.5 倍給 16 分、≥ 0.2 倍給 12 分、>0 給 7 分、
**賣超直接給 0 分**並標註。抓不到法人資料時給 5 分中性分並在報表註明。

### 4. 波動空間（15 分）
ATR14 ÷ 收盤價，`3% ~ 6%` 給滿分。太低（<2%）表示短線沒有肉，
太高（>8%）只給 4 分並提醒縮小部位 — 波動本身是雙面刃。

### 5. 突破結構（15 分）
收盤創 20 日新高給 8 分、接近（≥97%）給 5 分；
再看**收盤在當日 K 棒的位置**：收在上緣 30% 內給 7 分、上半部給 4 分，
收在下半部給 0 分並標註「隔日開盤先觀察」。

### 交易參考位怎麼算的

- **買進區**：`max(MA5, 收盤 − 0.5×ATR)` 到收盤價 — 不追高，等回落到這個帶再進。
- **停損**：`min(MA5, 收盤 − 1.5×ATR)` — 同時尊重均線與波動幅度。
- **目標**：`收盤 + 2×ATR`。
- 三個價位都會依台股檔位進位（50 元以下 0.05、50 元以上 0.1）。
- **R:R** 為報酬風險比，低於 1.5 的標的要特別謹慎。

## 模型限制（請務必讀完）

這個模型**不涵蓋**以下風險，跑出名單後仍需人工確認：

1. **處置股與注意股**：交易所的處置名單是另一份公告，本程式沒有串接。
   被列處置會改為分盤交易、需圈存，短線幾乎沒法操作。**下單前一定要查。**
2. **財報與除權息**：撞到法說會、財報公布或除權息，走勢會脫離技術面。
3. **消息面與基本面**：純量價籌碼模型，不看營收、毛利率、產業循環。
   建議搭配 `stock-radar` skill 對入選個股做個股深度分析。
4. **回測**：評分權重是依短線交易常識設定的先驗值，**尚未做歷史回測驗證**。
   把它當成「縮小研究範圍的漏斗」，不是「已驗證的獲利公式」。
5. **借券空單與軋空**：未納入融資融券與借券餘額。
