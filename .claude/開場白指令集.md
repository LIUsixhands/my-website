## 大樓建檔・網站頁・報告書（小登）

**★ 三合一：建檔＋網站頁＋買方銷售報告書**（細節見 `skills/skill-xiao-deng/references/七期大樓行情庫.md`「三合一開場白」）
```
找小登，建檔〈大樓名〉，〈七期住宅／界外住宅／商辦〉。
實登買賣、租賃都在這。

建完接著做：
① 網站加一頁這棟的行情分析
② 做一份給買方的銷售報告書，物件是：
   〈樓層〉樓、〈權狀坪數〉坪、〈格局〉、〈車位〉、開價〈 〉萬
   賣點：〈景觀／採光／屋況／管理…〉
```
網站頁只放大樓行情；這一戶的開價只在報告書，私下傳給買方。**報告書不 commit**（repo 公開）。

只建檔：
```
找小登，建檔〈大樓名〉，七期住宅。
實登買賣、租賃都在這。
```
列入豪宅精選名單：`找小登，建檔〈大樓名〉，列入助哥精選名單。實登在這。`
只查數字：`找小登，查〈大樓名〉行情`
客戶問一坪多少：`找小登，我要估〈標的〉，客戶問一坪多少`

## 土地・商辦（小登）

土地行情：`找小登，〈十三期／七期／某段〉土地現在多少`
商辦估價（屋主委託）：
```
找小登，商辦估價〈案名或門牌〉，屋主委託。
實登買賣、租賃都在這。
```
商辦買方上門：`找小登，商辦買方上門：要〈 〉坪、〈自用／收租〉、〈整層／單戶〉，幫我挑棟。`

## 撈實登的方法

內政部實價查詢 → 臺中市與區別 → 輸入**門牌** → 撈**買賣、租賃**（新案加**預售**）→ .xls 直接拖進對話框。
⛔ **樓層別、坪數、建物型態一律不要勾**，勾了會漏資料。
