# 工具：實照嵌入流程（chat 圖片救出 + PDF 嵌入）

> 助哥指定固化 2026-06-09。Claude Code on web 環境下，使用者「**貼圖到對話**」的照片不會落地成獨立檔案，但會 **base64 嵌在 session log** 裡。本工具直接從 log 救出來。

---

## 🎯 為什麼需要這個工具

| 上傳方式 | 落地路徑 | 我能直接讀檔？ |
|:--|:--|:--|
| 附件按鈕（迴紋針／+） | `/root/.claude/uploads/{session}/` | ✅ 直接讀 |
| **貼圖到對話** | ❌ 不落地成檔案 | ❌ 但 base64 在 session log，可救 |

> 任何員工要做「使用者貼圖 → PDF / HTML 嵌入」的任務，**先跑這支工具**。

---

## 🛠️ 用法

```bash
# 取最近 N 張（預設 5），存到 outdir（預設 /tmp/chat_imgs）
python3 .claude/tools/extract_chat_images.py [N] [outdir]

# 範例：取最後 4 張存到 /tmp/photos
python3 .claude/tools/extract_chat_images.py 4 /tmp/photos
```

輸出：
```
[+] 來源：/root/.claude/projects/-home-user-my-website/<session>.jsonl
[+] log 內共找到 49 張 user 上傳圖片
  → /tmp/chat_imgs/photo_1.jpg  (367 KB, ts=2026-06-09T14:46:39, line 1062)
  → ...
```

## 📄 嵌入 PDF（weasyprint 範例）

```python
import base64
from weasyprint import HTML

def b64(p):
    with open(p, 'rb') as f:
        return base64.b64encode(f.read()).decode()

V1 = b64('/tmp/chat_imgs/photo_1.jpg')
html = f'<img src="data:image/jpeg;base64,{V1}">'
HTML(string=html).write_pdf('out.pdf')
```

## 🎨 CSS 嵌圖排版建議

| 用途 | CSS | 為什麼 |
|:--|:--|:--|
| Banner / 含字主視覺 / 風景 | `object-fit:contain` ＋ 固定高 ＋ 米色襯底 | **不裁切**，文字 / 構圖完整 |
| 室內 / 補充小圖 | `object-fit:cover` ＋ 固定高 | 版面整齊（局部裁切可接受） |

```css
.big-photo { background:#F4EFE2; border-radius:6px; padding:5px; }
.big-photo img { width:100%; height:90mm; object-fit:contain; display:block; }
.photo-slot img { width:100%; height:55mm; object-fit:cover; display:block; }
```
