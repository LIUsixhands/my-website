## 🔀 GitHub：什麼要問、什麼不用問

**定案 2026-10-05。** 助哥問「等我合併是什麼意思」，說明後同意由 Claude 直接處理。

| 變更類型 | 處理方式 |
|:--|:--|
| **只動 `.claude/` 底下**（行情庫、SOP、計畫、記錄、工具腳本） | ✅ **Claude 直接合併，不用問** |
| **動到網站本身**（`*.html`、`sitemap.xml`、`netlify.toml`、根目錄檔案） | ⏸ **先給助哥看過再合併** |

**理由**：`.claude/` 是 AI 員工的工作筆記，不會改到客戶看到的網站，沒有審閱的必要；
而且**不合併就留在分支裡，新視窗讀不到**——助哥最在意的「換視窗資料不會消失」會失效。

> 📌 **關鍵觀念（講給未來的助哥聽）**：
> 新對話視窗讀的是 **main（主抽屜）**。
> 東西留在分支（草稿夾）裡，新視窗就讀不到。**所以筆記類更新一定要合併。**

**助哥不需要學 GitHub 操作。** 他只在 Claude 動到網站本身時看一眼就好。

## 🖥️ 環境限制（Claude 做不到的事，不要重複嘗試）

本執行環境的 egress proxy 擋住下列網域，一律回 403：

```
sixhands.tw          netlify.app        app.netlify.com
docs.netlify.com     answers.netlify.com
crt.sh（憑證查詢）    maps.app.goo.gl
net-chinese.com.tw   law.moj.gov.tw
```

**後果**：
- 無法替助哥驗證網站是否正常顯示、憑證是否生效 → **只能請他用瀏覽器開來看**

- DNS 查詢會被導向單一解析器，**無法直接問權威伺服器**，沒有繞過傳播時間的捷徑
