## ⭐ 先講最關鍵的一件事：「新四」法定不能做住宅

> **第四種新市政中心專用區（簡稱「新四」）｜容積率 650%｜不得作住宅使用**
> 僅能規劃**飯店、商場、百貨、商辦**。

這一條解釋了三件本庫先前的懸案：

| 懸案 | 解答 |
|:--|:--|
| 聯聚中雍實登為何寫「住宅大樓」型態卻是辦公用？ | 土地是新四，**法定不能做住宅**，型態欄僅為建物登記分類，不代表用途 |
| 市政北七路 98 號到底算不算七期？ | 土地分區為「**第四種新市政中心專用區**」＝新市政中心專用區內 → 屬七期核心（仍請助哥就在地四界拍板）|
| 為何惠國段全是商辦、飯店、百貨？ | **不是市場選擇，是法規限制** |

> 📌 **帶客可直接用**：客戶問「這裡以後會不會蓋住宅拉低檔次」→ **法規上不行**。這是硬依據。

### ⚠️ 為何皇翔 268 低於前一年興富發 323（−17%）？

## 🎯 對現有資料庫的三點回饋

### ① 補上商辦庫最缺的「大宗交易錨點」
```
整棟交易（中壽/豐邑A8，2022）約 51.3 萬/坪
散戶成交（聯聚中雍，成屋轉售中位）  64.85 萬/坪
→ 整棟約為散戶價的 79%
```
→ **大宗整棟交易折價約 2 成屬正常**（流通性差、單一買方、一次買斷滿租資產）。
→ 💡 若客戶問「整棟賣划不划算」，**這就是依據**：整棟出場要有折價心理準備。

### ② ⚠️ 修正我先前的「坪數＝分級機制」洞察

先前本庫依同業分級寫下「真正的分級機制是最小坪數」，**遇到反例**：

| | 聯聚中雍 | 聯聚中維 |
|:--|:--|:--|
| 同業分級 | 頂級企業總部級 | **同為**頂級企業總部級 |
| 坪數規劃 | **225–450 坪** | **80–120 坪** |
| 戶數 | 73 | 235 |
| 高度／樓層 | 192m／39F | 208m／42F |

→ 兩案坪數差約 3 倍、戶數差 3.2 倍，**卻被歸為同級**。
→ **修正**：坪數是**客群篩選器**（決定哪種企業買得到），
   但**不是品牌分級的唯一依據**——同業的「頂級」是看 **品牌＋規格＋地段**。
   引用分級框架時須同時看坪數，**不可只憑等級推斷產品型態**。

### ③ 四界爭議取得第三重證據
皇翔案報導明載該地為「**第四種新市政專用區（新四）**」，與聯聚中雍實登土地分區
「都市：第四種新市政中心專用區」同屬一系 → **市政北路一帶確為新市政中心專用區**。

## ⚖️ 合規與口徑

- **土地單價**：總價 ÷ 土地面積（坪），不含建物。
- **總銷金額**：建商自行公布之預估值，**非成交數據**，不得作為行情引用。
- **整棟交易單價**：以報載總面積反推，屬**推估**。
