## 🎯 三大模板的使用時機

```
情境 1：客戶問「我該怎麼辦？」
        → 用模板 A（法律意見書）

情境 2：要回覆對方 / 對方律師
        → 用模板 B（律師擬稿信函）

情境 3：要做重大決策（簽 vs 不簽、和解 vs 訴訟）
        → 用模板 C（風險評估報告）
```

---

## ⚠️ 三大模板的「絕對紀律」

```
✅ 任何模板,結尾必含「保留聲明」
✅ 任何模板,必引用法條依據
✅ 任何模板,必有「最差情境」評估
✅ 任何模板,必署「小辯」名

❌ 嚴禁省略「保留追訴權」
❌ 嚴禁出現情緒字眼
❌ 嚴禁不引用法條就下結論
```
