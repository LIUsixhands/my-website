# 合規紅線

> 稽核工具：`python3 socialpost.py check 貼文.md --industry 醫美`
> **工具只擋已知字詞，擋不掉「內容本身不實」。事實與授權永遠要人工確認。**

## 一、法規面（紅燈，一律不放行）

| 類型 | 依據 | 不可寫 |
|:--|:--|:--|
| 絕對化用語 | 公平交易法 §21（廣告不實） | 最好、第一、唯一、頂級、百分百、絕對 |
| 療效宣稱 | 食安法 §28、化粧品衛生安全管理法 §10、藥事法 §66–69 | 治療、根治、消炎、殺菌、排毒、增強免疫、醫療級 |
| 收益保證 | 銀行法 §29-1、投信投顧法 | 保證獲利、穩賺不賠、零風險、保本保息 |
| 傳銷用語 | 多層次傳銷管理法 | 下線、分潤、組織獎金、拉人頭 |
| 做不到的保證 | 廣告不實 | 保證有效、保證錄取、保證成交、保證瘦 |

**判準**：只要是「做不到就會被客訴或被檢舉」的承諾，就不要寫。
可以講**做法**（熬六小時）、講**事實**（開店十年）、講**範圍**（多數客人回報…），不要講**保證的結果**。

## 二、Meta 廣告與內容政策（會被拒登或降觸及）
1. **個人特徵斷言**：不可用「你是不是很胖／你有憂鬱症嗎／像你這種負債的人」這種指認對方屬性的第二人稱。
   改成描述情境：「很多人在意的是…」
2. **健康與美容的前後對比圖**：體重數字、身材前後對照、不理想的身體意象，屬高風險，廣告端幾乎必被拒。
   自然貼文風險較低但仍可能被檢舉，**醫美與美業一律先跟客戶確認**。
3. **誘導互動**：留言抽獎、按讚抽獎、標記三個朋友——會被演算法壓觸及。
4. **誤導性醫療內容**、成人內容、菸酒博弈、武器：一律不碰。

## 三、授權與個資（最容易出事的一段）
- **顧客照片、評價截圖、對話截圖**：先取得同意，**上稿前必掃個資**（本名、電話、地址、報名表照片、
  帳號全名、頭像可辨識人臉）。這條實際踩過，見 [[project_student_testimonial_video]]。
- **員工入鏡**：要肖像同意，離職後要不要下架也要先講好。
- **音樂**：API 發的影片不能用平台音樂庫，必須自備有授權的音檔（走 ElevenLabs 生成或已購授權曲）。
- **他人作品、他牌 logo、路人臉**：素材出手前目視掃過（[[feedback_ad_material_weapon_scan]]）。
- **未成年入鏡**：一律要監護人同意，能不拍臉就不拍臉。

## 四、產業特別注意
| 產業 | 額外要小心 |
|:--|:--|
| 醫美／診所 | 醫療法廣告限制極嚴；不可寫療程效果保證、不可用前後對比誘導、不可標榜「無恢復期」 |
| 保健食品 | 不可寫改善體質、調整體質、增強免疫等功效性宣稱 |
| 餐飲 | 「無添加、純天然、有機」要有依據；產地與成分不可誤導 |
| 房產 | 不可寫保證增值、保證出租；價格與坪數要與實際一致 |
| 金融保險 | 不可寫保證核貸、保證收益；商品說明要與條款一致 |
| 補教 | 不可寫保證上榜、保證考取；升學榜單要真實可查 |
| 美業 | 不可寫永久除毛、根除、無痛保證 |

## 五、發佈前最後三問
1. 這句話如果被截圖檢舉，我拿得出依據嗎？
2. 這張圖裡的人、聲音、音樂，我有授權嗎？
3. 客戶那邊誰看過並說可以發？（名字寫進發佈紀錄）

三題有一題答不出來，就不要發。
