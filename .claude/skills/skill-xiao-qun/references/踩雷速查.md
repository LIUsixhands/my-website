# 踩雷速查

| 症狀 | 真正原因 | 解法 |
|:--|:--|:--|
| IG 發圖一直失敗，說抓不到圖 | `image_url` 不是外網直連（雲端硬碟分享頁不算） | 改放真正的公開靜態空間，用瀏覽器無痕開一次確認 |
| IG 排程沒發出去 | **IG 沒有原生排程 API**，是本機到點才送，電腦睡了就沒送 | 電腦保持開機，或 IG 改人工發 |
| 貼文送出成功但粉專看不到 | 用了 `published=false` 卻沒給 `scheduled_publish_time`，變成未發佈草稿 | 到粉專的「發佈工具」找草稿 |
| Token 昨天還好好的，今天全掛 | 客戶改密碼／移除應用程式／權限被收回／API 版本被淘汰 | 照 Meta_API_設定SOP 第 7 節逐項排查，不要直接重產 Token |
| 一般客戶帳號用不了，只有自己能用 | 應用程式沒送審，只有應用程式角色內的人可用 | 送審，或把客戶加進應用程式角色 |
| 洞察指標抓不到 | Meta 每個 API 版本都在改指標名稱 | 先確認 `graph_version`，查官方指標清單，**不要猜指標名** |
| 圖卡中文變豆腐格 | 字型缺字（Songti SC 缺繁體、STHeiti 缺「・」） | 用 PingFang TC；**產完一定要打開目視**，程式抓不到豆腐格 |
| 觸及突然掉一半 | 常見是：發了誘導互動、連續發促銷、或改素材重送審 | 停促銷兩週、恢復內容配比；素材別燒死日期（[[feedback_fb_ads_dont_churn_audience]]） |
| 每次改活動日期就要重做圖 | 日期燒死在圖上了 | 日期只放文案與落地頁，圖上不放 |
| 影片發出去沒聲音／被消音 | 用了無授權音樂被 Content ID 擋 | 音樂走自備授權曲；API 發片本來就不能用平台音樂庫 |
| 排程時間被拒 | FB 排程要 10 分鐘以後、6 個月以內 | 調整時間 |
| 工作區檔案讀取間歇性失敗 | 放在桌面（iCloud）被移出本機 | 工作區一律放 `~/AI員工_小群/`，不放桌面（[[feedback_icloud_dataless_breaks_launchd]]） |

## 交件前必做的三個目視
1. **打開圖卡看過** — 字有沒有切邊、有沒有豆腐格、有沒有壓到安全區
2. **抽幀看過影片** — 他牌 logo、路人臉、違禁畫面、寫死的日期
3. **預覽整則貼文** — `socialpost.py preview`，把檢查清單逐項打勾
