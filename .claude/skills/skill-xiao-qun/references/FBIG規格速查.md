# FB／IG 規格速查

> ⚠️ 平台規格會變。這份是實務上安全的取值，不是官方保證值。
> 重要專案上稿前，用一則測試貼文實測一次最準。

## 圖片尺寸（產出用這幾種就夠）
| 用途 | 比例 | 建議像素 | 備註 |
|:--|:--|:--|:--|
| IG 動態（預設用這個） | 4:5 | 1080×1350 | 直式佔版最大，滑動時最吃版面 |
| IG／FB 方形 | 1:1 | 1080×1080 | 輪播與商品照常用 |
| 限時動態／Reels 封面 | 9:16 | 1080×1920 | 上下各留約 250px 安全區給介面 |
| FB 橫式與連結預覽 | 16:9 或 1.91:1 | 1920×1080 | 連結預覽圖太小會被裁 |

**安全區鐵律**：9:16 的文字不要碰到上下各 15% 的範圍，會被介面元件蓋掉。

## 文字長度
| 位置 | 建議 |
|:--|:--|
| FB 貼文 | 前 2–3 行就要說完重點（會被「查看更多」截斷） |
| IG 說明文字 | 上限約 2200 字元；**首行是生死線**，被折疊後只看得到第一行 |
| IG hashtag | 8–15 個。堆到 30 個不會比較好，只會像廣告 |
| FB hashtag | 最多 3 個，FB 的 hashtag 幾乎沒有發現流量 |
| 圖片內文字 | 主標一行不超過 12 字、最多 2 行；一張圖只講一件事 |

## 影片與 Reels
| 項目 | 建議 |
|:--|:--|
| 比例 | 9:16 |
| 長度 | 15–60 秒最穩；前 3 秒決定生死 |
| 字幕 | **一定要燒字幕**，多數人靜音看 |
| 封面 | 自己指定，別讓平台隨機抽幀 |
| 音樂 | API 發佈的影片不能用 IG 內建音樂庫，要自備有授權的音檔 |

⚠️ **API 發的 Reels 沒有內建音樂庫可選。** 想用平台熱門音樂就只能人工在手機上發。
這一點會直接影響「要不要全自動」的決策，接案時先講。

## 連結
- **IG 貼文的說明文字裡放連結沒有作用**，不可點。只有主頁連結、限動連結、廣告可點。
- FB 貼文放連結會影響觸及，但比「叫人自己搜尋」好。做法：連結放留言區或用短網址。
