# 小群 · 安裝與設定說明（交付給學員）

## 這隻員工能幫你做什麼
把你的 FB 粉專與 IG，從「不知道今天要發什麼」變成
**內容日曆 → 文案 → 圖卡 → 短片 → 合規檢查 → 排程發佈 → 月報** 一條龍。

**做不到的三件事，先講清楚：**
1. IG 只能發「公開網址」的圖片影片，所以要先有一個放素材的公開空間。
2. IG 沒有原生排程，到點發佈時電腦要開著。
3. 用 API 發的影片不能用平台內建的熱門音樂，要自備有授權的音檔。

## 安裝
1. 把 `skill-xiao-qun` 整個資料夾放進 `~/.claude/skills/`
2. 確認有 Python 3 與 Pillow：
   ```bash
   python3 -c "import PIL; print(PIL.__version__)"
   ```
   沒有的話：`python3 -m pip install --user pillow`
3. 建立你的工作區（客戶代號自己取，英數即可）：
   ```bash
   cd ~/.claude/skills/skill-xiao-qun/scripts
   python3 socialpost.py init 你的客戶代號
   ```

## 設定
1. 依 `references/Meta_API_設定SOP.md` 產生**你自己的** Token
2. 把 `page_id`、`ig_user_id`、`page_access_token`、`public_asset_base` 填進
   `~/AI員工_小群/你的客戶代號/config.json`
3. 驗證：
   ```bash
   python3 socialpost.py auth 你的客戶代號
   ```

🚨 **Token 等於你帳號的鑰匙。** 不要貼給任何人、不要放進簡報截圖、不要上傳雲端。
這個檔案的權限已自動設成只有你讀得到。

## 每天怎麼用
```bash
# 月初：排這個月要發什麼
python3 socialpost.py plan 你的客戶代號 --month 2026-10

# 寫完文案先檢查
python3 socialpost.py check 貼文.md --industry 餐飲

# 做圖卡
python3 socialpost.py card 你的客戶代號 --text "主標|副標|補充" --ratio 4:5 --out 圖卡.png

# 發之前先預覽（不會送出）
python3 socialpost.py preview 你的客戶代號 貼文.json

# 真的要發，才加 --confirm
python3 socialpost.py publish 你的客戶代號 貼文.json --confirm
```

## 最重要的一條
**沒加 `--confirm` 就什麼都不會送出。這是刻意的設計。**
貼出去的是你的招牌，撤下來也已經被人看過了。
每一則都用 `templates/送出前確認清單.md` 逐項打勾再送。
