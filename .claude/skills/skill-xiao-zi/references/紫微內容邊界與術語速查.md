# 十二宮 → 白話痛點速查（寫腳本時翻這張表）

> 原則：**先講現象，再講宮位。** 觀眾是為了自己的人生點進來，不是為了學術語。

| 宮位 | 一句白話 | 可用的生活現象（鉤子素材） | 邊界（不可跨） |
|:---|:---|:---|:---|
| 命宮 | 你出廠的預設反應方式 | 遇到壓力先閃還是先扛、第一反應是問人還是自己扛 | 不講「命好命壞」 |
| 兄弟宮 | 你身邊誰是真的接得住你的人 | 家裡誰在扛、朋友多但關鍵時刻找不到人 | 不評斷他人性格為定論 |
| 夫妻宮 | 你在親密關係裡的固定劇本 | 一直吸引到同一種人、越靠近越想逃 | 不預言離婚、不判定對方 |
| 子女宮 | 你跟晚輩／作品的緣分模式 | 跟小孩講不通、想生但一直沒到位 | 不預言生育結果 |
| 財帛宮 | 你跟錢的相處習慣 | 賺得到卻存不下、看到折扣就守不住 | ❌ 不預測發財、不報明牌 |
| 疾厄宮 | 你耗損自己的方式 | 熬夜硬撐、情緒往肚裡吞 | ❌ 不診斷疾病、不談療效 |
| 遷移宮 | 你在外面的樣子 | 在家沉默在外面很會、換環境才活過來 | 不預言意外 |
| 交友宮 | 你怎麼被群體對待 | 總是那個被拜託的、人脈廣但沒深交 | 不評斷特定人 |
| 官祿宮 | 你適合怎麼工作 | 做十幾年還是覺得不對、換了五份工作都撐不久 | 不保證升遷、不保證創業成功 |
| 田宅宮 | 你跟「安穩」的關係 | 一定要有自己的空間、家對你是充電還是消耗 | 不預測買房時機 |
| 福德宮 | 你怎麼消耗與補充心力 | 明明沒做什麼卻很累、閒下來反而焦慮 | 不談精神疾病 |
| 父母宮 | 你最早學會的相處方式 | 跟長輩講不出口、很怕讓人失望 | 不評斷原生家庭對錯 |

## 十四主星 → 一句人格素描（給非同好聽的版本）

## 術語使用規則

1. **前 3 秒零術語。**
2. 全片術語 ≤ 3 個，每個當場翻白話：「官祿宮——講白話就是你適合怎麼工作」。
3. 不用「化忌／自化／飛星」這類進階術語在冷流量片；那是給已購學員的內容。
4. 一支片只講**一個宮位**。講兩個以上，觀眾記不住，數據也會掉。
