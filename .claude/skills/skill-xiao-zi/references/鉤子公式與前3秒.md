# 前 3 秒生死線：鉤子公式

短影音的規則很殘酷：**前 3 秒沒抓住，後面寫得再好都不會被看到。**
命理類尤其危險——一開口就是「紫微斗數告訴我們」，非同好會立刻滑掉。

## 六個能用的鉤子公式

### 1. 否定式（最強）
> 「你不是 ___，你只是 ___。」

「你不是不努力，你只是一直在跟自己的個性打架。」
為什麼有效：先幫觀眾洗掉罪惡感，他會想聽完你怎麼替他說話。

### 2. 重複現象式
> 「為什麼你每次都 ___？」

「為什麼你每次都吸引到不會照顧你的人？」
為什麼有效：「每次都」暗示這是**模式**不是運氣，而模式可以被解釋。

### 3. 反常識式
> 「___ 其實不是 ___。」

「財帛宮好，不代表你會有錢。」
為什麼有效：打臉觀眾原本的理解，製造資訊落差。

### 4. 指名式（限定受眾）
> 「如果你 ___，這支影片是給你的。」

「如果你做同一份工作超過十年，卻越做越空——」
為什麼有效：篩掉不相干的人，留下的人留存極高。

### 5. 場景式
> 直接播一個畫面感很強的場景

「晚上十一點，你躺在床上滑手機，其實你不想睡，也不想醒著。」

### 6. 自曝式（老師本人）
> 「我第一次看自己的盤，看到 ___ 那一格，我坐在那邊很久。」

為什麼有效：命理是信任生意，老師的脆弱比老師的權威更有說服力。

## 前 3 秒禁忌

| ❌ | 為什麼 |
|:---|:---|
| 「大家好我是 XXX 老師」 | 前 3 秒是黃金地段，不能拿來自我介紹 |
| 「今天要跟大家分享」 | 空轉一句，觀眾已經滑走 |
| 「紫微斗數認為……」 | 術語勸退非同好 |
| 「命宮有紫微星的人……」 | 觀眾不知道自己有沒有，跟他無關 |
| 長 logo 動畫開場 | 品牌放片尾，不放片頭 |

## 三個結構檢查
1. 第一句話能不能單獨當標題？不能就重寫。
2. 把畫面關掉只聽聲音，前 3 秒還抓得住人嗎？
3. 第一句有沒有出現「你」？沒有的話，改成有。
