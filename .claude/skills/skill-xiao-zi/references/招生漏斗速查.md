# 招生漏斗速查（影片要接到哪裡去）

> 小紫只負責「段 1 的影片」。但你要知道整條路長什麼樣，才不會把 CTA 寫成死路。
> 完整版作戰書由 `小定`（定位）＋`小廣`（廣告）＋`小網`（頁面）接手。

```
段1 短影音（小紫）→ 段2 免費排盤頁／解讀報告 → 段3 LINE 7 天暖身
                                              → 段4 免費解盤直播（唯一成交場）
                                              → 段5 收單 → 段6 續售認證班／月費社群
```

## 段 1：短影音（小紫的戰場）
- 內容軸心：**不教排盤，只講現象。**
- 節奏：每週 3-5 支，同步 IG Reels／YT Shorts／TikTok。
- 每支公式：具體人生現象 →「這件事在盤上有位置」→ 一個當下能用的觀點 → CTA。
- CTA 只有三種選擇，一支片選一種：
  1. 「留言『命盤』我把 ___ 給你」（養互動，演算法最愛）
  2. 「簡介連結免費排你自己的盤」（收名單）
  3. 「這週四晚上八點直播，我帶你看命宮」（導直播）

## 段 2：名單磁鐵 — 免費排盤網頁
命理業最高價值的第一方資料是**出生年月日時**，而使用者願意主動給（因為他想看自己的盤）。
> 輸入生日 → 免費看盤面 → 只解鎖命宮一段 → 留 Email／加 LINE 領完整報告

⚠️ 蒐集生日 = 蒐集個資，頁面必須有告知同意聲明（見合規紅線第五條）。

## 段 3：LINE 七天暖身（全程不賣課）
Day1 報告怎麼看｜Day2 命盤不是命定論｜Day3 老師自己的故事｜Day4 學員案例｜
Day5 我為什麼不幫人算命而是教人自己看｜Day6 直播預告｜Day7 倒數＋議題徵集

## 段 4：免費解盤直播（唯一成交場）
0-10' 故事＋今晚會拿到什麼｜10-30' 真的教一件有用的事｜
**30-60' 現場抽人即時解盤（全場最高潮，無法造假的證據）**｜
60-70' 為什麼你需要自己會看｜70-85' 課程＋名額＋倒數｜85-90' Q&A

## 段 5：收單節奏
報價 → 發單 → 倒數 → 填單 → 加 LINE → 收款
名額要給**服務性的理由**（「每位學員我都會親自看過盤才開課，所以只收 N 人」），不要假稀缺。

## 段 6：續售
認證班（給想變現的療癒工作者）／月費解盤社群。
畢業作業設計成「幫三個朋友解盤」——同時是教學、口碑擴散、下一屆名單來源。

## 影片 CTA 對照表（別寫成死路）

| 這支片的目的 | CTA 寫法 | 終點要先準備好 |
|:---|:---|:---|
| 漲粉／養互動 | 「留言『命盤』」 | 有人回留言（自動或手動） |
| 收名單 | 「簡介連結免費排盤」 | 排盤頁已上線 |
| 導直播 | 「週四八點，連結在簡介」 | 直播已開、報名表已建 |
| 賣解盤服務 | 「私訊『解盤』看檔期」 | 檔期、價格、付款方式已定 |

> 終點沒準備好就不要寫那個 CTA——流量進來撲空，比沒有流量更傷。
