## 轉成 scenes.json

```json
[
  {"type": "text",  "big": "你不是不努力",
   "narration": "你不是不努力，你只是一直在跟自己的個性打架。"},
  {"type": "chart", "highlight": "官祿宮",
   "narration": "這件事在命盤上有個位置，叫官祿宮。"},
  {"type": "image", "image": "photos/class01.jpg",
   "narration": "上個月的課，有位學員看到這一格就笑了。"},
  {"type": "text",  "big": "留言「命盤」",
   "narration": "留言「命盤」，我把週四直播的連結給你。"}
]
```

存成 `scenes.json`，然後：

```bash
python3 ~/.claude/skills/skill-xiao-zi/scripts/make_ziwei_short.py scenes.json
```
