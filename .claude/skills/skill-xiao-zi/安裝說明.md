## 一、這隻 AI 員工幫你做什麼

把你的紫微斗數內容，變成一支支**能直接發**的短影片。

| 有小紫 | 沒小紫 |
|:---|:---|
| 講一個主題 → 出腳本 → 出成片 | 想了三天不知道拍什麼 |
| 命盤視覺自動生成（紫金風、可指定哪一宮發光） | 拿排盤軟體截圖硬貼，畫面很醜 |
| 每支片自動跑合規紅線（療效／收益／改運） | 一句「保證改運」讓帳號被檢舉 |
| 配音、字幕、Ken Burns、品牌尾卡一鍵完成 | 剪片剪到半夜 |

**⚠️ 小紫只做紫微斗數這一個主題。** 公司本業（不鏽鋼）的產品宣傳片是完全不同的受眾與法規，要另外開一隻。

## 二、安裝（macOS）

### 方法 A：解壓縮拖進去（推薦）

1. 解壓 `skill-xiao-zi.zip`
2. 把整個 `skill-xiao-zi` 資料夾拖到：
   ```
   ~/.claude/skills/
   ```
   （Finder 按 `Cmd + Shift + G`，貼上 `~/.claude/skills` 就會開啟）
3. 重開 Claude Code
4. 輸入「**小紫**」測試

### 方法 B：終端機一行

```bash
unzip -o ~/Desktop/skill-xiao-zi.zip -d ~/.claude/skills/
```

## 三、安裝（Windows）

資料夾路徑改成：

```
C:\Users\<你的帳號>\.claude\skills\
```

其餘相同。找不到 `.claude` 資料夾的話，在檔案總管開啟「顯示隱藏項目」。

> Windows 會用系統內建語音配音（品質比 Mac 差一些）。想要好聽的聲音，兩個平台都建議接 ElevenLabs（見第五節）。

## 五、開始用

### 最快的一次

```bash
mkdir -p ~/Desktop/紫微影片 && cd ~/Desktop/紫微影片
python3 ~/.claude/skills/skill-xiao-zi/scripts/make_ziwei_short.py
```

不給任何檔案，它會用內建範例腳本直接出一支 9:16 成片 `final.mp4`。**先跑這一次，確認環境沒問題。**

### 正式用

```bash
cd ~/Desktop/紫微影片
cp ~/.claude/skills/skill-xiao-zi/templates/scenes_範例.json  scenes.json
cp ~/.claude/skills/skill-xiao-zi/templates/chart_範例.json   chart.json
# 改 scenes.json（腳本）跟 chart.json（命盤星曜）
python3 ~/.claude/skills/skill-xiao-zi/scripts/make_ziwei_short.py scenes.json
```

橫式課程開場片：在最後加 `--169`。

### 只要一張命盤圖（做貼文、簡報、縮圖用）

```bash
python3 ~/.claude/skills/skill-xiao-zi/scripts/gen_chart.py chart.json 命盤.png 夫妻宮
```

### 想要更好聽的配音（選用）

申請 ElevenLabs 金鑰後，在終端機設定一次：

```bash
echo 'export ELEVEN_API_KEY="你的金鑰"' >> ~/.zshrc && source ~/.zshrc
```

之後產線會自動改用 ElevenLabs；沒設就用系統語音，一樣能出片。

### 想加背景音樂（選用）

把音樂放成 `./assets/bgm.mp3`（相對於你執行指令的資料夾），產線會自動混入，音量已壓到旁白之下。

| 檔案 | 什麼時候看 |
|:---|:---|
| `SKILL.md` | AI 讀的工作說明書（你不用讀，但可以改） |

| `templates/` | 腳本模板、上架文案包、範例 JSON |
| `scripts/` | 兩支 Python：出片、畫命盤 |

## 八、三個最常見的坑

1. **命盤資料要你自己填。** `gen_chart.py` 只畫圖、不排盤。星曜資料請從你慣用的排盤軟體抄進 `chart.json`——這條線鬆掉，影片就會出現錯誤的命理資訊。
2. **不要拿真實學員的盤直接上片。** 生日＋姓名是個資，要去識別化，還要有書面同意。
3. **合規紅線不是形式。** 「保證改運」「化解病痛」「跟著盤買股票」這三句話，會讓你從命理老師變成被檢舉的對象。詳見 `references/合規紅線與安全話術.md`。
