# 小音 踩雷速查

| 症狀 | 真因 | 解法 |
|---|---|---|
| 切完第一題的頭被吃掉 | 切點對齊迴圈的容忍區間會跟著 `cand` 一起往後滑 | 找到第一個符合的靜音就 `break`，見 `片頭偵測原理.md` |
| 切完還留半句中文導語 | 導語被 Whisper 切成兩句，只吃掉第一句 | 用 `while` 連續吃掉所有命中 INTRO_PAT 的句子（現行版已是逐句 loop） |
| 前面 10 秒明明是音樂，Whisper 卻辨出「字幕志願者 楊茜茜」 | Whisper 對非語音的固定幻覺 | 這是**特徵不是 bug**，`HALLU_PAT` 把它當成「音樂片頭」訊號 |
| `gap` 處理完聲音變成兩倍長／音調怪怪的 | 插入的靜音取樣率與人聲段不一致 | 產生 `anullsrc` 時必須帶原檔的 `sample_rate`（現行版已處理）— 見 [[feedback_ffmpeg_concat_sample_rate]] |
| `split` 只切出 1 段 | `--min-gap` 設太大，檔案裡沒有那麼長的停頓 | 先跑 `probe`／降低 `--min-gap`（聽力教材通常 3～5 秒） |
| 切完檔案播不出來／只有幾 KB | `-c copy` 對某些容器切不乾淨 | `ffcut()` 會自動退回重新編碼；若仍失敗看 stderr |
| 大量檔案跑很久 | Whisper large-v3-turbo 在 CPU 上每檔約數秒～數十秒 | 只辨識前 60 秒（`head_scan_seconds`），不是整檔 |
| 讀桌面檔案間歇性卡死／噴 EPERM | 桌面在 iCloud，檔案是 dataless | 工作資料一律放本機碟 — 見 [[feedback_icloud_dataless_breaks_launchd]] |
| 中文檔名在 shell 裡爆炸 | 沒加引號 | 路徑一律用雙引號包起來 |
