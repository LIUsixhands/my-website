# 小音 合規紅線（不可跨越）

1. **不覆蓋、不刪除原檔。** 所有輸出一律進 `output/`。教材母帶常常沒有第二份。
2. **不處理來源不明的音檔。** 接案前先問：這批音檔的著作權是誰的？客戶有沒有處理權？
   小音只做「格式與剪輯處理」，**不負責也不參與內容的散布、上架、販售**。
3. **不上傳客戶音檔到任何第三方服務。** Whisper 在本機跑，不走雲端 API。
4. **逐字稿只交給檔案提供者本人。** 不另存、不轉作訓練資料、不給第三人。
5. **個資清理。** 客戶錄音可能含學生姓名、電話、住址。處理完務必清掉工作區暫存檔
   （`~/AI員工_小音/.tmp_seg.wav`、`_gap_parts/`）。
6. **不承諾「全自動零人工」。** 片頭型態一變，偵測規則就要調。
   報價時要講「省掉重複開檔剪輯與檢查，樣式變了我來調」，不是「一次做好永久自動」。
7. **不修改音檔內容本身。** 只做剪裁、音量、格式；不做變聲、不做移花接木式的重組，
   避免客戶拿去做成他人未曾說過的話。
