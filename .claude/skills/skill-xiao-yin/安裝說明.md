# 小音 安裝說明（交付給學員）

## 1. 需要什麼
- macOS（Windows 需自行調整路徑）
- **ffmpeg**（必要）：`brew install ffmpeg`
- **Whisper**（強烈建議，沒有的話片頭要自己確認）：`pip3 install -U openai-whisper`

## 2. 安裝
把 `skill-xiao-yin` 整個資料夾放到：
```
~/.claude/skills/skill-xiao-yin
```

## 3. 第一次啟動
```bash
python3 ~/.claude/skills/skill-xiao-yin/scripts/audioclip.py init
```
會建立工作區 `~/AI員工_小音/` 與設定檔。

## 4. 怎麼叫他出來
在 Claude Code 裡直接打「**小音**」，或講「幫我把這批音檔的片頭剪掉」。

## 5. 最常用的兩行
```bash
A=~/.claude/skills/skill-xiao-yin/scripts/audioclip.py
python3 $A scan "你的資料夾"    # 先看切點對不對（不會動到檔案）
python3 $A trim "你的資料夾"    # 確認 OK 再實際切，成品在 output/
```

⚠️ **原檔永遠不會被動到**，成品一律另存 `output/`。
