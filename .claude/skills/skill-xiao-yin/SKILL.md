## 🚧 開工前必讀：三條硬規

這三條是踩過坑換來的，不可以為了「快一點」而跳過。

1. **原檔永不覆蓋。** 所有指令一律輸出到 `output/`。學員的教材母帶常常沒有備份，覆蓋掉就是永久損失。
2. **批次前一定先跑 `scan`。** 每個檔的片頭長度都不一樣（實測同一套教材：一個 17.2 秒、一個 5.3 秒），**絕對不可以用固定秒數批次切**。scan 只報告不動檔，讓人看過切點再決定。
3. **低信心預設不切。** 沒辨識到明確片頭導語的檔案，`trim` 會跳過並標記，要照切必須明確加 `--force`。寧可漏切讓人補，不可以誤切把第一題砍掉。

## 🧰 工具：`audioclip.py`（零第三方依賴 + ffmpeg／ffprobe）

位置：`~/.claude/skills/skill-xiao-yin/scripts/audioclip.py`
工作區：`~/AI員工_小音/`（**本機碟，不可放桌面 iCloud** — 見 [[feedback_icloud_dataless_breaks_launchd]]）

```bash
A=~/.claude/skills/skill-xiao-yin/scripts/audioclip.py

python3 $A init                                  # 建工作區與設定檔
python3 $A probe   <資料夾>                       # 掃規格：時長／取樣率／聲道／位元率
python3 $A scan    <資料夾>                       # ★ 偵測片頭切點，只報告不動檔
python3 $A trim    <資料夾>                       # 去片頭（低信心自動跳過；--force 照切）
python3 $A trimtail <資料夾>                      # 去片尾（結尾導語／音樂）
python3 $A cut     <檔> --start 5.5 --end 20     # 手動切一段
python3 $A split   <檔> --min-gap 3.0            # 依長靜音自動分題，一題一檔
python3 $A gap     <檔> --seconds 8 --min-gap 3  # 作答留白統一成 8 秒
python3 $A level   <資料夾>                       # 音量統一（EBU R128，-16 LUFS）
python3 $A convert <資料夾> --to mp3              # 轉檔 mp3／m4a／wav
python3 $A transcript <資料夾>                    # 逐字稿（需 Whisper）
python3 $A report                                # 歷次處理紀錄
```

**Whisper 是選配**：有裝 → 自動辨識中文片頭導語，準確度高；
沒裝 → 退化成純靜音偵測，所有結果標為「低信心」、`trim` 一律跳過，必須人工確認。
安裝：`pip3 install -U openai-whisper`（模型預設 `large-v3-turbo`，可在 `~/AI員工_小音/config.json` 改）。

## 📋 標準工作流：一袋音檔進來怎麼做

### 第 1 步：問清楚三件事（不要急著開跑）
1. **片頭要砍到哪裡？** 只砍中文導語，還是連前面的音樂片頭一起砍？
   （實測案例：教材檔中文導語前面還有 10 秒音樂，客戶只提到導語，**必須回頭確認**）
2. **原檔有沒有備份？** 沒有就先複製一份再動。
3. **成品要什麼格式？** 維持原格式（無損最快）還是統一轉 mp3？

### 第 2 步：`probe` 看規格
如果一批檔的取樣率／聲道不一致，後面 `gap`、合併類操作要特別小心
（見 [[feedback_ffmpeg_concat_sample_rate]]：取樣率不一致會讓聲音變速）。

### 第 3 步：`scan` 出切點表，給人看過
把 scan 的輸出整理成表格回報，**每一檔的片頭文字＋切掉幾秒＋剩幾秒**都列出來。
低信心的單獨標出來，講清楚「這幾個我不會自動切」。

### 第 4 步：`trim` 實際切，然後**複驗**
切完**一定要抽驗**：重新辨識成品的前 10 秒，確認
- 開頭**沒有**殘留中文導語
- 開頭**沒有**把第一題的第一個字切掉

```bash
python3 $A transcript <output 資料夾>   # 看第一句是不是正式內容
```

> 🚨 這一步不能省。曾經有一版程式因為迴圈變數被自己更新，切點滑到下一個停頓，
> 把「Number six.」整句吃掉——**只看指令沒報錯是抓不到的，一定要聽成品／看逐字稿**。

### 第 5 步：交付
成品在 `output/`，附一份處理清單（原長 → 新長、切掉什麼）。
對外交付掛品牌與 logo（觸發 `skill-ai-lobster-brand`）。

## 🚨 合規與紅線

見 `references/合規紅線.md`。摘要：
- **不處理來源不明的音檔**。客戶要處理的教材／課程音檔，著作權屬於誰要先問清楚；
  小音只做「格式處理」，不做內容散布、不上傳到任何平台。
- **不覆蓋原檔、不刪除原檔**，一律另存 `output/`。
- **逐字稿只交給檔案提供者本人**，不另作他用。
- 客戶音檔裡可能有個資（姓名、電話、學生名字），**處理完的暫存檔要清掉**，不要留在工作區。
