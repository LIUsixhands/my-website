## 一、安裝（三分鐘，Mac／Windows 都一樣）

### Mac
1. 把 `AI員工_小安` 這個資料夾**整個**放到：
   ```
   ~/.claude/skills/skill-xiao-an
   ```
   （終端機一行搞定：）
   ```bash
   cp -R ~/Desktop/AI員工_小安 ~/.claude/skills/skill-xiao-an
   ```
2. 重開 Claude Code。
3. 輸入 **「小安」** 測試，他會自我介紹並問你身分。

### Windows
放到 `C:\Users\你的帳號\.claude\skills\skill-xiao-an`，其餘相同。

## 二、第一次使用的順序（照做，不要跳）

```
1. 打「小安」
2. 回答他問的「身分四題」
     ① 你是業務員還是保經代？公司全名？
     ② 登錄字號？
     ③ 可以招攬哪些險種？
     ④ 你們公司的文宣審查流程與窗口？
3. 填 templates/業務員資料卡.json
4. 打開 references/待補15題.md，一次問完、填完
5. 小安才會開始產第一批內容
```

> 🚨 **第 1–4 題沒有答案之前，小安不會產出任何對外文字。**
> 這不是刁難 —— 保險文案沒有公司全名與登錄字號，
> 不是「不夠好」，是**不能發**。

## 四、三個指令（在 scripts 資料夾跑）

```bash
# 1. 寫完文案先掃禁語（最常用）
python3 an.py check 貼文草稿.txt

# 2. 這禮拜該聯絡誰
python3 an.py remind 客戶名單.csv --days 7

# 3. 產一個月的內容排程表
python3 an.py plan --month 2026-09

# 0. 第一次用，先把範本產到目前資料夾
python3 an.py init
```

## 五、🚨 小安絕對不做的十件事

1. 讓你**沒送審就發布**（他的產出一律叫「草稿」）
2. 寫保證獲利／穩賺／零風險／保本
3. 用**儲蓄・存款・定存・利息**代稱保險
4. 用**停售話術**逼單
5. 保證**節稅／免遺產稅**
6. 保證**理賠／過核保**
7. 勸你叫客戶**解舊保單改買新的**
8. 寫**加 LINE 送禮**這類利誘
9. 代填／代簽要保書，或暗示客戶少寫健康告知
10. 把保險招攬跟**命理、身心靈、直銷**綁在一起

> 這十條的理由只有一個：
> **出事的時候，扛責任的是你的登錄證，不是 AI。**
> 小安寧可少寫一句，也不讓你少一張登錄證。
