# 短影音腳本 SOP — 一支手機、30–60 秒、自己拍

> 保險短影音的目標**不是爆紅，是被記住**。
> 你不需要百萬觀看，你需要**你朋友圈的三百個人，一年看你講三十次保險**。
> 那三百個人，就是你未來十年的產能。

---

## 1. 保險短影音的三種可行型態

| 型態 | 拍法 | 適合誰 | 難度 |
|:---|:---|:---|:---|
| **口播型**（主力） | 對鏡頭講 30–45 秒 | 所有人 | ★ |
| **文件型** | 拍桌面：保單、收據、診斷書（**必須遮蔽個資**） | 想露臉但怕尷尬的 | ★★ |
| **情境短劇** | 兩人對話還原客戶問題 | 有夥伴、有梗的 | ★★★ |

> ⚠️ 拍文件型：**保單號碼、姓名、身分證字號、醫院名稱、病名一律遮蔽或用自製範例**。
> 最安全的做法：自己做一張假的範例表來拍。

---

## 2. 黃金結構（30–45 秒，五段）

```
0–3 秒　鉤子      ← 生死線。一句問題或一個反直覺結論
3–8 秒　共鳴      ← 「我上禮拜被問到…」讓觀眾對號入座
8–30 秒 乾貨      ← 三個點，一點一句，講完就停
30–38秒 收斂      ← 「這不是要你買什麼，是要你回去看一眼」
38–45秒 行動      ← 一個不含利誘的下一步 ＋ 口頭報上身分
```

### 開場三秒範例（直接可用）
- 「你上禮拜住院的收據，還在嗎？」
- 「保單買很多，不一定代表保障夠。」
- 「有人跟你說快停售了，先冷靜。」
- 「你的保單受益人，是幾年前填的？」
- 「這三個字沒寫在診斷書上，你可能要再跑一趟醫院。」

### 結尾行動範例（合規）
- 「想要保單整理表，留言『表』我傳給你。」
- 「不確定自己有幾張保單，私訊我，我教你怎麼查。」
- ❌「加 LINE 送禮券」「限時免費諮詢名額只剩三個」

## 3. 完整腳本範例

### 範例 A｜〈出院前一定要問的三件事〉42 秒

| 時間 | 口白 | 畫面 |
|:---|:---|:---|
| 0–3 | 「出院那天最容易漏掉的，其實是文件。」 | 正面口播，中景 |
| 3–8 | 「上禮拜陪一個朋友補件，來回跑了兩趟。」 | 同上 |
| 8–16 | 「第一，診斷書上要有住院的起訖日期。」 | 手指比 1（或文件示意畫面） |
| 16–24 | 「第二，如果有手術，要寫手術名稱，不是只寫病名。」 | 比 2 |
| 24–32 | 「第三，收據問清楚要不要正本、要幾份。」 | 比 3 |
| 32–38 | 「這不是要你買什麼，是下次真的用得到。」 | 口播 |
| 38–42 | 「我是〔公司全名〕的〔姓名〕，保單的事都可以問我。」 | 定格＋字幕尾註 |

**字幕尾註（燒在畫面上）**：`〔公司全名〕｜〔姓名〕｜登錄字號〔〕｜內容僅供參考，給付以條款及核定為準`

### 範例 B｜〈有人叫你解舊保單，先看這一點〉38 秒
### 範例 C｜〈「意外」不是你想的那個意外〉40 秒
### 範例 D｜〈受益人該更新的四個時機〉35 秒
### 範例 E｜〈快停售了？先冷靜〉40 秒 —— **示範怎麼中性談商品調整**

> 範例 B–E 由小安依學員的實際身分與可招攬險種現場生成，
> 結構一律套用第 2 節的五段式。

## 4. 拍攝清單（印出來貼在手機殼背後）

**開拍前**
- [ ] 手機**橫放拍直式**？ → 不對，直接直式 9:16
- [ ] 背景乾淨：不要有客戶資料、保單、白板上的名單
- [ ] 光源在**你前方**（窗戶對著臉，不要背光）
- [ ] 手機架在**眼睛高度**（低角度會很有壓迫感）
- [ ] 收音：安靜房間 ＞ 領夾麥 ＞ 手機內建

**拍的時候**
- [ ] 第一句話**不要停頓**，直接講鉤子
- [ ] 語速稍快一點（後製不加速也順）
- [ ] 每個重點之間**停 0.5 秒**（方便剪）
- [ ] 一次拍三個 take，選最自然的

**發布前**
- [ ] 字幕（**必加**，多數人靜音看）
- [ ] 尾註三件事：公司全名／姓名／登錄字號
- [ ] 跑 `an.py check` 掃逐字稿
- [ ] **送公司審查**

## 6. 頻率建議

| 階段 | 頻率 | 重點 |
|:---|:---|:---|
| 前 30 天 | 每週 2 支 | 先習慣鏡頭，不管數據 |
| 31–90 天 | 每週 3 支 | 固定時段，測哪種鉤子留得住人 |
| 90 天後 | 每週 2–3 支 ＋ 每月 1 支長版 | 開始做系列（例：「保單三分鐘」EP01…） |

> **不要每天發。** 保險內容一週三支已經很夠，
> 這行贏的是**持續三年**，不是衝三十天。
