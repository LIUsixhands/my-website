# 合規改寫對照表 — 違規話術 → 可以送審的寫法

> 用法：寫完文案先跑 `python3 scripts/an.py check 你的檔案.txt`，
> 掃出來的紅字，到這張表找替代寫法。
> **禁語不是「不能講這個概念」，是「不能用這個講法」。** 概念幾乎都有合規的說法。

---

## A. 保證與報酬類（最高風險）

| ❌ 不可寫 | ✅ 改寫 |
|:---|:---|
| 保證獲利／穩賺／穩賺不賠 | 依保單條款約定之給付項目 |
| 零風險／無風險 | 本商品之風險與費用揭露請見商品說明書 |
| 保本 | （投資型商品）**直接刪除**，並揭露「投資標的之運用損益由要保人自行承擔」 |
| 一定領得到／保證領回 | 符合保單條款約定之條件時，得依約定給付 |
| 年報酬率 X%／複利 X% | 宣告利率／預定利率為 X%，**宣告利率不等於報酬率**，實際給付依保單條款 |
| 錢放這裡最安全 | 保險的功能在於風險轉嫁，與投資工具的目的不同 |
| 比定存好 | **整句刪除**（存款類比較是明確禁區） |
| 幫你賺退休金 | 協助您規劃退休階段的現金流來源之一 |

## B. 存款代稱類

| ❌ 不可寫 | ✅ 改寫 |
|:---|:---|
| 儲蓄險 | 依商品性質正名：人壽保險／年金保險／利率變動型壽險 |
| 存錢／幫你存／零存整付 | 分期繳納保險費 |
| 定存／定期存款 | **刪除**，不做任何存款比較 |
| 利息／複利滾存 | 宣告利率／增值回饋分享金（依商品條款用語） |
| 到期領回本金 | 滿期保險金／依條款約定之給付 |

## C. 最高級與比較類

| ❌ 不可寫 | ✅ 改寫 |
|:---|:---|
| 最好／最強／第一／唯一 | 具體描述功能，不做排名（例：「涵蓋 A、B、C 三類給付」） |
| 最便宜／CP 值最高 | 保費會因年齡、性別、體況、投保金額而異，實際以核保結果為準 |
| 業界最推薦／人人都該買 | 是否適合須經需求分析評估 |
| 別家都不賠只有我們賠 | **刪除**（跨公司比較高風險） |
| 這張是最完整的保單 | 沒有一張保單涵蓋所有風險，重點是**你的缺口在哪裡** |

## D. 急迫與停售類

| ❌ 不可寫 | ✅ 改寫 |
|:---|:---|
| 即將停售／最後一張／賣完就沒了 | 〇年〇月起本類商品投保條件將調整，如需了解可與我聯繫 |
| 限時／最後三天／再不買就漲價 | **刪除急迫性用語**（年齡增加保費會變動可中性說明一次） |
| 先簽再說／名額有限 | 建議先做需求分析，再決定是否投保 |

## E. 理賠保證類

| ❌ 不可寫 | ✅ 改寫 |
|:---|:---|
| 一定賠／全賠／什麼都賠 | 是否符合理賠要件，以保單條款及保險公司核定為準 |
| 有病就賠／住院就賠 | 需符合條款所定之給付要件（含等待期、除外責任） |
| 這個一定過核保 | 核保結果由保險公司依體況與規範判斷 |
| 我幫你喬理賠 | 我可以協助您準備申請文件、追蹤進度；認定權在保險公司 |

## F. 稅務類

| ❌ 不可寫 | ✅ 改寫 |
|:---|:---|
| 保險金免稅 | 稅務效果因個案而異，實際認定以稽徵機關與稅務專業人員意見為準 |
| 保單不列入遺產／完美節稅 | 稽徵機關得依實質課稅原則個案認定（重病、高齡、躉繳、鉅額、舉債、密集投保等樣態風險較高） |
| 用保單合法避稅 | 保險在資產規劃上的功能，須與會計師／稅務專業人員共同評估 |

## G. 利誘與贈品類

| ❌ 不可寫 | ✅ 改寫 |
|:---|:---|
| 加 LINE 送 7-11 禮券 | 加 LINE 領「**保單整理表**」／「**理賠文件清單**」（知識型贈品） |
| 投保回饋現金／退佣 | **整段刪除**（提供不當利益屬明定違規） |
| 介紹朋友給你抽成 | 轉介感謝以**服務**表達（例：協助整理保單、陪同送件），不得給付金錢 |

## H. 告知義務類（最危險的口語）

| ❌ 不可說 | ✅ 改說 |
|:---|:---|
| 這個不用寫啦 | 健康告知請照實填寫，這是保障您未來理賠權益最重要的一步 |
| 講出來會被拒保，先不要講 | 有體況不代表不能投保，可能是加費或批註除外；不告知才會真的拿不到理賠 |
| 兩年後就不能解約了（帶過去） | 我把契約撤銷期、等待期、除外責任跟您說明清楚 |

## I. 轉保與解約類

| ❌ 不可說 | ✅ 改說 |
|:---|:---|
| 舊保單很爛，解掉買新的 | 我們先盤點現有保障，**解約可能損失既有保障、重新計算等待期，且解約金可能低於已繳保費**，是否調整由您決定 |
| 這張早就過時了 | 條款設計會隨年代不同，我們看的是**你現在的缺口**，不是新舊 |

## J. 恐懼行銷的分寸

保險行銷一定會談風險，但**不能製造恐慌或個別化恐嚇**。

| ❌ 過當 | ✅ 合宜 |
|:---|:---|
| 你不買，你小孩以後怎麼辦 | 家庭主要收入來源中斷時，通常需要考慮生活費、房貸與教育費三塊 |
| 沒有保險等於等死 | 醫療費用的自費項目逐年增加，這是規劃時常被忽略的部分 |
| 我看過太多沒買保險家破人亡 | 我協助過的個案裡，**準備好文件的家庭，理賠流程通常順利很多**（去識別化、不誇大） |
