# 增員內容 SOP — 合規版（先有獲客軌，才有增員軌）

> ⚠️ **小安的第一個建議通常是：現在先不要做增員內容。**
> 理由：如果你自己的獲客系統還沒跑起來，增進來的人也複製不到東西，
> 三個月後就會離開，你只是不斷在補人。
>
> **順序永遠是：獲客軌先跑起來 → 有可複製的流程 → 才開增員軌。**
> （這一點與Sixhands Studio既有的「組織發展停滯」診斷結論一致。）

---

## 1. 增員內容的三條紅線

1. **絕不承諾收入。**
   「月入十萬」「輕鬆百萬」「保證年薪」都不能寫。
   → 改寫：「收入結構為〔佣金／獎金／津貼〕，實際收入依個人業績與公司制度而定，個別差異大。」

2. **絕不隱瞞這一行的真實條件。**
   須誠實揭露：多數為**承攬／非固定薪**、需**考取證照並登錄**、有**業績考核與登錄維持條件**、
   初期收入不穩定。
   → 隱瞞會造成大量三個月陣亡，也會惹上勞資與招募爭議。

3. **絕不用招攬客戶的方式增員，也不用增員的場合招攬。**
   兩件事分開講、分開場合、分開內容。

---

## 2. 增員內容的正確定位

> 不要賣「這行很好賺」，要賣「**這行適不適合你**」。

因為你要的不是「來看看」的人，是**留得下來**的人。
篩選型內容比吸引型內容，長期產能高得多。

### 四種可行主題

| 主題 | 例 |
|:---|:---|
| **真實日常** | 「我今天做了什麼」— 拜訪、送件、被拒絕、陪理賠 |
| **適合／不適合** | 「這三種人做保險會很痛苦」（誠實勸退） |
| **這行學到什麼** | 「做保險三年，我學會的三件事」（不談錢） |
| **制度說明** | 誠實說明證照、登錄、考核（不含收入承諾） |

---

## 3. 增員貼文模板（三則）

### 1｜誠實勸退型（轉換率最高）
```
這三種人，我不建議做保險。

一、需要每個月固定收入的人。
　這行多數是承攬制，前半年收入很不穩定，這是事實。

二、不喜歡被拒絕的人。
　被拒絕是日常，不是失敗。

三、覺得靠人情就能做起來的人。
　人情只能撐前三個月。

如果看完這三點你還有興趣，
我們可以坐下來聊，我會把真實的狀況跟你說清楚。
```

### 2｜真實日常型
```
今天的行程：
早上陪一位客戶跑理賠補件，
中午整理三份保單盤點表，
下午被拒絕兩次，
晚上寫這則貼文。

沒有很精彩，但這就是這份工作。
如果你想知道更真實的樣子，可以問我。
```

### 3｜制度說明型
```
常有人問我：做保險要準備什麼？

・先考證照（人身／財產，看你要做哪一塊）
・考過之後要向公司登錄，才能執業
・有登錄維持與教育訓練的要求
・收入結構是佣金與獎金為主，會浮動

我不會跟你說賺多少，因為每個人差很多。
但我可以跟你說清楚制度怎麼跑。
```

---

## 4. 增員面談的四段

1. **他為什麼想換工作**（先聽，不推）
2. **誠實揭露**：收入結構、考核、初期辛苦
3. **看他的條件**：有沒有人脈基礎、能不能撐半年、家人支不支持
4. **給時間**：不逼、不設限時，「你回去想一週，我們再談」

> ⚠️ 「家人支不支持」這一題最常被跳過，卻是三個月留存率最大的變數。

---

## 5. 交件檢查

- [ ] 沒有任何收入數字或收入承諾
- [ ] 有誠實揭露承攬性質與考核要求
- [ ] 沒有把增員與招攬混在同一則內容
- [ ] 跑過 `an.py check`
- [ ] 依所屬公司招募規範送審
