## 1. 險種地圖（寫內容時的分類骨架）

| 大類 | 保障的是什麼 | 客戶最容易誤會的地方 |
|:---|:---|:---|
| **人壽保險** | 身故／全殘後，家人的生活與責任 | 以為「我沒有小孩就不需要」（有房貸、有扶養一樣需要） |
| **醫療保險** | 住院、手術、雜費等醫療支出 | 以為健保都有給付（自費項目才是主要缺口） |
| **實支實付型** | 收據上的自費項目 | 以為可以重複領（涉及正副本與各家規定） |
| **意外保險** | 外來、突發、非疾病所致之傷害 | 以為「跌倒就是意外」（成因是疾病所致可能不算） |
| **重大疾病／特定傷病／癌症** | 確診後的一次金或療程支出 | 以為「有癌症就賠」（定義、期別、等待期都有條款） |
| **失能保險** | 因傷病失去工作能力 | 最被忽略、但對家庭衝擊最大的一塊 |
| **長期照顧／類長照** | 需要照顧時的長期支出 | 認定標準各商品不同 |
| **年金保險** | 老後的現金流 | 不是「存錢」，是把錢換成一段期間的給付 |
| **投資型保險** | 保障 ＋ 投資標的（**損益自負**） | 以為保本、以為是理財商品 |

## 2. 客戶最常搞混的十個名詞（內容金礦）

1. **要保人／被保險人／受益人** — 三個角色可以是不同人，影響權利與稅務
2. **等待期** — 契約生效後一段期間內因疾病就醫可能不給付
3. **除外責任** — 條款明列不賠的情形
4. **既往症／批註除外** — 投保前已存在的體況
5. **契約撤銷期** — 收到保單後一段期間內可撤銷
6. **寬限期／停效／復效** — 沒繳費不是立刻失效，但有時限
7. **保單價值準備金／解約金** — 解約金常低於已繳保費
8. **實支實付的正本／副本** — 影響能不能同時申請多家
9. **宣告利率／預定利率** — **都不等於報酬率**
10. **豁免保費** — 特定情形下不用再繳，但保障繼續

> 這十個名詞，每一個都可以做成一則貼文 ＋ 一支短影音。
> **一個名詞一支影片，你就有二十則內容。**

## 3. 理賠實務要點（最受歡迎的內容題材）

### 常見必備文件
- 診斷證明書（含**住院起訖日期**；有手術須載明**手術名稱**）
- 醫療費用**收據**（正本／副本依商品規定）
- 醫療費用**明細**
- 保險金申請書、受益人身分文件、存摺影本
- 意外事故：可能需要事故證明（如警方文件）

### 常見卡關原因
1. 診斷書資訊不全 → 要重開
2. 收據只有一份，多家申請時卡住
3. 手術名稱與條款所列名稱對不上
4. 事故發生時未即時就醫，因果關係難認定
5. 未在條款規定期間內通知／申請

> ⚠️ 寫這些內容時一律附註：**是否給付以保單條款及保險公司核定為準。**

## 4. 稅務觀念（只寫觀念，不下結論）

- 保險給付的稅務效果**因個案而異**
- 稽徵機關得依**實質課稅原則**認定，常見高風險樣態：
  重病投保、高齡投保、躉繳、短期投保、鉅額投保、舉債投保、密集投保、保險費與保險金額相當
- 部分保險給付涉及**基本所得額（最低稅負制）**
- **結論一律交給會計師／稅務專業人員**

## 5. 台灣保險市場的三個結構事實（寫內容時的背景）

1. **投保率高、但保障缺口大** — 很多人有很多張保單，卻在「失能」「長照」「自費醫療」上是空的。
   → 這正是「保單健檢」型內容有效的原因。
2. **通路多元** — 保險公司業務員、保經代、銀行保險、網路投保並存。
   → 客戶手上的保單常來自不同通路，**沒有人幫他整合**。這是你的空間。
3. **服務差異化 > 商品差異化** — 條款與費率在市場上高度可比，
   客戶最終選的是「出事時誰會出現」。
