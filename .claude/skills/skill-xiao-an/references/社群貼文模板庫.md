### 1｜理賠實務・診斷證明書
```
診斷證明書多開一次，平均要多跑一趟、多等好幾天。

上禮拜協助一位朋友整理住院文件，
發現診斷書上少了兩個東西，只好再回醫院一次。

出院前，這幾件事建議先確認：
・診斷書上有沒有寫「住院起訖日期」
・有沒有寫「手術名稱」（不是只寫病名）
・收據是不是「正本」，需不需要多開幾份
・如果有轉院，兩邊的文件都要留
・醫療費用明細不要丟

這不是要你買什麼，是提醒你——
文件準備得好，理賠流程會順很多。

如果你手邊剛好有住院文件不確定齊不齊，可以私訊我，我幫你看一下要不要補。
```

### 2｜除外陷阱・等待期
```
「我上禮拜才買保險，這禮拜就住院，為什麼不賠？」

這是我最常被問到的問題之一。
答案通常跟一個詞有關：**等待期**。

簡單說：
・多數醫療、癌症相關保障，契約生效後會有一段期間
・這段期間內因疾病就醫，可能不在給付範圍
・意外通常沒有等待期（但「意外」有它的定義）
・不同商品的天數不一樣，要看你自己的條款

所以「什麼時候買」有時候比「買多少」還重要。

要不要現在打開你的保單，找一下「等待期」這三個字？
個案是否給付，仍以保單條款及保險公司核定為準。
```

### 3｜盤點工具・受益人
```
你的保單受益人，是幾年前填的？

我遇過最多的三種狀況：
・結婚了，受益人還是爸媽
・離婚了，受益人還是前配偶
・小孩出生了，從來沒加上去

受益人不是填了就永遠對，
它應該跟著你的人生一起更新。

要改其實不難，跟你的服務人員或公司客服申請變更就可以。
花十分鐘，避免以後家人花十個月。

如果你不確定自己有幾張保單、受益人是誰，
我做了一張「保單整理表」，私訊我可以拿去用。
```

### 4｜人生節點・第一份工作
```
剛出社會的第一份工作，保險先看哪三件事？

不用一次買齊，順序比金額重要：

1️⃣ 你倒下的時候，收入會不會斷
　（實支實付、住院、失能，先看有沒有）
2️⃣ 你的職業風險
　（外勤、需要騎車的工作，意外的規劃邏輯不一樣）
3️⃣ 公司團保有沒有、保什麼
　（很多人不知道自己已經有一部分）

先盤點，再補洞。
沒盤點就買，最容易買到重複的。
```

### 5｜人生節點・房貸下來那天
```
房貸核下來那天，很多人只想到「終於買到了」。

但有一件事同時發生了：
你身上多了一筆二十年、每個月都不能停的責任。

這時候通常會考慮的是：
・如果主要收入中斷，這筆貸款誰接
・家庭生活費要撐多久
・已經有的保障夠不夠覆蓋這段期間

我不會告訴你要買什麼，
但我會建議你，至少把「這筆責任有多大」算出來。

想算的話，可以找我，我陪你算，不推商品。
```

### 6｜個人品牌・我的原則
```
做這行，我有三個原則：

一、我不會叫你解掉舊保單。
　舊的解掉，等待期重算、體況重審，很多時候是損失。
　我只做盤點，補缺口。

二、健康告知我一定請你照實寫。
　現在少寫一行，以後可能少一筆理賠。

三、我不會用「快停售了」催你。
　需要就規劃，不需要就不要買。

如果這三件事跟你的想法一樣，我們大概可以聊得下去。
```

### 7｜個人品牌・這週我做了什麼
```
這週陪一位客戶跑了理賠。

（去識別化敘述：不寫姓名、不寫公司、不寫可辨識細節）
文件補了兩次、跟醫院要了一份明細，
最後順利送出。

我常說：買保險那天不是服務的開始，
真正的服務，是出事那天你打得通我的電話。

如果你的保單放在抽屜很久沒動過，
歡迎找我做一次盤點，不推商品。
```

### 8｜避雷型・轉保
```
有人跟你說「舊保單過時了，解掉買新的」，先別急。

解約可能發生的事：
・原有保障立刻中止
・新契約要重新健康告知，體況變了可能加費或除外
・等待期重新起算
・解約金常常低於已繳保費

不是說永遠不能調整，
而是**調整前要先看清楚你會失去什麼**。

需要的話，我可以幫你把現有保單列成一張表，
你自己看得懂，再決定。
```

### B｜保單三個人搞不清楚
P1：要保人、被保險人、受益人，差在哪？
P2：要保人＝繳費、有權變更契約的人
P3：被保險人＝保障的對象
P4：受益人＝領錢的人
P5：三個人可以不同人 → 這會影響稅務與權利，個案請諮詢專業人員

P4：所以醫師怎麼寫病因很重要
P5：認定以條款與保險公司核定為準
