# 保障觀念內容 SOP — 不推商品，反而賣得更好

> 這是小安的**主力產線**。
> 保險業務員最大的行銷困境是：一發商品文就沒人看、還怕被公司說違規。
> 解法不是把商品寫得更漂亮，是**根本不寫商品**。

---

## 1. 為什麼「不推商品」反而有效

| | 商品貼文 | 保障觀念貼文 |
|:---|:---|:---|
| 讀者反應 | 「又在推銷」→ 滑掉 | 「這個我不知道」→ 停下 |
| 被存下／轉傳 | 幾乎不會 | 常常（尤其清單型、避雷型） |
| 送審通過率 | 低，要走完整商品審查 | 高，通常屬觀念宣導 |
| 帶來的名單 | 少而且冷 | **主動舉手的熱名單** |

> 核心邏輯：**你教他怎麼「用」保險，他就會找你「買」保險。**
> 因為他發現自己的保單有問題的那一刻，會想問的人是你。

## 2. 五大內容支柱（每月各出 4 則，共 20 則）

### 支柱一：**「原來這個要留」** — 理賠實務型（最強）
教客戶怎麼準備文件、怎麼留證據。
- 診斷證明書要註明什麼才不用重開
- 收據正本 vs 副本，什麼情況要正本
- 手術名稱與健保代碼為什麼會影響給付
- 出院前一定要問醫院哪三件事

> 這類內容的威力：**看的人會截圖存起來**，而且會傳給家人。

### 支柱二：**「原來這個不賠」** — 除外與陷阱型
不是嚇人，是釐清。
- 等待期是什麼、為什麼剛買就住院可能不賠
- 「意外」的定義（外來、突發、非疾病）常見誤會
- 既往症與批註除外
- 健康告知沒寫，兩年後是不是就沒事了？（正確講法：不是絕對）

⚠️ 寫這類內容一律加：「個案是否給付以保單條款及保險公司核定為準」。

### 支柱三：**「你的保單長什麼樣子」** — 盤點工具型
- 一張表看懂你的保單有哪幾類保障
- 怎麼查自己有幾張保單（保險存摺／公司客服）
- 受益人多久沒更新了？（離婚、再婚、子女出生後最常忘）
- 要保人、被保險人、受益人差在哪

> 這支柱是**名單引擎**：附一份可下載的「保單整理表」，私訊索取＝合規的知識型 lead magnet。

### 支柱四：**「人生節點」** — 情境型
用人生階段講需求，不講商品。
- 剛出社會第一份工作，先看哪三件事
- 結婚後受益人要怎麼調
- 第一個小孩出生，家庭保障的優先順序
- 房貸下來那天，該同時想什麼
- 父母年紀大了，子女要先確認的三份文件

### 支柱五：**「我是誰」** — 個人品牌型（每月 2–4 則）
客戶最後買的是你。
- 我為什麼做這一行（真實故事，不催淚不誇大）
- 我這週陪一位客戶做了什麼（**去識別化**：不寫姓名、公司、可辨識細節）
- 我怎麼服務：從需求分析到理賠陪伴的流程圖
- 我的原則：例如「我不會叫你解舊保單」

## 3. 單則貼文結構（小安固定用這個骨架）

```
① 鉤子（1 行）        ← 具體情境或反直覺，不用「大家好」開頭
② 場景（2–3 行）      ← 讓讀者對號入座
③ 知識點（3–5 點）    ← 短句、換行、可截圖
④ 一句提醒            ← 「這不是要你買什麼，是要你回去看一眼」
⑤ 行動（1 行）        ← 知識型贈品或一個提問，不含利誘
⑥ 合規尾註            ← 公司全名／姓名／登錄字號／免責
```

### 鉤子公式（挑一個）
- **數字式**：「診斷證明書多開一次，平均要再等 7 天。」
- **提問式**：「你的保單受益人，是幾年前填的？」
- **反直覺**：「保單買很多，不代表保障夠。」
- **情境式**：「上禮拜有位家長問我：小孩的保單要不要重買？」
- **避雷式**：「這三種收據，醫院不會主動提醒你留。」

## 5. 三個絕對不做

1. **不寫具體商品名稱與費率**（要寫＝走完整商品文宣審查，且極易誤導）。
2. **不用真實客戶案例可辨識的細節**（年齡可寫區間、職業可寫類別，不寫公司與地區組合）。
3. **不在觀念文末尾偷推商品**（「所以趕快買 XX 險」→ 整篇性質變成商品廣告，審查會被退）。
