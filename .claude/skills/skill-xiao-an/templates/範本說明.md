# templates 使用說明

| 檔案 | 什麼時候用 |
|:---|:---|
| `業務員資料卡.json` | **第一步**。填完小安才會產對外文案（尤其身分、登錄字號、審查流程四欄） |
| `客戶名單範本.csv` | 名單經營的核心檔。⚠️ **含個資，放本機碟、設密碼、不放 iCloud／公開雲端** |
| `保單盤點表範本.csv` | 保單健檢用。只列不評，任何調整建議須同時揭露解約可能損失 |
| `內容排程表範本.csv` | 月度內容排程。`狀態` 欄要走完 草稿→送審→核可→發布 |
| `合規送審檢核表.md` | **每一則對外內容都要跑一次**。小安交件時一定附這張 |

## 三條使用鐵律

1. **所有小安的產出都是草稿。** 送審核可後才可發布。
2. **客戶名單就是個人資料。** 蒐集要告知、使用不逾目的、不轉他人、客戶說停就停。
3. **檔案放本機碟。** 桌面（iCloud）同步會造成腳本讀檔失敗，也增加外洩面。
