# 廣告法規紅線 —— 小鐵的逐句體檢表

> 這一行的行銷風險，九成不在文案好不好看，在**有沒有寫到會出事的那句話**。
> 鐵皮屋業最敏感的三件事：**違建、不實廣告、結構安全**。
> 這份是「紅字換句表」，每一句紅字都有對應的安全寫法。

> ⚠️ 本文件是**行銷用語自我約束指引，不是法律意見**。
> 個案認定請洽主管建築機關、建築師、結構技師或律師（法務可轉小辯）。

---

## 一、違建相關（最高風險）

**法源背景**
- 《建築法》第 25 條：建築物非經申請直轄市、縣（市）主管建築機關審查許可並發給執照，不得擅自建造或使用。
- 《建築法》第 86 條：違反規定擅自建造者，可處罰鍰並勒令停工、補辦手續或拆除。
- 違章建築另依《違章建築處理辦法》處理；部分縣市對特定期日前之**既存違建**採分類分期查報拆除。
  ⚠️ **「緩拆」不等於「合法」，也不代表以後不會拆。**

### 🔴 絕對不能寫

| 紅字 | 為什麼危險 | ✅ 安全寫法 |
|:---|:---|:---|
| 「保證合法」「合法加蓋」 | 合法與否只有主管建築機關能認定 | 「是否須申請執照，請以貴地主管建築機關認定為準」 |
| 「保證不會被拆」「不怕檢舉」 | 等於承諾公權力行為 | 不寫。改講施工品質與保固 |
| 「代辦免拆」「幫你搞定」 | 可能被解讀為關說或不法承諾 | 「可協助配合合格建築師／技師辦理相關申請」 |
| 「頂樓加蓋沒問題啦」 | 多數縣市頂加屬違建 | 「頂樓工程請先確認可施作範圍，我們配合合法圖說施工」 |
| 「農地蓋鐵皮屋沒關係」 | 農業設施須依容許使用規定申請 | 「農地案件請先取得容許使用許可，我們依核准圖說施工」 |
| 「不用申請，做了就好」 | 直接教唆違規 | 絕不寫 |

### ✅ 建議固定附註（放在報價單與官網頁尾）
> 本公司承攬鐵皮屋頂修繕、翻修、鋼構施作等工程。
> 工程是否涉及《建築法》所定之建造行為、是否須申請執照，
> **依各地主管建築機關認定為準**；如需執照，我方配合業主委託之
> 合格建築師／結構技師辦理，並依核准圖說施工。

## 二、不實廣告（公平交易法第 21 條：不得為虛偽不實或引人錯誤之表示）

### 🔴 絕對不能寫

| 紅字 | ✅ 安全寫法 |
|:---|:---|
| 「永不漏水」 | 「防水施作面保固 5 年」 |
| 「終身保固」 | 「結構保固 X 年、防水保固 Y 年」＋排除條款 |
| 「一勞永逸」 | 「正常使用下可維持 X 年，建議每年檢查一次」 |
| 「全台最便宜」「業界第一」 | 除非有可查證依據，否則不寫 |
| 「政府補助」 | 除非確有該補助方案並註明名稱與條件 |
| 「零風險」「包好包滿」 | 不寫 |

### 保固怎麼寫才安全（三段式）
> **保固範圍**：本次施作之屋頂板材接縫與防水面。
> **保固年限**：自完工驗收日起 5 年。
> **不含**：地震、颱風等不可抗力；他人後續加工、鑽孔、加裝設備所致破壞；
> 　　　　原有結構既有瑕疵；未依建議清理天溝所致堵塞。

## 三、報價與價格標示

### 🔴 誘餌式報價（客訴與檢舉第一名）
- ❌「屋頂翻修 一坪 X,XXX 起！」（旁邊沒有任何說明）
- ✅ 「屋頂翻修 一坪 X,XXX 元起
　　**含**：0.5mm 烤漆浪板、C 型鋼檁條、自攻螺絲、基本收邊
　　**不含**：舊屋頂拆除清運、吊車鷹架、隔熱層、天溝更換、防水工程、假日施工加成
　　實際價格以現場丈量後之正式報價單為準。」

**鐵律**：凡出現「起」字，同一則內容必須出現「含／不含」。

## 四、照片與影像（最容易被忽略的一條）

1. **絕不使用不是自己施作的照片。** 網路圖、同業案例、廠商型錄圖都不行。
2. **AI 生成圖只能當示意圖**，且必須標註「示意圖，非實際案場」。
3. **上傳前必遮蔽**：門牌號碼、車牌、住戶姓名、室內私人物品。
4. **屋主同意**：拍攝可辨識之住宅外觀並公開發布前，應取得屋主口頭以上同意；
   建議在報價單加一行勾選欄：「□ 同意本工程施工照片作為施工實績使用（可去識別化）」。
5. 工地人員入鏡：自家師傅需告知；他人（鄰居、路人）避免入鏡或打碼。

## 五、結構與安全（不能靠嘴保證的事）

| 🔴 不能寫 | ✅ 改寫 |
|:---|:---|
| 「保證耐 X 級地震」 | 「依結構技師簽證圖說施工」 |
| 「絕對不會被颱風掀掉」 | 「採用 X 規格固定件，固定間距依規範施作」 |
| 「這樣蓋一定撐得住」 | 「載重需求請由結構技師評估」 |
| 自行判斷既有結構可承載 | 「需加蓋前，建議先由技師確認原結構承載力」 |

## 六、其他容易忽略的三件事

1. **同業比較**：不點名貶低同業。可以講「有些做法會…」，不要講「XX 公司都…」。
2. **消費爭議**：一律書面報價單＋雙方簽名，載明工項、規格、金額、工期、付款方式、保固。
   口頭追加一律補簽變更單。（爭議升級請轉小辯）
3. **勞安**：高處作業影像若明顯無安全帽、無安全母索，**不要拿來當宣傳素材**——
   那不只是形象問題，是會被檢舉的問題。

## 七、小鐵的自動體檢流程（每一則對外文字都要跑）

```
1. 掃「合法／不拆／代辦／免申請」→ 有 = 退回重寫
2. 掃「永不／終身／保證／絕對／最」→ 有 = 換成具體數字或刪除
3. 掃「起」→ 有沒有配「含／不含」？沒有 = 補上
4. 掃照片來源 → 是不是自己做的？門牌車牌遮了嗎？
5. 掃結構承諾 → 有沒有變成技師才能講的話？
```
五關全過才交件。**一關沒過，小鐵不交。**
