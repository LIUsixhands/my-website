# 貼文模板庫 —— 直接改地區名跟電話就能貼

> 用法：`{地區}`、`{公司名}`、`{電話}`、`{LINE_ID}`、`{保固年限}` 全部換掉再貼。
> 純文字排版，老闆用手機直接複製貼上，**不要加 Markdown 符號**。
> ⚠️ 每則貼上去之前，跑一次 `廣告法規紅線.md` 的五關檢查。

---

## 模板 1：知識文（地方社團專用・最安全不會被踢）

```
最近{地區}下雨，滿多人問屋頂為什麼一直修一直漏。

分享 3 個最常見的原因：

1. 螺絲的橡膠墊圈老化
超過 10 年的屋頂，墊圈會硬化龜裂，水就順著螺絲孔滲下來。
這種只換螺絲跟墊圈就能解決，不用整片翻。

2. 天溝堵住
落葉泥沙塞住，大雨時水滿出來往裡面倒灌，
很多人以為是屋頂破，其實是天溝。

3. 收邊沒做好
屋頂跟牆壁交接的地方，泛水收邊做不確實，
從外面看完全看不出來。

先不用急著花大錢整片換，
可以先拍一張照片，我幫你看是哪一種。

{公司名}｜{地區}
LINE：{LINE_ID}
```

## 模板 2：施工前後對比（案例文）

```

上去看才發現，板子底下的檁條已經鏽到快斷了，
上面補幾次都沒用。

這次做法：
・舊屋頂全拆、廢料清運
・鏽蝕檁條換新
・0.5mm 烤漆浪板
・天溝、落水管一併更新
・防水收邊重做

工期 3 天。
防水施作面保固 {保固年限} 年。

屋頂的問題通常不在你看到的地方。
有需要可以拍照傳 LINE，我先幫你判斷。

{公司名}｜服務{地區}一帶
{電話}
```

## 模板 3：季節提醒文（梅雨／颱風前，轉發率最高）

```
雨季要來了，屋頂自己先看這 5 個地方：

1. 天溝有沒有塞落葉
2. 螺絲頭的橡膠墊圈有沒有裂開
3. 板子有沒有鏽到出現咖啡色斑點
4. 屋頂跟牆壁交接的地方有沒有翹起來
5. 室內天花板有沒有淡淡的水漬圈

第 5 點最重要。
天花板出現水漬，代表已經漏一陣子了，
只是水被隔熱層吸住，還沒滴下來。

不確定的話拍給我看，不用錢。
早點處理都是小工程，拖到爛掉才是大錢。

{公司名}｜{地區}
LINE：{LINE_ID}
```

## 模板 4：隔熱（夏季主打）

```
頂樓熱到不能睡，是很多{地區}透天的老問題。

先講實話：
隔熱不是刷一層漆就會涼。

真正有效的順序是：
1. 通風 - 讓熱空氣有地方跑（通風球、開口）
2. 隔熱層 - 屋頂下加隔熱棉或用夾心板
3. 反射 - 淺色板材或隔熱漆
4. 雙層屋頂 - 效果最好，但成本最高

預算不同做法差很多，
可以先跟我說你頂樓大概幾坪、現在是什麼屋頂，
我跟你講哪一種對你最划算。

不一定要做最貴的那種。

{公司名}｜{電話}
```

## 模板 5：報價透明（建立信任・成交前推一把）

```
常常有人問「一坪多少？」

老實說，這個問題我沒辦法在電話裡回答，
因為同樣一坪，這幾件事會讓價格差快一倍：

・要不要拆舊的、清運
・幾樓、需不需要吊車
・板子的厚度（0.4 跟 0.6 差很多）
・要不要加隔熱層
・檁條要不要換
・天溝要不要一起做

所以我的做法是：
你先拍幾張照片給我，我大概抓一個範圍，
如果你覺得可以再約時間現場丈量，
丈量跟報價都不收費。

報價單上會寫清楚含什麼、不含什麼，
不會做到一半才跟你說這個要另外算。

{公司名}｜{地區}
LINE：{LINE_ID}
```

## 模板 6：廠房 B2B（發給業主、不發社團）

```
廠房屋頂翻修，業主最在意的通常不是價格，是「能不能不要停工」。

我們的做法：
・先做施工計畫，分區施作，一次只開一區
・當日開挖當日封閉，不留過夜開口
・雨備方案先講好（帆布、臨時導水）
・下班後與假日時段可排入工期
・施工前後各拍一次現況存證

如果貴廠今年有屋頂翻修預算，
可以先安排一次免費現勘，我們提供分區施工計畫與報價。

{公司名}｜{電話}
```
