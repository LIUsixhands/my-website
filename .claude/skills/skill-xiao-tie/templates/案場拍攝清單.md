# 案場拍攝清單（印出來放車上・每個案子都要跑）

## 🔴 開工前（沒拍完不准開工）
- [ ] 遠景全屋（**記住站的位置，完工要站回同一點**）
- [ ] 破損特寫（鏽穿／裂縫／脫落螺絲）
- [ ] 室內漏水痕跡（天花板水漬）
- [ ] 舊材料剖面（鏽到什麼程度）
- [ ] 老闆講一句話的影片（10 秒：「這個屋頂大概幾年了，你看這裡…」）

## 🟡 施工中
- [ ] 切割火花
- [ ] 吊料／上板
- [ ] 鎖螺絲特寫
- [ ] 收邊細部
- [ ] 高處俯瞰全景
- [ ] 現場防護（鋪設保護、清潔）

## 🟢 完工後
- [ ] **與「前」完全相同角度**的全屋
- [ ] 細部收邊特寫
- [ ] 室內往上看（乾淨的天花板）
- [ ] 天溝與落水管
- [ ] 屋主合照（**需口頭同意**）

## ⚠️ 上傳前必檢查
- [ ] 門牌號碼已遮蔽
- [ ] 車牌已遮蔽
- [ ] 沒有拍到屋主姓名、室內私人物品
- [ ] 高處畫面有安全帽／安全繩（沒有的不要用）
- [ ] 已取得屋主同意（報價單勾選欄）

## 📁 存檔命名
`年月_地區_工項` → 例：`202608_歸仁_屋頂翻修`
每案一個資料夾，內分 `01_前` `02_中` `03_後`
