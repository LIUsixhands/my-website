# 🏠 小屋（591 房屋影片上架專員）安裝說明

> 出品：Sixhands Studio AI數字員工 🦞
> 版本 v1.0（2026-09-09）· Mac／Windows 通用

---

## 一、這是什麼

小屋是你的**591 影片上架助理**。影片你已經拍好剪好了，
它負責最後那一哩：

1. 檢查影片規格對不對（格式、長度、大小、封面會不會全黑、手機聽不聽得到）
2. 不合格就自動轉檔修好
3. 產出上架標題、說明、標籤，含**法定必載欄位**
4. 幫你開 591 後台、把影片掛上去，**停在送出前一步**
5. 上架後回查前台真的看得到
6. 每一支都留紀錄，月底出一份報表

**小屋不拍片**（拍片是小曲的事），**也不代你按送出**。

## 二、安裝（3 分鐘）

### Mac
1. 把 `skill-xiao-wu` 整個資料夾放到 `~/.claude/skills/skill-xiao-wu`
   （Finder 按 `Cmd + Shift + G`，貼上 `~/.claude/skills`，把資料夾拖進去）
2. 裝 ffmpeg：
   ```bash
   brew install ffmpeg
   ```
3. 開工作區：
   ```bash
   cd ~/.claude/skills/skill-xiao-wu/scripts
   python3 houseclip.py init
   ```

### Windows
1. 資料夾放到 `C:\Users\你的帳號\.claude\skills\skill-xiao-wu`
2. 裝 ffmpeg（`winget install ffmpeg`），確認 `ffprobe -version` 有反應
3. 一樣跑 `python houseclip.py init`

## 三、第一次使用前，一定要做的一件事

591 **沒有公開的影片規格文件**，網路上查到的數字多半是舊的。
所以小屋出廠時設定檔是**空白**的，需要你實測一次：

```bash
python3 houseclip.py spec
```

它會印出七題，你照著在 591 後台實測一輪，把答案填進
`~/AI員工_小屋/config/591_spec.json`。填完之後規格檢查才有依據。

**沒實測也能用**，只是規格檢查只做得了通用品質項目（黑封面、音量、有沒有音軌），
平台限制類的項目會標「未實測」。

## 四、每天怎麼用

```bash
cd ~/.claude/skills/skill-xiao-wu/scripts

python3 houseclip.py check 影片.mp4          # 1. 檢查
python3 houseclip.py fix   影片.mp4          # 2. 不合格就修
python3 houseclip.py pack  物件.json          # 3. 產文案
python3 houseclip.py precheck A123           # 4. 送出前確認清單
#    → 自己按送出
python3 houseclip.py log add A123 <網址>      # 5. 記一筆
python3 houseclip.py log verify              # 6. 隔天回查
python3 houseclip.py report                  # 7. 月底出報表
```

物件 JSON 照 `templates/物件範例.json` 改。

## 五、三件小屋不會替你做的事（也請不要要求它做）

1. **不會替你按送出。** 刊登是對外發布，廣告的法律責任在經紀業與經紀人身上。
2. **不會輸入你的帳號密碼或簡訊驗證碼。** 請你自己在瀏覽器登入好，它只在已登入的視窗操作。
3. **不會解驗證碼、不會高頻批次刷 591。** 那會讓你的帳號被鎖，損失遠大於省下的時間。
