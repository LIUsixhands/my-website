# 上架文案寫法與法定必載欄位

## 一、標題公式

591 影片說明的標題要在**手機一行內看完**，抓「這支影片值得點」的理由。

```
【區域＋物件亮點】格局／坪數｜一支影片看完
```

範例（結構示意，實際數字必須來自謄本與委託書）：
- `【永康 三房平車】32坪｜一支影片看完格局動線`
- `【東區 店面】一樓臨路｜影片實拍騎樓與人流`

**三個不准**：
1. 不准寫沒發生的事（「屋主急售」除非委託書寫明）
2. 不准用最高級詞（最便宜、唯一、第一）
3. 不准把別間房子的畫面當本物件

## 二、說明結構（四段，共 150–300 字）

1. **第一句就講影片內容**：「這支影片從大門走到主臥，一鏡看完動線。」
2. **物件三個事實**：坪數、格局、樓層／屋齡（**逐項對得上謄本**）
3. **周邊生活機能**：走路幾分鐘到什麼（距離用實測，不用「步行 1 分鐘」這種灌水寫法）
4. **行動呼籲＋必載聲明**

## 三、法定必載（不可省）

依《不動產經紀業管理條例》，**經紀業與委託人簽訂委託契約書後，方得刊登廣告及銷售；
廣告內容應與事實相符，並應註明經紀業名稱**。

所以每一則上架說明的結尾固定掛：

```
—
經紀業：{經紀業名稱}
經紀人：{經紀人姓名}（不動產經紀人證書字號：{字號}）
本廣告內容與事實相符，物件資料以土地建物謄本及不動產說明書為準。
```

🚨 **實際必載項目以主管機關公告與 591 當期刊登規則為準。**
上面的格式是工作範本，**不是法律意見**。字號、經紀業名稱一律由房仲提供，小屋不代填不代查。
有疑義時：先問房仲的公司法務或經紀人，不要自行判定。

## 四、標籤

挑 5–8 個，全部是**事實類**標籤：區域、格局、樓層、車位有無、電梯有無、屋齡帶。
不要放「投資」「增值」「潛力」這類預測性標籤（見 `合規紅線.md`）。
