# 踩雷速查（已知會炸的地方）

## 平台面

| 症狀 | 真因 | 解法 |
|---|---|---|
| 後台顯示影片已上傳，前台看不到 | 前後台不同步或需審核 | **一律用未登入的無痕視窗驗證**，隔天再查一次 |
| 找不到影片欄位 | 物件類型或方案等級不支援 | 回報房仲，不要自行升級方案（會花錢） |
| 上傳到一半失敗且無錯誤訊息 | 檔案超規但提示被吃掉 | 先 `check`，再 `fix` 轉檔重試；兩次失敗就停手 |
| 突然跳驗證碼 | 操作太密集觸發風控 | 停手，當天不要再自動化，改人工 |
| 這次的頁面跟 SOP 完全不一樣 | 591 改版 | 停手，重寫 SOP，不要硬猜按鈕位置 |

## 影片面

| 症狀 | 真因 | 解法 |
|---|---|---|
| 影片封面是全黑 | 首幀是黑畫面或淡入 | `check` 會抓首幀亮度；`fix` 會裁掉開頭黑幀 |
| 手機看聲音很小 | 音量沒正規化 | `fix` 會做 loudnorm |
| 直式影片上去被切邊 | 平台以橫式為主 | 依 config 的 `aspect` 決定要不要補邊；不確定就先問 |
| 影片畫面是別間房子 | 檔案配錯物件 | Step 1 交辦單強制對物件代號；`precheck` 會再問一次 |

## 資料面

| 症狀 | 真因 | 解法 |
|---|---|---|
| 物件代號搜出多筆 | 用地址搜的 | 一律用物件代號搜 |
| 上架後被公司要求下架 | 公司政策沒確認就開工 | 開工前確認 591 帳號與物件歸屬（見 SKILL.md 限制 2） |
| 月底算不出做了幾支 | 沒即時記 log | 每上一支就 `log add`，不要月底補記 |
