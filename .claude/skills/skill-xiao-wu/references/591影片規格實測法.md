# 591 影片規格實測法（第一次導入必做）

> **為什麼要實測**：591 沒有公開的影片規格文件，也沒有上架 API。
> 網路上查到的數字多半是舊版或別的平台的。**我不編數字**，所以第一次導入時我們自己量一次，
> 量完寫進 `~/AI員工_小屋/config/591_spec.json`，之後 `check` 與 `fix` 才有依據。
> 規格會隨平台改版變動，**建議每季複測一次**，或一退件就複測。

## 前置
- 用房仲本人的帳號登入 591 後台（他自己登入，小屋不碰密碼）
- 準備一支測試影片，以及一支故意超規的影片（超長、超大）

## 實測七問（照順序做，邊做邊填）

| # | 要問出來的事 | 怎麼測 | 填進 config 的欄位 |
|---|---|---|---|
| 1 | 影片是**上傳檔案**還是**貼 YouTube 連結**？兩種都支援嗎？ | 打開任一物件的編輯頁，找影片欄位，看它要什麼 | `mode`：`upload` / `youtube` / `both` |
| 2 | 接受哪些檔案格式？ | 拿 mp4、mov 各試一次 | `formats` |
| 3 | 檔案大小上限？ | 拿故意做大的檔上傳，記下被擋時的提示文字 | `max_mb` |
| 4 | 長度上限／下限？ | 拿超長檔試，記提示文字 | `max_seconds` / `min_seconds` |
| 5 | 解析度或長寬比有沒有限制？直式吃不吃？ | 拿 1080×1920 直式與 1920×1080 橫式各試一次 | `resolutions` / `aspect` |
| 6 | 一個物件能掛幾支影片？ | 掛第二支看擋不擋 | `max_videos_per_object` |
| 7 | 上傳後多久前台才看得到？要不要審核？ | 上傳後用**未登入**瀏覽器每 10 分鐘看一次 | `publish_delay_note` |

## 測完怎麼填

```bash
cd ~/.claude/skills/skill-xiao-wu/scripts
python3 houseclip.py spec            # 印出空白表與 config 路徑
# 手動編輯 ~/AI員工_小屋/config/591_spec.json 填入實測值
python3 houseclip.py check 測試影片.mp4   # 驗證 config 讀得到
```

## 三個實測時最容易搞錯的地方

1. **後台看得到 ≠ 前台看得到。** 一定要用無痕視窗（未登入）驗證。
2. **提示文字才是真規格。** 被擋時跳出來的那句話（例如「檔案不得超過 XX MB」）是唯一可信來源，
   把**原文照抄**進 config 的 `evidence` 欄，將來吵架有據。
3. **不同物件類型（出售／出租／店面／土地）欄位可能不一樣。** 至少測「出售」與「出租」各一次。
