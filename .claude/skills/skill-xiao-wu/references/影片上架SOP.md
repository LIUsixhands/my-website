# 影片上架 SOP（瀏覽器自動化逐步）

> 工具：Chrome MCP（`mcp__claude-in-chrome__*`）。591 沒有 API，這是唯一的路。
> **鐵律：停在送出前一步。** 送出鍵由房仲本人按。

## 0. 前置檢查（少一項就不要開瀏覽器）

- [ ] `houseclip.py check` 已通過，或已 `fix` 轉檔完成
- [ ] `houseclip.py pack` 的文案包已產出，房仲已看過標題與說明
- [ ] 房仲**本人已在他的 Chrome 登入 591**（小屋不輸入帳密）
- [ ] 確認這個 591 帳號的物件是**可以由他刊登的**（公司政策已確認）

## 1. 開後台、對物件

1. 在已登入的分頁開 591 會員中心 → 我的物件／刊登管理
2. 用**物件代號**搜尋，不要用地址搜（同路段多筆會挑錯）
3. 進編輯頁前，先 `read_page` 讀一次，確認頁面上顯示的**地址與售價**跟交辦單一致
   ❗ 不一致就停手回報，這代表物件代號給錯了

## 2. 找到影片欄位

- 依 config 的 `mode`：
  - `upload` → 找檔案上傳按鈕，用 `file_upload` 帶入本機影片路徑
  - `youtube` → 找連結輸入框，用 `form_input` 貼入 YouTube 網址
- 找不到影片欄位時的兩個常見原因：
  1. 這個**物件類型**沒有影片欄位（土地、車位常見）
  2. 這個**方案等級**沒有影片功能 → 需要升級方案，回報房仲，不要自行升級（會花錢）

## 3. 填說明文字

把 `packs/<物件代號>.md` 的內容貼進去。
**用剪貼簿貼，不要逐字打**（延續 [[feedback_line_desktop_never_type_multiline]] 的教訓：
逐字打多行在某些編輯器會觸發送出或洗版）。

## 4. 停手，交回真人

1. `computer` 截圖整頁
2. 把 `houseclip.py precheck <物件代號>` 的清單連同截圖一起給房仲
3. 明講一句：**「確認無誤請你按送出，我不代按。」**
4. 等他回報已送出，才進入 Step 5

## 5. 上架後驗證（送出後 30 分鐘內做一次，隔天再做一次）

```bash
python3 houseclip.py log add <物件代號> <物件前台網址>
python3 houseclip.py log verify
```
用**未登入的無痕視窗**開前台網址，確認：影片欄位有出現、按下去能播、封面圖不是黑的。

## 失敗如何退回人工

出現以下任一狀況，**立刻停止自動化，改回人工並回報**：

| 狀況 | 判讀 | 動作 |
|---|---|---|
| 出現驗證碼／人機驗證 | 風控觸發 | 停手，絕不代解，請房仲本人處理 |
| 連續兩次上傳失敗 | 可能規格或網路 | 停手，先重測規格 |
| 頁面版型與 SOP 描述對不上 | 591 改版 | 停手，重寫 SOP 後再跑 |
| 要求輸入密碼或簡訊驗證碼 | 登入階段 | 停手，小屋不經手任何驗證碼與密碼 |
| 跳出付費／升級方案 | 會花錢 | 停手，回報房仲決定 |

**不可以做的事**：連續高頻操作、同時開多個分頁批次刷、繞過驗證碼、用腳本模擬登入。
這些會讓房仲的帳號被鎖，損失遠大於省下的時間。
