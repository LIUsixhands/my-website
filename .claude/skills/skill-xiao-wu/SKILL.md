## 🚧 開工前必讀：這隻員工的三個先天限制

寫在最前面，因為這三件事決定了「能承諾什麼、不能承諾什麼」。報價前一定要先跟房仲講清楚。

1. **591 沒有公開的上架 API。** 只能走瀏覽器自動化（Chrome MCP）。平台一改版、一加驗證碼、一調風控，流程就要重修。
   **絕對不可以講「一次做好永久自動」**，要講「省掉重複打字與檢查，改版時我來修」。
2. **帳號是誰的，決定能不能做。** 公司後台物件、公司 591 帳號，屬於公司資產。
   個人導入前先確認公司政策（見 [[project_realtor_591_auto_listing]]，該案學員明講是個人導入，但物件在公司後台）。
   **沒確認就不要開工。**
3. **省下的時間不一定會變成錢。** 如果房仲真正的瓶頸是帶看轉換或議價，而不是曝光，那上架再快也不會多成交。
   接案第一輪先問清楚（見 `references/待補15題.md` A 段）。

## 🧰 工具：`houseclip.py`（零依賴標準庫 + ffprobe/ffmpeg）

位置：`~/.claude/skills/skill-xiao-wu/scripts/houseclip.py`
工作區：`~/AI員工_小屋/`（**本機碟，不可放桌面 iCloud** — 見 [[feedback_icloud_dataless_breaks_launchd]]）

```bash
cd ~/.claude/skills/skill-xiao-wu/scripts

python3 houseclip.py init                      # 建工作區與設定檔
python3 houseclip.py spec                      # 印出「591 影片規格實測表」，實測後填進 config
python3 houseclip.py check <影片檔>             # 規格檢查（讀 config，不硬寫數字）
python3 houseclip.py fix <影片檔>               # 依 config 轉檔到符合規格
python3 houseclip.py pack <物件.json>           # 產出上架文案包（標題／說明／標籤／必載聲明）
python3 houseclip.py precheck <物件代號>        # 送出前確認清單（含禁字與必載欄位稽核）
python3 houseclip.py log add <物件代號> <網址>   # 記一筆上架
python3 houseclip.py log verify                # 上架後回查：影片是不是真的看得到
python3 houseclip.py report                    # 產出當月上架月報
```

🚨 **`config/591_spec.json` 出廠是空的，這是故意的。**
591 的影片規格（格式／長度／檔案大小／解析度／是上傳檔案還是貼 YouTube 連結）**沒有公開文件可查**，
我不編數字。第一次導入時照 `references/591影片規格實測法.md` 實測一輪，把真實限制填進 config，
之後 `check` 與 `fix` 才有依據。**config 是空的就先跑實測，不要猜。**

## 📋 主線工作流（六步）

### Step 1｜接單：物件與影片對上號
收「物件代號 + 影片檔路徑」。缺任何一個就先問，不要自己配對。
用 `templates/物件影片交辦單.md` 收齊：物件代號、地址（只到路名）、售價或租金、坪數、格局、
影片檔路徑、影片是誰拍的、有沒有出現人臉或門牌、屋主同意刊登了沒。

### Step 2｜規格檢查
```bash
python3 houseclip.py check /path/to/影片.mp4
```
檢查項目：容器格式、編碼、長度、檔案大小、解析度、長寬比、音軌有沒有、首幀是不是黑畫面、音量是不是太小。
不符合就 `fix` 轉檔，**不要拿原檔硬上傳後才發現被退**。

### Step 3｜上架文案包
```bash
python3 houseclip.py pack objects/A123.json
```
產出標題、說明、標籤，以及**法定必載聲明**（經紀業名稱、經紀人姓名、廣告與事實相符聲明）。
寫法規則見 `references/文案寫法與必載欄位.md`。

### Step 4｜掛上 591（瀏覽器自動化）
用 Chrome MCP 開 591 後台 → 找到該物件 → 影片欄位 → 上傳或貼連結 → **停在送出前一步**。
完整步驟與截圖判讀見 `references/影片上架SOP.md`。

🚨 **停在送出前一步，把 `precheck` 的清單貼給房仲，由他本人按送出。**
理由有三：刊登是對外發布行為、廣告內容的法律責任在經紀業與經紀人身上、按錯會刊錯物件。

### Step 5｜上架後驗證
```bash
python3 houseclip.py log add A123 https://...
python3 houseclip.py log verify
```
用**沒登入的瀏覽器**開物件頁，確認影片真的出現、真的能播。
後台看得到不等於前台看得到（見 `references/踩雷速查.md`）。

### Step 6｜紀錄與月報
每筆上架都進 `data/上架紀錄.csv`。月底 `report` 產出月報：這個月上了幾支、平均耗時、退件幾次、原因分佈。
月報是**續約的憑據**，也是回答「這隻員工到底幫我省了多少」的唯一方法。

## 🚨 合規紅線（七條，不可刪）

1. **不代按送出**。最後一步永遠是真人。
2. **不經手帳號密碼**。要登入請房仲本人在他的瀏覽器登入，我只在已登入的視窗操作。
3. **不碰公司後台的寫入權限**。物件資料只讀，不改不刪。
4. **廣告內容必須與事實相符**。坪數、格局、屋齡、價格以謄本與委託書為準，影片畫面不得是別間房子。
5. **必載欄位不可省**：經紀業名稱、經紀人姓名。依《不動產經紀業管理條例》，經紀業須簽訂委託契約書後方得刊登廣告，且廣告需與事實相符。**實際欄位以主管機關與 591 當期規定為準，有疑義先問，不要自己判定。**
6. **禁字一律擋**：保證、穩賺、絕對、零風險、包漲、投報保證、急售（非事實時）等。清單見 `references/合規紅線.md`。
7. **個資與門牌**：影片若拍到門牌、車牌、鄰居人臉、屋主家人，上架前必須打碼或剪掉。屋主未書面同意的影片不上架。
