# 內容矩陣與貼文模板庫 —— 每個月 20 則，不用想

> 用法：小村會先問「這個月主打哪一種房型／哪一種客群」，
> 再從下面的矩陣抽題，產出**可直接複製的純文字版**。

---

## 一、內容矩陣（每月 20 則的配方）

| 類型 | 佔比 | 目的 | 每月則數 |
|:---|:---|:---|:---|
| **A. 日常生活**（菜單、活動、光景） | 40% | 讓人相信這裡是活的、是家 | 8 |
| **B. 知識型**（怎麼選、怎麼開口、費用怎麼比） | 25% | 在他還沒需要你時建立信任＋被搜尋到 | 5 |
| **C. 人的故事**（住民、員工、家屬） | 20% | 情感連結，最容易被分享 | 4 |
| **D. 透明資訊**（費用、房型、參訪、立案） | 10% | 給干擾者與出資者的彈藥 | 2 |
| **E. 行動邀請**（參訪、試住、說明會） | 5% | 收單 | 1 |

> ⚠️ **E 不能超過 5%。** 一個滿版都在招住民的粉專，家屬看了會怕。

## 二、20 個模板（直接套）

### A. 日常生活（8 則）

**A1｜一週菜單**
```
這禮拜的菜。

星期一　滷雞腿、炒時蔬、味噌湯
星期二　鯖魚、蒸蛋、冬瓜排骨湯
（…）

有幾位阿公阿嬤跟廚房說想吃筍子，
所以星期四加了一道。

想看更多平常的樣子，隨時歡迎來走走。
```
> 配圖：菜色實拍（不要打光過度，真實比漂亮重要）。零同意書風險。

**A2｜早上七點**
```
早上七點，這裡在做什麼。

七點　起床、量血壓
七點半　早餐（今天是稀飯配菜脯蛋）
八點半　散步，走到院子那棵樹再走回來
九點　量測記錄，交班

沒有什麼特別的。
但長輩要的，常常就是「每天都一樣」。
```

**A3｜光**（純環境）
```
下午三點的交誼廳。
這個時間陽光會斜斜地照進來，
所以大家都自己搬椅子過來坐。

我們沒有規定要坐哪裡。
```

**A4｜手**（拍手不拍臉）
```
今天的手作課，做的是艾草包。

有位阿嬤說她年輕的時候在田裡做過，
一邊做一邊教旁邊的人。

我們常覺得，這裡最好的老師不是我們。
```

**A5｜下雨天** ｜**A6｜節氣（冬至／中秋／重陽）** ｜**A7｜院子裡的菜** ｜**A8｜今天的一件小事**
> 結構相同：一個具體的場景 + 一句不推銷的收尾。

### B. 知識型（5 則）—— 這一區是搜尋流量的金礦

**B1｜怎麼跟爸媽開口**（全網最缺，發了就會被存）
```
「要怎麼跟爸媽說，我想讓他去住機構？」

這是我們最常被問的問題。分享幾個實際有效的做法：

1. 不要用「送」這個字。改說「去住一陣子看看」。
2. 不要一次講完。先講「有個地方在辦活動，我們去吃個飯」。
3. 先讓他認識人，不是先看設施。長輩在意的是「那裡有沒有我聊得來的人」。
4. 讓他保留退路。「不喜歡我們就回家」，這句話一定要說。
5. 找他信任的第三方講（醫師、里長、老朋友），比子女講有效十倍。

如果你正在為這件事失眠，這很正常。
需要的話，可以先來看看，不用帶爸媽，不用留電話。
```

**B2｜參訪要問的 10 個問題**（連問你自己不利的問題都列上去 → 信任爆表）
```
如果你要去看機構，這 10 個問題一定要問：

1. 立案字號幾號？核准的服務類型是什麼？
2. 白班一個照服員照顧幾位？夜班呢？
3. 月費含什麼？不含什麼？（請他把「不含」的先講）
4. 保證金多少？什麼情況退？多久退？
5. 有狀況怎麼送醫？誰通知家屬？多久之內通知？
6. 可不可以試住？幾天？費用怎麼算？
7. 可以帶自己的家具嗎？
8. 探視有沒有時間限制？可以不預約直接來嗎？
9. 最近一次評鑑結果？（請他給你看文件）
10. 這裡待最久的員工待幾年了？

第 10 題最重要。員工留得住的地方，長輩才留得住。
```

**B3｜費用怎麼比才不會被騙**
**B4｜長輩剛出院，接下來三個選擇**（回家自顧／請看護／機構，各自的真實成本）
**B5｜「我不想去養老院」背後真正在說什麼**

### C. 人的故事（4 則）

**C1｜員工故事**
```
張阿姨在這裡第 12 年。

她記得每一位長輩的名字，
也記得誰的湯要少鹽、誰晚上要多一件被子。

有人問我們最大的優勢是什麼。
其實就是這種「記得」。
```

**C2｜住民故事**（須同意）｜**C3｜家屬的一句話**（匿名引用，須同意）｜**C4｜開這間的原因**（老闆故事，一年講一次）

### D. 透明資訊（2 則）

**D1｜費用表**
```
我們把費用公開寫出來。

月費：NT$〇〇,〇〇〇 起（依房型與照顧等級）
含：住宿、三餐點心、日常生活照顧、清潔洗衣、團體活動
不含：紙尿褲等個人耗材、營養品、醫療與掛號費、交通接送、額外加派看護
保證金：NT$〇〇,〇〇〇（履約擔保，非投資、不生孳息、不得轉讓，退住時依契約結算退還）

床位數量隨實際狀況變動，實際以現場確認為準。
本機構經〇〇市政府許可設立，立案字號：〇〇字第〇〇號。
```

**D2｜房型與空床狀況**（每月更新一次，寫「候補中」不寫「保證入住」）

## 三、寫作規格（不可違反）

1. **一則只講一件事。**
2. **不用行銷詞**：樂齡、賦能、共融、頂級、尊榮、專業團隊 —— 全部刪掉。
3. **不用驚嘆號。** 這一行的語氣是「穩」，不是「熱情」。
4. **不用愧疚句。** 檢查每一句：這句會讓家屬更輕鬆，還是更難過？
5. **句子短**。長輩要看得懂，家屬在通勤時要滑得完。
6. **結尾一定有一個低門檻動作**，且**永遠不是「立刻簽約」**。
7. **每一則發布前跑一次紅線 1–8。**
