# 影像素材與短影音 SOP —— 用手機就能拍，而且不會出事

---

## 一、拍攝前的唯一一道關卡：同意書

> **沒有同意書的臉，一律不准出現在任何對外素材上。**

| 對象 | 誰簽 | 注意 |
|:---|:---|:---|
| 意識清楚的住民 | 本人 | 用大字版同意書，當面唸給他聽 |
| 失智／無法表達 | 法定代理人／監護人／主要家屬 | 保留書面，不接受口頭 |
| 員工 | 本人 | 離職後是否繼續使用要寫清楚 |
| 訪客／家屬 | 本人 | 活動現場請立牌告知 |

同意書必載：**用途（官網／FB／IG／廣告／簡報）、期限、可隨時書面撤回、撤回後下架時程**。

### 檔名規則（不可省略）
```
202609_中秋活動_王阿嬤_已同意.jpg     ← 可用
202609_中秋活動_住民C.jpg             ← 有臉但沒「已同意」→ 不准用
202609_中秋活動_手作特寫.jpg          ← 無臉，可用
```

## 二、零風險素材清單（不用同意書就能拍）

1. **手**：搓湯圓、寫書法、澆花、按摩、包水餃
2. **背影**：走廊上、窗邊、散步
3. **餐桌**：菜色、碗筷、廚房備料
4. **空間**：光線、窗、花園、走廊、交誼廳（**沒有人的時候拍**）
5. **物件**：日曆、活動表、盆栽、住民的作品
6. **員工**（已簽同意）：交班、備餐、扶著扶手教走路

> **這一行最好的畫面，八成不需要拍到臉。**

## 三、絕不拍、絕不用
❌ 臥床、餵食、包尿布、失禁、身體約束、醫療處置、跌倒、哭泣、爭執
❌ 拍到別人的病歷、藥袋、床頭卡、姓名牌
❌ 把長輩的失能狀況當作賣點（「看看他多需要照顧」）
❌ 表演式擺拍（讓長輩排排坐比讚）—— 家屬一眼看得出來，而且很傷

## 四、三支必拍的基本款短影音（30–45 秒，手機直拍 9:16）

### 📹 支 1：「一日流程」
```
0–3秒   畫面：早晨的走廊 + 字卡「早上七點，這裡在做什麼」
3–10秒  量血壓的手、早餐擺盤
10–20秒 散步的背影、院子
20–30秒 午餐、交誼廳的光
30–40秒 字卡：「沒有什麼特別的。但長輩要的，常常就是每天都一樣。」
40–45秒 尾卡：機構名 + 地址 + 「歡迎來吃一頓飯」
```

### 📹 支 2：「這禮拜的菜」（週更，最穩定）
```
0–3秒   一鍋剛起鍋的菜 + 字卡「這禮拜吃什麼」
3–30秒  五道菜輪播，每道 5 秒，左下角小字寫菜名
30–40秒 廚房阿姨的手在備料
40–45秒 尾卡
```

### 📹 支 3：「怎麼跟爸媽開口」（知識型，最會被存與分享）
```
0–3秒   純字卡（黑底白字）：「要怎麼跟爸媽說，我想讓他去住機構？」
3–8秒   「第一，不要用『送』這個字。」
8–15秒  「第二，先讓他來吃一頓飯，什麼都不談。」
15–25秒 「第三，一定要留退路：不喜歡我們就回家。」
25–35秒 「第四，找他信任的人講，比子女講有效十倍。」
35–45秒 「如果你正在為這件事失眠，這很正常。」+ 尾卡
```

## 五、拍攝清單（發給現場人員）

**每次活動至少拍到這六樣：**
- [ ] 一張**空景**（沒有人的空間 + 光）
- [ ] 三張**手**的特寫
- [ ] 一張**餐桌／食物**
- [ ] 一段 10 秒的**環境音**（笑聲、聊天、鍋鏟聲 —— 聲音比畫面更有感）
- [ ] 一張**員工工作中**（已同意）
- [ ] 一張**成果**（作品、菜、佈置）

**技術要求（不要求好看，只要求能用）：**
- 手機**橫拍一份、直拍一份**（橫的給官網、直的給 Shorts／Reels）
- **順光**，不要背光；室內請開燈
- 手機**擦鏡頭**（這一條解決 50% 的畫質問題）
- 一段影片**至少 5 秒不動**，剪接才有素材

---

## 六、字幕與字級（銀髮向鐵律）

- 字幕**大**：直式影片字高不低於畫面高度的 5%
- 用**黑體、粗體、白字加深色描邊**
- 繁體中文一律用 **Songti TC／黑體 TC**，**不要用 SC**（會有缺字變空白）
- 一行不超過 **13 個字**，一次不超過 **2 行**
- 字幕位置：畫面 **62–65% 高度**，避開下方平台 UI

---

## 七、發布前最後檢查（五秒鐘）

1. 有臉的畫面，檔名有沒有 `_已同意`？
2. 有沒有拍到別人的姓名牌、病歷、藥袋？
3. 有沒有出現療效、保證、最高級用語？（紅線 2、3、6）
4. 有沒有一個低門檻的下一步？
5. 尾卡有沒有：機構名、地址、聯絡方式？
