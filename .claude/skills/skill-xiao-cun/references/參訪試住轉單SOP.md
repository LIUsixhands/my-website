# 參訪・試住・轉單 SOP —— 從「有人問」到「住進來」

> 這一行的漏斗是：
> **看到 → 問 → 參訪 → 試住 → 家庭會議 → 簽約 → 入住 → 轉介**
>
> 大多數機構卡在兩個地方：**「問了不來看」** 和 **「看了沒下文」**。
> 這份 SOP 就是專門解這兩關。

---

## 漏斗全圖與健康值

| 階段 | 動作 | 健康轉換率（參考值，請以自家數據校正） |
|:---|:---|:---|
| 諮詢 → 參訪 | 邀約 | 40–60% |
| 參訪 → 試住 | 提出試住 | 30–50% |
| 試住 → 簽約 | 追蹤 | **60–80%（最高的一段）** |
| 簽約 → 入住 | 行政 | 90%+ |
| 入住 → 轉介 | 家屬滿意度經營 | 每 10 位住民應產生 1–3 個轉介 |

> 哪一段最低，資源就放哪一段。**不要在最上游猛加廣告去補下游的洞。**

## 第 1 關：諮詢當下（黃金 5 分鐘）

### ❌ 千萬不要做的三件事
1. 一開口就報價（報完就結束了）
2. 一直問「請問怎麼稱呼、電話幾號」（他會逃）
3. 說「這個電話講不清楚，你來一趟」

### ✅ 正確的四句話順序

**① 先問人，不問需求**
> 「是幫爸爸還是媽媽找？」
> 「他現在住在哪裡，身邊有人嗎？」

**② 問一個讓他覺得你懂的問題**
> 「是最近有發生什麼事嗎？跌倒還是剛出院？」
> —— 這一句會讓 80% 的家屬開始講真話。

**③ 先給，再要**
> 「我先傳一份費用表和照片給你，你自己先看。不用留電話，加 LINE 就好。」
> —— **降低門檻永遠比追單有效。**

**④ 邀約用「吃飯」，不用「參觀」**
> 「你什麼時候方便，來吃一頓飯？帶不帶長輩都可以。」
> —— 「參觀」聽起來像被推銷，「吃飯」聽起來像被邀請。

### 必問的五個資訊（用聊的，不要用問卷）
1. 長輩狀況（能不能自己走、吃飯、上廁所；有沒有失智、管路）
2. 觸發事件（跌倒／出院／看護走了／照顧者累了）
3. 時間急迫性（這禮拜就要，還是先看看）
4. 誰是決策者（有幾個兄弟姊妹要同意）
5. 從哪裡知道我們（**這一題一定要問，決定明年預算怎麼花**）

→ 全部填進 `範本/1_潛在名單.csv`。

## 第 2 關：參訪（讓他忘記自己在被推銷）

### 參訪的目標不是介紹設施，是**讓他在這裡感覺舒服**。

**動線腳本（約 40 分鐘）**

| 時間 | 做什麼 | 為什麼 |
|:---|:---|:---|
| 0–5 分 | 泡茶、坐下、**不談生意** | 先降警戒 |
| 5–10 分 | 問「你們家的狀況」，聽 | **聽比講重要，這 5 分鐘決定成敗** |
| 10–25 分 | 走一圈：先看**餐廳**，再看**房間**，最後看**公共空間** | 先吃飯的地方，家屬最在意伙食 |
| 25–30 分 | 遇到住民，自然打招呼（不安排、不表演） | 真實感 |
| 30–35 分 | 回座位，**攤開費用表，先講不含什麼** | 建立誠實形象 |
| 35–40 分 | 提試住，**不逼單** | 給下一步，不給壓力 |

### 帶看鐵律
- **不要用「我們有…」開頭，用「你剛剛說…所以…」開頭。**（呼應他的處境）
- **不迴避缺點。** 「我們沒有電梯直達花園，這是我們的缺點。」→ 講一個真缺點，其他優點才會被相信。
- **一定要讓長輩本人講到話。** 決策者是子女，**否決者是長輩**。
- **讓他們單獨待 3 分鐘。**「我去倒茶，你們自己看一下。」—— 這 3 分鐘他們會講真話，回來後你就知道真正的異議是什麼。

### 參訪結束的最後一句（不要問「覺得如何」）
> 「你今天回去，最不放心的是哪一件事？」
> —— 這句話會直接把真正的異議挖出來，而不是得到一句客氣的「不錯啊」。

→ 全部填進 `範本/2_參訪試住紀錄.csv`。

## 第 3 關：試住（真正的成交發生在這裡）

### 為什麼一定要有試住
- 家屬最大的恐懼是「我媽會不會適應」，**這件事只能用經驗回答，不能用話術回答**。
- 試住把「一個沉重的永久決定」拆成「一個可逆的小決定」。
- 試住期間長輩交到一個朋友 → 成交率大幅上升。

### 試住方案設計原則
| 項目 | 建議 |
|:---|:---|
| 天數 | 3–7 天（太短感受不到、太長家屬會拖） |
| 費用 | 收費，但**成交可全額或部分折抵**（免費會被當作沒價值，也容易被濫用） |
| 退場 | 明說「隨時可以中止、隨時可以回家」 |
| 期間溝通 | **第 1 天晚上、第 3 天、結束前一天**各主動聯繫家屬一次 |
| 素材 | 每天傳 1–2 張照片給家屬（拍手、拍餐、拍活動；**有臉需同意**） |

> ⚠️ 試住不得對外宣稱「保證適應」「保證入住」，且**試住期間的照顧內容不得超出核准服務類型**。

### 試住結束的收尾對話
> 「這幾天他自己講了什麼？」（先問長輩的感受）
> 「你觀察下來，最放心的是什麼？最不放心的是什麼？」
> 「要不要找一天，我把你們兄弟姊妹一起約來，我把費用和契約一次講清楚？」
> —— **主動邀請「家庭會議」，把干擾者變成參與者。**

## 第 4 關：追蹤（80% 的機構死在這裡）

### 追蹤節奏（參訪後）
| 時間 | 動作 | 內容 |
|:---|:---|:---|
| 當天晚上 | LINE | 「今天謝謝你來。這是我們的費用表和剛剛講到的〇〇。」（**附檔案，不催**） |
| 第 3 天 | LINE | 回答他當天說「最不放心」的那一件事，給具體資訊 |
| 第 7 天 | LINE | 給一則相關的知識型內容（如「怎麼跟爸媽開口」） |
| 第 14 天 | 電話 | 「你們家後來討論得怎麼樣？有沒有卡在哪裡？」 |
| 第 30 天 | LINE | 一則日常內容（菜單／活動），**不推銷** |
| 之後每月 | LINE | 每月一則日常內容，直到他明確說不用了 |

### 追蹤鐵律
1. **每一次接觸都要給一個東西**（資訊、照片、回答），不要只是「請問考慮得怎麼樣」。
2. **不要問「有沒有決定」，要問「卡在哪裡」。**
3. **「暫時不用了」不等於結束**，轉成每月一則的長期名單。這一行的成交常常發生在第 6 個月。
4. **一定要記錄下次聯繫日期** → 這就是 `scripts/villagemgr.py check` 每天在幫你叫的東西。

## 第 5 關：入住後（最便宜的行銷從這裡開始）

| 時間 | 動作 |
|:---|:---|
| 入住第 3 天 | 主動打給家屬報告適應狀況（**不要等他問**） |
| 第 2 週 | 傳 2–3 張照片 |
| 每月 | 一次固定的「本月狀況回報」（吃、睡、活動、體重、情緒） |
| 每季 | 家屬座談或個別會談 |
| 滿 3 個月且滿意 | **開口要口碑**：「如果你身邊有朋友也在煩這件事，可以叫他來找我們。」 |

> **一次主動的回報，抵過十次廣告。**
> 家屬最大的恐懼不是照顧不好，是**「我不知道裡面發生什麼事」**。
