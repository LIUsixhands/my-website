## 一、型態光譜（用錯名稱＝法規問題，不是文案問題）

```
健康 ─────────────────────────────────────────────► 失能

 一般住宅型     老人公寓/      安養         養護型      長期照護型
 銀髮宅/CCRC    住宿型             機構           機構        機構
 ────────────  ──────────  ──────────  ──────────  ──────────
 生活自理       生活自理      生活自理      需協助      需專業照護
 不含照顧服務   輕度支持      含生活照顧    日常照顧    含護理需求
```

| 型態 | 白話 | 行銷重點 |
|:---|:---|:---|
| **銀髮住宅／養生村（健康型）** | 「退休後住的地方」 | 賣**生活**：社交、活動、自由、餐食、風景 |
| **老人公寓／安養** | 能自理，但有人在旁邊 | 賣**安心**：有人顧、有事有人叫、不用煮飯 |
| **養護型** | 需要日常照顧 | 賣**專業**：人力比、照顧計畫、與家屬的溝通頻率 |
| **長期照護型** | 有護理需求 | 賣**放心**：夜間人力、緊急送醫流程、與醫院的距離 |
| **日照中心** | 白天去、晚上回家 | 常是機構入住的**前一站**，是最好的名單來源 |

⚠️ **你只能宣傳你核准的類型。**
養護型的機構寫成「五星級養生村」、健康型的住宅寫成「有專業照護」，
前者是誇大、後者可能是**未經許可提供照顧服務**。這是紅線 1 與紅線 6。

## 二、家屬會拿來比較的七個硬指標

| 指標 | 家屬真正的問題 | 你要準備的答案 |
|:---|:---|:---|
| 1. 費用 | 「一個月到底要多少？」 | 含／不含拆開列，含級距 |
| 2. 人力比 | 「一個人顧幾個？晚上呢？」 | 白班／夜班分開講，據實 |
| 3. 醫療 | 「有狀況怎麼辦？」 | 特約院所、巡診頻率、送醫流程、通知家屬機制 |
| 4. 房型 | 「有沒有單人房？可以帶東西嗎？」 | 坪數、衛浴、對外窗、可帶物品清單 |
| 5. 伙食 | 「吃得好不好？」 | 一週菜單照片（**這是點閱王**）、特殊飲食 |
| 6. 活動 | 「整天在幹嘛？」 | 一週活動表、一日流程 |
| 7. 距離 | 「我下班來得及嗎？」 | 到主要醫院／交流道／捷運站的分鐘數 |

> **把這七項做成一張圖，就是全機構最有價值的一張素材。**
> 大多數同業不敢公開第 1 和第 2 項 —— 你敢，你就贏一半。

## 三、名詞速查（不要用錯）

| 名詞 | 意思 | 使用注意 |
|:---|:---|:---|
| 立案／設立許可 | 主管機關核准設立 | 對外文案應揭露字號 |
| 評鑑 | 主管機關定期辦理之機構評鑑 | 引用須註明**年度與評鑑名稱**，不得只寫「優等」 |
| 喘息服務 | 讓家庭照顧者休息的短期照顧 | 屬長照給付項目，**申請條件與額度依核定為準** |
| 長照給付／額度 | 長照 2.0 相關給付 | **絕不寫死金額**，一律「依評估核定為準」 |
| 出院準備服務 | 醫院協助出院後照顧銜接 | 最重要的轉介通路之一 |
| 個管師／照專 | 個案管理師／照顧管理專員 | 轉介關係人，不是客戶 |
| ADL／IADL | 日常生活活動能力量表 | 內部評估用，**對家屬要翻譯成白話** |
| CCRC | 持續照顧退休社區 | 台灣少見完整型，**不要亂用這個詞抬身價** |
| 定型化契約 | 主管機關公告應記載及不得記載事項 | 契約條款請交小辯／法務，不由行銷決定 |

## 四、這一行的成本結構（決定你能怎麼行銷）

- **人事成本佔大宗**（照服員、護理、廚房、行政），且**人力比是法定的**，壓不下去。
- **床位是固定的**：空床的邊際成本很低、邊際收益很高 → **入住率每 +5% 幾乎全是淨利**。
- **住民平均在住時間長**（數月到數年）→ **一個成交的終身價值極高**，
  所以「花 3 個月養一個名單」在數學上完全合理。
- **口碑的複利極強**：一個滿意的家屬平均會影響 3–5 個同溫層家庭。

→ 三個推論：
1. **行銷預算應該用「每床成交成本」而不是「每則貼文成本」來算。**
2. **不要為了滿床亂收不該收的個案** —— 一次照顧失敗的口碑，抵銷十次廣告。
3. **現住民家屬的滿意度，就是最便宜的行銷。** 每月一次的家屬溝通，比廣告有效。

## 五、常見的內容題材礦源（永遠寫不完）

| 礦源 | 例子 |
|:---|:---|
| 一週菜單 | 「這禮拜的菜單」（固定週更，最穩定的流量） |
| 一日流程 | 「早上 7 點，這裡在做什麼」 |
| 節氣與節日 | 中秋、重陽、冬至搓湯圓、農曆年圍爐 |
| 住民的手 | 手作、書法、種菜、按摩 —— 拍手不拍臉，零同意書風險 |
| 工作人員故事 | 「在這裡待了 12 年的張阿姨」 |
| 家屬的一句話 | 匿名引用（須同意），最強的社會證明 |
| 知識型 | 「怎麼跟爸媽開口」「參訪要問的 10 個問題」「機構費用怎麼比較」 |
| 環境 | 光、窗、走廊、花園、下午三點的交誼廳 |

> **知識型內容是唯一能在「他還沒需要你」時就建立信任的題材。**
> 而且它們會長期被搜尋到 —— 這是這一行的 SEO 金礦。
