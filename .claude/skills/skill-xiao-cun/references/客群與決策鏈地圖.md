# 客群與決策鏈地圖 —— 到底在說服誰

> 養生村行銷失敗最常見的原因只有一個：
> **把一段文案，同時寫給三種完全相反的人看。**

---

## 一、決策鏈的四個角色

```
        ┌──────────── 觸發事件 ────────────┐
        │  跌倒 / 中風 / 失智診斷 / 出院 /  │
        │  主要照顧者累垮 / 外籍看護空窗    │
        └───────────────┬──────────────────┘
                        ▼
   【發起人】────►【出資者】────►【使用者】
   通常是女兒/媳婦   通常是兒子/長輩自己   長輩本人
   負責找資料         負責付錢/殺價        擁有「否決權」
                        │
                        ▼
                   【干擾者】
        另一個手足 / 鄰居 / 親戚 / 里長 / 醫師
        一句「那種地方不好啦」就能讓整個案子停掉
```

**成交條件 = 發起人找到你 × 出資者覺得合理 × 使用者不抗拒 × 干擾者無話可說。**
四個裡面缺一個，案子就會卡住而且你永遠不知道為什麼。

---

## 二、四個角色，四套語言

### 1️⃣ 發起人（女兒／媳婦，35–55 歲）
- **在哪裡**：Google 搜尋、FB 社團（照顧者社團、在地社團）、IG、朋友私訊
- **搜尋什麼**：「〇〇市 養生村 費用」「安養中心 推薦」「爸媽不肯去養老院怎麼辦」
- **真正的情緒**：**罪惡感 + 疲憊 + 怕被說不孝**
- **要給他的**：
  - 費用表（**最想看、最少人給**）
  - 一日流程
  - 「怎麼跟爸媽開口」的說帖 ← **這是全網最缺、也最容易讓他愛上你的內容**
  - 一個不用留電話的第一步
- **禁忌**：任何加重愧疚的句子

### 2️⃣ 出資者（兒子／長輩本人，40–70 歲）
- **關心**：總花費、有沒有隱藏費用、退費、契約、會不會漲價、政府補助
- **要給他的**：**一張把「不含項目」寫得比「含項目」還清楚的費用表**
- **金句**：「我們把不含的先寫給你看。」
- **禁忌**：模糊報價、「來看了再說」、限時優惠

### 3️⃣ 使用者（長輩，70–90 歲）
- **真正的恐懼**：被丟掉、失去自主、跟一群「病人」住、沒有隱私、不能出門
- **要給他的**：
  - **「這是你的家，不是醫院」**
  - 可以帶自己的東西（椅子、佛桌、電視、棉被）
  - 可以自己出門、可以回家住幾天
  - 有沒有同齡、聊得來的人（**同溫層比設施重要**）
  - 吃的東西（長輩最在意的第一名往往是伙食）
- **文案規格**：字要大、句子要短、不要英文、不要「樂齡／賦能／共融」這種詞

### 4️⃣ 干擾者（另一個手足、鄰居、親戚）
- **他要的只有一樣**：**可查證的事實**
- **要給他的**：立案字號、評鑑結果、人力比、費用表、契約範本、環境照片、可實地參訪
- **金句**：「歡迎所有家人一起來看，我們不介意你們比較。」

## 三、四大異議與回應（不逼單、不辯論）

| 異議 | ❌ 錯誤回應 | ✅ 小村的回應 |
|:---|:---|:---|
| 「我媽不肯去」 | 「勸久了就會去啦」 | 「這很正常，十個有九個一開始都不肯。我們的做法是先請她來吃一頓飯，什麼都不談。很多長輩是先認識了這裡的人，才願意考慮的。」 |
| 「太貴了」 | 「我們可以再談」 | 「我先把費用拆給你看，包含什麼、不含什麼。你可以拿去跟其他家比。如果預算真的有落差，我也可以跟你說有哪些補助可以問。」 |
| 「送去會不會被虐待／被綁起來」 | 「我們不會啦」 | 「我知道新聞看多了會怕。我們可以讓你不預約直接來看，任何時間都可以。也可以先試住 X 天，你自己判斷。」 |
| 「別人說機構都不好」 | 反駁對方 | 「每一家真的都不一樣，所以我從來不叫人家用聽的。你多看幾家再決定，看完再來找我都沒關係。」 |

> 核心原則：**永遠站在家屬那一邊，不站在自己的床位那一邊。**
> 「你多看幾家」這句話，是這一行最強的成交句。

## 四、時機地圖（什麼時候他最會行動）

| 時機 | 觸發 | 行銷對策 |
|:---|:---|:---|
| **出院前 3 天** | 醫院說「回家要有人顧」 | 醫院社工／出院準備服務轉介（見 `獲客通路SOP.md`） |
| **外籍看護空窗／逃逸** | 突然沒人顧 | 短期入住／喘息型方案 |
| **過年後** | 全家聚完，手足吵完，決定了 | 農曆年後 1–2 個月是全年旺季，內容與預算前置 |
| **主要照顧者生病／崩潰** | 照顧者自己倒下 | 「照顧者也要休息」主題內容、喘息服務 |
| **長輩跌倒送急診** | 一夜之間改變全家想法 | 隨時能被搜尋到（Google 商家、官網 24 小時可看資訊） |

→ **這也是為什麼小村堅持「長期內容」而不是「一波廣告」**：
　 你不知道他哪一天會需要你，你只能確保那一天他找得到你。
