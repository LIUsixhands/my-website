## 一、他能幫你做什麼

| 你現在的痛 | 小村怎麼解 |
|:---|:---|
| 「我們照顧得很好，但外面的人不知道」 | 品牌定位＋每月 20 則貼文（日常／知識／故事／透明資訊，配方固定不用想） |
| 「有人打電話問，但都不來看」 | 諮詢黃金 5 分鐘話術 —— 用「來吃一頓飯」取代「歡迎參觀」 |
| 「來看了，回去就沒消息」 | 參訪動線腳本＋**參訪後 5 段追蹤 SOP**（大部分機構就是死在這一關） |

| 「不知道錢該花在哪裡」 | 來源別漏斗分析 —— 成交最多的那條通路才加碼，不是花最多的那條 |

一律要由貴機構的負責人、法規窗口、醫師或律師處理。
小村會把資料整理到「可以直接用」的程度，**但不會替你承擔那些責任**。

## 三、第一次使用（照這個順序，不要跳）

### 第 1 步：回答「三個號碼」

打「小村」，他第一件事就會問你這三題。**答不出來，他不會替你寫任何對外文字**：

1. **立案（設立許可）字號**是幾號？核准的**服務類型**是什麼？
2. **床位數／房型**多少？**目前入住率**多少？
3. **月費含什麼、不含什麼？保證金多少、怎麼退？**

> 為什麼這麼硬？因為未立案就對外招收住民、或宣傳超出核准的服務類型，
> 是主管機關開罰的第一順位。**這不是行銷問題，是先要處理的事。**

### 第 2 步：建表

```bash
cd ~/Documents          # 或任何你想放資料的地方（不要放 iCloud 桌面）
python3 ~/.claude/skills/skill-xiao-cun/scripts/villagemgr.py init --dir "./養生村資料"
```

會產生五個檔案，**用 Excel 或 Numbers 直接打開，不會亂碼**：

```
養生村資料/
  0_機構資料卡.json    ← 先填這個！所有文案的事實來源
  1_潛在名單.csv       ← 每一通諮詢建一列
  2_參訪試住紀錄.csv
  3_內容排程.csv
  4_通路成效.csv
```

### 第 3 步：把 15 題問完

翻 `references/開工前必問15題.md`，用 LINE 直接傳給老闆。
**一題都不要用猜的** —— 猜錯的費用、猜錯的服務類型，發出去就是罰單。

### 第 4 步：每天早上跑健檢

```bash
python3 ~/.claude/skills/skill-xiao-cun/scripts/villagemgr.py check --dir "./養生村資料"
```

輸出長這樣：

```
**🔴 立即處理 3 件　🟠 三天內 2 件　🟡 補資料 3 件**　（2026-09-10）

## 🔴 立即處理（3）
- 🔴 L-004 黃先生／黃爸（試住中）：逾期 9 天未跟進　※他最不放心：費用
- 🔴 V-001 參訪（09-05）名單 L-001：下一步「提試住」逾期 2 天
- 🔴 內容 C-002「張阿姨12年」：09-12 要發，**肖像同意書還沒拿到** → 不准發
```

**只看🔴，五分鐘就處理完。**

## 六、小村的四句核心判斷（看懂這四句，就懂他為什麼這樣建議）

**一、買的人和用的人不是同一個人。**
決定的是子女，否決的是長輩，攪局的是另一個手足。
每一則文案都要先問：**這是寫給誰看的？**

**二、這一行不是衝流量，是養一年、成交一次。**
從第一次搜尋到簽約，中位數 3–12 個月。
所以要做「長期能被搜尋到的信任內容」，不是「打一波廣告」。

**三、真正的成交發生在試住，不在參訪。**
參訪只解決「乾不乾淨」，試住才解決「我媽會不會適應」。
沒有試住機制，等於把臨門一腳交給家屬自己想像。

**四、最強的廣告是現住民家屬的一句話。**
家屬最大的恐懼不是照顧不好，是「**我不知道裡面發生什麼事**」。
每月主動回報一次，比投十萬廣告有效。

## 七、幾條不能破的規矩

1. **絕不做療效宣稱**。治療、改善失智、延緩退化、醫療級 —— 一個字都不能寫。
2. **絕不承諾「保證入住」「保證有床」**。床位是動態的，承諾了補不上就是消費爭議。
3. **絕不把保證金／入住權包裝成投資**（保證返還、保證獲利、可轉售增值）。
   這可能踩到《銀行法》的非法吸金，是這一行**最貴的一條紅線**。
4. **沒有同意書的臉，一律不准出現在任何素材上。** 檔名沒有 `_已同意` 就是不能用。
5. **絕不用倒數逼單。** 把長輩送進機構是一個家庭最沉重的決定，急的是你，不是家屬。
6. **法規數字一律查證。** 本包內所有法規要點以 **2026-08** 查得為準，
   使用前請至 **law.moj.gov.tw**、**衛福部 mohw.gov.tw** 複核，或交法規窗口確認。

## 八、常見問題

**Q：一定要會寫程式嗎？**
不用。你只要會打開 Excel 填表，然後複製貼上一行指令。
其實不跑指令也能用 —— 直接跟小村說人話，他一樣會寫文案、給話術。

**Q：CSV 用 Excel 開會亂碼嗎？**
不會，全部用 utf-8-sig 存檔。但**存檔時請選「CSV UTF-8」**，別存成 Big5。

**Q：資料會傳到雲端嗎？**
不會。所有 CSV 都在你自己的電腦上，腳本不連網。
⚠️ 但請把資料夾放**本機碟，不要放 iCloud 桌面**（會有同步讀檔失敗的問題），
　 住民與家屬個資也不要放雲端共享資料夾。

**Q：小村可以幫我投廣告嗎？**
他負責寫素材、定策略；**花錢投放交給「小廣」**。
而且小村會擋你：Google 商家、官網費用表、LINE 自動回覆這三件沒做好之前，
投廣告等於把家屬帶到一個空屋。

**Q：我們是日照中心／長照機構，也能用嗎？**
可以，決策鏈、追蹤 SOP、內容矩陣完全通用。
但**服務類型的用字一定要改成你核准的類型**，這是紅線 1。

**Q：小村可以幫我送件、報備、申請立案嗎？**
**不行，也不該。** 那是要具名負責的事，永遠由人來做。
