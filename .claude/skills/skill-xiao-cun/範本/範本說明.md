# 範本說明

這個資料夾裡的檔案是**空白範本**，可以直接複製到你自己的工作資料夾去用。
（或者更省事：直接跑 `python3 scripts/villagemgr.py init --dir "./養生村資料"`，
　它會幫你在指定位置生一份新的。）

| 檔案 | 用途 | 誰維護 |
|:---|:---|:---|
| `0_機構資料卡.json` | **最重要**。所有文案的事實來源：立案字號、費用、人力比、收案條件 | 老闆／行銷窗口，每季複核 |
| `1_潛在名單.csv` | 每一通諮詢都要建一列。**「下次聯繫日」是靈魂欄位** | 接電話的人，當天填 |
| `2_參訪試住紀錄.csv` | 每一次參訪／試住的紀錄，重點是「最不放心的事」與「下一步」 | 帶看人，當天填 |
| `3_內容排程.csv` | 每月 20 則的排程與素材狀態 | 行銷窗口，每月初排 |
| `4_通路成效.csv` | 每月各來源的諮詢／參訪／試住／簽約數 | 行銷窗口，每月初填 |
| `肖像使用同意書.md` | 拍到臉就要簽。**請先給法務審閱** | 社工／行政 |

---

## 三個欄位絕對不能空

1. **`1_潛在名單.csv` 的「下次聯繫日」**
   → 空的就等於這個名單不存在。`check` 指令就是靠它每天叫你。

2. **`1_潛在名單.csv` 的「來源」**
   → 每一通諮詢都要問「請問你從哪裡知道我們的？」
   　 這一題決定明年的行銷預算怎麼花。

3. **`2_參訪試住紀錄.csv` 的「最不放心的事」**
   → 帶看結束一定要問：「你今天回去，最不放心的是哪一件事？」
   　 這些原話會變成下個月的內容題目（跑 `report` 會自動幫你統計）。

## 存檔注意

- CSV 全部用 **utf-8-sig**，Excel 和 Numbers 直接打開不會亂碼。
- **存檔時請選「CSV UTF-8」，不要存成 Big5。**
- ⚠️ 住民與家屬資料屬個人資料，**請放本機碟，不要放 iCloud 桌面或雲端共享資料夾**，
  也不要用個人 LINE 群組傳送。
