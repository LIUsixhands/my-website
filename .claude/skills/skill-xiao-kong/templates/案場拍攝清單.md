# 案場拍攝清單

> **沒拍「施工前」，將來就沒有前後對比，等於白做。**
> 資料夾命名：`年月_屋主姓_地區_屋型`（例：`202609_林_大安_三房舊翻新`）
> 固定四個子資料夾：`01_現況照`／`02_丈量`／`03_提案`／`04_施工紀錄`

## 01_現況照（丈量當天必拍，缺一不可）

- [ ] 大門外觀（**遮蔽門牌**）
- [ ] 玄關（從門口往內、從內往門口，各一張）
- [ ] 每個空間的**四個角**（將來要做前後對比，角度要能重現）
- [ ] 天花板（含樑位、管線、既有燈具）
- [ ] 地板（材質、破損處）
- [ ] 所有窗戶（開啟方式、外面看出去是什麼）
- [ ] 配電盤（**打開拍內部，含迴路標示**）
- [ ] 給排水管位置、水錶、瓦斯管路
- [ ] 冷氣室內機與室外機位置、既有管線路徑
- [ ] **所有漏水、壁癌、裂縫**（近拍＋遠拍定位，加比例尺物）
- [ ] 疑似結構牆（拍全景定位，供技師判讀）
- [ ] 公共區域（電梯、樓梯、走廊 —— 保護工程與押金依據）

## 02_丈量

- [ ] 每個空間的長寬高
- [ ] 樑深、樑寬、樑的位置
- [ ] 窗台高、窗寬、窗高
- [ ] 門洞尺寸
- [ ] 既有開關插座位置與高度
- [ ] 排水孔位置（衛浴、陽台、廚房）
- [ ] 手繪草圖一張（拍照存檔，比記憶可靠）

## 04_施工紀錄（每週回報的素材來源）

- [ ] **每週同一角度**拍同樣幾張（讓屋主看得出進展）
- [ ] 天花封板前的管線全記錄（**未來維修的救命資料**）
- [ ] 防水施作完成、試水
- [ ] 水電配管完成（含開關插座放樣膠帶＋屋主現場確認照）
- [ ] 隱蔽狀況發現當下（壁癌、管線老化、結構異常）→ 立即拍照通知
- [ ] 每次變更施作前後

## 交屋後

- [ ] 完工照（**需屋主書面授權才可用於作品集**）
- [ ] 授權範圍：可否露出行政區／可否錄影／可否標註案名
- [ ] 發布前檢查：門牌、地址、車牌、家人照片、可辨識個人物品 → 全部遮蔽或裁切
