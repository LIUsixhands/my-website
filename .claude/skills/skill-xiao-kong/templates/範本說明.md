# 範本使用說明

| 檔案 | 什麼時候用 | 誰填 |
|:---|:---|:---|
| `客戶資料卡.json` | **開案第一件事**。事務所段填一次終身用；本案段每案填一次 | 設計師 |
| `生活習慣訪談表.md` | 訪談當天＋訪談後 24 小時內 | 設計師（用屋主原話） |
| `設計需求確認書範本.md` | 訪談後產出，**屋主確認才開始設計** | 小空產草稿 → 屋主確認 |
| `追加減帳變更單.csv` | 任何「順便幫我做一下」發生的當天 | 設計師，屋主書面確認 |
| `案場拍攝清單.md` | 丈量當天＋每週施工回報 | 現場人員 |

## 順序

```
客戶資料卡 → 訪談表 → 設計需求確認書（屋主簽） → 提案 → 定案（屋主簽）
   → 施工（每週回報 + 變更單） → 預驗收 → 交屋 → 案例授權
```

## 兩個鐵律

1. **「必須」項目不超過 5 項，而且由屋主自己排序。**
2. **沒有書面確認的追加，等於免費。** 一律走 `spacemgr.py change`。

## ⚠️ 存放位置

專案資料夾請放**本機碟**，不要放 iCloud 桌面（同步會造成腳本讀檔失敗）。
屋主平面圖、地址、門牌屬個人資料，備份與交付前先確認去識別化。
