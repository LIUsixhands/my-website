# 空間規劃知識庫 —— 動線、尺寸、收納、光

> ⚠️ 本表是**設計常用參考值**，用來檢核「配置合不合理」，不是法規值。
> 涉及法定尺寸（樓梯、避難、無障礙、防火區劃）以《建築技術規則》與主管機關為準；
> 涉及結構、消防、機電，回到技師（紅線 2、3）。

## 一、動線（三軸檢核之一）

| 動線 | 建議淨寬 |
|:---|:---|
| 主動線（玄關→客餐廳→房間） | 90–120 cm |
| 次動線（房內、櫃前） | 70–80 cm |
| 單人側身通過（極限） | 55–60 cm |
| 單排廚具前 | 90–110 cm |
| 雙排／中島廚具之間 | 100–120 cm（<90 兩人會撞） |
| 餐椅拉開（不通行） | 75–90 cm |
| 餐椅拉開＋後方要通行 | 105–120 cm |
| 床邊 | 至少 60 cm，舒適 70–90 cm |
| 衣櫃／書櫃門片開啟前 | 櫃深 + 60 cm |
| 輪椅通行（有長輩需求時） | 直行 90 cm 以上，迴轉直徑 150 cm |

**動線檢核四問**：
1. 有沒有「必須穿越某個機能區才能到另一個區」？（例：穿過餐廳才能進主臥 → 高機率被抱怨）
2. 早上尖峰時段，有幾個人同時在同一條動線上？（玄關、衛浴）
3. **家事動線**：洗 → 晾 → 摺 → 收，這四步走幾公尺？超過三個轉折就要重想。
4. 買菜進門到冰箱，要繞多遠？

## 三、收納量體（三軸檢核之三）

**不要問「收納要不要多」，要算「量」。**

| 物件 | 估算方式 |
|:---|:---|
| 鞋 | 每 100 cm 寬層板約放 5–6 雙／層。40 雙 ≈ 需 7–8 層 × 100 cm |
| 衣物吊掛 | 成人每人 90–120 cm 吊桿寬（大衣多的再加） |
| 棉被／季節寢具 | 每組約 60 × 60 × 40 cm 的空間 |
| 行李箱 | 每個約 45 × 30 × 75 cm，須留高櫃或儲藏室 |
| 大型物（嬰兒車／露營／腳踏車） | **一定要指定固定位置**，否則會長期占用玄關或客廳 |

**收納率參考**：住宅收納空間投影面積約占室內面積 **10–12%**。
低於 8% → 幾乎一定會亂；高於 15% → 檢查是不是犧牲了活動空間。

**收納三原則**：
1. **就近原則**：東西收在「會用到它的地方」，不是收在「有空位的地方」。
2. **一動作原則**：常用物品要能一個動作拿到（不用先移開另一個東西）。
3. **留白 20%**：新家收納若一開始就塞滿，兩年後必爆。

## 四、光

| 空間 | 建議照度 | 色溫 |
|:---|:---|:---|
| 客廳（環境光） | 100–300 lux | 2700–3000K |
| 餐桌 | 300 lux 左右 | 2700–3000K（食物顯色好） |
| 廚房工作面 | 500 lux | 4000K |
| 書桌／閱讀 | 500–750 lux | 4000–5000K |
| 臥室 | 100–150 lux | 2700K |
| 衛浴鏡前 | 300–500 lux，**光要打在臉上，不是頭頂** | 3000–4000K |

**照明三層**：
① 環境光（整體亮度）② 任務光（工作面）③ 情境光（間接、洗牆、重點照明）
只有第①層 = 像辦公室。三層都有 = 有氛圍。

**採光檢核**：
- 白天不開燈能不能活動？暗的是哪幾個位置？
- 新增的隔間有沒有把唯一的窗擋掉？（改格局最常見的災難）
- 西曬牆面：夏天的體感與冷氣成本，要提前跟屋主講。

## 五、平面配置的常見錯誤（Checklist）

- [ ] 冰箱門打開會不會擋住走道／撞到牆？（開門側預留 5–10 cm）
- [ ] 房門開啟會不會撞到床、櫃、另一扇門？
- [ ] 衛浴門正對餐桌或床頭？（不談風水，談使用感受與氣味）
- [ ] 洗衣機位置到晾曬區要走幾公尺、經過幾個門？
- [ ] 有沒有「只能側身通過」的地方？
- [ ] 電視牆與沙發的距離是不是因為要放櫃子而被壓縮？
- [ ] 主臥有沒有留下**未來可能加嬰兒床／護理床**的空間？
- [ ] 開放式廚房 + 高頻率煎炒 → 油煙問題有沒有解？
- [ ] 每個房間至少有一支獨立照明開關在門口？
- [ ] 大型家電（洗烘、冰箱、掃地機器人基座）都有指定位置與插座？
- [ ] 空調室內機出風有沒有直吹床頭或沙發？室外機位置與管線路徑有沒有確認？
- [ ] 有沒有任何一項規劃需要動到牆、樑、樓板？→ **停，回紅線 2**

## 六、屋型常見課題速查

| 屋型 | 主要課題 | 常用解法方向 |
|:---|:---|:---|
| 老公寓（30 年以上） | 管線老化、壁癌、格局零碎、無電梯 | 水電全換、防水重做、打開公共區、儲物集中 |
| 小坪數（15 坪以下） | 收納與空間感衝突 | 垂直收納、複合機能、統一色調、減少實體隔間 |
| 狹長型 | 中段暗、通風差 | 透光隔間、天井式配置、把公共區放採光面 |
| 樓中樓／夾層 | 淨高、法規、樓梯位置 | 淨高優先、樓梯不擋光、確認夾層合法性（→ 紅線 1） |
| 毛胚／新成屋客變 | 決策時間壓力大 | 先定水電與格局（不可逆的先做決定），表面後談 |
| 商業空間 | 法規、消防、動線與坪效 | **供公眾使用建築物 → 必查裝修審查（紅線 1、3）**；坪效與客動線優先 |
