# 空間設計・法規與廣告紅線

> 用途：小空在產出任何**對外文字**（提案、報價、合約附件、廣告、貼文、簡報）前，
> 必須逐句對照本表。發現紅字 → 換成「安全寫法」欄的句子。
>
> ⚠️ 本文件是**行銷與溝通用的避雷指引**，不是法律意見。
> 個案是否需申請、能不能施作，一律以主管建築機關、開業建築師與相關技師的認定為準。
> 涉及爭議與求償 → 轉 `skill-xiao-bian`（小辯）。

## 一、室內裝修審查（最容易出事的一條）

**法源概念**：《建築法》第 77 條之 2 — 供公眾使用建築物之室內裝修應由內政部登記許可之室內裝修從業者辦理；
圖說應先送主管建築機關或審查機構審核，施工完成後應申請竣工查驗合格。
非供公眾使用建築物是否納入，依內政部指定範圍與各地方政府規定。

| ❌ 絕不能寫 | ✅ 安全寫法 |
|:---|:---|
| 「住家不用申請啦」 | 「本案是否須辦理室內裝修審查，以案場所在地主管建築機關認定為準。」 |
| 「我們有辦法讓它過」 | 「如需辦理，由具室內裝修業登記資格之單位及開業建築師／專業技術人員辦理送審。」 |
| 「保證審查通過」 | 「送審由專業單位辦理，審查結果由主管機關決定；如需補正，補正作業由我方協助。」 |
| 「先做再說，被抓再處理」 | **不寫。這句話本身就是把客戶推進罰則。** |

**小空的固定動作**：任何案子第一次對話，就要問清楚三件事並記進客戶資料卡——
① 建物用途（住宅／店面／辦公／其他）② 是否為供公眾使用建築物 ③ 大樓管委會的裝修規約與押金規定。

## 二、結構安全（拆牆、開口、樓板）

**原則**：主要構造（承重牆、剪力牆、樑、柱、樓板、外牆）一律**預設不能動**。

| ❌ 絕不能寫 | ✅ 安全寫法 |
|:---|:---|
| 「這面牆可以打掉」 | 「此牆是否為結構牆，須調閱原始結構圖並經結構／土木技師確認後始得評估。」 |
| 「開個窗沒問題」 | 「開口位置與尺寸須由技師評估並提出補強方式。」 |
| 「樓板加高沒差」 | 「增加載重（如浴缸、水池、大量磚材、書牆）須先評估樓板載重。」 |
| 「保證不會裂」 | 「新舊介面、輕隔間交接處可能因熱脹冷縮或建物沉降產生細微裂縫，屬正常現象，保固範圍見合約第 X 條。」 |

## 三、消防與防火材料

| ❌ 絕不能寫 | ✅ 安全寫法 |
|:---|:---|
| 「消防一定過」 | 「消防安全設備與裝修材料等級，依主管機關核准圖說施作。」 |
| 「用這個板子防火沒問題」 | 「使用具耐燃／防焰合格證明之材料，證明文件於施工前提供。」 |
| 「窗簾隨便挑就好」 | 供公眾使用場所之地毯、窗簾、布幕等應使用**防焰物品**並具標示。 |

## 四、3D 圖 / 示意圖（客訴第一名）

**強制標註**（每一張對外的透視圖、情境圖、AI 生成參考圖都要有）：

> 示意圖僅供空間感受參考。實際材質紋理、色差、五金樣式、燈光色溫、家具尺寸與比例，
> 以合約圖說、建材樣板及實際到貨品項為準。

| ❌ 絕不能寫 | ✅ 安全寫法 |
|:---|:---|
| 「完工就長這樣」 | 「完工後的空間感與此圖一致，材質與色彩以樣板為準。」 |
| AI 圖不標示，混在作品集裡 | AI 圖必標「風格參考圖（AI 生成），非本公司實際完工案例」。 |
| 用同業／圖庫照當實績 | **只放自己施作的案子。** 屋主完工照須取得書面授權，並遮蔽門牌與可識別個資。 |

## 五、報價與追加減帳

**原則**：住宅裝修受內政部公告之「住宅室內裝修工程定型化契約應記載及不得記載事項」規範，
付款方式、驗收、保固、遲延責任、變更程序須符合規定；契約條款爭議 → 小辯。

| ❌ 絕不能寫／做 | ✅ 安全做法 |
|:---|:---|
| 「一坪 X 萬起」旁邊沒有含項說明 | 公開任何價格，必須同時寫**含什麼、不含什麼**。 |
| 口頭答應「這個順便幫你做」 | 一律開**書面變更單**（項目／單價／數量／金額／工期影響／雙方確認）。 |
| 「不會再有追加了」 | 「本報價依現況可見範圍估算；拆除後如發現壁癌、管線老化、結構異常等隱蔽狀況，將另開變更單經您確認後施作。」 |
| 「保證如期完工」 | 「預計工期 XX 個工作天，不含假日、天候因素、政府停工、建材缺料及變更追加所生之展延。」 |

**常見「不含項」清單**（報價單一定要列）：
拆除清運、公共區域保護工程、大樓管理費與裝修押金、電梯使用費、冷氣主機與安裝、
家電、活動家具、窗簾、燈具、油漆以外的表面處理、細清、垃圾清運、假日／夜間施工加成、
消防與裝修送審規費、水電外線與管制申請。

## 六、建材與健康宣稱

| ❌ 絕不能寫 | ✅ 安全寫法 |
|:---|:---|
| 「零甲醛」「無毒」 | 「使用符合 CNS 2215 F☆☆☆☆ 等級板材，檢測報告可提供。」 |
| 「保證不長壁癌」 | 「已施作防水／除壁癌工法，惟外牆滲漏、頂樓漏水等非本工程範圍之因素不在保固內。」 |
| 「終身保固」 | 「保固期 X 年，範圍為本工程施作項目之施工瑕疵；不含正常使用磨耗、他人後續施作、不可抗力。」 |
| 「絕對防水」 | 「防水施作範圍為 XX，保固 X 年。」 |

> 無法出示依據的效能／健康宣稱，可能涉《公平交易法》第 21 條不實廣告。

## 七、風水

- 屋主提風水，**只做設計回應，不做吉凶斷言**。
- ✅「開門見灶的疑慮，我們可以用一道半高櫃或玻璃隔屏處理，同時剛好幫你增加 X 尺收納。」
- ❌「這樣擺會漏財」「這個方位不好會影響健康」。
- 若屋主堅持配合特定老師，**請屋主提供書面指示**，並註記「依業主指定之堪輿意見調整，本公司不對其效果負責」。

## 八、個資與隱私

- 屋主的**地址、門牌、平面圖、家庭成員狀況、預算**皆屬個人資料，不得對外揭露或作為行銷素材。
- 案例分享一律：取得**書面同意** → 去識別化（不寫完整地址，只寫行政區）→ 遮蔽門牌車牌。
- 案場照片中若拍到鄰居門戶、住戶車輛，發布前必須裁切或遮蔽。
