# SOP 02｜增員名單開發

## 鐵律：名單不是「有沒有」的問題，是「敢不敢開口」的問題
漏斗卡在「接觸數」的人，九成不是沒名單，是**開不了口**。
開不了口通常是因為第一句話設計錯了 —— 你把它設計成「來做保險」。

## 一、六個來源（依成本由低到高）

| 來源 | 怎麼來 | 第一句話怎麼設計 |
|:---|:---|:---|
| **緣故** | 手機通訊錄、同學、前同事 | 不談工作，先談近況。第二次見面才提 |
| **舊客戶** | 服務過、理賠陪過的人 | 「你身邊有沒有正在想轉換的人？」先問轉介，不直接問他本人 |
| **轉介** | 客戶／同業／異業朋友介紹 | 讓介紹人先講一句你是誰，比你自我介紹十句有用 |
| **異業交流** | 商會、社團、家長群 | 先當那個「有問題可以問的人」，半年後才有增員的資格 |
| **社群** | 用內容吸引，不用私訊轟炸 | 內容找 `skill-xiao-an`（小安）產，小增只接手已經舉手的人 |
| **同業** | 主動或被動接觸 | 🚨 開場第一句就要講：「名單不要帶過來，那不是你的。」 |

## 二、接觸的三段式（不要一次講完）

**第一次｜只問近況，不談工作。**
目的只有一個：確認他現在的狀態。有沒有痛？痛在哪？
> 「最近工作還順嗎？」「你做這個幾年了？」「如果三年後還是這樣，你 OK 嗎？」
結束前不要提保險，也不要提機會。**忍住。**

**第二次｜給他一個「不用承諾的下一步」。**
> 「我最近在幫單位找人，可是我不太想找那種被說服才來的。
> 你要不要來聽一場，聽完覺得不適合就算了，我保證不追你。」
關鍵是「**我保證不追你**」—— 而且要真的做到。

**第三次｜才是面談。** 見 `增員面談與評估SOP.md`。

## 三、名單管理
每個人一列填進 `templates/增員名單表.csv`，跑：
```bash
python3 scripts/zeng.py pipeline 增員名單表.csv
```
會告訴你：階段分布、哪個來源真的變成人、**誰超過 30 天沒動作**。

> 超過 60 天沒接觸的名單，基本上等於重新開始。
> 與其硬追，不如換一個純問候、完全不談工作的接觸。

## 四、🚨 不要做的四件事
1. 群發訊息。轉換率極低，而且會燒掉你的社群形象。
2. 買名單、交換名單。個資法問題，而且品質是零。
3. 對同一個人連續追三次以上。他說不要就是不要，記錄下來，半年後再說。
4. 用「聚餐」「創業說明」等模糊名義騙人來聽招募說明會 —— 那叫不實揭示。
