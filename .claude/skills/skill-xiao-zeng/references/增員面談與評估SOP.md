# SOP 04｜三次面談法與評估

## 原則
**第一次聽，第二次攤，第三次讓他自己決定。**
一次面談就要人點頭的，留不住。

---

## 第一次面談｜只問，不推（60 分鐘，你講不超過三成）

八個問題，照順序問，逐字記在 `templates/面談評估表.json` 的「他自己說的話」：

1. 你現在的工作，做幾年了？
2. 當初為什麼做這個？
3. 現在最讓你想改變的是什麼？（**聽是「逃離」還是「想要」**）
4. 如果三年後還是這樣，你可以接受嗎？
5. 你身邊有沒有人做過業務？你看到的是什麼？
6. 家裡的人知道你在想這件事嗎？他們會怎麼說？
7. 如果接下來三個月完全沒有收入，你的生活會怎樣？
8. 你想從我這裡知道什麼？

> 第 7 題是全場最重要的一題。他的答案決定他能不能被報聘，
> 而且要**現在問**，不是等他辭職以後才發現。

結束時只說一句：「你回去想，我下次把難的部分講給你聽。」

---

## 第二次面談｜攤開誠實揭露包（這場會篩掉一半，這是好事）

```bash
python3 scripts/zeng.py disclose 招募主管資料卡.json
```
九項全部攤開：契約性質、報酬結構、底薪或津貼、考核、自付成本、勞健保、
本單位新人存活實況、前三個月典型收入、以及**四句不可修飾的話**。

🚨 這一場禁止做的事：
- 不要在他猶豫時加碼講好處
- 不要說「別人都可以你為什麼不行」
- 不要現場給截止期限（「這期訓練班最後一梯」）
- 不要單獨對他的配偶／家人施壓

他猶豫是對的。**猶豫過的人留得比較久。**

---

## 第三次面談｜由他講，你聽

問三題就好：
1. 你想清楚的是什麼？
2. 你還不確定的是什麼？
3. 你打算怎麼跟家人講？

然後跑評分：
```bash
python3 scripts/zeng.py score 面談評估表.json
```

## 評分七維度與硬性門檻

| 維度 | 權重 | 在看什麼 |
|:---|:--|:---|
| 動機真實性 | 20 | 逃離 vs 想要 |
| **財務緩衝** | 20 | 沒收入能撐幾個月 |
| 人際存量 | 15 | 願意接他電話的人（不是好友數） |
| 學習與抗壓 | 15 | 被拒絕後多久回得來 |
| 家庭支持 | 10 | 另一半知不知道、支不支持 |
| 時間投入 | 10 | 每週真的拿得出多少小時 |
| **誠信紀錄** | 10 | 門檻項，不是加分項 |

**四條硬性門檻（分數再高也停）**
1. 誠信 ≤2 → 直接停止
2. 財務緩衝 ≤1（撐不到 3 個月）→ 現在不報聘
3. 家庭明確反對 → 先安排家屬在場的說明
4. 動機只有「逃離現職」→ 再談一次

## 🚨 評估表不可以寫的東西
年齡、性別、婚姻狀況、容貌、五官、身心障礙、星座、血型、家族病史、信用紀錄。
那些是就業歧視事由與隱私資料，寫上去就是證據。
評分結果是**內部參考**，不得作為對外的錄取／不錄取理由。
