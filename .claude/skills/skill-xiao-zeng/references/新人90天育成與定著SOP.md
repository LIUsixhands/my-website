# SOP 07｜新人 90 天育成與定著

## 一句話
**前 90 天只考核活動量，不考核業績。**
業績是結果，活動量才是能被教、能被練、能被陪的東西。

```bash
python3 scripts/zeng.py plan90 --name 阿凱 --start 2026-09-15
```

## 週次骨架
| 週 | 主題 | 關鍵動作 |
|:--|:---|:---|
| 1 | 報到與心理契約 | 再走一次誠實揭露包；一起寫下「什麼情況我會離開」 |
| 2 | 工具與制度 | 系統實際走一次；合規訓練（不實告知的後果） |
| 3 | 名單盤點 | 100 個名字，先寫完再篩；同業轉入者 🚨 明確禁帶原公司名單 |
| 4 | 第一次陪訪 | 主管親自 ≥3 件，前 2 件主管講他看 |
| 5 | 他主講 | ≥3 件，主管只補充 |
| 6 | **第一次挫折** | 主管**主動**打那通電話，不要等他來說 |
| 8 | 轉市場預告 | 提早講：緣故會用完，第 4 個月要有新來源 |
| 10 | 獨立作業 | 主管退到事前沙盤＋事後覆盤 |
| 12 | 90 天覆盤 | 三方對齊（含家人）；誠實對照「當初講的 vs 實際拿到的」 |

## 主管的三個不可外包
1. **陪訪** —— 前 6 週不能只丟給資深同事。
2. **那通電話** —— 他被連續拒絕之後的那一通，主動打。
3. **誠實** —— 收入不好就說不好。新人分辨得出你在粉飾。

## 兩個死亡點
**第 6 週｜第一次連續被拒。**
症狀：回報變少、開始說「我在整理名單」。
治本：主管主動出現，陪跑兩件，讓他看到「被拒絕之後還是有下一件」。

**第 4-6 個月｜緣故名單燒完。**
症狀：活動量斷崖，開始接觸「不熟的熟人」。
治本：**第 3 個月就要開始練陌生／轉介的固定動作**，不要等他斷糧才教。

## 定著追蹤
每月更新 `增員名單表.csv` 的階段與脫落欄位，然後：
```bash
python3 scripts/zeng.py retention 增員名單表.csv
```
會給你：留存率、死在第幾個月的分布、脫落原因統計。

> 🚨 脫落原因要**問離開的人本人**，不要用主管的猜測填。
> 猜出來的原因，會讓你一直修錯的地方，然後下一個人用一模一樣的方式離開。

## 離職面談（很少人做，但這是整條線最便宜的情報）
三題，不辯解、不挽留：
1. 什麼時候開始覺得做不下去的？
2. 當初聽到的跟實際上，差最多的是哪一件事？
3. 如果我早一點做什麼，你會不會留下來？

第 2 題的答案，直接拿回去改你的誠實揭露包。
