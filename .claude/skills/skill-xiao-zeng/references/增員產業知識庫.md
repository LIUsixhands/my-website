# 增員產業知識庫（名詞與常識）

> 🚨 本頁只解釋**名詞與運作邏輯**，不記載任何費率、比率、金額、時數、期限。
> 那些數字各公司不同、且會修訂，一律以所屬公司與主管機關公告為準。

## 一、身分與資格
| 名詞 | 意思 | 增員時要注意 |
|:---|:---|:---|
| **登錄** | 業務員須經所屬公司向公會辦理登錄，取得資格後始得招攬 | **未登錄不得招攬**，這是增員第一條界線 |
| **資格測驗** | 人身保險業務員測驗（壽險公會）；產險另有其測驗 | 依他要賣什麼決定要考哪幾張，先問公司 |
| **附加資格** | 如投資型保險商品、外幣收付非投資型保險商品等 | 通常有先後順序，不要一次全排 |
| **教育訓練與換證** | 登錄後有持續教育訓練與換證規定 | 到職時就要講清楚，不是之後才發現 |
| **保經代** | 保險經紀人／代理人公司 | 與保險公司業務員的登錄與審查主體不同 |

## 二、契約與報酬
| 名詞 | 意思 | 增員時要注意 |
|:---|:---|:---|
| **承攬制** | 多數保險業務員的契約性質，非僱傭 | **沒有底薪、沒有公司投保勞健保**是常見事實，要誠實講 |
| **僱傭制** | 少數單位或特定職位採用 | 若是僱傭，薪資揭示規定要遵守 |
| **初年度佣金（FYC）** | 第一年保費對應的報酬 | 不得用來反推「你可以賺多少」當招募誘因 |
| **續年度服務津貼** | 後續年度的報酬 | 🚨 不是「被動收入」，須持續服務並符合制度才有 |
| **新人津貼／輔導金** | 部分單位提供，有條件與期限 | 條件、期間、未達成的後果，三項都要寫進揭露包 |
| **考核** | 週期性業績或活動量門檻 | 沒達成的後果要講明白（例如降級、解約） |

## 三、增員漏斗的語彙
名單 → 接觸 → 約談 → 說明會出席 → 深度面談 → 報聘 → 考取 → 到職 → 滿 3 月 → 滿 13 月

- **報聘**：決定加入、送出聘任文件的那一刻
- **13 個月定著**：業界最常用的留存指標之一，因為它跨過了「緣故燒完」與「第一次續期」
- **脫落**：到職後離開。要記**第幾個月**離開，不只是記「走了」

## 四、增員最常見的三個錯誤認知
1. **「先進來再說，做不做得起來看他自己。」**
   → 這句話的成本是：他的機會成本、你的訓練時間、以及他對整個行業的印象。
2. **「增員件數就是績效。」**
   → 增員件數容易衝，13 個月定著衝不了。看後者。
3. **「講太白會沒人來。」**
   → 前段會變窄，後段會變寬。跑 `zeng.py funnel` 看的是後段。
