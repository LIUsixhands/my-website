# 招募文案模板庫（合規版）

> 每一則都設計成可以通過 `zeng.py check`。
> 但**通過掃描 ≠ 可以發** —— 對外前仍須經所屬公司／保經代文宣審查核可。
> 括號 ______ 的地方要填真實資料，填不出來就不要發。

---

## A. 社群貼文｜誠實型（最推薦）

```
我在幫單位找人，但我想先講難的那一半。

這份工作是承攬性質，收入不固定，可能連續幾個月是零。
有考核制度，沒達成會有後果。有些成本要自己出：______、______。
我這個單位近一年進來 ___ 個人，滿三個月的是 ___ 個。

我不會保證你的收入，也不會保證你考得上。
我不收任何費用，也不扣留你的證件。
如果你現在有工作，我會建議你先不要離職。

如果看到這裡你還想聊，我請你喝杯咖啡，聽聽你現在卡在哪裡。
聊完不適合就算了，我保證不追你。

______（姓名）｜______（公司全名）　登錄字號 ______
```

---

## B. 一對一訊息｜緣故第一次接觸（不談工作）

```
Hey，最近好嗎？好久沒聊了。
你那邊工作還順嗎？前陣子想到你，就想說問一下。
哪天有空吃個飯？沒事，就純聊。
```
> 🚨 第一次不要提保險、不要提機會、不要提說明會。忍住。

---

## C. 一對一訊息｜第二次（給不用承諾的下一步）

```
上次聊完我一直在想你講的那件事。

我最近在幫單位找人，不過我不太想找那種被說服才來的。
______（日期）有一場職涯說明會，你要不要來聽？
會講這行實際在做什麼，也會講難的部分——收入不固定、有考核、有些錢要自己出。
聽完覺得不適合就算了，我保證不追你，也不收任何費用。
```

---

## D. 說明會邀約卡（合規必要元素）

```
【職涯說明會】______ 公司 ______ 單位
時間：______　地點：______
內容：這個行業實際在做什麼／報酬結構與考核制度／要自己負擔的成本／Q&A
・本場為招募說明會，不收取任何費用、不扣留任何證件。
・收入依個人業績與公司制度而定，可能為零。
・是否錄取、能否通過測驗與登錄，依相關規定辦理。
主辦：______（姓名）　登錄字號 ______
```

---

## E. 同業接觸開場（一定要有的第一句）

```
先講一件事：如果你真的過來，名單不要帶。
你原公司的客戶名單不是你的，帶過來對你、對客戶、對我都是風險。
也不要動你原本客戶的保單——解約重買是害他，不是幫他。

如果這樣你還願意聊，我們再談制度跟訓練。
```

## 🚫 禁用詞速查
保證收入／月入○萬／年薪百萬／收入穩定／被動收入／睡後收入／下線／組織倍增／
不用業績／沒有壓力／時間自由／在家就能／輕鬆／包教包會／
限男女／年齡○○／形象佳／星座血型／保證金／押證件／
名單帶過來／解約重買／退佣／先掛我這邊／先辭再說
