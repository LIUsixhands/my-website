# SOP 06｜考照與報聘輔導

> 🚨 小增**不背數字**：測驗梯次、報名費、及格標準、登錄與換證規定、教育訓練時數，
> 全部以各公會、主管機關與所屬公司**當期公告**為準。
> 這一頁只講「流程怎麼帶、哪裡會掉人」。

## 一、他要考什麼（先問公司，不要用猜的）
一般人身保險業務的起點是**人身保險業務員資格測驗**（壽險公會辦理）。
依他未來要銷售的商品，可能另需其他資格，例如投資型保險商品、外幣收付非投資型保險商品等；
若涉及產險商品，另有產險業務員資格。

📌 到職前必問公司三題（填進資料卡）：
1. 我要考哪幾張？順序是什麼？
2. 報名費誰出？如果沒過，重考費誰出？
3. 從考取到完成登錄，通常要多久？

## 二、時程管理（掉人最多的一段）
| 節點 | 主管要做的事 | 常見死因 |
|:---|:---|:---|
| 決定報聘 → 報名 | **當週就報名**，不要等下一梯 | 拖到下梯，熱度冷掉 |
| 準備期 | 指定每週進度＋每週回報一次 | 「你自己看書」＝沒人看書 |
| 考前一週 | 模擬測驗一次，抓弱章節 | 第一次就落榜，信心崩 |
| 考取 → 登錄 | **兩週內完成**，中間不要空窗 | 空窗越久掉越多 |
| 登錄完成 | 第一天就排陪訪 | 「先熟悉環境」＝空轉一個月 |

跑 `zeng.py funnel`，如果卡在「考取」或「到職」，問題就在這張表。

## 三、三條紅線
1. **未完成登錄前不得招攬、不得收件。**
2. **不得掛件、借牌**（「你先掛我這邊做」）—— 這是撤登錄等級的違規，兩個人一起賠。
3. **不得代考、不得提供試題、不得保證考取。**

## 四、還沒考到之前，他可以做什麼
- 跟著陪訪（只看、不談、不收件）
- 整理自己的人際盤點（100 個名字）
- 讀商品與條款、練自我介紹
- 参加公司內部訓練

## 五、如果他落榜
第一句話不要說「沒關係下次再來」，那等於宣告這件事不重要。
✅ 說法：「我們看一下哪幾章掉分，這週補完，下一梯報名我幫你送。」
**當場把下一梯報名日期寫進行事曆。**
