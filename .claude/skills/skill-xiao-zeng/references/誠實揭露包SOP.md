# SOP 05｜誠實揭露包（小增的招牌）

## 一句話
**把難的話講在前面，留下來的人才會留得久。**

增員最大的成本不是找不到人，是**找到了、進來了、三個月走了**。
那三個月裡，主管的時間、公司的訓練資源、他的人生，全部沉沒。
而幾乎每一次，離開的理由都是同一句：「跟我當初聽到的不一樣。」

誠實揭露包就是把「當初聽到的」跟「實際是什麼」對齊。

## 九項欄位（填在 `templates/招募主管資料卡.json`）
1. 公司全名
2. 契約性質（承攬／僱傭）
3. 報酬結構（初年度／續年度／獎金項目／發放時點）
4. 底薪或新人津貼（金額、期間、條件、未達成會怎樣）
5. 考核制度（週期、標準、未達成的後果）
6. 自付成本（證照報名費、訓練、交通、通訊、名片、加保管道，**逐項列金額**）
7. 勞健保與退休金安排
8. 本單位新人存活實況（近一年到職幾人／滿 3 個月幾人／滿 13 個月幾人）
9. 前三個月典型收入區間（**含有幾人是 0**）

```bash
python3 scripts/zeng.py disclose 招募主管資料卡.json
```
任何一欄是「待補」，指令會擋下來。**去問你的主管與教育訓練單位，不要自己估。**

## 四句不可修飾的話（逐字講）
1. 這份工作的收入不是固定的，可能連續幾個月是零。
2. 是否錄取、是否登錄、是否通過考試，都不是我能保證的。
3. 我不會向你收任何保證金、報名費，也不會扣留你的證件。
4. 你如果現在有工作，我建議你先不要離職。

## 什麼時候攤開
**第二次面談。** 不是報聘後，不是到職後，更不是他問了才講。

## 常見反對意見（來自主管，不是來自增員對象）

> 「講這麼白，誰還敢來？」

會少 —— 但少掉的是本來就會在三個月內走的人。
你的漏斗前段會變窄，**後段（滿 3 月、滿 13 月）會變寬**。
跑 `zeng.py funnel` 看的是後段，不是前段。

> 「別家都沒這樣講。」

那正是你可以講的話：
「你可以去別家聽聽看。如果有人跟你保證收入，你就知道那句話的重量。」
