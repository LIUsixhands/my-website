# 小增範本說明

| 檔案 | 什麼時候用 | 配哪個指令 |
|:---|:---|:---|
| `招募主管資料卡.json` | **第一次見面就填**，九項誠實揭露欄位 | `zeng.py disclose` |
| `增員名單表.csv` | 每個增員對象一列，階段變了就改 | `zeng.py pipeline` / `retention` |
| `增員漏斗表.csv` | 每月月底填一列數字 | `zeng.py funnel` |
| `面談評估表.json` | 每次深度面談後填 | `zeng.py score` |
| `誠實揭露包範本.md` | **第二次面談就攤開**，不是報聘後才講 | `zeng.py disclose` 產草稿後填 |
| `新人90天育成計畫範本.md` | 到職當天給 | `zeng.py plan90` |
| `合規送審檢核表.md` | 任何招募文案交出去前 | `zeng.py check` |

## 🚨 三件事
1. 這些檔案含**求職者個資**（現職、家庭、財務狀況）。放本機碟，不要放 iCloud 桌面，不要丟進任何群組。
2. 未錄取者的資料，依當初告知的保存期間定期銷毀。
3. 評估表不得記載年齡、性別、婚姻、容貌、星座、血型 —— 那些是就業歧視項目，寫上去就是證據。
