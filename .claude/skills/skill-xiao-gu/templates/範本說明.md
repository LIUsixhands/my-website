# 範本說明

| 檔案 | 什麼時候用 | 給誰看 |
|:---|:---|:---|
| `顧問資料卡.json` | 第一次啟用小顧就要填 | 只給小顧看 |
| `客戶資料卡.json` | 每個客戶一份，面談後補齊 | 內部 |
| `保單盤點表.csv` | 收到客戶保單後逐張登錄 | 內部 |
| `保障缺口報告範本.md` | 產建議書草稿的骨架 | **送審後**才給客戶 |
| `解約損失揭露單.md` | 只要動到既有保單就要附 | 客戶簽名 |
| `面談紀錄表.md` | 面談後 24 小時內填 | 內部 |
| `送件追蹤表.csv` | 理賠送件時建立 | 內部 |
| `合規送審檢核表.md` | 每份對外文件都附一張 | 送審用 |

⚠️ 客戶資料含病史、健康檢查等**特種個人資料** ——
放本機碟、不放 iCloud 桌面與公開雲端，個案一律去識別化（客戶A、先生32Y），
不要寫本名、身分證字號、病歷號、保單號全碼。
