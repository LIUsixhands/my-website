# 顧問合規紅線與改寫對照表

> 用法：寫完任何要給客戶看的文字 → 跑 `python3 scripts/gu.py check <檔案>` → 紅字全清 → 再對照本表人工複看一次。
> ⚠️ 法規條號會修訂，本表一律以**規則名稱＋規範內容**表述，最新規定以主管機關與所屬公司法遵單位公告為準。

---

## 一、七大類禁區

| 類別 | 為什麼 |
|:---|:---|
| **保證報酬／保本／穩賺** | 對保險商品之報酬、給付為誇大不實表示，屬業務員管理規則明定之懲處事由 |
| **存款代稱**（儲蓄險／定存／利息／幫你存） | 主管機關禁止以易使人誤認為存款之名詞行銷保險 |
| **停售逼單／限時／最後一張** | 以停售製造搶購，為主管機關長期列管之不當招攬態樣 |
| **保證理賠／一定賠／什麼都賠** | 理賠認定屬保險公司權責，顧問無權下結論 |
| **保證節稅／免遺產稅** | 稽徵機關得依實質課稅原則個案認定，另有最低稅負制規定 |
| **勸誘解約轉保（churning）** | 使客戶損失既有保障與保價金、重新起算等待期，屬明定懲處事由 |
| **指名商品比較／跨公司比較表／費率試算** | 屬招攬廣告，須送審；且業務員自製比較資料風險極高 |

## 二、改寫對照表（顧問版）

| ❌ 常見講法 | ✅ 合規改寫 |
|:---|:---|
| 這張保證領回 | 依保單條款約定之給付項目辦理 |
| 比定存好／利息比銀行高 | （整句刪除，不與存款比較） |
| 儲蓄險 | 人壽保險／年金保險／利率變動型保險商品 |
| 年報酬率 ○% | 宣告利率／預定利率（**不等於報酬率**），且可能變動 |
| 這張最完整、CP 值最高 | 保障內容與保費依年齡、體況、商品規則而異，以核保結果為準 |
| 這個一定賠 | 是否符合理賠要件，以保單條款約定及保險公司核定為準 |
| 保險金免稅、不列入遺產 | 稅務效果因個案而異，以稽徵機關及會計師／稅務專業人員意見為準 |
| 舊的解掉買新的比較划算 | 調整前請一併考量：解約金低於已繳保費、保障空窗、等待期重算、既往症除外、年齡加費（**逐項列出**） |
| 這個不用告知啦 | 請據實告知，由核保判斷；不確定的一律寫上去 |
| 這張快停售了要快 | ○年○月起本類商品投保條件將調整，如需了解可與我聯繫 |
| 我幫你簽就好 | 要保書與健康告知須由本人親簽 |

## 三、每份對外文件必備的四段揭露

1. 本文件為**需求面教育性分析**，非投保建議，亦非精算或稅務意見。
2. 所有金額均基於文中列示之**假設**，假設變動結果即不同。
3. **是否承保、加費或除外，以保險公司核保結果為準。**
4. **是否理賠及給付金額，以保單條款約定及保險公司核定為準。**

（涉及調整既有保單者，另加**解約損失揭露單**。）

---

## 四、送審這件事，沒有例外

保險業依主管機關規定應建立招攬處理制度及程序；業務員自製之文宣、建議書、比較資料、社群內容，
**須依所屬公司（或保經代）內部審查程序核可後始得使用**。

→ 小顧產出的一切，在送審通過前都叫「**草稿**」。
→ 交件一律附 `templates/合規送審檢核表.md`。
