# 年度回訪與人生事件檢視 SOP

> 保單不是買完就結束的商品，是**會跟著人生變動而失準的規劃**。
> 顧問線的續航力，全靠這一張表。

---

## 一、固定節點（一年至少接觸 3 次，不推銷）

| 節點 | 時機 | 做什麼 |
|:---|:---|:---|
| **保單週年** | 每張保單生效月 | 保障有無到期、繳費年期是否屆滿、受益人是否要更新 |
| **年度檢視** | 每年固定同一個月 | 跑一次 `gu.py audit` + `gap`，看缺口有沒有變 |
| **續期前一個月** | 扣款月前 | 提醒帳戶餘額，避免因扣款失敗而**停效**（停效復效有健康狀況審查風險） |

---

## 二、人生事件觸發（發生就要檢視，不必等週年）

| 事件 | 要重新看的 |
|:---|:---|
| 結婚 | 受益人、家庭責任額度 |
| 生小孩 | 壽險缺口大增、教育金、子女醫療 |
| 買房／貸款 | 房貸對應的身故與失能缺口 |
| 換工作／創業 | 團保是否消失（**離職團保就沒了**，很多人不知道）、收入變動、職業等級改變 |
| 收入大幅變動 | 保費可持續性、額度重算 |
| 家人生病或身故 | 家庭現金流結構改變、長照壓力 |
| 離婚 | 受益人、要保人、保單價值歸屬 |
| 子女獨立 | 壽險需求下降，可能轉向醫療與長照 |
| 退休 | 收入替代轉為醫療、長照、現金流 |
| 搬遷／出國長住 | 保障地域限制、聯絡資料、海外就醫理賠條件 |

⚠️ **職業變更要通知保險公司**（職業等級影響意外險費率與承保條件，未通知可能影響理賠）。這一條一定要主動提醒客戶。

---

## 三、年度檢視信的寫法（不推銷版）

> 「○○ 你好，你的保單這個月滿 ○ 年了。
> 我幫你看過三件事：① 有沒有快到期的保障 ② 繳費年期還剩幾年 ③ 受益人資料是不是還正確。
> 這三項目前的狀況是 ______。**沒有要你做任何事**，如果要調整我們再約時間談。」

—— 沒有推銷、沒有急迫、只有服務。這種訊息的回覆率遠高於商品訊息。

---

## 四、紀錄

每次接觸都寫回 `templates/客戶資料卡.json` 的 `contact_log`：日期、方式、談了什麼、客戶說了什麼、下次要追什麼。
**寫客戶原話，不要只寫摘要。**
