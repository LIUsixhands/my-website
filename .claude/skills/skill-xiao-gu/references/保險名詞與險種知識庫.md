# 保險名詞與險種知識庫（顧問溝通用）

> 用途：讓顧問**用客戶聽得懂的話**解釋保障。
> ⚠️ 本庫只講**保障功能的通則**，不涉及任何特定商品、費率、給付倍數。
> 實際條款定義與給付條件，一律**以該張保單條款為準**。

---

## 一、六大保障類別（小顧的分類骨架）

| 類別 | 這一塊在保什麼 | 客戶最常誤會的 |
|:---|:---|:---|
| **身故／全失能** | 我不在了，家還付得起 | 以為「有保險」就夠，沒算過房貸與教育費 |
| **醫療（日額型）** | 住院期間的病房差額、看護、收入中斷 | 以為日額可以支應自費藥材 |
| **醫療（實支實付型）** | 健保不給付的自費項目 | 不知道有「限額」與「正副本」的差別 |
| **重大疾病／重大傷病** | 一次給付，撐過治療期不上班的日子 | 以為所有癌症都賠，忽略定義與等待期 |
| **失能／長照** | 人還在、需要長期照顧的錢 | 最常見的缺口，也是最貴的風險 |
| **意外** | 意外導致的身故與失能 | 以為意外險什麼意外都賠，忽略「外來、突發、非疾病」三要件 |

## 二、關鍵名詞（用白話解釋）

- **主約／附約**：附約是掛在主約上的。**主約解約，附約通常一起失效。** 健檢一定要標。
- **等待期（waiting period）**：保單生效後一段期間內發生的疾病不賠，避免帶病投保。**新換保單會重新起算。**
- **告知義務**：投保時要據實說明健康狀況。未據實告知，保險公司在一定條件與期間內得解除契約。
- **除外責任**：條款明列不賠的情形。
- **既往症**：投保前已存在的疾病，可能被除外或加費。
- **停效／復效**：保費未繳致契約停止效力；復效可能需再次審核健康狀況，**不是想復效就能復效**。
- **保單價值準備金／解約金**：解約金通常**低於已繳保費**，前幾年差距最大。
- **失能程度表**：失能給付看的是**等級**，不是傷得多嚴重的感覺。
- **受益人**：身故給付要指定；未指定或指定不明會回到法定繼承，處理更麻煩。**離婚、再婚後最常忘記改。**
- **要保人／被保險人／受益人**：三者可不同；要保人變更涉及保單價值歸屬，影響很大。
- **團保**：多數團保**離職即終止**。轉職空窗期是常見的保障破口。
- **社會保險（勞保／勞退／健保）**：算缺口時要先扣掉，但**不要替客戶核算金額**，請他上勞保局查詢或以官方核算為準。

## 三、講給客戶聽的三個比喻（好用且不違規）

1. **保單像家裡的鎖**：門鎖（醫療）大家都裝，但**落地窗（失能長照）常常沒鎖**。
2. **實支實付像加油卡**：有額度、要收據；**日額像日租金**，跟你花多少沒關係。
3. **主約附約像插座**：附約是插在主約上的電器，**主約拔掉，全部斷電。**

## 四、小顧不回答的問題（一律轉出去）

| 客戶問 | 轉給誰 |
|:---|:---|
| 我這個症狀會不會有事 | 醫師 |
| 這張賠不賠 | 保險公司理賠單位（顧問陪送件） |
| 我這樣體況能不能買 | 保險公司核保（顧問陪送件） |
| 保險金要不要繳稅 | 會計師／稅務專業人員 |
| 保單要怎麼分給小孩 | 律師（繼承）／稅務專業人員 |
| 這筆錢投資在哪比較好 | 具投顧資格者 |
