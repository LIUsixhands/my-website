# 🧭 AI 員工「小顧」— 保險顧問　安裝與使用說明

> Sixhands Studio AI數字員工　🦞
> 這位員工只做一件事：**把一疊看不懂的保單，變成一張看得懂的保障地圖。**
> 他不推商品、不算保費、不判理賠 —— 那些是公司系統與核保理賠單位的事。
> 他做的是**需求分析、保單健檢、缺口試算、面談準備、理賠陪伴、年度檢視**。

---

## 一、安裝（三分鐘，Mac／Windows 都一樣）

### Mac
```bash
cp -R ~/Desktop/AI員工_小顧 ~/.claude/skills/skill-xiao-gu
```
重開 Claude Code，輸入 **「小顧」** 測試。

### Windows
整個資料夾放到 `C:\Users\你的帳號\.claude\skills\skill-xiao-gu`，其餘相同。

---

## 二、第一次使用的順序（照做，不要跳）

```
1. 打「小顧」
2. 回答身分四題
     ① 你是業務員還是保經代？公司全名？
     ② 登錄字號？
     ③ 可以招攬哪些險種？
     ④ 你們公司的建議書／文宣審查流程與窗口？
3. 填 templates/顧問資料卡.json
4. 打開 references/待補12題.md，一次問完、填完
5. 小顧才會開始出第一份文件
```

**身分四題沒答案，小顧不會出任何對外文件。** 這行猜錯身分，賠上的是登錄證。

---

## 三、六個指令（在 skill 資料夾底下跑）

```bash
python3 scripts/gu.py audit  保單盤點表.csv     # 客戶給你一疊保單 → 六大類別彙總＋缺漏／到期
python3 scripts/gu.py gap    客戶資料卡.json    # 他到底缺多少 → 缺口試算（假設全列）
python3 scripts/gu.py brief  客戶資料卡.json    # 明天要面談 → 這次該問哪幾題
python3 scripts/gu.py claim  --type 住院        # 客戶出事了 → 文件清單＋流程＋時效
python3 scripts/gu.py review 客戶資料卡.json    # 保單週年 → 年度檢視＋人生事件
python3 scripts/gu.py check  建議書草稿.md      # 交件前必跑 → 紅字＝不准交件
python3 scripts/gu.py init                      # 在目前資料夾產出全部範本
```

`claim --type` 可用：住院／手術／意外／失能／重疾／身故／癌症

## 四、跟「小安」怎麼分

| 你要做的事 | 找誰 |
|:---|:---|
| 寫貼文、拍短影音、經營名單、約訪、轉介、增員 | **小安**（保險行銷專員） |
| 盤保單、算缺口、寫規劃建議書、陪理賠、年度檢視 | **小顧**（本員工） |

小安負責把人帶到桌前，小顧負責桌上那一小時。兩隻可以一起用。

---

## 五、🚨 三件事一定要記住

1. **小顧的產出都是「草稿」。** 送所屬公司／保經代審查核可之後，才可以交給客戶。
2. **不指名商品、不算保費、不判核保理賠、不下稅務結論。** 這些不是 AI 該扛的責任，也不是你該替公司扛的。
3. **客戶保單含病史等特種個資。** 檔案放本機碟（不要放 iCloud 桌面），個案一律去識別化寫「客戶A」，
   不要打本名、身分證字號、病歷號、保單號全碼。

---

## 六、遇到問題

- 指令跑不動 → 確認有裝 Python 3（終端機打 `python3 -V`）
- 中文變成問號 → 用 UTF-8 存檔
- 不確定某句話能不能講 → 丟給 `gu.py check`，再對照 `references/顧問合規紅線.md`
