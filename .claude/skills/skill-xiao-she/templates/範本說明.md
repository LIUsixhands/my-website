# templates 使用說明

小社的表單**不是靜態檔案，是用指令現產的** —— 因為每張表都要帶入
協會全銜、日期、活動名稱、經費來源，寫死在範本裡反而容易用錯。

## 各表單怎麼產

| 要的表單 | 指令 |
|:---|:---|
| 活動簽到表、活動紀錄卡、系統貼上包 | `she.py event --type 共餐 --date YYYY-MM-DD` |
| 憑證清冊、經費結報表、風險清單 | `she.py expense 憑證明細.csv --period "115年第3季"` |
| 成果報告 | `she.py report --period "115年第3季"` |
| 開會通知、議程、簽到簿、會議紀錄、備查函 | `she.py meeting --kind 會員大會 --date YYYY-MM-DD` |
| 年度會刊（六大單元） | `she.py journal --year 115` |
| 年度行事曆 | `she.py calendar --all --days 90` |
| 協會基本資料卡 | `she.py init` |

## 這個資料夾裡的檔案

- **憑證明細範本.csv** —— 唯一需要手動填的輸入檔。
  欄位：`日期,品名,廠商,憑證種類,金額,科目,抬頭,統編,附件`
  - `日期` 必須是 `YYYY-MM-DD`，否則會被標成 A 類風險
  - `抬頭`／`統編` 照發票或收據上**實際印的**填，不要照理想值填
    —— 小社就是靠比對這兩欄抓出 B、C 類退件風險的
  - `附件` 欄：有附領據／估價單／印領清冊就寫上，空白代表沒有
  - `科目` 請對照該補助案作業要點允許的科目

## 為什麼沒有空白 PDF 範本

因為空白範本最常見的用錯方式，是「去年的表改一改日期就送出去」——
結果活動名稱、經費來源、屆次全都是舊的。
用指令現產只要三秒，而且每個欄位都是這次活動的。
