# 補助申請與核銷 SOP —— 每季一輪

> 客戶原話：「跟那個社會局申請核銷，**每一季要申請核銷**。」
> 也就是說，一年要跑四輪。這是總幹事最痛的固定性工作。

## ⚠️ 使用前提

台灣各縣市社會局的補助作業要點**逐年、逐案不同**。
本 SOP 提供的是**通用骨架與檢核邏輯**，
**實際期限、金額門檻、應附文件，一律以貴會該案的「補助作業要點」＋「核定函」為準**。
小社在產文件時會把不確定處印成 `【依作業要點第__點】`，請總幹事對照函文填。

## 一、一季的四個節點

```
①申請 → ②執行 → ③核銷（結報）→ ④撥款
```

| 節點 | 要做的事 | 常見死因 |
|:--|:--|:--|
| ① 申請 | 計畫書、經費預算表、立案證明、負責人資料 | 逾期、預算科目寫錯、自籌款沒列 |
| ② 執行 | 照計畫辦活動、收簽到／照片／憑證 | 變更活動沒報備、憑證日期跑到期間外 |
| ③ 核銷 | 經費結報表、憑證清冊、原始憑證、成果報告 | 抬頭錯、單據缺、成果報告寫太空 |
| ④ 撥款 | 領據、存摺影本 | 帳戶戶名與立案全銜不符 |

## 二、申請階段：計畫書骨架

1. 計畫名稱、依據（作業要點名稱）
2. 目的與需求（**寫社區的真實問題**，例：獨居長者共餐需求、失能預防）
3. 辦理單位、對象、預計人數
4. 實施期程與內容（**列表：日期／活動／時數／預計人次**）
5. 經費預算表（見下）
6. 預期效益（**可量化**：場次、人次、涵蓋里別）

### 經費預算表原則
- 科目要**對得上作業要點允許的科目**（常見：講師鐘點費、材料費、膳食費、印刷費、雜支）
- **雜支通常有比例上限**（依要點）→ 小社會標出 `【雜支上限：依要點第__點】`
- 自籌款欄位不可留白（若要點要求自籌）
- 合計數字**由腳本加總**，不手算

## 三、核銷階段：三份主文件

```bash
python3 scripts/she.py expense 憑證明細.csv --period "115年第3季" --out 出件/
python3 scripts/she.py report  --period "115年第3季" --out 出件/
```

### 1. 經費結報表（收支對照）
| 科目 | 核定預算 | 實支金額 | 差異 | 說明 |
- 實支金額 = 憑證清冊加總，**兩者不符就不准出表**（同小帳「借貸要平」邏輯）
- 有結餘要寫明處理方式（多半是繳回）

### 2. 憑證清冊
| 序號 | 日期 | 品名／用途 | 廠商 | 憑證種類 | 金額 | 科目 | 備註 |
- 序號要與**原始憑證黏貼順序一致**（黏貼簿按序號排）
- 小社會自動標出四種風險（見下）

### 3. 成果報告
固定六段，**不要寫成流水帳**：
1. 計畫概述（一段）
2. 辦理情形總表（場次／人次／日期一覽表）
3. 各場次紀錄（活動名、日期、內容摘要 3–5 行、實到人數）
4. **照片頁**（每場 2–3 張，附圖說：日期＋活動＋在做什麼）
5. 效益分析（量化數字 ＋ 質化回饋，質化可引用長輩原話）
6. 檢討與建議（**要寫真的問題**，例：場地不足、志工人力老化 —— 這段寫得誠實，承辦人反而信任）

## 四、🚨 四種必退件風險（小社自動標，但由總幹事判斷）

| 風險 | 判斷方式 | 處理 |
|:--|:--|:--|
| **A. 日期出界** | 憑證日期 < 補助期間起日 或 > 迄日 | 該筆抽掉，改列協會自籌 |
| **B. 抬頭錯誤** | 抬頭非協會立案全銜 | 請廠商重開；已無法重開的抽掉 |
| **C. 統編錯誤** | 統編與 `協會資料.json` 不符 | 同上 |
| **D. 大額單據缺附件** | 金額 ≥ 要點門檻卻無領據／估價單／印領清冊 | 補齊附件 |

> 小社**只標示、不刪改**。要不要抽掉某筆，是總幹事＋承辦人的判斷。

## 五、與承辦人溝通的三個原則

1. **先問再做**。不確定的科目、金額、格式，**打電話問承辦人比事後補件快十倍**。
   問完把答案寫進 `協會資料.json` 的備註，下次不用再問。
2. **保留書面**。承辦人口頭同意的變更，用 email 或公文再確認一次。
3. **提前一週送**。壓死線送件，遇到退件就沒有補救時間。

> 已依貴局指正事項補正如下：
> 一、（項目）：已補附○○○。
> 二、（項目）：該筆單據因（原因），本會改列自籌款支應，已自結報表扣除，
> 　　結報總額由 ○○○ 元更正為 ○○○ 元。
> 檢附補正後之經費結報表、憑證清冊及原始憑證乙份，敬請查收。
> 如有其他需補正事項，敬請不吝告知。感謝您的協助。
