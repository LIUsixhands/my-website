# 會議文書 SOP —— 會員大會 × 理監事會

> 客戶原話：「每一年都要，到年底都要開那個會議。」
> 社區發展協會屬《人民團體法》規範的社會團體，會議程序有**法定要求**，
> 程序瑕疵會導致決議效力被質疑，甚至影響改選與補助資格。

## ⚠️ 使用前提（非常重要）

**會議頻率、通知前置天數、出席與決議門檻，一律以「貴會章程」為準。**
《人民團體法》及相關函釋設有下限，各協會章程可訂得更嚴格。
小社**不填這些數字**，一律印成 `【章程第__條】` 由總幹事對照章程填入。
若章程與法規有疑義 → 轉**法務部小辯**或逕詢主管機關。

## 一、會議種類

| 種類 | 性質 | 常見時點 |
|:--|:--|:--|
| **會員（會員代表）大會** | 最高權力機關；定期會議每年召開 | 多在年底或年初 |
| **理事會** | 執行決議、日常會務 | 定期召開，頻率依章程 |
| **監事會** | 監察財務與業務 | 定期召開，頻率依章程 |
| **臨時會議** | 特殊事由（改選、章程修正、重大財務） | 不定期 |

## 二、一次會議的完整文書（小社一鍵產五件）

```bash
python3 scripts/she.py meeting --kind 會員大會 --date 2026-12-20 --out 出件/
```

| # | 文件 | 重點 |
|:--|:--|:--|
| 1 | **開會通知** | 須載明時間、地點、**議程**；依章程於會前○日送達 |
| 2 | **議程** | 報告事項／討論事項／臨時動議 三段式 |
| 3 | **簽到簿** | 出席者親簽；**法定人數靠這張證明**，務必保存正本 |
| 4 | **會議紀錄** | 含出席人數、主席、記錄、決議內容與表決結果 |
| 5 | **報主管機關備查函** | 會後於規定期限內函報，附會議紀錄與簽到簿 |

## 三、議程標準結構（會員大會）

```
一、主席致詞
二、報告事項
　　（一）上次會議決議執行情形報告
　　（二）○○年度會務工作報告
　　（三）○○年度經費收支決算報告
　　（四）監事會財務監察報告
三、討論事項
　　第一案　案由：○○年度工作計畫（草案），請討論。
　　　　　　說明：……
　　　　　　辦法：通過後據以執行。
　　　　　　決議：
　　第二案　案由：○○年度經費收支預算（草案），請討論。
　　第三案　案由：○○年度經費收支決算，請追認。
四、臨時動議
五、散會
```

### 議案四要素（缺一不可）
**案由 → 說明 → 辦法 → 決議**
「決議」欄在通知階段留白，**開會當下填**，不可事後自己編。

## 四、會議紀錄必載欄位

- 會議名稱、屆次、時間、地點
- **應到人數／實到人數**（是否達法定開會人數）
- 主席、記錄
- 出列席人員
- 報告事項摘要
- **各案決議與表決結果**（通過／修正通過／保留／不通過；必要時記票數）
- 臨時動議及決議
- 散會時間
- **主席與記錄簽章**

## 五、年度會議的兩份財務文件

年底大會一定會碰財務，這兩份**由財務部小帳產、小社排版**：
1. **年度經費收支決算表**（去年實際）
2. **下年度經費收支預算表**（明年計畫）

小社的責任是確認：**決算表的數字 = 會刊「帳戶」單元的數字**。
兩份對不起來，會員一定當場問。

## 六、🚨 五個常見程序地雷

1. **通知不足期限** → 決議可能被質疑。提早發，並保留寄送／簽收紀錄。
2. **未達法定人數硬開** → 紀錄要誠實寫實到人數；不足就依章程處理（改期或續會）。
3. **決議事後補寫** → 現場就要記，散會前唸一次決議確認。
4. **改選年度沒依程序** → 改選涉及任期、當選公告、報備查，**改選年務必提前一個月確認流程**。
5. **會議紀錄逾期未報備查** → 依規定期限函報主管機關，附簽到簿。
