# 合規紅線與安全話術（scan 指令的規則來源）

## 一、招生文宣禁用詞表

| 類別 | 禁用語句 | 法源／原因 | 安全替代 |
|:---|:---|:---|:---|
| 效果保證 | 保證學會、一定學得會、包會 | 公平交易法 §21 不實廣告 | 課程結束可完成一支自己的作品 |
| 收入保證 | 保證接單、學完就能賺、月入○萬、穩賺 | 公平法／消保法 | （不提收入。真實個案須經本人同意且註明個案） |
| 考照保證 | 保證考取、包過 | 同上 | 課程內容涵蓋○○ |
| 冒用公權力 | 政府認證、官方指定、教育部認證師資 | 涉及冒用公務機關名義 | 本課程由【單位】補助辦理 |
| 費用不實 | 完全免費（實際須先繳費） | 廣告不實 | 先繳 $X，補助核撥後全額退還 |
| 不實稀缺 | 最後一名、只剩一個（非真實） | 不實促銷 | 僅寫真實剩餘名額 |
| 醫療效能 | 預防失智、治療憂鬱、改善失眠、復健療效 | 醫療法 §84、§86 概念 | 動手動腦，很多長輩說做完很有成就感 |
| 貶損同業 | 比某某老師教得好、外面都教錯 | 公平法 §24 | （不提同業） |

> 🔴 **長輩班最容易踩的是「預防失智」**。這句話幾乎所有樂齡課程都在寫，
> 但它是明確的醫療效能宣稱。一律改寫成主觀感受敘述。

## 二、補助行政的四條刑事級紅線

1. **簽到不可代簽、補簽、預簽** —— 偽造文書。
2. **時數不可灌水** —— 實際上 2 小時不可報 3 小時。
3. **人數不可灌水** —— 沒到的人不可列入成果。
4. **憑證不可湊、不可改金額、不可列私人支出** —— 詐領補助款。

> 這四條的共同點：**做了會被追繳並移送，且無法用「行政疏失」解釋。**
> 小招在任何情況下都不協助產出這四類文件，也不提供「怎麼做比較不會被發現」的建議。

## 三、機具安全告知（必須寫進安全告知書並口頭宣達）

- 木工車床、鑽床、刀具屬高風險機具
- 穿著：包鞋、束髮、不戴垂掛飾品、不穿寬袖
- 護具：護目鏡（操作時全程配戴）
- 未滿【待補：年齡】須家長全程陪同
- 身體狀況不佳、飲酒、服用嗜睡藥物者不得操作機具
- 緊急處理：急救箱位置、最近醫院、緊急聯絡人

🔴 紅字（必改，不改不准交付）

🟢 通過
