# 展示現場留資 SOP — 把展示點變成招生點

> 客戶原話：「我們主要是做教學，然後展示……在各個【待補：場館】做展示。」
> 🔴 **沒有留資動作的展示，等於白做。**
> 展示帶來的是「當下想要」，如果當下沒有留下聯絡方式，這個人就永遠消失了。

## 一、展示桌的標準配置

| 位置 | 放什麼 | 為什麼 |
|:---|:---|:---|
| 最前面 | **成品筆 3–5 支，可以摸** | 「可以拿起來」的轉換率遠高於「請勿觸摸」 |
| 成品旁 | **一塊原木原料** | 前後對比，一秒懂價值 |
| 中間 | 平板／手機循環播放縮時影片（30 秒） | 說明「三小時能做出來」 |
| 桌角 | **A5 立牌：QR Code + 一句話** | 留資入口 |
| 手邊 | 紙本留資單 + 筆（長輩不掃 QR） | **長輩客群一定要有紙本** |

## 二、留資的一句話（立牌文案）

```
下一梯什麼時候開？
掃這裡，開課前我通知你。
（【待補：補助單位】補助・【待補：費用說明】）
```

> 不要寫「加入好友」（沒有理由），要寫「**開課前我通知你**」（給對方一個明確好處）。

## 三、現場三句話話術

1. **（對方拿起筆時）**「這支是學員自己車的，第一次做木工。」
   → 立刻打掉「我做不到」的心理障礙。
2. **（對方問多少錢）**「這堂課有【待補：補助單位】補助，【待補：費用說明】。」
   → 誠實講清楚金流（見紅線第 4 條），不要含糊帶過。
3. **（要留資時）**「你住哪一區？我下次在你那邊開班的時候通知你。」
   → 順便收到「地區」這個欄位，這是排班表最有用的資料。

## 四、留資單必收四個欄位（不要貪多）

1. 姓名（或稱呼）
2. 手機 或 LINE
3. **居住區域** ← 決定下一班開在哪
4. 想上哪一種（成人／親子／團體）

> 欄位超過四個，填寫率會明顯下降。身分證字號、生日、地址**現場一律不收**，
> 等到正式報名、確定需要補助資格證明時再收（個資最小蒐集原則）。

## 五、展示後 48 小時內必做

- [ ] 留資單當天拍照備份（紙本會弄丟）
- [ ] 48 小時內發第一則訊息（拖過三天，對方就忘了你是誰）
  > 「您好，我是【待補：姓名】，昨天在【待補：場館】做原木筆展示的。
  > 下一梯開課我會通知您。這是那天的成品照片 📷」
- [ ] 依「居住區域」分群，累積到【待補：最低開班人數】就可以在那一區開班
- [ ] 記錄「這場展示收到幾張留資」→ 排出**最值得跑的展示場館**

## 六、展示成效表（每場都記，跑三場就知道該去哪）

| 場館 | 日期 | 停留人數 | 留資數 | 留資率 | 後續報名數 | 值得再來？ |
|:---|:---|:---|:---|:---|:---|:---|
| 【待補】 | | | | | | |

> 留資率 = 留資數 ÷ 停留人數。低於 10% 要檢討立牌文案或話術；
> 後續報名數才是真指標 —— 有些場館人多但轉不動，有些人少但每個都來上課。
