# 招生打法與文案庫（補助免費課專用）

## 0. 先認清：免費課的招生難點不是「說服掏錢」

| 一般付費課 | 補助免費課（本案） |
|:---|:---|
| 難點：讓人願意付錢 | 難點：**免費 → 感覺沒價值／怕有陷阱／報了不來** |
| 主打投報率、學完能賺 | 主打**作品帶回家**、**限量名額**、**在地就近** |
| 個人決策 | **揪團決策**（社區、班群、親子、退休族一起來） |
| 買廣告 | **在地節點**：里長、社區發展協會、圖書館、樂齡中心、農會、學校家長會 |
| KPI：報名數 | KPI：**報到率**（免費課的 no-show 率極高，30–50% 很常見） |

> 🔴 **免費課最大的敵人是 no-show。**
> 所有招生設計都要同時解決「報名」與「一定要來」兩件事。

---

## 1. 三大核心打法

### 打法一：作品先行，不是課程先行
貼文／海報的主角**永遠是那支做好的原木筆**，不是課表、不是講師介紹、不是課程大綱。

- ❌ 錯：「原木手工筆課程開課囉！時間 9/15，地點○○活動中心，歡迎報名」
- ✅ 對：「這支筆，是林太太第一次拿車床做出來的。／三個小時，你也可以帶一支回家。／
  本梯次○○名額，○○補助，學員免費。」

**原則**：先給畫面 → 再給「你也可以」→ 最後才給時間地點。

### 打法二：通路招生 > 廣告招生
一個里長 ≒ 半班；一個社區發展協會 ≒ 一班；一個樂齡中心 ≒ 常態合作。
免費課對通路方是**送給居民的福利**，通路方有動機幫你發，這是付費課永遠拿不到的優勢。

**通路優先順序**（依成本效益排）：
1. 村里長／里幹事（一張 LINE 群發抵一百次貼文）
2. 社區發展協會、關懷據點、樂齡學習中心
3. 圖書館、文化中心、農會家政班
4. 學校家長會、親子社團（若開親子場）
5. 已上過課的舊生（回流 + 帶朋友）
6. 最後才是 FB／IG 廣告

→ 話術與合作一頁紙見本檔第 4 節。

### 打法三：展示點 = 招生點
客戶本來就在各場館做展示。**每一次展示沒有留資，等於白做。**
展示現場的標準動作見 `展示現場留資SOP.md`。

## 2. 文案模板（三個角度，每班都可換）

### 角度 A：作品感（給第一次接觸的人）
```
一塊原木，三個小時，變成一支你自己的筆。

不是買的，是你自己車出來的。
木頭的紋路每一支都不一樣，所以你手上這支，全世界只有一支。

【○○課程・第○梯】
📅 【待補：日期時間】
📍 【待補：場地名稱與地址】
👥 限額【待補：人數】人
💰 本課程由【待補：補助單位／計畫名稱】補助，【待補：學員免費／先繳○元補助後退還】
🔗 報名：【待補：報名連結】
```

### 角度 B：揪團感（給社區、班群、退休族）
```
找三個朋友，一起做一支筆。

我們這梯次就在【待補：場地】，走路就到。
不用會木工，不用自己帶工具，來就好。
做完直接帶回家，當天就能用。

三人以上一起報名，我們幫你們排在同一桌。
【待補：日期】／限額【待補：人數】人／【待補：費用說明】
報名 👉【待補：連結】
```

### 角度 C：送禮感（給有目的性的人：教師節、母親節、退休禮、婚禮小物）
```
今年送什麼？送一支你自己做的筆。

刻上他的名字，木頭會愈用愈亮。
三小時的課，換一個十年後還在他桌上的東西。

【待補：日期】／【待補：場地】／限額【待補：人數】人
【待補：費用說明】｜報名 👉【待補：連結】
```

## 3. 五則社群貼文骨架（可直接套 recruit 指令產出）

| # | 型態 | 鉤子 | 用途 |
|:--|:---|:---|:---|
| 1 | 成品特寫 | 「這支筆的木紋，是它自己長出來的」 | 建立想要感（發在開班前 30 天） |
| 2 | 過程縮時 | 「三小時，從一塊木頭到這樣」 | 降低門檻恐懼（開班前 21 天） |
| 3 | 學員實拍 | 「○○阿姨說她這輩子沒摸過車床」（須本人同意） | 社會證明（開班前 14 天） |
| 4 | 名額倒數 | 「這梯次剩下【待補】個位子」 | 催單（開班前 7 天） |
| 5 | 開課前提醒 | 「明天見！記得穿包鞋、綁頭髮」 | **降低 no-show ＋ 安全提醒**（開班前 1 天） |

> 第 5 則不是可有可無 —— 它同時是**報到率武器**與**安全告知的第一層**。

## 4. 通路開發話術（打電話／親自拜訪用）

### 對村里長／社區發展協會
> 「里長好，我是做原木手工筆教學的【待補：姓名】。
> 我們這邊有【待補：補助單位】的補助，可以在您這邊開一班，
> **居民不用花錢**，三小時做一支筆帶回家。
> 場地借用您這邊的活動中心就好，工具、材料、老師我們全部帶過去。
> 您這邊大概能找到【待補：最低開班人數】位以上的居民嗎？」

**為什麼有效**：對里長來說這是「不花錢的居民福利 + 可以拍照的活動成果」，
他有動機，而且他手上有現成的 LINE 群。

### 對學校家長會／親子社團
> 「我們有一堂三小時的木作體驗，親子可以一起做一支筆。
> 有補助所以家長不用付費，只需要提供教室跟【待補：人數】位參加者。」

### 合作一頁紙（拜訪時留下）必含欄位
1. 我們是誰（含展示照片 2–3 張）
2. 這堂課學員會帶走什麼（成品照）
3. **你們要出什麼**（場地、人數、日期）— 寫得愈具體愈好談
4. **我們出什麼**（老師、工具、材料、保險、行政文件）
5. 過去合作單位（真實的才寫）
6. 聯絡方式

## 5. 🚫 禁用詞（scan 指令會抓）

| 禁用 | 原因 | 可用替代 |
|:---|:---|:---|
| 保證學會／一定學得會 | 效果保證，違反公平法 | 「課程結束可完成一支自己的作品」 |
| 保證接單／學完就能賺 | 收入保證 | 「有學員後續自行接單（須真實個案且經同意）」 |
| 保證考取／包過 | 考照保證 | 「課程內容涵蓋○○」 |
| 政府認證／官方指定 | 冒用公權力背書 | 「本課程由【單位】補助辦理」 |
| 完全免費（若實際要先繳費） | 廣告不實 | 「先繳 $X，補助核撥後全額退還」 |
| 名額最後一個（不實） | 不實促銷 | 只寫真實剩餘數 |
| 療效類（療癒、紓壓可用；治療、改善失眠、預防失智不可用） | 醫療法／健康食品法概念延伸 | 「動手做的過程很專注」 |

> ⚠️ 特別提醒：對長輩班很容易脫口而出「**預防失智**」——
> 這是明確的醫療效能宣稱，**一律禁用**，改寫成「動手動腦，很多長輩說做完很有成就感」。
