## 一、開班前

### 1. 開班計畫必填欄位
班別編號／日期時間／場地名稱地址／講師與助教／人數上下限／
補助案名稱與核定字號／每人補助額／預計材料成本／保險投保狀態

### 2. 場地檢核（沒有自有教室 → 這張表每班都要跑）
- [ ] 電源：車床／集塵設備的用電量夠嗎？有幾個插座？
- [ ] 空間：每人工作面寬夠嗎？機具間距安全嗎？
- [ ] 通風／集塵：木屑粉塵處理方式？
- [ ] 出入口與逃生動線是否淨空
- [ ] 急救箱位置、最近醫院
- [ ] 場地借用同意書／使用時段（含佈場撤場時間）
- [ ] 清潔還原責任歸屬（木屑清潔常是爭議點）

### 3. 保險（🔴 不可略過）
- [ ] 公共意外責任險（多數場地方會要求）
- [ ] 學員團體平安險（含當日名單）
- [ ] 投保名單是否等於實際到課名單（換人要通知保險公司）

## 二、開課／不開課決策（D-3）

| 報名數 vs 最低開班數 | 燈號 | 建議動作 |
|:---|:---|:---|
| ≥ 上限 | 🟢 滿班 | 開候補名單，考慮加開一梯 |
| ≥ 最低 × 1.2 | 🟢 安全 | 照常開，發行前通知 |
| ≥ 最低 | 🟡 剛好 | **催單 + 提醒**（免費課會 no-show，剛好等於不夠） |
| < 最低 | 🟠 危險 | 通路加壓、考慮與鄰近梯次併班 |
| < 最低 × 0.6 | 🔴 建議延期 | 提前 3 天通知比當天取消傷害小很多 |

> 🔴 **免費課的報名數要打折看。** 建議以「報名數 × 0.7」當實際到課估計，
> 直到累積出自己的真實報到率為止（`close` 每班會自動記錄，跑幾班後就有真數字）。

## 三、現場行政（D-0）必備五件

1. **學員名冊**（姓名、聯絡方式、補助身分別欄位）
2. **簽到表**（🔴 學員本人親簽，不可代簽、不可事後補簽）
3. **安全告知書**（機具風險、穿著規定、緊急處理，學員簽名）
4. **肖像權同意書**（拍照用於成果報告與宣傳，勾選同意範圍）
5. **教材與工具清點表**（開課前清點、結束後清點，刀具類特別註記）

**穿著與安全規定（寫進行前提醒 + 安全告知書）**
- 穿包鞋，不可穿涼鞋拖鞋
- 長髮束起，不可戴垂掛式項鍊、圍巾、寬袖衣物
- 操作機具時配戴護目鏡
- 未滿【待補：年齡】需家長全程陪同

## 四、結案核銷（D+14）

### 常見核銷文件包
- [ ] 成果報告（含課程內容、時數、人數、照片）
- [ ] 簽到表正本
- [ ] 學員名冊（含補助資格證明文件）
- [ ] 經費支出憑證清冊
- [ ] 原始憑證（發票／收據，抬頭統編正確）
- [ ] 照片（含現場全景、上課過程、成品、簽到情形）
- [ ] 學員回饋表統計

### 🔴 四種最常見的退件原因（`close` 會自動自檢）
1. **憑證抬頭／統編錯誤** —— 開錯抬頭幾乎必退，且很難重開。
2. **簽到人數 ≠ 名冊人數 ≠ 成果報告人數** —— 三個數字必須完全一致。
3. **日期矛盾** —— 憑證日期早於核定日、或晚於計畫執行期間。
4. **照片無法佐證** —— 沒有拍到簽到情形、沒有拍到全景、照片看不出日期與地點。

> 補助單位不是在刁難，是他們自己也要被審計。
> **把這四項在課程當天就處理掉，核銷會從三天變三十分鐘。**

---

## 五、每班結束後要留下的「資產」（最容易被忽略）

每一班跑完，除了核銷，一定要留下這四樣，它們是明年招生的本錢：
1. **成品照片庫**（每班挑 3 張最好的）
2. **學員金句**（回饋表裡的一兩句真心話，經同意後可引用）
3. **通路來源紀錄**（這班的人從哪來 → 累積出真正有效的通路排行）
4. **真實報到率**（報名 N 人、實到 M 人 → 下一班的缺額判斷才會準）
