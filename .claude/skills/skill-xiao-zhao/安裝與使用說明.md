# 小招（Xiao Zhao）安裝與使用說明

> AI 員工・課程招生與開班行政專員
> 出品：Sixhands Studio AI數字員工

## 一、安裝（一次就好）

把 `skill-xiao-zhao` 整個資料夾放到：

- **Mac**：`~/.claude/skills/skill-xiao-zhao/`
- **Windows**：`C:\Users\你的名字\.claude\skills\skill-xiao-zhao\`

放好之後，在 Claude Code 裡打「**小招**」就會叫出他。

## 二、第一次使用：先填一張卡

```bash
cd 你要放班務檔案的資料夾
python3 ~/.claude/skills/skill-xiao-zhao/scripts/zhao.py init
```

會產出兩個東西：
1. `開班基本資料卡.pdf` ← 印出來或直接看著填
2. `班務資料.json` ← 填好的資料寫進這裡（或直接跟小招說，他幫你寫）

**填不出來的欄位就留空**，留空會印成紅色【待補】，比填錯安全。

🔴 其中最重要的一題是 **B 區的「金流模式」**：
你的學員是**全程不用掏錢**，還是**先繳費、補助下來再退**？
這一題決定文宣能不能寫「免費」兩個字，填錯會變成廣告不實。

## 三、每開一班，跑這五個指令

```bash
Z=~/.claude/skills/skill-xiao-zhao/scripts/zhao.py

python3 $Z plan              # 開班計畫表（排班、看倒數）
python3 $Z recruit B08       # 招生素材包（文案、貼文、通路話術）
python3 $Z dashboard         # 還差幾個人？該催單還是該延期？
python3 $Z roster B08        # 現場行政包（名冊/簽到/安全/肖像/清點）
python3 $Z close B08         # 結案核銷包（憑證清冊/成果報告/退件自檢）
```

## 四、出門前一定要跑這一個

```bash
python3 $Z scan 招生文案.txt
```

會自動抓出「保證學會」「學完就能賺」「政府認證」「預防失智」這類會出事的句子。
**有紅字就不要發。**

## 五、小招不做的事（請自己來）

- ❌ 代簽到、代填學員資料
- ❌ 把沒到的人寫進成果、把 2 小時報成 3 小時
- ❌ 代你登入補助單位的系統、代簽名、代用印
- ❌ 在文宣寫「保證接單」「學完就能賺」

**不是他不會做，是這幾件事做了會被追繳並移送。**
法定責任該由你扛的部分，小招一律只做草稿、不代你出手 —— 這樣這個員工才能長期用下去。

## 六、還沒問完的 15 題

打開 `references/待補15題.md`。
在那 15 題問完之前，小招產出的數字欄位都會印【待補】，這是刻意的，不是壞掉。
