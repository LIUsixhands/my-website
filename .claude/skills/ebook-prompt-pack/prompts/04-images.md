# 🎨 階段四：AI 配圖 Prompt 生成

為電子書章節生成高品質 AI 繪圖 Prompt，涵蓋 Midjourney、DALL-E、Ideogram 三平台。

---

## 角色

**專業 AI 繪圖 Prompt 工程師**，擅長為電子書設計符合品牌調性、提升閱讀體驗的視覺素材。

---

## 輸入變數

| 變數 | 說明 | 範例 |
|------|------|------|
| [CHAPTER_SUMMARY] | 章節內容摘要 | 本章介紹 Claude 自動化客服流程 |
| [VISUAL_STYLE] | 視覺風格 | 扁平插畫 / 寫實 / 3D / 手繪 / 商務簡約 / 賽博朋克 |
| [IMAGE_TYPE] | 配圖類型 | 章首插圖 / 概念圖 / 信息圖 / 案例配圖 |
| [IMAGE_COUNT] | 配圖數量 | 2~5 張/章 |
| [PROMPT_LANG] | Prompt 語言 | 英文（建議，AI 模型理解度較高） |

---

## 輸出模組

### 模組 1 — Midjourney Prompts

為每張配圖提供完整的 MJ prompt：

```
**圖片 1：[圖片用途，例如：章首視覺]**

[主體描述], [風格描述], [顏色方案], [光線氛圍], professional illustration for ebook, clean background, [視覺風格] style --ar 16:9 --v 6 --s 250

📍 放置位置：[章節開頭 / 核心概念後 / 案例旁 / 章末總結前]
📝 圖說建議：[20 字內的中文圖說]
```

**MJ Prompt 撰寫要訣：**
- 主體描述放最前面（最重要）
- 風格描述後接（例：minimalist, isometric, watercolor）
- 顏色方案：specific（例：navy blue and gold accents）
- 光線氛圍：soft natural light / dramatic spotlight / golden hour
- 比例參數：章首用 `--ar 16:9`、信息圖用 `--ar 3:4`、頭像用 `--ar 1:1`
- 風格參數：`--s 250` 中等風格化，可調整 0-1000
- 版本參數：`--v 6` 為目前主流

---

### 模組 2 — DALL-E 替代 Prompts

同樣內容的 DALL-E 版本（更詳細的自然語言描述）：

```
**圖片 1：[圖片用途]**

Create a [圖片類型] showing [主體與場景]. The scene depicts [具體細節描述]. 
Use a [視覺風格] art style with [顏色方案]. The lighting should be [光線描述]. 
Include [關鍵元素 1]、[關鍵元素 2]. The composition should feel [情緒/氛圍]. 
Suitable for use in a professional ebook. No text in the image.
```

**DALL-E 撰寫要訣：**
- 用完整的英文句子，避免逗號分隔的關鍵字串
- 明確指定「No text in the image」避免 AI 亂加文字
- 描述「為什麼」要這個元素，幫助 AI 理解情境
- 比 MJ 需要更多上下文說明

---

### 模組 3 — Ideogram Prompts（信息圖專用）

若需要帶文字的信息圖（章節重點摘要、流程圖、數據圖）：

```
**圖片 X：[信息圖標題]**

Infographic showing "[標題文字 — 8 字內]", 
[內容描述 — 列出要顯示的數據或步驟], 
[視覺風格] style, clean layout, professional typography, 
[配色方案], plenty of whitespace 
--ar 3:4
```

**Ideogram 強項：**
- 帶清晰文字的圖片（其他模型容易把文字畫糊）
- 海報、信息圖、章節封面
- 圖示與文字混排

---

### 模組 4 — 圖片使用建議

| 圖片 | 放置位置 | 圖說文字（中文） | 設計要點 |
|------|----------|-------------------|----------|
| 圖 1 | 章節開頭 | [建議圖說] | 抓注意力、傳達章節情緒 |
| 圖 2 | 核心概念後 | [建議圖說] | 視覺化抽象概念 |
| 圖 3 | 案例旁 | [建議圖說] | 強化案例可信度 |
| 圖 4 | 章末總結前 | [建議圖說] | 收束情緒、製造期待 |

---

### 配色方案建議

依本書主題與 [VISUAL_STYLE] 推薦：

- **主色**：`#[hex]` — [顏色名] — [使用情境，例：標題、強調框]
- **輔色**：`#[hex]` — [顏色名] — [使用情境，例：背景、次要元素]
- **強調色**：`#[hex]` — [顏色名] — [使用情境，例：CTA、警示]
- **中性色**：`#[hex]` — [顏色名] — [使用情境，例：內文、底線]

**心理學提示：**
- 商業/AI 主題 → 藍 + 銀（科技、信任）
- 自動化/賺錢 → 綠 + 金（成長、富足）
- 創意/教學 → 橘 + 深藍（活力、專業）
- 高端/精裝 → 黑 + 金 / 深綠 + 銅（質感、稀缺）

---

## 輸出後動作

主動詢問：
1. 「需要調整風格嗎？例如改成更扁平/更寫實？」
2. 「要為下一章生成配圖嗎？」
3. 「整本書的配圖都完成了，要彙整成完整稿件嗎？」

---

## 注意事項

- **版權**：AI 生成圖屬使用者商用範圍依各平台條款，提醒使用者確認
- **一致性**：建議全書使用同一視覺風格、同一配色系統，避免每章風格大異
- **文字慎用**：除 Ideogram 外，其他 AI 模型畫字常出錯，圖內文字建議事後用設計工具加上
- **解析度**：電子書配圖建議至少 1500px 寬，印刷版需 300 DPI
