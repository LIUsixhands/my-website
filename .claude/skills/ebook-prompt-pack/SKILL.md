# 電子書製作 AI 提示詞包 Skill

協助使用者從 YouTube 影片素材（透過 NotebookLM 彙整）製作完整精裝版電子書，
涵蓋大綱、內文、標題、配圖四大階段。

## 使用流程

### Step 1：辨識當前階段

判斷使用者目前處於電子書製作的哪個階段：

| 階段 | 任務 | 對應 Prompt 檔 |
|------|------|----------------|
| 📋 階段一 | 規劃大綱、書名、章節架構 | `prompts/01-outline.md` |
| ✍️ 階段二 | 撰寫各章節完整內容 | `prompts/02-content.md` |
| 🏷️ 階段三 | 為章節創作吸睛標題 | `prompts/03-titles.md` |
| 🎨 階段四 | 生成 AI 繪圖 Prompt | `prompts/04-images.md` |

若使用者剛開始一個新專案，預設從階段一進入。
若使用者已有大綱，詢問要進入哪個階段。

### Step 2：載入對應 Prompt 模板

從 `prompts/` 目錄讀取對應檔案，依模板的「輸入變數」清單收集資訊。

### Step 3：收集必要變數

依當前階段詢問必要變數。**已提供的不再重複問**，只詢問缺少的：

**階段一（大綱）需要：**
- 電子書主題
- 核心觀點（全書靈魂，將貫穿每一章）
- 目標讀者（痛點 + 期望）
- 電子書類型（精裝版 / 入門版 / 工具書）
- 章節數量（建議 5~8 章）
- 輸出語言（預設繁體中文）

**階段二（內文）需要：**
- 章節大綱（從階段一輸出帶入）
- 寫作風格（口語 / 專業 / 故事化 / 教學）
- 內容深度（入門 / 進階 / 專家）
- 每章字數
- 輸出語言

**階段三（標題）需要：**
- 章節內容摘要
- 電子書主題
- 標題風格偏好（好奇懸念 / 結果導向 / 數字清單 / 問題解答 / 行動指令）

**階段四（配圖）需要：**
- 章節內容摘要
- 視覺風格（扁平插畫 / 寫實 / 3D / 手繪 / 商務簡約）
- 配圖類型（章首插圖 / 概念圖 / 信息圖 / 案例配圖）
- 配圖數量
- Prompt 語言（建議英文，AI 模型理解度較高）

### Step 4：依模板輸出

嚴格依照各 Prompt 模板規定的「輸出模組」順序輸出。
不要省略任何模組，不要自行增刪欄位。

### Step 5：銜接下一階段

每個階段輸出完成後，主動詢問：
- 階段一 → 「要進入階段二開始寫第 X 章嗎？」
- 階段二 → 「要為這一章生成標題嗎？或繼續寫下一章？」
- 階段三 → 「要為這一章生成配圖 Prompt 嗎？」
- 階段四 → 「整本書都完成了，要彙整成完整稿件嗎？」

## 工作流程鏈（Workflow Chain）

當使用者表達「我要做一本電子書」這類完整目標時，依以下順序執行：

### 完整製書鏈
1. **階段一**：產出大綱（NotebookLM Prompt + 框架 + 章節表 + 提取指引）
2. **階段二**：逐章撰寫內文（建議一次一章，避免過長）
3. **階段三**：為每章優化標題（從 5 個選項中讓使用者挑選）
4. **階段四**：為每章生成配圖 Prompt（建議 2~3 張/章）

### 快速啟動鏈
若使用者只想先看大綱：執行階段一 → 暫停，等使用者確認後再繼續。

## 核心原則

- **核心觀點貫穿全書**：階段一收到的「核心觀點」必須在每一章都呼應，
  在輸出大綱表的「如何呼應核心觀點」欄位明確標註，
  在階段二撰寫內文時自然融入。
- **NotebookLM 友善**：階段一的 Prompt 設計要能直接複製貼到 NotebookLM 使用，
  指令清楚、結構化、可被機器解析。
- **繁體中文優先**：所有面向讀者的內容預設繁體中文（台灣用語）。
  AI 繪圖 Prompt 例外，建議使用英文。
- **不要直接顯示模板原文**：依模板執行，輸出最終成品，不要把整個 Prompt 模板貼給使用者。
- **保留空欄留白**：若使用者未提供某變數，可標示 `[待補：XX]` 並繼續，不要中斷流程。
- **多版本優先**：書名、副標、章節標題預設輸出 3~5 個版本供使用者挑選。

## 觸發範例

使用者說「我要用龍蝦影片做一本電子書」→ 進入階段一，
詢問核心觀點、目標讀者、章節數，輸出 4 個模組（NotebookLM Prompt、框架、章節表、提取指引）。

使用者說「幫我寫第 3 章」→ 進入階段二，
從上下文或詢問取得該章節大綱，依結構（Hook → 核心內容 → 小結 → 行動清單 → 下章預告）撰寫。

使用者說「這章標題不夠吸引人，再給我幾個」→ 進入階段三，
輸出 5 種風格主標 + 主副標組合 + 公式 + SEO 版。

使用者說「幫我想章首的圖」→ 進入階段四，
輸出 MJ / DALL-E / Ideogram 三平台 Prompt + 放置建議 + 配色方案。
