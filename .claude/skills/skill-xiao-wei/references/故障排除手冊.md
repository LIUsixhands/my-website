# 故障排除手冊｜依症狀查根因

> 原則：**照順序查，不要跳步**。跳步猜測是浪費最多時間的做法。

## 症狀：完全打不開

```bash
python3 webcheck.py check <網址>        # 先看狀態碼
nslookup <網域>                          # DNS 解析得到嗎
python3 webcheck.py cert <網域>          # 網域是不是過期了
```

| 現象 | 根因 | 處置 |
|---|---|---|
| DNS 查不到 | 網域過期／DNS 設定被改／剛換 NS 還沒生效 | 查註冊商到期日；剛改設定的話等 24–48 小時 |
| DNS 有，連線逾時 | 主機掛了／防火牆 | 查平台狀態頁；Netlify/GitHub 通常是全域事故 |
| 憑證錯誤 | 憑證過期／網域綁定跑掉 | 重新簽發，Netlify 是 Domain settings → renew certificate |

## 症狀：出現 404

1. 部署有沒有成功？看平台 deploy log 最新一筆是不是 failed。
2. 首頁檔名是不是 `index.html`（大小寫敏感）。
3. GitHub Pages：Settings → Pages 的分支與資料夾（`/` vs `/docs`）對不對。
4. 剛改過網址結構？舊網址要設轉址，不然 Google 排名一起陪葬。

## 症狀：500 / 502 / 503
平台端錯誤，看 log。靜態網站極少出現，出現多半是：函式（Netlify Functions）掛了、或用了需要後端的表單服務。

## 症狀：打得開但一片空白
JS 錯誤。開瀏覽器 console 看紅字。常見：
- 外部 CDN 掛了或被擋（改自帶檔案）
- 混合內容被瀏覽器擋（http 資源）
- 語法錯誤（剛改過程式碼？回滾快照）

## 症狀：中文變亂碼
1. 檔案存檔編碼不是 UTF-8。
2. HTML 缺 `<meta charset="utf-8">`。
3. **GHL 網站專屬**：base64 注入沒處理好中文 → 固定用 `decodeURIComponent(escape(atob(...)))`，不要自己發明編碼方式。

## 症狀：手機版跑版
1. 缺 `<meta name="viewport" content="width=device-width, initial-scale=1">`。
2. 固定寬度（`width: 1200px`）沒有 `max-width: 100%`。
3. 圖片 `height` 屬性壓過 CSS `aspect-ratio` 把 hero 撐爆（吃茶咖踩過）。
4. 表格／程式碼區塊沒包 `overflow-x: auto`，整頁被撐出橫向捲軸。

## 症狀：表單送出沒收到
**這是最貴的故障，因為沒人會通知你。**
1. 表單 `action` 指向哪裡？第三方服務（Formspree/Netlify Forms）額度用完了嗎？
2. 通知信進垃圾郵件了嗎？
3. 收件信箱還在用嗎（客戶換信箱沒說）？
4. **每月人工實測送一筆**，這是唯一可靠的驗證方式。

## 症狀：內容被改了 / 疑似被入侵
```bash
python3 webcheck.py diff <客戶代號>      # 比對消失與新增的內容
```
- 消失的是法定必載欄位 → **立刻補回並通知客戶**，這有法律風險
- 出現不明外連、賭博／藥品關鍵字 → 疑似被掛馬，立刻通知客戶改後台密碼，並從版控回滾
- 只是客戶自己改的 → 記錄下來，提醒客戶「改動請走工單，不然改壞了我們無法還原」

## 回滾
一律靠 **版控（git）或快照**，禁止用 `rm` 清檔案。
沒有版控的客戶站，第一次接手就先建 git repo 或至少留一份完整壓縮備份。
