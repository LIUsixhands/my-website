# 合規稽核規則｜9 種產業的禁字與必載

> 小維做的是**提示**，不是法律意見。命中禁字＝「這句話有風險，請人工判斷或改寫」，
> 涉及法律爭議一律轉 `skill-xiao-bian`（小辯）。

## 使用方式
```bash
python3 webcheck.py audit <網址> --industry realestate
python3 webcheck.py industries        # 列出所有產業代號
```

## 判定等級
- **FAIL**：法律硬紅線，命中就要改
- **WARN**：修辭風險，看上下文人工判斷（例：餐廳寫「白飯殺手第一名」是形容詞不是不實廣告）

## 各產業重點

### realestate 不動產
- **禁**：保證增值／穩賺／零風險／包租保證獲利／絕對會漲
- **必載**：經紀業名稱、經紀人（營業員）姓名、證書字號
- 缺法定必載欄位是**主管機關直接開罰**的項目，發現當天必修

### medical 醫療診所
- **禁**：根治／治癒／保證見效／最有效／第一／唯一／免費看診／折扣優惠／術前術後對比
- **必載**：醫療機構或醫師身分
- 策略：**走衛教不走廣告**（醫療法§87 II 除外規定），深度內容放官網

### counseling 心理諮商／催眠／身心靈
- **禁**：非心理師使用「心理諮商／心理治療」（心理師法§42，客戶若為執業心理師則免）、宣稱治療憂鬱焦慮創傷、保證改善
- **必載**：非醫療行為聲明
- 對外用「催眠引導」「陪伴」「探索」，不用「諮商」

### health 保健食品／器材
- **禁**：治療／療效／抗癌／降血壓血糖／消炎殺菌／保證瘦／假借衛福部認證
- 只能用「溫熱舒緩」「生活風格」訴求

### finance 金融保險投資
- **禁**：保證獲利／保本保息／零風險／具體報酬率承諾／代操
- **必載**：投資風險警語
- 保證收益條款可能觸及**銀行法§29-1 非法吸金**，最嚴重的一類

### education 補教招生
- **禁**：保證錄取／保證考上／保證就業／100% 上榜
- **WARN**：「免費」——附條件的免費**必須同頁標明條件**，否則構成廣告不實
- **必載**：退費規定

### food 餐飲
- **禁**：治療／抗癌／降三高／藥用
- **WARN**：最好吃／第一名（菜色形容詞屬修辭，人工判斷）
- **必載**：營業資訊與聯絡方式

### beauty 美業／民俗調理
- **禁**：整脊／矯正脊椎／推拿治療／醫美級／微整（醫療法§84）
- **必載**：非醫療性質說明
- 「整脊」改寫「骨架平衡」是已驗證的安全說法

### general 一般商業
- **禁**：保證獲利／保證有效／零風險／穩賺不賠

## 佔位殘留（不分產業，一律 FAIL）
待補／待確認／TBD／TODO／FIXME／Lorem Ipsum／`.todo` 區塊／假電話（09XX、123-456-7890）／範例信箱（example.com、test@test）／樣板預設文字。

**這些上線＝客戶第一眼就知道你沒做完。** 上線前必查第 1 項。

## 新增規則
編輯 `scripts/webcheck.py` 的 `RULES` 字典，格式：
```python
"產業代號": {
    "label": "顯示名稱",
    "forbidden": [(r"正規表示式", "為什麼不行", "法源", "FAIL 或 WARN")],
    "required":  [(r"正規表示式", "應揭露什麼")],
}
```
