# 小帳作業手冊：月結 SOP、憑證規則、會計師交接包

## 一、每月結帳五步驟（月結日＝次月 5 日前）

| 步驟 | 動作 | 產出 |
|:---|:---|:---|
| 1 蒐集 | 收齊：進項發票／收據、銷項發票、銀行對帳單、信用卡帳單、薪資表、平台金流報表 | 憑證資料夾 |
| 2 登帳 | 填流水帳 CSV（`bookkeeper.py init` 產範本）→ `classify` 產分錄 | `分錄.csv` |
| 3 對帳 | 銀行存款餘額 vs 對帳單、信用卡應付 vs 帳單、金流平台入帳 vs 收入 | 差異清單 |
| 4 出表 | `journal` 產試算表／損益表／資產負債表；`vat` 產營業稅試算 | `月報.md` |
| 5 覆核 | 三問：借貸平不平？差額有沒有解釋？異常科目有沒有跳增？ | 覆核意見 3 句 |

**對帳優先於出表。** 沒對過帳的報表只是把錯誤排得漂亮。

## 二、憑證規則（台灣中小企業實務）

- **費用要能列報，先看憑證**：對外交易原則上要統一發票或收據；抬頭與統編要正確，抬頭寫錯的發票不能扣抵。
- **能扣抵進項稅額**：三聯式發票（載明買受人統編）、載有稅額的收銀機發票。
- **不能扣抵**：二聯式發票、交際應酬支出、自用乘人小客車相關、供員工個人使用之支出、免稅／零稅率相關進項的比例部分。→ 稅別欄請填「應稅(不可扣抵)」。
- **無憑證的支出**：先入帳並標註「待補憑證」，月結時列成待辦，不要默默塞「其他費用」。
- **保存年限**：憑證與帳簿依規定至少保存 5 年（帳簿 10 年），電子檔＋紙本雙存。

## 三、常見科目判斷（爭議點先問，不要自己決定）

| 情境 | 處理 |
|:---|:---|
| 買 5 萬元筆電 | 金額達耐用年限資產標準者列固定資產分年折舊，未達者可列費用 → **問教練公司政策**再入帳 |
| 老闆用私人卡付公司費用 | 借 費用／貸 **業主往來**（股東往來），不要直接記現金 |
| 預收整期學費（課程尚未開） | 借 銀行／貸 **預收貨款**，開課依期間轉列收入 |
| 平台抽成（Gumroad／金流商） | 收入認列**總額**，抽成另列「手續費」，不要只記淨額 |
| 外包給個人 | 屬各類所得，可能需**扣繳**並開扣繳憑單 → 標記提醒，交記帳士確認 |
| 交際費 | 單獨科目、進項不得扣抵、稅上有限額 → 一律獨立記，不要混進伙食費 |

## 四、給記帳士／會計師的交接包（每期／每年度）

一個資料夾，六樣東西，寄出前逐項打勾：

1. `分錄.csv`（全期）
2. `月報.md` × 各月（試算表＋損益表＋資產負債表）
3. 銷項發票明細＋作廢／折讓紀錄
4. 進項憑證掃描檔（依月份分資料夾，檔名＝日期_對象_金額）
5. 銀行對帳單、信用卡帳單、金流平台結算單
6. 薪資表、勞健保費單、扣繳資料
7. **待確認清單**：小帳標記為「需人工確認」的每一筆（科目存疑、憑證缺漏、扣繳與否）

## 五、每月給教練的三句話（報表之外一定要講）

1. **這個月賺賠多少、跟上個月差在哪一科**
2. **手上現金還能撐幾個月**（＝期末現金 ÷ 近三個月平均支出）
3. **一個要盯的異常**（某科目暴增、應收超過 60 天未收、留抵稅額一直累積）
