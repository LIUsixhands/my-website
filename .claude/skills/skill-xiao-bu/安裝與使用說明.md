# 🧮 小簿（Xiao Bu）安裝與使用說明

> 你的專屬記帳 AI 員工。
> 幫你把每天的收支，變成三個答案：**這個月賺不賺、現金撐幾個月、該不該漲價。**

---

## 一、安裝（一次就好，三分鐘）

1. 解壓縮 `AI員工_小簿_記帳.zip`
2. 把整個 `skill-xiao-bu` 資料夾放到：
   - **Mac**：`~/.claude/skills/`
   - **Windows**：`C:\Users\你的名字\.claude\skills\`
3. 重開 Claude Code
4. 打「**小簿**」看它有沒有回應 —— 有，就裝好了

> 找不到 `.claude` 資料夾？它是隱藏資料夾。
> Mac 在 Finder 按 `Cmd + Shift + .` 就會顯示。

**電腦要有 Python 3**（Mac 內建）。不確定的話，終端機打 `python3 --version` 看有沒有版本號。
小簿**不需要**安裝任何套件、不需要金鑰、不需要網路。你的帳只留在你自己電腦裡。

## 二、第一次使用（十分鐘）

### 步驟 1：建立你的帳本

行業四選一：`餐飲店`、`個人工作室`、`零售電商`、`接案自由業`

```bash
cd ~/.claude/skills/skill-xiao-bu/scripts
python3 bizbook.py init --dir ~/我的生意帳 --industry 餐飲店 --name "你的店名"
```

### 步驟 2：把 `profile.json` 填成你的實際數字

用文字編輯器打開 `~/我的生意帳/profile.json`，四個地方一定要填：

| 欄位 | 怎麼填 |
|:---|:---|
| `期初現金` | 今天的銀行餘額 ＋ 手上現金 ＋ 收銀機備用金 |
| `老闆每月投入時數` | **含備料、採買、客服、記帳、進修** —— 不是只算站在店裡的時間 |
| `老闆每月要領走的錢` | 你家裡每個月的開銷 |
| `固定成本` | 房租、薪資、水電這些每月固定要付的，填實際金額 |

### 步驟 3：開始記帳

打開 `ledger.csv`（Excel 可以直接開），把裡面的範例刪掉，開始記你自己的。
或者用指令記，比較不會弄壞格式：

```bash
python3 bizbook.py add --dir ~/我的生意帳 --io 收入 --item "日結" --amount 8600 --doc "收銀日結單"
python3 bizbook.py add --dir ~/我的生意帳 --io 支出 --item "市場叫菜" --amount 2400 --who "阿明蔬果行" --doc "手寫收據#012"
```

> 💡 **想不起來分類就別填**，小簿會猜。
> 💡 **想不起來金額不要編**，寫「不確定」，月底一起處理。

## 三、平常怎麼用

| 時機 | 指令 | 你會看到 |
|:---|:---|:---|
| 每天打烊 | `add` | 記一筆，30 秒 |
| 每週一次 | `alert` | 誰欠你錢、哪筆缺憑證 |
| 每月月初 | `tidy` → `cash` → `report` | 帳本體檢 → 對銀行 → 月結儀表板 |
| 三個月一次 | `price --ticket 你的客單價` | 該不該漲價、每天要幾個客人 |
| 交事務所前 | `handoff` | 憑證清冊＋缺什麼＋要問他們什麼 |

```bash
python3 bizbook.py report --dir ~/我的生意帳 --month 2026-08 --minwage 200
```

`--minwage` 填「你如果去打工的時薪」，小簿會拿來對照你的**真實時薪**。
很多老闆算完會嚇一跳 —— 那不是要打擊你，是要你知道**現在是在用你的命補貼這門生意**，
然後才有底氣談漲價、砍品項、或請人。

## 四、最重要的一件事：對銀行餘額

`cash` 會算出「帳上現金」。**每個月拿它跟你的銀行 App 對一次。**

- 差幾百塊：零錢、找零，記一筆「差異調整」註明清楚
- **差幾千以上：一定有筆沒記到** —— 回去翻當月的現金支出

**對不上就不要看 report**，那份報表是假的。

## 五、⚠️ 小簿不能做的事（法律規定）

| 不能做 | 為什麼 | 找誰 |
|:---|:---|:---|
| 幫你報稅、填 401 | 《記帳士法》的法定業務 | 記帳士事務所 |
| 出具財報給銀行／投資人看 | 《會計師法》要簽證 | 會計師 |
| 設計節稅方案 | 同上 | 記帳士／會計師 |
| 判斷「這筆能不能報」 | 那是他們的專業認定 | 事務所（`handoff` 會幫你列成清單） |

小簿做的是**內部管理帳**：把資料整理齊、把數字算清楚、把該問的問題列出來。
**判斷跟申報，交給有牌照的人。**

還有一條規矩，小簿不會通融：**帳只跟憑證一致**。
找不到憑證就照實說找不到，不湊發票、不調數字。
帳的價值不在漂亮，在**你敢照著它做決定**。

## 六、想換行業、想加分類？

打開 `references/industry_presets.json`，改完存檔就生效，不用改程式：

- `支出關鍵字` — 加一個詞，小簿就多認一種寫法
- `支出屬性` — 每個分類是「變動／固定／老闆」，**這決定毛利率算得對不對**
- `健康值` — 跟同業比的參考區間

搞不定就直接跟 Claude 說「小簿，我要加一個分類叫 XXX」，它會幫你改。
