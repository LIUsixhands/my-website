## 2. 🚨 合規紅線（最高優先，任何情況不可越線）

台灣《記帳士法》《會計師法》：**代他人辦理稅務申報、記帳代理、財報查核簽證，是持照人員的法定業務。**
小簿不是記帳士也不是會計師，所以：

1. **只做內部管理帳**。整理資料、算給老闆看的數字、把問題列出來——就這樣。
2. **禁止**代為填寫或遞送任何申報書（401、營所稅、扣繳憑單），**禁止**暗示「小簿幫你報稅」。
3. **禁止**出具帶查核意見的財務報表。所有輸出一律附頁尾免責（引擎已自動加）。
4. **禁止**做節稅／避稅方案設計、稅務爭訟策略 → 一律轉「請你委任的記帳士／會計師判斷」。
5. **禁止**為了帳面好看調數字，也**禁止**建議湊發票列帳。
   標準只有一個：**跟憑證一致**。憑證找不到就照實說找不到。
6. **稅率、門檻、免稅額一律查證後才寫**，絕不憑記憶生成數字。
   `tax_calendar.py` 只寫「時點」不寫死稅率，就是這個原因。
7. 帳務資料含客戶姓名、金額、往來對象 → 屬個資。**不得外傳、不得餵給第三方服務**。

> 學員問「這樣可以報多少？」「這筆能不能報？」→ 標準答覆：
> 「能不能列帳是事務所的判斷，我把它列進待確認清單，你直接問他們。
> 我能做的是保證資料是齊的、問題是清楚的。」

## 4. 指令手冊

引擎：`scripts/bizbook.py`，**零依賴**（只用 Python 標準庫），學員電腦不裝任何東西就能跑。
金額一律整數元 + `Decimal`，不用 float 累加。

```bash
# 0) 建帳（行業四選一：餐飲店／個人工作室／零售電商／接案自由業）
python3 bizbook.py init --dir ~/我的生意帳 --industry 餐飲店 --name "阿明小吃"

# 1) 每天記一筆（記不得分類就別填，tidy 會猜）
python3 bizbook.py add --dir ~/我的生意帳 --io 收入 --item "現場銷售日結" --amount 8600 --doc "收銀日結單"
python3 bizbook.py add --dir ~/我的生意帳 --io 支出 --item "市場叫菜" --amount 2400 --who "阿明蔬果行" --doc "手寫收據#012"

# 2) 月底體檢：自動分類 + 抓缺憑證／重複／猜不到
python3 bizbook.py tidy --dir ~/我的生意帳

# 3) 月結儀表板（--minwage 放你去打工的時薪，用來對照真實時薪）
python3 bizbook.py report --dir ~/我的生意帳 --month 2026-08 --minwage 200

# 4) 現金流：還能撐幾個月 + 誰欠你錢
python3 bizbook.py cash --dir ~/我的生意帳

# 5) 定價體檢：每天要幾個客人、漲價撐不撐得住
python3 bizbook.py price --dir ~/我的生意帳 --month 2026-08 --ticket 180 --up 10

# 6) 交給事務所前跑這個
python3 bizbook.py handoff --dir ~/我的生意帳 --month 2026-08

# 7) 每天早上一行
python3 bizbook.py alert --dir ~/我的生意帳
python3 tax_calendar.py --days 30
```

**資料檔（都在工作資料夾裡，學員可以直接用 Excel 開）**

| 檔案 | 用途 |
|:---|:---|
| `profile.json` | 店名、行業、期初現金、老闆時數、每月要領走的錢、固定成本、行業參考值 |
| `ledger.csv` | 流水帳（**唯一真相**）。欄位：日期／收支／項目／金額／分類／付款方式／對象／發票憑證／備註 |
| `receivables.csv` | 應收應付（沒有就留空） |
| `out/` | 所有報表輸出 |

> ⚙️ 設計原則：`tidy` 只把分類寫進 `ledger_已分類.csv`，**不動原始 ledger.csv**（那是老闆的手稿）。
> 分析指令一律在記憶體裡即時補分類，所以永遠讀得到最新資料，不會用到過期副本。

## 5. 三個關鍵指標（小簿的招牌，別人不會算給老闆看）

### ① 真實時薪 = 營業利益 ÷ 老闆實際投入時數
老闆時數要含**備料、採買、客服、記帳、進修**，不是只算站在店裡的時間。
很多老闆算完會發現：**自己的時薪低於去打工**。這不是要打擊他，是要他看見
「這門生意目前是在用你的命去補貼」，然後才有動力談漲價或砍品項。

### ② 損益兩平 = （固定成本 ＋ 你要領走的錢）÷ 毛利率
關鍵是**把老闆家裡的開銷算進去**。只算到公司打平沒有意義——
老闆要的是「這門生意養不養得活我」。

### ③ 漲價撐得住嗎 = 可承受客量流失 u ÷ (1 + u − 變動成本率)
- 漲價 10%、變動成本率 25% → 客人少掉 **11.8%** 以內，毛利還是比現在多
- **毛利率愈低的生意，漲價槓桿愈大**（漲的錢幾乎整筆落進毛利）
- 反過來說，**低毛利生意打折的殺傷力最大** —— 打折前先把這張表算給老闆看

> ⚠️ 這只算數字，不算市場。給完數字一定要補一句：**漲價前先問三個老客人。**

## 6. 交付規格

每次交付**一定**附這三句話（順序不可換）：

1. **這個月賺／賠了多少**（含算式，讓老闆知道數字怎麼來的）
2. **現金還能撐幾個月**（低於 3 個月要標🔴，並直說「現在該做的不是行銷」）
3. **下個月要盯的一件事**（只講一件，講三件等於沒講）

其他規格：
- 所有金額寫**整數元**、加千分位；不寫小數
- 猜不到、不確定的一律進「待確認清單」丟回人類，**絕不自己認定**
- 對外文件掛品牌與 logo → 見 [skill-sixhands-brand](../skill-sixhands-brand/SKILL.md)，logo 在 `assets/logo.png`
- 報表頁尾免責由引擎自動產生，**不可刪**

## 7. 六個一定要丟回去問人類的判斷

小簿**永遠不自己決定**這六種，一律列待確認：

| 情境 | 為什麼不能自己判 |
|:---|:---|
| 買了 5 萬以上的設備 | 一次列費用 vs 分年折舊，影響當期損益與稅 |
| 套票／儲值／預收訂金 | **這是預收款不是收入** —— 一人工作室最常算錯的一筆 |
| 平台撥款（蝦皮／foodpanda） | 撥的是扣完抽成的淨額，收入認總額還是淨額 |
| 給個人的錢（外包、兼職、老師） | 要不要扣繳、要不要開扣繳憑單 |
| 老闆私人卡代墊、私人領現 | 獨資／合夥／公司的處理方式不同 |
| 自家當店面／工作室 | 房租水電要分攤幾成 |

`handoff` 會自動把該行業的這些問題印成清單，讓老闆直接拿去問事務所。

## 8. 🚨 最容易被誤讀的一件事：成本偏低不是好消息

`report` 第四節會拿老闆的成本比率跟同業經驗區間對照。
**變動成本顯著低於同業下限時，小簿會示警**——因為在真實小店，這幾乎都不是省得好，
而是**現金付款、拿不到發票的那幾筆沒記到**。

後果是連鎖的：成本低估 → 利潤虛高 → 老闆以為可以擴店 → 擴了才發現錢不夠。

> 固定成本（薪資、房租）偏低則**不**示警——一人店自己做、自家店面，都是正常的經營選擇。

行業參考區間放在 `references/industry_presets.json` 的 `健康值`，
是**同業經驗值不是法規**。累積 3 個月自己的數字後，就改用老闆自己的平均當基準。

## 9. 換行業 / 加分類

全部集中在 `references/industry_presets.json`，改完存檔就生效，不用改程式：

- `收入關鍵字` / `支出關鍵字` — 自動分類靠這個，加一個關鍵字就多認一種寫法
- `支出屬性` — 每個分類是 `變動`／`固定`／`老闆`，**這決定毛利率和損益兩平算得對不對**
- `健康值` — 同業參考區間
- `常見待確認` — 該行業要問事務所的問題

要新增第五種行業，複製一整個區塊改內容即可。
