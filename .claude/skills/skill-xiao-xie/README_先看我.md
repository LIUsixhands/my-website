## 二、安裝（三分鐘，只做一次）

### Mac

1. 把解壓出來的 `AI員工_小械` 整個資料夾，放到這個位置並改名：

```bash
mkdir -p ~/.claude/skills
mv ~/Desktop/AI員工_小械 ~/.claude/skills/skill-xiao-xie
```

（如果你是解壓在「下載」資料夾，就把 `~/Desktop` 換成 `~/Downloads`。）

2. 確認裝好了：

```bash
ls ~/.claude/skills/skill-xiao-xie
```

看到 `SKILL.md`、`scripts`、`references` 就對了。

3. 重開 Claude Code，打「**小械**」兩個字，他就會出來報到。

### Windows

把資料夾放到 `C:\Users\你的帳號\.claude\skills\skill-xiao-xie`，其餘相同。
指令裡的 `python3` 請改成 `python`。

## 三、第一次使用（照這個順序）

### 第 1 步：建表

```bash

```

會產生五個 CSV，**用 Excel 或 Numbers 直接打開，不會亂碼**：

```

  3_來源流向.csv
  4_借出試用機.csv
  5_保養校正.csv
```

打開 `1_器材主檔.csv`，**把最後一列的★範例列刪掉**，換成你自己的品項。
不確定欄位怎麼填 → 看 `references/器材主檔欄位規範.md`，20 個欄位逐欄有說明。

> 💡 第一個月的唯一目標就是**把主檔建完**。主檔沒建，後面全部卡住；主檔建完，其他表可以慢慢補。

## 六、先做這三件事

1. **打開 `references/config.json`**，把「公司」區塊的資料填上（名稱、統編、許可執照字號、法規窗口）。
2. **翻 `references/開工前必問清單.md`**，15 題自己先答一遍 —— 答不出來的，就是這家公司真正的風險點。
3. **建主檔**。一天填 10 項，一週就完成。

## 七、幾條不能破的規矩

1. **過期品只有三條路**：隔離、退原廠、報廢。**沒有「展延」這個選項。**
2. **批號／序號原樣抄**，不補零、不改大小寫、不「順手整理格式」— 追溯全靠它對得上。
3. **盤點差異找不到原因，不准直接改平**。在稽核眼中，改平比有差異嚴重得多。
4. **法規數字一律查證**。`config.json` 裡的天數、年限都是 2026-08 查得的，**用之前請複核**
   （全國法規資料庫 law.moj.gov.tw、食藥署 fda.gov.tw）。
5. **對外行銷素材不得有療效宣稱**，醫材廣告另有事前核准制 —— 要做影片或官網，先過法規窗口。

## 八、常見問題

**Q：一定要會寫程式嗎？**
不用。你只要會打開 Excel 填表，然後複製貼上一行指令。

**Q：CSV 用 Excel 開會亂碼嗎？**
不會，全部用 utf-8-sig 存檔。但**存檔時請選「CSV UTF-8」**，別存成 Big5。

**Q：可以接我們現有的 ERP 嗎？**
可以。把 ERP 匯出成 CSV，欄位對照 `器材主檔欄位規範.md` 改一下欄名就能用。

**Q：資料會傳到雲端嗎？**
不會。所有 CSV 都在你自己的電腦上，腳本不連網。

**Q：小械可以幫我報備／通報嗎？**
**不行，也不該。** 他只幫你把資料整理到能直接送件的程度，送件永遠是人具名。
