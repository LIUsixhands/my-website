# 📋 器材主檔欄位規範（`1_器材主檔.csv`）

主檔是全公司的**唯一真相來源**。其他四張表都靠「品項編號」串回這裡。
主檔填錯，後面全錯；主檔沒建，健檢會一直叫「品號不在主檔」。

---

## 欄位逐項說明

| # | 欄位 | 必填 | 怎麼填 | 常見填錯 |
|:--|:---|:--:|:---|:---|
| 1 | **品項編號** | ✅ | 自訂但**永不重複、永不改**。建議 `MD-001` 三碼流水，或用原廠料號。 | 用品名當編號 → 改個字就對不上 |
| 2 | **品名** | ✅ | 用**許可證上的中文品名**，不是業務口語。 | 寫「監視器」，許可證上是「病人監視器」 |
| 3 | 型號 | ✅ | 原廠 Model No.，大小寫照抄。 | 補零、去掉連字號 |
| 4 | 品牌 | | 對外講的品牌名。 | 與製造廠混填 |
| 5 | **製造廠** | ✅ | 許可證上的製造廠全名。 | 填成貿易商 |
| 6 | 原廠國別 | | 製造國。 | 填成出貨港 |
| 7 | **風險等級** | ✅ | 填 `1`／`2`／`3`。**以許可證為準，不要自己猜。** | 憑印象填 |
| 8 | **許可證字號** | ✅ | 照抄，例如 `衛部醫器輸字第00000號`。 | 只填後面數字 |
| 9 | **許可證有效期限** | ✅ | `YYYY-MM-DD`。**這格空著，小械就沒辦法提醒你展延。** | 空白 |
| 10 | UDI-DI | | 單一裝置識別碼的 DI 部分（若有）。 | 把整串 UDI（含批號效期）貼進來 |
| 11 | **是否植入式** | ✅ | `Y`／`N`。決定要不要記載患者資訊。 | 全部填 N 圖方便 → 該記的沒記 |
| 12 | **是否公告申報品項** | ✅ | `Y`／`N`。**必須查主管機關公告，不可憑感覺。** 填 Y 才會有季申報倒數與永久保存提示。 | 全填 N → 漏申報 |
| 13 | 單位 | ✅ | 台／組／盒／支／片。與盤點單位一致。 | 進貨用箱、出貨用盒，數字對不起來 |
| 14 | 保存條件 | | 溫濕度、避光、勿倒置。GDP 稽核會問。 | 留白 |
| 15 | 供應商 | ✅ | 直接供應來源（原廠或上游商）。 | 填成最終客戶 |
| 16 | 供應商聯絡 | | 出事時要立刻找得到人。 | 只寫公司名 |
| 17 | 採購成本 | | 純數字，不要千分位、不要「元」。用於庫存金額估算。 | 填 `80,000 元` → 算不出來 |
| 18 | 建議售價 | | 純數字。用於月報出貨帳面金額估算。 | 同上 |
| 19 | **安全庫存** | ✅ | 純數字。低於它小械就會叫。**不想被叫就填 0，別留空。** | 留空 → 永遠不提醒 |
| 20 | 備註 | | 任何提醒。⚠️ 內含 `★` 的列會被腳本當成範例列**自動略過**。 | 拿 ★ 當重點符號 → 整列被忽略 |

## 三種品項，三種管法

| 類型 | 例子 | 關鍵欄位 | 主要在哪張表 |
|:---|:---|:---|:---|
| **耗材** | 輸液套、電極片、導管 | 批號、有效期限、數量 | 2 庫存批號、3 來源流向 |
| **設備** | 監視器、超音波、雷射 | 序號、保養週期、所在單位 | 4 借出試用機、5 保養校正 |
| **植入式** | 骨釘、支架 | 序號、患者資訊、永久保存 | 3 來源流向（最嚴格） |

**同一家代理商常常三種都有 → 三種表都要維護，不能只顧設備忘了耗材。**

## 日期格式

腳本吃三種：`2026-08-23`、`2026/8/23`、民國 `115.08.23`。
但**輸出一律西元 `YYYY-MM-DD`**。填的時候盡量統一，Excel 自動轉格式是最常見的坑 ——
建議在 Excel 把日期欄先設成「文字」再貼。

## 編號設計建議

```
品項編號   MD-001          品項層級，永不變
庫存編號   S-2026-0001     每一筆進貨批次一個
借出單號   L-2026-001      每一次借出一個
單據號碼   PO-xxx / SO-xxx 進貨單 / 出貨單，與會計傳票對得起來
```

**單據號碼要跟財務（小帳）用同一套**，否則對帳時兩邊各說各話。
