> 助哥指定參考標竿（2026-05-22）。樂居是台灣實價登錄地圖的標竿網站。
> **學它的方法論與呈現原則，不抄它的資料**（它的資料庫是它的資產）。
> 來源：樂居官網介紹 + 數位時代報導 + 助哥提供的實際操作影片。

## 🎯 樂居的定位
「最好用的實價登錄、買房搜尋網站」——整理 / 清洗政府實登資料，**消除資訊不對稱**，主打**簡單、好讀、可信**。

## 🏆 它做得好的 5 件事（值得學）

| # | 長處 | 細節 |
|:--|:--|:--|
| 1 | **資料清洗到位** | 花 2 年清洗政府資料：**扣除車位、排除極端值（去頭去尾）** |
| 2 | **以「社區 / 大樓」為聚合單位** | 同一棟的成交歷史聚在一起看，不是散亂逐筆 |
| 3 | **地圖視覺化** | 地圖直接標社區 / 建案 + **戶數**，一眼看出密度與分布 |
| 4 | **重劃區範圍框** | 藍框標出重劃區邊界 + 該區戶數（助哥影片所見）|
| 5 | **簡單好讀 + 標來源** | UI 乾淨、數據可信、可閱讀性高 |

## 🚀 未來「七期房價查詢系統」要學 + 要超越的點

**學**：
- 資料清洗口徑一致（已對齊）
- 逐棟成交歷史時間軸視覺化（樂居有，我們要做得更深）

**超越**（呼應助哥願景：讓人愛上 + 主動轉介）：
- **聚焦七期、做到極致**：樂居是全台廣度，我們用**在地深度**勝出（逐棟、含助哥的成交內幕判斷）
- **獨家判斷力**：樂居給數字，我們**加上助哥的「判斷」**（這棟值不值得買、議價空間）— 別處查不到
- **轉介機制**：內建分享誘因（樂居沒有強轉介），呼應小潔 SOP 4-3

> 結論：樂居證明「**清洗乾淨的逐棟實登 + 範圍框 + 簡單好讀**」是對的路。我們不跟它拼全台廣度，**用七期在地深度 + 助哥判斷力 + 轉介機制**做出別人沒有的東西。
