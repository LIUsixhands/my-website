## ⚖️ 合規與口徑（小法紅線，務必遵守）

- **資料來源**：內政部不動產交易實價登錄（公開資料）
- **去識別化**：只記「社區 / 大樓名 + 樓層 + 坪數」，**不記完整門牌、不記屋主個資**
- **單價口徑**：統一「**不含車位**」單價（萬元/坪）；若原始含車位，另記於備註
- **警語**：本庫僅供參考，個別物件受樓層 / 屋況 / 面向影響甚大；不代表未來走勢，**無增值或報酬保證**
- **對外發布前一律經小法審稿**

## 📥 助哥餵食格式（照這個貼，我就能彙整）

每筆成交一行，用「｜」隔開，順序固定：

```
社區名｜成交年月｜樓別｜權狀坪數｜單價(萬/坪,不含車位)｜總價(萬)｜車位(有/無/類型)｜備註
```

**範例貼法**（一次貼一棟、多筆沒關係）：
```
惠宇敏行｜2024-03｜12F｜45.2｜58.5｜2644｜平面車位1｜邊間
惠宇敏行｜2024-09｜7F｜45.0｜56.0｜2520｜平面車位1｜
惠宇敏行｜2025-06｜18F｜46.1｜62.0｜2858｜平面車位2｜高樓視野
```

> 💡 你不用算單價也行——把實登原始列（含總價、坪數）貼來，我幫你換算成「不含車位單價」。
