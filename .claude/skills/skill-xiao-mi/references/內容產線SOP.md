# 泌尿科內容產線 SOP

> 一個症狀 → 一組內容包（1 長文 + 3 短文 + 1 短影音 + 1 商家問答）
> 全程走「衛教」路線，不走「廣告」路線。理由見 `法規要點與紅線.md` 第 0 節。

---

## 一、為什麼泌尿科的行銷長這樣

泌尿科的病人有一個別科沒有的特徵：**他不敢問人。**

攝護腺、性功能、漏尿、性病、包皮——這些題目病人不會問朋友、不會問家人，
甚至不會在門診主動講。他只會做一件事：**半夜自己打開 Google 搜。**

這推導出三個結論：

1. **主戰場是搜尋，不是社群。** 社群靠「被推播」，泌尿科的病人是「主動找」。
2. **匿名感比親切感重要。** 病人要的不是「醫師好親切」，是「我可以先偷偷了解，不用先暴露自己」。
3. **內容本身就是轉化。** 一篇把「尿柱變細」講清楚的文章，比十張診所門面照有用。

所以小泌的產線只做一件事：**把病人半夜搜的那句話，變成一篇他讀完會決定掛號的文章。**

## 二、選題：優先序怎麼排

```bash
python3 scripts/medmkt.py kw --dir "./行銷資料"
```

**優先序分數 = 難言之隱度 × 2 + 就醫急迫度**

- **難言之隱度**（1-5）：病人有多不敢問人。越高 → 搜尋依賴度越高、競爭內容越少、你越容易佔位。
- **就醫急迫度**（1-5）：讀完會不會馬上想掛號。越高 → 轉化越快。

難言之隱度給雙倍權重，因為那是泌尿科真正的護城河：
「腎結石好痛」全網都有人寫，「早發性射精」沒幾個醫師願意好好寫。

## 三、長文結構（官網／部落格，1,500–2,500 字）

官網享有醫療法第 85 條第 3 項的特權——內容範圍不受正面表列限制。**深度內容一律放官網。**

```
1. 標題        用病人的原話，不用醫學名詞
                ✅「尿完還想尿、尿柱變細，是攝護腺的問題嗎？」
                ❌「良性攝護腺肥大之診斷與治療」

2. 開場 100 字  先接住焦慮，不急著衛教
                「很多人拖了兩三年才來看，不是不在意，是不知道該不該看。」

3. 這是什麼     用生活比喻講機轉。攝護腺包住尿道 → 像水管外面長了東西壓住

4. 你可能有的症狀  條列，讓病人自我對照（這段停留時間最長）

5. 什麼情況要看醫生  ← 最重要的一段。給明確門檻，不給診斷
                    「出現血尿、完全解不出來、發燒合併腰痛 → 當天就醫」

6. 到院會做什麼   拆掉「怕做侵入性檢查」的恐懼。先講最不可怕的那一項
                 「第一次通常就是問診 + 尿液檢查 + 抽血，不會馬上做侵入性檢查」

7. 治療大方向     只講「有哪幾類」，不講「哪一種最好」、不寫藥品商品名
                 「臨床上依嚴重度分為觀察追蹤、口服藥物、手術三個方向，
                   由醫師依個別狀況評估。相關藥物均須經醫師處方。」

8. 常見誤解 3 條   破除迷思，建立專業感

9. 風險揭露       提到手術或治療就必須寫
                 「任何治療都有其適應症、禁忌症與可能副作用…」

10. 衛教聲明 + 就醫指引
                 「※ 本文為衛生教育資訊…不能取代醫師的親自診察」
                 + 診療科別、診療時間、掛號連結（第 85 條第 1 項容許事項）
```

**寫完必跑：**
```bash
python3 scripts/medmkt.py scan 草稿.md
```

## 四、短文（社群，300–500 字）

社群**只做導流摘要，不做完整衛教**。原因：社群無法完整揭露風險，
而「未完整揭露醫療風險的類文章式廣告」已被主管機關認定為不正當方式。

```
鉤子一句（病人的原話）
↓
三行說清楚一個小觀念
↓
「什麼情況該看醫生」一句
↓
「完整說明看這裡 → 官網連結」
↓
衛教聲明 + 不問診聲明
```

**社群禁區**：不放優惠、不放價格、不放病人留言截圖、不徵集心得、不辦抽獎。

## 五、短影音（30–60 秒）

泌尿科短影音只做兩類，因為這兩類**不需要露出病灶、不需要談療效**：

1. **拆掉尷尬型**：「第一次看泌尿科會發生什麼事」「男生看泌尿科要脫褲子嗎」
   → 直接處理「不敢來」這個最大的轉化障礙。
2. **判斷門檻型**：「這三種血尿要當天就醫」
   → 給行動門檻，不給診斷。

腳本結構：`0-3 秒說出病人心裡那句話 → 中段三個要點 → 結尾一句就醫指引 + 衛教聲明字卡`

**短影音禁區**：不拍手術畫面、不拍器械特寫、不拍病人、不做「前後對比」。

## 六、Google 商家問答（每個症狀配一則）

用商家問答功能自問自答是**合法且有效**的：那是機構自己提供的資訊，不是假借他人名義。
但**問題要用病人的話，答案要簡短並導向官網**。

```
Q：夜尿要看哪一科？
A：夜尿常見的原因包含攝護腺、膀胱功能、睡眠或內科疾病等，
   泌尿科可以做初步評估。若合併血尿、發燒或解不出尿，建議儘早就醫。
   詳細衛教說明：（官網連結）　※本資訊不能取代醫師診察。
```

> **「這篇文章把診所名字拿掉之後，還是一篇有用的衛教文嗎？」**

是 → 它受醫療法第 87 條第 2 項保護，不視為醫療廣告。
不是 → 它其實是廣告，回去改。
