# 平台操作 SOP（官網／Google 商家／社群／留言）

---

## 一、四個平台的分工（不要每個平台都做一樣的事）

| 平台 | 角色 | 為什麼 |
|:---|:---|:---|
| **診所官網** | 主場・深度內容・轉化終點 | 醫療法 §85 III：機構官網內容範圍**不受正面表列限制**。唯一能寫深度衛教的地方 |
| **Google 商家** | 攔截「泌尿科 + 地名」的當下需求 | 病人決定要看醫生的那一刻，第一個動作是搜地圖 |
| **社群（FB/IG）** | 摘要 + 導流 | 只做鉤子與導流，完整衛教一律回官網 |
| **短影音** | 拆掉「不敢來」的心理門檻 | 泌尿科最大的流失點不是不知道，是不敢 |

**鐵律：所有招徠性資訊（診療時間、掛號、地址、科別）掛在「醫療機構」名義下。**
醫師個人帳號只做純衛教與觀點分享——因為醫療法第 84 條規定，**非醫療機構不得為醫療廣告**。

## 二、Google 商家經營

### 該做的
- 診療科別、診療時間、地址、電話、交通路線（§85 I 明文容許）
- 每月 4 則商家貼文，內容＝官網長文的摘要 + 連結
- 每個高優先序症狀配一則「問答」（自問自答合法，見 `內容產線SOP.md` 第六節）
- 相片只放：門口、候診區、掛號櫃檯、衛教海報、醫師執業照
- 評論一律回覆，目標 **48 小時內**

### 不該做的
- ❌ 放手術照、器械特寫、任何病灶影像
- ❌ 徵集好評、請病人留言、提供任何形式的回饋換評論
- ❌ 在貼文放優惠、折扣、免費、限時、名額

## 三、評論回覆話術（最容易出事的地方）

### 🚨 回覆的三條鐵律
1. **不確認、也不否認留言者是本院病人。**
   一句「感謝您上週來院」＝ 公開了對方的就醫事實，個資法第 6 條特種個資。
2. **不談任何病情細節。** 不管對方在留言裡講得多詳細，你都不能接。
3. **不隔空診斷。** 醫療法 §86③ 明文禁止「公開答問」為宣傳。

### 好評回覆
```
謝謝您的回饋，我們會繼續努力。
若有任何健康上的疑問，歡迎於門診時間至診間由醫師評估。
```
> 不要寫「謝謝您選擇本院治療 OO」——那是替對方公開病情。

### 負評回覆（等候太久、態度、費用）
```
謝謝您的意見，很抱歉造成不好的體驗。
關於您反映的情形，我們已請同仁了解並檢討流程。
若方便，歡迎於門診時間來電（電話），由院方為您進一步說明。
```
> 三個動作：**道歉 → 說已在處理 → 把對話拉離公開版面。**
> 絕不在公開版面辯解醫療處置內容，那會同時踩到個資與醫療廣告兩條線。

### 涉及醫療爭議的負評
**不要自己回。** 先通報醫師本人與（必要時）法律顧問，
公開版面只留一句：
```
謝謝您的來訊，我們重視您反映的狀況，
已請專責同仁與您聯繫，請您於門診時間來電（電話）。
```

## 四、留言／私訊統一回覆（防「隔空診斷」）

病人一定會問：「我這樣是不是攝護腺肥大？」「我小便有血是不是癌症？」

**標準回覆（複製即用）：**
```
您好，網路上無法判斷個別狀況，也不適合在公開留言討論個人病情。
您描述的情形建議由醫師實際評估，可於門診時間掛號（連結）。
若出現血尿、完全解不出尿、或發燒合併腰痛，請儘早就醫。
※ 本平台不提供線上診斷或個別醫療建議。
```

三個成分：**拒絕診斷 → 給就醫路徑 → 給紅旗警訊（這句最有價值，也最安全）。**

所有回覆紀錄寫進 `4_評論回覆紀錄.csv`，月報會抓未回覆的。

## 五、官網必備欄位（醫療法 §85 I 容許事項，缺一不可）

- [ ] 醫療機構名稱
- [ ] 開業執照字號
- [ ] 地址、電話、交通路線
- [ ] 負責醫師姓名、專科醫師證書字號
- [ ] 診療科別、診療時間
- [ ] 健保特約字樣（若為特約診所）

全部填在 `references/config.json` 的「診所資料」，
之後所有內容的頁尾都從那裡帶，改一次全站同步。

## 六、⚠️ 廣播與電視

利用**廣播、電視**之醫療廣告，**須先經所在地直轄市或縣（市）主管機關核准**。
平面與網路不需事前核准，但事後會被稽查。
