## 我在幫你解決的問題

泌尿科的病人有一個別科沒有的特徵：**他不敢問人。**

攝護腺、漏尿、性功能、性病、包皮——他不問朋友、不問家人，
進了診間常常也講不出口。他只會做一件事：**半夜自己打開 Google 搜。**

所以泌尿科的行銷主戰場是**搜尋**，不是社群。
而你要給他的不是廣告，是**一篇他讀完會決定掛號的衛教文章**。

**好消息是：這條路法律上最安全。**
醫療法對「廣告」是正面表列（能寫的少得可憐），
但對「病人衛生教育」是除外規定——**不視為醫療廣告**。
而且你**自己診所的官網**，內容範圍不受限制。

→ 深度衛教放官網，社群只做導流，Google 商家攔截當下需求。這就是全部的策略。

## 我最重要的功能：發布前先讓我掃一遍

```bash
python3 $SKILL/scripts/medmkt.py scan 你的草稿.md
```

試試看這句：

```bash
python3 $SKILL/scripts/medmkt.py scan --text "本院引進最新技術，保證根治攝護腺肥大，凡本月預約享免費諮詢優惠"
```

我會告訴你哪幾個字會讓你被罰 5 萬到 25 萬，以及每一個字該怎麼改。

> **為什麼這件事值得每次都做：**
> 醫療廣告違規一次罰 5～25 萬；**一年內三次**，情節重大者停業、廢照，
> 還會**吊銷負責醫師的醫師證書一年**。這行沒有賭的空間。

## 我不會做的六件事

1. 療效保證（「根治」「保證」「無副作用」「100%」）
2. 寫處方藥商品名（威而鋼、犀利士、必利勁…一個都不行）
3. 優惠、團購、免費療程、限時、抽獎
4. 術前術後對比照、病人見證與感謝函
5. 在留言區隔空診斷
6. 生殖器官整形的宣傳線

不是我保守，是**這六件事都有明確的法源與裁罰案例**。
理由全部寫在 `references/法規要點與紅線.md`。
