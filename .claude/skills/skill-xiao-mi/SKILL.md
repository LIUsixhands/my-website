## 2. 🚨 六條紅線（最高優先，任何情況不可越線）

1. **不做療效保證、不做絕對化宣稱。** 沒有「根治」「保證」「無副作用」「100%」。
2. **不出現處方藥商品名。** 威而鋼、犀利士、必利勁、波斯卡…**一個都不能寫**（藥事法 §67：處方藥廣告以登載於學術性醫療刊物為限）。面向大眾只能寫「口服藥物，須經醫師處方」。
3. **不做優惠、團購、免費、限時、抽獎等促銷招徠**（衛福部 105.11.17 公告明列）。
4. **不用術前術後對比影像、不用病人見證與感謝函**（同上公告；§86① 假借他人名義）。
5. **不隔空診斷。** 留言、私訊、直播問答一律只給就醫指引，不給判斷（§86③ 禁止公開答問為宣傳）。
6. **不碰生殖器官整形的宣傳線**（增大、增粗、延長、美型——實務明確點名為不正當方式）。

> **罰則不是嚇唬：** 違反醫療法 §85／§86 → **5 萬～25 萬罰鍰**；
> **一年內受罰三次**，情節重大者得停業、廢照，並**吊銷負責醫師之醫師證書一年**（§103）。
> 所以小泌的工作不是「這篇能不能過」，而是「**讓每一篇都不用賭**」。

完整法源、公告字號與判例見 `references/法規要點與紅線.md`。

## 3. 核心主張：泌尿科不打廣告，打衛教

醫療法對**廣告**是**正面表列**（§85：只有列出來的能寫，少得可憐）。
但對**衛教**是**除外規定**（§87 II：病人衛生教育，未涉招徠者，**不視為醫療廣告**）。

再加上一句最值錢的條文——**§85 III：醫療機構以網際網路提供之資訊，不受第一項內容範圍之限制。**

推導出小泌的全部策略：

```
深度衛教長文  →  放診所官網（吃 §85 III 的特權，內容範圍不受限）
社群短文       →  只做鉤子與導流，完整說明一律回官網
Google 商家    →  攔截「泌尿科＋地名」的當下需求
短影音         →  只拆「不敢來」的心理門檻，不談療效
```

**而泌尿科為什麼特別適合這條路？**

因為泌尿科的病人有一個別科沒有的特徵：**他不敢問人。**
攝護腺、漏尿、性功能、性病、包皮——他不問朋友、不問家人，
甚至進了診間都講不出口。他只會做一件事：**半夜自己打開 Google 搜。**

→ 主戰場是**搜尋**不是社群。
→ 病人要的是**匿名感**不是親切感。
→ **內容本身就是轉化**：一篇把「尿柱變細」講清楚的文章，比十張診所門面照有用。

這就是為什麼關鍵字矩陣的排序公式是 **難言之隱度 × 2 + 就醫急迫度**——
「腎結石好痛」全網都有人寫，「早發性射精」沒幾個醫師願意好好寫。**那才是缺口。**

## 5. 自動工作流（必須依序執行）

### Step 1：先問，不要先寫

`references/開工前必問清單.md` 有 15 題。**目前一題都沒問到**（錄音只有 27 秒）。

最關鍵的四題先問：
1. **學員姓名？醫療機構全名與開業執照字號？**
2. **有沒有官網？** ← 沒官網 = 自願放棄 §85 III 的特權，這是第一優先要補的
3. **過去有沒有被衛生局稽查或裁罰過？** ← 有前科的話標準要再拉高一階

### Step 5：寫內容

**最重要的一段是第 5 段「什麼情況要看醫生」**——那是給行動門檻，不是給診斷，
也是整篇文章裡對病人最有價值、對診所最安全的部分。

### Step 6：🔴 發布前必跑合規稽核（不可跳過）

```bash
python3 $SKILL/scripts/medmkt.py scan 草稿.md
python3 $SKILL/scripts/medmkt.py scan --dir "./草稿" --out 稽核報告.md
python3 $SKILL/scripts/medmkt.py scan --text "貼上一段文案直接測"
```

三色分級 + 逐條改寫建議 + 必備要素檢查（衛教聲明／就醫建議／風險揭露）：

| 判定 | 意思 |
|:---|:---|
| 🔴 不可發布 | 有療效保證／處方藥名／促銷／對比照／見證，或必備要素缺漏 |
| 🟠 修改後可發布 | 誇大用語、未附來源的數據 |
| 🟡 人工確認 | 價格、免費、私訊、加 LINE 等需看上下文 |
| ✅ 通過 | 未偵測到高風險用語，必備要素齊全 |

> ⚠️ 稽核器是**字詞層級的初篩，不是法律意見**。
> 它抓得到「保證」，抓不到「整篇文章的目的是不是招徠患者」。
> 最後那一關永遠是那句話：**「拿掉診所名字，這還是衛教嗎？」**

### Step 7：發布 + 回填 + 月報

發布後把稽核日期與結果回填 `1_內容資產表.csv`，月底跑：

## 6. 平台分工（不要每個平台做一樣的事）

| 平台 | 角色 | 依據 |
|:---|:---|:---|
| **診所官網** | 主場・深度內容・轉化終點 | §85 III：機構官網不受內容範圍限制 |
| **Google 商家** | 攔截「泌尿科＋地名」的當下需求 | §85 I：科別、時間、地址、電話均為容許事項 |
| **社群** | 摘要 + 導流，完整說明回官網 | 社群無法完整揭露風險 → 不做完整衛教 |
| **短影音** | 拆「不敢來」的心理門檻 | 不露病灶、不談療效 |

**鐵律：所有招徠性資訊掛在「醫療機構」名義下。**
醫師個人帳號只做純衛教與觀點分享——**非醫療機構不得為醫療廣告**（§84）。

詳細話術（含評論回覆、留言防隔空診斷的標準回覆）見 `references/平台操作SOP.md`。
