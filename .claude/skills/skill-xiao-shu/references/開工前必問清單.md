# 小書開工前必問清單

問不到答案 → 標「待確認」寫進交付物，**不要自己假設**。

## A. 作業說明書（4 問）

1. **這份給誰看？**
   - 新人（零基礎）→ 每個名詞都要解釋，畫面元素都要描述
   - 同事（會用系統）→ 只寫「這條流程」的差異點
   - 客戶 → 不可放內部後台截圖、不可出現同事姓名
   - 稽核／交接 → 要寫「為什麼這樣做」與依據文件編號

2. **做完算成功的標準是什麼？**（沒有驗收標準 = 這份說明書沒寫完）
   - 畫面上出現什麼？系統寄出什麼信？表格多一列？

3. **這條流程多久做一次？**
   - 每天 → 寫成一頁 checklist，細節放附錄
   - 每月／每年 → 要寫背景、原理、上次踩過的坑

4. **圖是完整的嗎？**
   - 中間有沒有跳步（畫面 A 跳到畫面 C）
   - 有沒有「失敗長怎樣」的圖（例外處理最需要圖）
   - 有沒有需要權限才看得到的畫面

### 附帶要確認
- 版本號從幾號開始？取代哪一份舊文件？
- 誰是這份文件的維護人（流程變了誰負責改）？
- 要不要輸出 PDF 以外的格式（Word／列印雙面／護貝）？

## B. 郵件（4 問，第一次設定時問，之後沿用）

1. **哪些信要看？** 預設 `newer_than:1d -in:spam -category:promotions`；要不要包含促銷／社交分頁？
2. **哪些寄件人是 VIP？**（客戶、主管、會計、平台官方）→ 一律升 🔴 優先看。
3. **哪些事教練一定要親自決定？**（報價、簽約、退費、人事）→ 這類信小書只擬草稿並留空白待填。
4. **草稿要用什麼語氣／署名？** 中文還英文？署名寫本名還是「Sixhands Studio AI數字員工」？

### 每次收信前快速確認
- 時間範圍（今天／本週／某人）
- 要不要一起追「超過 N 天沒回」的舊信（預設 3 天）
