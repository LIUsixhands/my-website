# 內容 SEO 與文章結構

> 技術 SEO 是「讓 Google 看得懂」，內容 SEO 是「讓 Google 有東西可以排」。
> 只有幾頁銷售頁的網站，天花板很低——因為沒有任何一頁在回答「還沒想買的人」正在問的問題。

## 1. 文章的唯一任務

**接住一個具體問句，回答完，然後給一條路走。**

一篇文章 = 一個主關鍵字 = 一個問句 = 一個 CTA。

## 2. 標準大綱模板

```
H1：（含主關鍵字的完整問句或承諾）

前言（100-150 字）
  - 第一句就給答案（Google 精選摘要抓的就是這段）
  - 第二段說「這篇會講什麼、看完你會得到什麼」

H2：先講結論（TL;DR / 三句話版本）
H2：為什麼會有這個問題（情境共鳴，用客戶原話）
H2：做法步驟一
  H3：具體怎麼做（截圖／指令／表格）
H2：做法步驟二
H2：常見錯誤與怎麼避開
H2：真實案例（自家或學員，有數字最好）
H2：常見問題 FAQ（3-5 題，同步掛 FAQPage schema）
結尾 CTA：導到報名頁／LINE／健診工具
```

## 3. 字數與品質

- 資訊字文章：**1,200-2,000 字**。少於 800 字很難排。
- 不要為了湊字數灌水。Google 現在看的是「有沒有把這個問題回答完」。
- **加入別人沒有的東西**：自己的實測數據、自己的案例、自己的截圖、自己踩過的坑。這是 AI 生成內容做不到、也是唯一能排贏的地方。

## 4. 一定要有的元素

| 元素 | 原因 |
|:---|:---|
| 明確的作者與更新日期 | E-E-A-T（經驗、專業、權威、可信）的基本盤 |
| 至少 2 張自製圖／截圖 | 停留時間、圖片搜尋流量 |
| 表格或清單 | 容易被抓成精選摘要 |
| 3 個以上內部連結 | 把權重導向報名頁 |
| 1-2 個外部權威連結 | 引用政府／官方文件會加分 |
| FAQ 區塊 | 吃長尾問句 + 拿 FAQ 複合式摘要 |

## 5. 內鏈規則（最被低估的免費槓桿）

1. **金字塔**：文章 → 分類頁 → 報名頁／課程頁。錢頁（會賺錢的頁）收最多內鏈。
2. **錨點文字寫關鍵字**，不要寫「點這裡」。
3. 每篇新文章發布時，回頭找 2-3 篇舊文章加一條連結指向它。
4. **不要有孤島頁**：任何頁面都要有其他頁連進去。
5. 導覽列與頁尾的連結每頁都有，權重分配低；正文裡的連結權重高。

## 6. 內容排程（12 週起跳）

- 一週一篇，比一個月爆 10 篇再停半年有效得多。
- 前 4 篇打**最長尾、最好排**的字，先讓網站被 Google 認識。
- 第 5 篇起打中等難度。
- 每季回頭更新舊文（更新日期 + 補新資訊），**更新舊文的投報率常常高於寫新文**。

## 7. 🚨 紅線

- 不用 AI 大量生成文章沖量（Google 明列 scaled content abuse）。AI 可以打草稿，但必須加入真實經驗與查證。
- 不抄競品段落。
- 不寫沒做過的案例、不編數據。
- YMYL 主題（醫療、金融、法律）必須標作者資歷與免責聲明。
