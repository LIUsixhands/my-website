# FB 粉專貼文寫法（同步部落格新文用）

> 目的不是把文章搬過去，是**讓沒打算讀長文的人也拿到一個重點**，順便把想深入的人帶回網站。

## 版面規則

- **前兩行就是全部**：FB 大約 125 字元就摺疊成「顯示更多」。鉤子沒在前兩行出現，等於沒有。
- **連結放結尾**：貼文中間插連結會壓低觸及，也打斷閱讀。
- **一則只講一件事**：文章有五個重點，貼文挑最有感的那個。
- **hashtag 3-5 個**：多了像自動發文。
- **不要用「小編」語氣**：這個粉專的人格是助哥本人，用第一人稱講話。

## 結構

```
第 1 行：一個具體的數字或反常識的斷言
第 2 行：把它講白（讓摺疊前的兩行是完整的意思）

（空行）

3-6 段短內容——文章裡最有畫面的那段，用條列或短句
不要把整篇搬過來，留一個「所以呢」在網站上

（空行）

一句話帶到完整內容 👇
網址

#標籤 ×3-5
```

## 寫之前先確認

- 數字有沒有依據？（能不能在文章裡查到）
- 有沒有承諾成效？（「保證」「一定」「馬上」全部拿掉）
- 有沒有誇大？食品、保健、美容、金融這幾類的法規用詞限制特別嚴
- 是不是用客戶原話而不是行話

## 🚨 發布時

- **「發佈」跟「加強推廣」的位置會位移**。發佈對話框載入完成前不要點，點之前先看清楚按鈕文字——按到加強推廣會直接花錢。
- 貼文發出後才發現錯字，用編輯而不是刪除重發（刪掉會失去已累積的觸及）。
- 連結預覽圖沒出來，通常是 FB 快取還沒抓；用 Facebook 的分享偵錯工具重新抓一次即可。

## 節奏

跟部落格同步：每兩天一篇文章、一則貼文。不要為了衝量把舊文重貼。
