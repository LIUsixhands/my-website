# YouTube／影片 SEO

> YouTube 是全球第二大搜尋引擎，而且影片同時會出現在 Google 搜尋結果。
> 但先講清楚：**Shorts 幾乎不吃搜尋，吃的是推薦流量**；SEO 的施力點在長片與「有人在搜的主題」。

## 1. 標題（最重要的欄位）

- **主關鍵字放最前面**。觀眾在手機上只看得到前 30 個中文字左右。
- 硬上限 100 字元，但視覺寬度建議 ≤60（約 30 個中文字）。
- 公式：`主關鍵字 + 具體數字 + 鉤子`
  - ✅「AI 寫貼文教學：3 個指令，10 分鐘生一週內容」
  - ❌「EP12 我們今天來聊聊一些 AI 的東西」
- 分隔線（｜、-）最多 1-2 個，切太碎關鍵字會被拆散。
- **不要標題殺人**：點進來發現不是那回事，觀看時長崩掉，比沒排名更慘。

## 2. 描述

| 位置 | 內容 |
|:---|:---|
| **前 120 字元**（摺疊前唯一可見） | 一句話講清楚影片在幹嘛 + **最重要的那條連結** |
| 中段（300 字以上） | 自然地把主關鍵字與相關詞寫進去，講清楚影片涵蓋什麼 |
| 時間戳章節 | `0:00 開場` 這種格式，第一個必須是 `0:00`。可拿 Google 的 key moments |
| 固定區塊 | 訂閱、其他影片、社群連結、品牌介紹 |
| Hashtag | 3 個以內，前 3 個會顯示在標題上方 |

## 3. 標籤（權重低，但別空著）

- 主關鍵字、同義詞、常見拼字錯誤、品牌字、頻道名。
- 總長上限 500 字元。
- 標籤救不了爛標題，別花太多時間。

## 4. 縮圖

- 排名靠 CTR，CTR 靠縮圖。
- 大字 ≤6 個字，手機縮到指甲大也要看得懂。
- 表情要誇張，臉部佔比要大。
- 縮圖上的字**不要和標題重複**，兩者要互補成一句話。
- 上限 2MB。

## 5. 其他訊號

| 訊號 | 做法 |
|:---|:---|
| **前 30 秒留存** | 開場直接給結論，不要自我介紹 |
| 平均觀看時長 | 比觀看次數更重要 |
| 字幕 | 上傳正確的字幕檔（不要只靠自動字幕），YouTube 靠它理解內容 |
| 播放清單 | 同主題串成清單，帶動系列觀看 |
| 章節 | 提高 Google key moments 曝光 |
| 留言互動 | 發布後 1 小時內回覆留言 |

## 6. 網站端的影片 SEO

在官網嵌入影片時加 `VideoObject` schema（`seocheck.py schema video`），能在 Google 搜尋結果拿到影片縮圖。
必填：`name`、`description`、`thumbnailUrl`、`uploadDate`、`duration`（ISO 8601，例 `PT8M30S`）。

## 7. 檢查指令

```
python3 scripts/seocheck.py yt --title "標題" --desc 描述.txt --tags "關鍵字1,關鍵字2"
```

檢查：標題長度與鉤子、描述前 120 字元有沒有連結、有沒有時間戳、標籤總長。

## 8. 🚨 紅線

- 不用與內容無關的熱門標籤（誤導性中繼資料，違反平台政策）。
- 不買觀看數與訂閱。
- 標題與縮圖不得造假承諾。
- 涉及健康、金融、法律的 AI 人格內容，另受營利政策限制（見「YouTube AI 內容營利新規」記憶）。
