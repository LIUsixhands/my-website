# 小搜 · 安裝與使用說明（Mac／Windows 通用）

## 需要什麼

只需要 **Python 3.8 以上**。`seocheck.py` 不使用任何第三方套件，不需要 `pip install`。

- **Mac**：內建就有，終端機輸入 `python3 -V` 確認。
- **Windows**：到 python.org 下載安裝，安裝時**務必勾選「Add Python to PATH」**。之後在命令提示字元輸入 `python -V` 確認。

## 放在哪裡

```
~/.claude/skills/skill-xiao-sou/        # Mac
%USERPROFILE%\.claude\skills\skill-xiao-sou\   # Windows
```

底下應該有 `SKILL.md`、`scripts/seocheck.py`、`references/`。

## 怎麼用

Mac：

```bash
python3 ~/.claude/skills/skill-xiao-sou/scripts/seocheck.py scan ./你的網站資料夾
```

Windows（命令提示字元）：

```
python %USERPROFILE%\.claude\skills\skill-xiao-sou\scripts\seocheck.py scan .\你的網站資料夾
```

## 五個指令

| 指令 | 做什麼 |
|:---|:---|
| `scan <路徑>` | 掃出所有 SEO 問題，`[X]` 是必修、`[!]` 是建議 |
| `report <路徑> --out 報告.md` | 產出可以交給客戶的健檢報告 |
| `sitemap <資料夾> --base <網址>` | 產生 sitemap.xml 與 robots.txt |
| `schema <類型>` | 產出結構化資料樣板（event／organization／course／faq／localbusiness／breadcrumb／video） |
| `yt --title "標題" --desc 檔案 --tags "a,b"` | 檢查 YouTube 影片的標題描述標籤 |

常用參數：
- `--base https://你的網域` — 讓 canonical／sitemap 用正式網址
- `--exclude 片段` — 不想掃的路徑（例：`--exclude tiktok-callback`）
- `--all` — 連備份檔一起掃（預設會跳過檔名含「備份」「未採用」的檔案）

## 中文顯示問題

Windows 命令提示字元若出現亂碼，先執行：

```
chcp 65001
```

腳本本身已強制 UTF-8 輸出，一般不會有問題。

## 注意

- 掃描是**離線靜態分析**，只看 HTML 檔案本身，不會連到你的網站，也不會送出任何資料。
- 網站速度、是否被 Google 索引、實際排名這三件事，掃描器看不到，要到 PageSpeed Insights 與 Search Console 查。
