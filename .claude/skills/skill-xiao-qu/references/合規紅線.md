# 小曲 · 合規紅線（每支片出門前逐條過）

> 任一紅燈 → **先改再交**。這六條沒有一條可以「這次就算了」。

---

## 紅線 1：本職紅線（你自己的飯碗，排第一）

你的本職在郵局內勤。開這條副業之前：

- [ ] **先查清楚任職單位的兼職／兼營規定**（人事單位、員工工作規則、聘僱契約都要看）。
      中華郵政為國營公司，員工雖非公務員，但仍有兼職相關規範；不同職務、不同單位規定不同，
      **以你單位的白紙黑字為準，不要以同事口耳相傳為準**。
- [ ] **永遠不用單位的電腦、網路、印表機、帳號、信箱**跑這條產線。客戶素材不進單位設備。
- [ ] **不佔用上班時間**接單、回訊、剪片。
- [ ] 不拿單位的名義、識別、制服、場地做招攬。
- [ ] 客戶資料只存在自己的私人電腦。

> 錄音裡教練問過「會不會管制」，這件事**你要自己去確認一次**，不是我幫你判斷。
> 這條沒過，後面五條做再好都沒意義。

## 紅線 2：音樂授權

- ✅ **只用 ElevenLabs `/v1/music` 生成的歌**（`scripts/gen_song.py`）。
- 🚫 不從 YouTube、pixabay、抖音、任何網站抓音樂——就算標「免費」「無版權」也不行。
      YouTube Content ID 會把營收判給第三方，客戶的片被下架是你賠。
- 🚫 不丟連結叫客戶自己去下載素材（這是雙重錯誤：既沒解決問題，又把責任推給客戶）。
- 生成的歌請保留 `audio/take*.mp3` 原檔與生成日期，客戶問來源時拿得出來。

---

## 紅線 3：素材授權

- ✅ 客戶書面提供的照片／影片、你自己現場拍的、AI 生成的通用畫面。
- 🚫 Google 圖片搜尋來的照片。
- 🚫 **AI 仿製有授權的 IP 角色**（Sanrio、寶可夢、迪士尼、球隊隊徽…）。
      客戶賣的是正版授權商品時，只用客戶的**實拍產品照**，不要用 AI 生一隻很像的。
- 🚫 畫面裡出現競品 logo、他人店招、車牌 → 裁掉或模糊。
- 二手影片（客戶給的已上字幕成片）：浮水印／燒死的字幕要逐段實測乾淨區再裁，
  白色轉場動畫程式偵測不到，**只能目視**。

## 紅線 4：廣告不實

歌詞、字幕、尾卡、上架文案**全部**適用：

| 🚫 不能寫 | ✅ 改成 |
|:---|:---|
| 保證、一定、必、百分百 | 「很多客人回頭找的」 |
| 第一、唯一、最便宜、最強 | 「在地做了 XX 年」 |
| 療效、治療、根治、消炎、抗癌、增強免疫 | 生活風格訴求：「暖暖的、放鬆一下」 |
| 瘦幾公斤、幾天見效 | 不寫數字承諾 |
| 點名同業比較 | 只講自己 |

- **食品**不能講療效與醫療效能；**保健品／器材**不能暗示治病；**化妝品**不能寫醫療用語。
- 價格、優惠期限一定要跟客戶書面確認過再上尾卡（口頭說的不算）。
- 客戶堅持要寫紅線字 → 把這頁截圖給他，請他書面確認，你留存。

## 紅線 5：個資與肖像

- 畫面出現可辨識的真人（員工、客人、學員）→ 要有同意，最好是書面／訊息紀錄。
- 小孩入鏡一律要監護人同意。
- 尾卡的電話／LINE／地址**只用客戶自己給的版本**，逐字比對，不要自己從網路查。
- 客戶素材裡的訂單、收據、名單、車牌 → 一律模糊或裁掉。

---

## 紅線 6：品牌歸屬

- **交付給客戶自用的商業片 → 不掛Sixhands Studio logo**，純用客戶自己的 CI。
  在 `mv.json` 設 `"brand": false`。
- 要拿來當**自己的作品集／教學案例** → 另出一版掛 logo，並取得客戶同意公開。
- Sixhands Studio自己的招生片、講座開場片 → 一律掛 logo（`"brand": true`，預設值）。
