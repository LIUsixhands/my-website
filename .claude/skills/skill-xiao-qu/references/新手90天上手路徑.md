# 小曲 · 新手 90 天上手路徑

> 給「對 AI 很不熟、本職是郵局內勤、想做副業」的你。
> 每週要做的事寫死了，照跑就好。不要跳，也不要一次做兩週的份。

---

## 前置（第 0 週，兩個晚上）

- [ ] 確認任職單位**兼職規定**（見 `合規紅線.md` 紅線 1）。這件事沒做完，其他都先不要開始。
- [ ] 準備一台**私人**筆電（不是單位的）。
- [ ] 裝好：Claude Code、ffmpeg、Python 3、Whisper。
      ```bash
      brew install ffmpeg
      pip3 install openai-whisper pillow requests
      ```
- [ ] 拿到 ElevenLabs API key，寫進 `~/.zshrc`。
- [ ] 建資料夾 `~/練習_MV/`（**家目錄，不要放桌面**）。

---

## 第 1–4 週：把產線跑通（不接單）

| 週 | 任務 | 完成標準 |
|:--|:---|:---|
| 1 | 用 `templates/mv_範例.json` 跑一次全流程，素材用**你自己手機拍的任何 8 張照片** | 出得來一支 50 秒 mp4 |
| 2 | 拍**巷口早餐店**（先問老闆能不能拍，說是練習），做第一支真實素材片 | 抽幀拼圖你自己看得下去 |
| 3 | 同一批素材做 **9:16 和 16:9 兩版** | 兩版都沒有切邊、沒有缺字 |
| 4 | 做第 3、第 4 支（髮廊、機車行、手搖飲挑兩家） | 累積 4 支作品 |

**第 4 週結束你要有：4 支成片。** 這就是你的作品集。沒有作品集不要開口報價。

---

## 第 5–8 週：第一個免費客戶 → 第一個付費客戶

| 週 | 任務 |
|:--|:---|
| 5 | 挑**一家你最想放進作品集的店**，免費幫他做一支。交件時用 `接案報價與交付.md` 的話術。 |
| 6 | 拿那支成片去問另外 3 家店：「我幫隔壁做了這支，你要不要也來一支？」報**體驗價 1,500–2,000**。 |
| 7 | 成交第一單。**收 50% 訂金再開工。** 歌詞給客戶書面確認過才生歌。 |
| 8 | 交件、收尾款、**當場問轉介**：「你認識的老闆裡，誰也需要一支？」 |

**第 8 週結束你要有：第一筆收入 + 至少 1 個轉介名單。**

---

## 第 9–12 週：把價格拉上來、把時間壓下去

| 週 | 任務 |
|:--|:---|
| 9 | 價格調到 **NT$ 3,000**。用作品集談，不用價格談。 |
| 10 | 記錄自己每一支的**實際工時**。超過 5 小時的那一步，就是你要優化的地方。 |
| 11 | 談第一個**月約**（4 支／月）。月約才是穩定收入，單支是散工。 |
| 12 | 盤點：接了幾單、收入多少、每小時多少錢。**低於時薪 600 就要調價或調流程。** |

---

## 90 天後的樣子（合理目標，不是保證）

- 作品集 8–12 支
- 付費客戶 3–5 個
- 月收 NT$ 10,000–20,000（副業，每週投入 6–8 小時）
- 至少 1 個月約

---

## 三個最容易死掉的地方

1. **卡在「我還沒準備好」** → 第 5 週那支免費片，不管你覺得夠不夠好，都要交出去。
2. **接了低價客戶然後被無限修改** → 修改次數一開始就寫進報價單。
3. **用單位的電腦／時間做** → 這個會讓你連本職一起賠掉。第一條紅線不是形式。
