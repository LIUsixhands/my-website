# 小曲 · 踩雷速查（撞牆先翻這裡）

---

## 音畫長度對不上（最常見）

**症狀**：影片比音樂長／短一大截，後段抽不到幀。

- ffmpeg 混軌前**音訊取樣率要統一 44100Hz**。macOS `say` 出來是 22050Hz，
  跟 44100 的軌接在一起，聲音會變成兩倍長。
- `build_mv.py` 已經鎖 `-ar 44100`，但**你自己接的外部音軌要先轉**：
  ```bash
  ffmpeg -i in.mp3 -ar 44100 -ac 2 out.mp3
  ```
- 差 0.3 秒以內正常（編碼誤差），超過就是出事。

---

## ffmpeg 跑到天荒地老／檔案爆到幾百 MB

**症狀**：4 秒的鏡頭跑出 464 秒、246MB 的檔案，而且不報錯。

- `zoompan` **絕對不可以配 `-loop 1`**，會變成 n×n 幀爆量。
- 本產線的解法：Ken Burns 全部用 **PIL 逐幀算**，根本不碰 zoompan。
  自己另外寫 ffmpeg 指令時千萬別把這兩個湊在一起。

---

## 中文變空白／豆腐格

- 繁體大字**用 Songti TC，不要用 Songti SC**——SC 缺繁體字，會直接渲染成空白，而且不報錯。
- 本產線預設 `STHeiti Medium.ttc`（黑體）＋ `Songti.ttc`（明體），index 用 0。
- **每次產出都要抽幀目視**，缺字只有眼睛抓得到。

## 手機照片躺著／上下顛倒

- 一律先 `ImageOps.exif_transpose()`。`build_mv.py` 已內建，自己寫腳本時別忘。

## 專案放桌面會卡死

- 桌面在 iCloud 底下，讀檔可能噴 `EDEADLK / EPERM / Errno 60`，而且**症狀是間歇性的**
  （今天好、明天壞），很容易誤判成「腳本壞了」。
- **專案資料夾一律放家目錄**：`~/客戶名_MV/`，不要放 `~/Desktop/`。
- 交件時再把成片複製到桌面。

## AI 生圖翻車

用 Imagen／MiniMax 補畫面時，這幾個必檢：

- prompt **不要寫 "for a hardcover book"** 之類的實體物件描述，會被照字面畫成「一本書的照片」。
- 空景鏡頭**不要送角色參考圖**，參考圖上的衣服顏色會滲進空房間。
- 人種／年齡會在同一批圖裡漂走 → 每批圖先拼 contact sheet 目視再用。
- 手指、畫面裡的文字幾乎一定會壞 → 特寫避開手、不要讓 AI 生中文字。

- 模型第一次會下載（約 1.5GB），要等。

## 二手影片（客戶給的已上字幕成片）

- 浮水印／燒死字幕：逐段實測哪一區乾淨，再決定裁切框，**不要整片套同一個裁切**。
- 緊裁會把原本在邊角的東西（例如背景那把刀）放到畫面正中央 →
  **每個裁切鏡位都算一個新素材，都要重新掃違禁畫面**。
- 白色轉場動畫用色彩偵測抓不到，只能目視。
- 擋不掉的字幕：用「上影像窗 + 下設計面板」的版型把它蓋掉。

---

## 剪輯鐵律（不是 bug，是品質）

- **聲音是主軸，畫面是耗材**：先鎖音軌，再排畫面。
- **音訊零留白**：開頭不要有靜音，結尾切在音樂收乾淨的地方。
- **平均一鏡 2 秒**，副歌可壓到 1.2–1.5 秒。
- **三層證據換媒材**：情境照 → 產品特寫 → 現場／人臉。
- **字幕壓畫面高度 62–65%**（本產線預設 0.63）。

---

## 換比例（9:16 ↔ 16:9）文字整個爆版

**症狀**：直式做好好的，改成橫式之後尾卡的資訊行被 CTA 按鈕壓住、logo 被切掉一半。

- 原因：字級如果照**畫面寬**算，16:9 的寬是 1920，字會直接大 1.8 倍。
- 正解：**字級一律照短邊 `min(W, H)` 算**，版面用「先量總高再置中」的流式排版，
  不要把元素釘在固定的 y 百分比上。
- `build_mv.py` 已經是這樣寫的；你自己另外畫圖卡時要記得。
- **換比例後一定要重抽尾卡那一幀來看**，這個 bug 不會報錯。

## Windows 專屬（Mac 學員可跳過）

| 症狀 | 原因 | 解法 |
|:---|:---|:---|
| `❌ 找不到可用的中文字型` | 微軟正黑體被移除 | 設定→個人化→字型 重裝 msjh，或在 `mv.json` 用 `"fonts"` 指定路徑 |
| `'ffmpeg' 不是內部或外部命令` | winget 裝完沒重開視窗 | **關掉 PowerShell 重開**（PATH 要重新載入） |
| `'python3' 不是內部或外部命令` | Windows 沒有 `python3` 這個別名 | 一律用 `py -3` |
| 金鑰設了還是說沒有 | `setx` 寫進去要新視窗才生效 | 關掉 PowerShell 重開，再 `echo $env:ELEVENLABS_API_KEY` 確認 |
| 字尾被切掉／字幕爆出畫面 | **微軟正黑體字寬 ≠ STHeiti 字寬** | 這是換系統的必然結果，不是 bug。縮字級或減字數，**改完重跑 `check_frames.py` 目視** |
| 讀 md／json 噴 `UnicodeDecodeError` | Windows 預設 cp950 不是 utf-8 | 腳本內部都已寫死 `encoding="utf-8"`；你自己寫的小工具也要記得加 |

🚨 **跨系統的第一支片，Step 8 抽幀目視絕對不能跳過。**
字型換掉之後排版問題**不會報錯**，只會安靜地把字切掉。

## 生歌跳句、兩句黏成一句、Outro 沒唱（2026-09-18 實測）

- 症狀：STT 轉回來少了整句，或兩句被壓成一句；**不會報錯**，只能靠轉錄比對發現。
- 原因：只給 prompt＋整份歌詞時，模型自己決定每段多長，歌詞塞不下就跳過。
- 解法：改用 `composition_plan`，把每段的歌詞和秒數寫死。範例在 `~/房地產代銷_MV/gen_song_plan.py`。
- 秒數照實際唱的速度給：主歌約 3.2 秒一句，副歌約 4.2–4.5 秒一句，Outro 一句至少 6 秒。
  加起來超過 55 秒，就讓歌變長（58 秒也行），**不要把段落秒數壓短**。
