## 自檢（寫完逐條打勾）

- [ ] **店名／品牌名沒有出現在歌詞裡**（只放尾卡）
- [ ] 每句 8–14 字，沒有超過 16 字的
- [ ] 沒有數字流水帳（數字單獨成句、寫成口語）
- [ ] 沒有：保證／一定／第一／最便宜／唯一／療效／根治
- [ ] 副歌有押韻（一段一個韻腳）
- [ ] 副歌第一句是三個賣點裡最強的那個
- [ ] Outro 只有一個動作
- [ ] 唸出來一遍不換氣唸得完
