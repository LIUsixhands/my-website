# 🎬 小曲（AI MV 製作專員）安裝說明

> 出品：Sixhands Studio AI數字員工 🦞
> 版本 v1.1（2026-09-02）· Mac／Windows 通用

---

## 一、這是什麼

小曲是你的 **AI MV 製作組**。給它照片、賣點、和「你要客人做什麼」，
它幫你生一首歌、排好分鏡、燒好字幕、掛上尾卡，直接吐一支能發的 MP4。

- 9:16 直式 → IG Reels／YT Shorts／TikTok
- 16:9 橫式 → 店內螢幕／講座開場／官網
- 全程**不用剪輯軟體**，用 Python + ffmpeg。

---

## 二、安裝（3 分鐘）

### Mac

1. 把 `skill-xiao-qu` 這個資料夾整個放到：
   ```
   ~/.claude/skills/skill-xiao-qu
   ```
   （在 Finder 按 `Cmd + Shift + G`，貼上 `~/.claude/skills`，把資料夾拖進去）

2. 開「終端機」，裝相依套件：
   ```bash
   brew install ffmpeg
   pip3 install openai-whisper pillow requests
   ```

3. 設 ElevenLabs 金鑰（生歌用）：
   ```bash
   echo 'export ELEVENLABS_API_KEY=你的金鑰' >> ~/.zshrc
   source ~/.zshrc
   ```

4. 驗證：
   ```bash
   ffmpeg -version
   python3 -c "import PIL, requests, whisper; print('OK')"
   ```

字型自動用系統內建的 **STHeiti**，不用另外裝。

---

### Windows

> Windows 版是同一套腳本，差別只在「指令長得不一樣」。
> 全部在 **PowerShell** 裡跑（開始鍵搜尋「PowerShell」）。

1. 把 `skill-xiao-qu` 這個資料夾整個放到：
   ```
   C:\Users\你的帳號\.claude\skills\skill-xiao-qu
   ```
   （檔案總管網址列貼上 `%USERPROFILE%\.claude\skills` 按 Enter，把資料夾拖進去。
   如果沒有 `.claude` 資料夾，先開一次 Claude Code 它就會自己建）

2. 裝 ffmpeg 和 Python 套件：
   ```powershell
   winget install Gyan.FFmpeg
   py -3 -m pip install openai-whisper pillow requests
   ```
   > 裝完 ffmpeg **要把 PowerShell 關掉重開**，否則 `ffmpeg` 指令會找不到。

3. 設 ElevenLabs 金鑰（生歌用）：
   ```powershell
   setx ELEVENLABS_API_KEY "你的金鑰"
   ```
   > `setx` 是寫進系統環境變數，**設完一樣要關掉重開 PowerShell** 才生效。

4. 驗證：
   ```powershell
   ffmpeg -version
   py -3 -c "import PIL, requests, whisper; print('OK')"
   ```

**Windows 的 3 個不一樣，記起來：**

| 項目 | Mac | Windows |
|:---|:---|:---|
| 跑 Python | `python3 xxx.py` | `py -3 xxx.py` |
| 路徑 | `~/練習_MV` | `%USERPROFILE%\練習_MV` |
| 中文字型 | STHeiti（內建） | 微軟正黑體 msjh.ttc（內建） |

⚠️ **字型不同 = 字寬不同**。同一份 `mv.json` 在 Mac 排得剛好，到 Windows 可能字尾被切掉。
**Windows 出第一支片一定要跑 `check_frames.py` 用眼睛看抽幀拼圖**，確認字沒爆版、沒被切邊。

如果出現「❌ 找不到可用的中文字型」，代表微軟正黑體被移除了。
到「設定 → 個人化 → 字型」重裝，或在 `mv.json` 自己指定：
```json
"fonts": { "bold": "C:/Windows/Fonts/msjhbd.ttc", "light": "C:/Windows/Fonts/msjh.ttc" }
```

### 確認裝好了

開 Claude Code，打「**小曲**」。它會自我介紹，就代表成功。

## 三、怎麼用

在 Claude Code 裡直接說人話就好：

| 你說 | 小曲會做 |
|:---|:---|
| 「小曲」 | 自我介紹 + 問你要做什麼 |
| 「幫我做一支早餐店的 MV」 | 從收料問卷開始帶你走完 |
| 「幫我寫歌詞」 | 用五段式模板寫，寫完自檢 |
| 「生歌」 | 跑 ElevenLabs，生 2 個 take |
| 「挑 take」 | 用 Whisper 比咬字，機器挑 |
| 「出片」 | 合成 final.mp4 |
| 「驗收」 | 抽幀拼圖 + 逐條檢查表 |

## 四、第一次用，照這個順序

**Mac**
```bash
mkdir -p ~/練習_MV && cd ~/練習_MV          # 🚨 家目錄，不要放桌面
cp ~/.claude/skills/skill-xiao-qu/templates/mv_範例.json mv.json
mkdir assets                                  # 把照片丟進來
# 改 mv.json：歌詞、曲風、分鏡、尾卡

python3 ~/.claude/skills/skill-xiao-qu/scripts/gen_song.py    mv.json
python3 ~/.claude/skills/skill-xiao-qu/scripts/pick_take.py   mv.json
python3 ~/.claude/skills/skill-xiao-qu/scripts/align_subs.py  mv.json --take 2
# 手動修 subs.json
python3 ~/.claude/skills/skill-xiao-qu/scripts/build_mv.py    mv.json
python3 ~/.claude/skills/skill-xiao-qu/scripts/check_frames.py out/final.mp4
```

**Windows（PowerShell）**
```powershell
$S = "$env:USERPROFILE\.claude\skills\skill-xiao-qu"
mkdir "$env:USERPROFILE\練習_MV"; cd "$env:USERPROFILE\練習_MV"
copy "$S\templates\mv_範例.json" mv.json
mkdir assets                                  # 把照片丟進來
# 改 mv.json：歌詞、曲風、分鏡、尾卡

py -3 "$S\scripts\gen_song.py"    mv.json
py -3 "$S\scripts\pick_take.py"   mv.json
py -3 "$S\scripts\align_subs.py"  mv.json --take 2
# 手動修 subs.json
py -3 "$S\scripts\build_mv.py"    mv.json
py -3 "$S\scripts\check_frames.py" out\final.mp4
```

> 其實你根本不用背這些指令 —— 在 Claude Code 裡打「小曲，幫我出片」，它會自己判斷你是 Mac 還是 Windows 並用對的指令。上面這串是給你想自己手動跑時對照用的。
