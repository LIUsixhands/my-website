## 使用方式

```bash
cd ~/.claude/skills/skill-xiao-zhi/scripts
python3 orgmgr.py init --dir "./天麗組織資料"
```

`init` 會把上面這些檔案複製一份到你指定的資料夾（含一列 ★範例，**填之前請刪掉**）。

---

## ⚠️ 三個注意事項

1. **不要放敏感個資。**
   身分證號、金融帳號、地址完整門牌**不進這些 CSV**，一律走公司加密系統。
   名冊只放：編號、稱呼、聯絡方式、階級、推薦關係、狀態。

2. **不要放在 iCloud 同步資料夾（如桌面／文件）。**
   建議放在使用者家目錄下的本機資料夾，例如 `~/天麗組織資料`。
   iCloud 的「未下載檔案」會讓腳本讀檔卡住或報錯。

3. **CSV 請用「UTF-8」開啟。**
   Excel 直接雙擊若出現亂碼，請用「資料 → 從文字/CSV → 編碼選 UTF-8」匯入。
   腳本輸出一律為 `utf-8-sig`，Excel 通常可直接開。
