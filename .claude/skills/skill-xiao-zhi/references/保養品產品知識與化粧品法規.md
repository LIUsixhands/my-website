# 保養品產品知識與化粧品法規

> 給天麗保養品的經銷團隊。
> **一個人講錯一句療效，罰的是那個人，賠的是整個品牌。**

---

## 一、法規基本盤

主要法源：《化粧品衛生安全管理法》
主管機關：衛生福利部食品藥物管理署（TFDA）／地方衛生局

| 要點 | 內容 |
|:---|:---|
| **產品登錄** | 化粧品應依規定完成產品登錄，並符合標示規定 |
| **含藥化粧品** | 特定用途化粧品（如防曬、染髮、止汗等）需經**查驗登記**取得許可證 |
| **廣告** | **不得虛偽、誇大，不得宣稱醫療效能** |
| **標示** | 品名、成分、用途、用法、重量容量、製造或輸入業者名稱地址、批號或製造日期、保存期限等 |
| **PIF** | 產品資訊檔案應由業者建立保存 |

> ⚠️ 罰則金額與細節請至 `law.moj.gov.tw` 及 TFDA 網站確認現行規定。

## 二、絕對禁用字（掃描字庫）

### 🔴 醫療效能類（最重）
治療、療效、根治、痊癒、消炎、殺菌、抗菌、抑菌、除疤、去疤、淡化疤痕、
改善濕疹、改善異位性皮膚炎、改善酒糟、治痘、抗痘、除痘、痘痘消失、
除皺、去皺、消除細紋、生髮、防止落髮、豐胸、瘦身、減肥、燃脂、排毒、
修復受損細胞、活化細胞、促進膠原蛋白增生、抗發炎、鎮定紅腫、
醫療級、藥用、藥妝級、可取代醫美、術後修復、替代雷射

### 🔴 誇大不實類
瞬間、立即、三天見效、七天變白、保證有效、無效退費（療效向）、
永久、一勞永逸、零副作用、無副作用、100%天然、絕對安全、
全世界最好、業界唯一、第一品牌、銷售冠軍（無佐證）

### 🟡 需要佐證才能用
最新科技、專利成分、實驗證實、臨床測試、皮膚科醫師推薦
→ **有報告才准講，且必須揭露測試機構、樣本數與條件；報告要能立刻拿得出來。**

## 三、安全的講法（給經銷商背）

| 想表達 | ✅ 安全說法 |
|:---|:---|
| 保濕 | 幫助肌膚保持潤澤、減少乾燥緊繃感 |
| 美白 | 幫助肌膚看起來勻亮（若為特定用途化粧品，依許可用途敘述） |
| 抗老 | 幫助修飾外觀、維持肌膚彈潤感 |
| 痘痘肌 | 幫助維持清爽、適合油性肌膚日常保養 |
| 敏感肌 | 質地溫和，建議先於耳後或手臂內側試用 |
| 使用心得 | 「這是我個人使用後的感受，每個人膚況不同」 |

### 三句保命句（建議寫進所有商品貼文模板）
1. 「本產品為化粧品，非藥品，不具醫療效能。」
2. 「以上為個人使用感受，實際感受因人而異。」
3. 「如有皮膚不適或疾病狀況，請諮詢皮膚科醫師。」

## 四、經銷商自媒體發文規範（簽署版重點）

新人在 D2 合規課後應簽署，內容至少包含：

1. 不使用上列禁用字；不宣稱醫療效能。
2. 不使用**未經同意**的他人照片，尤其**素顏、膚況、前後對比照**。
3. 前後對比照若使用：須有本人書面同意、註明拍攝條件與期間、
   並標註「個人感受，效果因人而異」。**不修圖、不換光線騙人。**
4. 不承諾收入、不寫「被動收入」「躺著賺」。
5. 不冒用公司名義發言；頭銜一律標示「天麗**獨立經銷商**」。
6. 商品說明與制度說明**只轉發公司統一版本**。
7. 違規時：接獲通知**24 小時內下架**；重複違規依制度處理（警告→暫停獎金→終止契約）。

## 五、客訴與不良反應處理

| 情況 | 處理 |
|:---|:---|
| 使用後泛紅、刺癢 | ①請立即停用②冷水沖洗③**建議就醫**④通報公司留存紀錄 |
| 顧客要求「你說會好結果沒好」 | 調閱該經銷商的對話紀錄，若有療效宣稱 → 立即處理並補償 |
| 主管機關來函 | **不要自己回**，交公司法規窗口／小辯 |

> 🔴 **不良反應一律通報並留存紀錄**。
> 　 隱瞞一次，將來就是整批商品被追。
