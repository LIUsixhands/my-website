## 二、安裝（三分鐘，只做一次）

### Mac

把解壓出來的 `AI員工_小織` 整個資料夾放到這個位置並改名：

```bash
mkdir -p ~/.claude/skills && mv ~/Desktop/AI員工_小織 ~/.claude/skills/skill-xiao-zhi
```

（如果你是解壓在「下載」資料夾，就把 `~/Desktop` 換成 `~/Downloads`。）

確認裝好了：

```bash
ls ~/.claude/skills/skill-xiao-zhi
```

看到 `SKILL.md`、`references`、`scripts`、`範本` 就成功了。

### Windows

1. 把 `AI員工_小織` 資料夾放到：
   `C:\Users\你的帳號\.claude\skills\`
2. 資料夾名稱改成 `skill-xiao-zhi`
3. 開啟「命令提示字元」確認：

```
dir %USERPROFILE%\.claude\skills\skill-xiao-zhi
```

> Windows 執行腳本時，把所有 `python3` 換成 `python`。
> 若出現 `'python' 不是內部或外部命令`，請到 python.org 安裝 Python 3，
> 安裝時**記得勾選 Add Python to PATH**。

## 三、開工（照這個順序，不要跳）

```bash
cd ~/.claude/skills/skill-xiao-zhi/scripts

# 1. 建立你的資料夾（⚠️ 不要放桌面／文件，那是 iCloud）
python3 orgmgr.py init --dir "~/天麗組織資料"

# 2. 打開 0_品牌資料卡.json，先填「制度屬性」四題
#    （不會填 → 看 references/開工前必問15題.md 第 1～4 題）

# 3. 制度屬性判定 —— 這是第 0 號文件，沒過不准往下走
python3 orgmgr.py verdict --dir "~/天麗組織資料"

# 4. 獎金結構健檢
python3 orgmgr.py comp --dir "~/天麗組織資料"

# 5. 組織藍圖（現況／12 個月／36 個月）
python3 orgmgr.py blueprint --dir "~/天麗組織資料" --target 300

# 6. 招募漏斗與今天該聯繫誰
python3 orgmgr.py pipeline --dir "~/天麗組織資料"

# 7. 每月 5 號：組織健檢 → 出月報
python3 orgmgr.py health --dir "~/天麗組織資料" --period 2026-09
python3 orgmgr.py report --dir "~/天麗組織資料" --period 2026-09

# 8. 任何招募文案發出去之前，一定要跑這個
python3 orgmgr.py scan --file "招募貼文.txt"
```

## 五、三個一定要記得的觀念

1. **零售佔比是這個組織的體溫。**
   低於 50%，代表錢主要不是從「賣東西給真正的消費者」來的 ——
   那已經不是營運問題，是《多層次傳銷管理法》第 18 條的法律問題。

2. **活動率沒到，就不要招人。**
   名冊上 100 個人只有 20 個在動，再招 50 個進來，只會變成 150 個人裡 25 個在動。
   數字更難看，而且你更累。

3. **先能複製，再談倍增。**
   一個帶不動 5 個人的系統，帶 500 個人只會崩得更快。
