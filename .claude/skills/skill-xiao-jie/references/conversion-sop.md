# 三、導流轉化 SOP（房地產版）

導流轉化是把流量變成有效名單與委託 / 帶看的關鍵。目標：讓每一分行銷預算都產生可追蹤的回報（ROI ≥ 3.0x）。終點是 **LINE OA 加好友 → 帶看預約 / 賣方委託**。

---

## SOP 3-1：Facebook / Google 廣告投放管理

系統化管理在地廣告投放（派小賺執行），從預算到素材到成效。

### 流程步驟

| 步驟 | 執行內容 | 頻率 | 工具 |
|------|---------|------|------|
| 1. 月度預算規劃 | 依當月目標分配，建議 Facebook 70% + Google 30% | 每月初 | 預算表 |
| 2. 受眾設定 | 3-5 組受眾：核心（興趣：房地產 / 裝潢 / 室內設計 + 在地）、相似（成交客戶 Lookalike 1-3%）、再行銷（網站訪客 / 速查表填寫者 / 物件頁瀏覽者） | 每月更新 | 廣告管理員 |
| 3. 素材製作 | 每組 2-3 版素材（圖片 + 文案組合）做 A/B 測試 | 每週更新 | Canva + 文案 |
| 4. 廣告上線 | 設定 活動 → 廣告組 → 廣告，確認追蹤像素與轉化事件（名單 / 加 LINE） | 素材就緒後 | FB / Google Ads |
| 5. 每日監控 | 每天看花費、曝光、點擊、CPC、CPL，異常立即調整 | 每日 10 分鐘 | 廣告後台 |
| 6. 週優化 | 暫停表現差的素材，擴大表現好的預算，調整受眾 | 每週三 | 廣告後台 |
| 7. 月度報告 | 彙整月成效：總花費、總名單、CPL、CPA、ROAS，與上月對比 | 每月初 | 表格 + AI |

### 廣告關鍵指標基準

> ⚠️ 房地產客單高、成交週期長，這裡的「轉化」以**有效名單 / 帶看預約**為主，CPA 指「每筆有效諮詢成本」。實際門檻請依在地行情與物件單價校準。

| 指標 | 目標值 | 警戒線 | 觸發行動 |
|------|--------|--------|---------|
| CPC（每次點擊） | ≤ NT$15 | > NT$25 | 立即優化素材或受眾 |
| CPL（每條名單） | ≤ NT$150 | > NT$250 | 檢視落地頁與表單流程 |
| CPA（每筆有效諮詢 / 帶看） | ≤ NT$1,000 | > NT$2,000 | 暫停廣告組，全面檢討 |
| ROAS / ROI | ≥ 3.0x | < 2.0x | 暫停投放，檢討策略 |
| CTR（點擊率） | ≥ 1.5% | < 0.8% | 更換素材，測試新角度 |

### 廣告文案結構

1. **痛點開頭**：「在七期看了 30 間還是不敢下手？」
2. **解方呈現**：「助哥用 12 個判斷點，幫你看對再出手」
3. **社會證明**：「在地深耕 X 年，住宅 / 土地 / 廠房都成交」
4. **CTA**：「免費領『七期實價登錄速查表』→ 加 LINE」
5. ⚖️ 合規：不得「保證增值 / 穩賺 / 最低價」，發布前過小法

## SOP 3-2：導流誘餌推廣流程（購屋判斷力測驗 / 實價登錄速查表）

免費誘餌是最重要的自動化導流漏斗，取代原 AI 健診。目標每月 200+ 人領取 / 填寫。

### 流程步驟

| 步驟 | 執行內容 | 頻率 | 產出物 |
|------|---------|------|--------|
| 1. 推廣素材製作 | 3 種切角：痛點型（「你買房的判斷力及格嗎？」）、好奇型（「測測你的購屋判斷分數」）、利益型（「免費領七期實價速查表 + 30 分鐘諮詢」） | 每月更新 | 3 組素材 |
| 2. 多管道投放 | 社群（每週 1 篇提及）、廣告、電子報 CTA、LINE OA、個人 Profile 連結 | 持續 | 各管道上線 |
| 3. 名單追蹤 | 每天看新名單，在表格標來源管道與意願級別 | 每日 | Google Sheet |
| 4. 分級跟進 | 依意願 / 需求進行差異化跟進（見下表） | 即時 | LINE + 電話 |
| 5. 轉化追蹤 | 追蹤每位填寫者後續行為，計算各級別轉化率 | 每週彙整 | 轉化追蹤表 |

### 名單分級跟進策略

| 級別 | 訊號 | 跟進方式 | 時效 |
|------|------|---------|------|
| 🔥 高意願 | 明確時程 / 已看屋 / 已備頭款 | **24 小時內主動致電**，邀約帶看 / 一對一購屋諮詢 | 24 小時 |
| 🟡 中意願 | 有需求但時程未定 | 發物件推薦 + 成交案例 + 在地行情報告 | 48 小時 |
| 🔵 起步探索 | 觀望、收集資訊 | 加入電子報持續培育 + 推薦電子書 / 速查表 | 1 週 |
| ⚪ 低意願 | 純好奇 / 同業 | 發免費購屋入門資源 + 邀入 LINE 經營 | 1 週 |

## SOP 3-3：賞屋團 / 購屋講座行銷推廣流程

線下活動是重要轉化場。目標：80 人報名、60 人到場、促成帶看預約 / 委託意向。

### 六週倒推時程表

| 時間軸 | 執行內容 | 負責人 | 產出物 |
|--------|---------|--------|--------|
| 活動前 6 週 | 確認日期場地、製作主視覺與報名頁、開始社群預熱 | 小潔 | 報名頁上線 |
| 活動前 4 週 | 啟動廣告（報名導流）、電子報通知、LINE OA 推播、邀在地 KOL 協宣 | 小潔 | 廣告上線 + 推播 |
| 活動前 2 週 | 追蹤報名數據、準備現場物料（海報 / DM / 速查表）、撰寫接待話術 | 小潔 | 物料確認 |
| 活動前 3 天 | 發報名確認提醒（Email + LINE）、活動指南、確認場地設備 | 小潔 + 助哥 | 行前通知 |
| 活動當天 | 現場報到引導、即時直播、帶看預約 / 委託諮詢引導 | 小潔 | 現場名單統計 |
| 活動後 1 週 | 回顧信、3-5 支精華影片、未到場者追蹤、成效報告 | 小潔 | 成效報告 |

### 現場轉化策略

1. **價值錨定**：先講「買錯一間多付 800 萬」，再凸顯「判斷服務」的價值
2. **限時誘因**：現場預約帶看享優先看屋 + 免費「購屋判斷 12 點清單」
3. **雙人同行**：揪團賞屋加贈在地行情報告
4. **即時預約**：QR Code 帶看 / 諮詢預約表隨掃隨填
5. ⚖️ 合規：活動文宣不得保證增值 / 報酬，不得誇大稀缺（如不實「最後一戶」），過小法

## SOP 3-4：落地頁轉化率優化

持續優化物件落地頁 / LINE 加好友頁 / 服務介紹頁，提升自然流量轉化（目標 ≥ 3%）。

### 流程步驟

| 步驟 | 執行內容 | 頻率 | 工具 |
|------|---------|------|------|
| 1. 數據基線 | 記錄落地頁訪客數、停留、跳出率、轉化率、熱區 | 初始設定 | GA4 + Hotjar |
| 2. A/B 測試 | 每月至少 1 次。優先序：標題 > CTA 按鈕 > 信任元素（成交數 / 見證）排列 | 每月 1 次 | A/B 工具 |
| 3. 文案優化 | 依名單回饋與數據，優化痛點、服務價值、FAQ、見證 | 每 2 週 | 文件 |
| 4. 信任更新 | 每月更新客戶見證、成交案例數據、媒體 / 在地報導 | 每月 | 落地頁後台 |
| 5. 轉化追蹤 | 每週記錄轉化率，分析 流量來源 × 轉化率，找高價值管道 | 每週 | GA4 + 表格 |

### 落地頁結構最佳實踐

1. **Hero 區**：一句話痛點 + 一句話解方（不賣房子賣判斷）+ CTA
2. **問題放大**：3-4 個買賣方具體痛點場景
3. **解方呈現**：助哥的判斷服務 / 房仲土仲差異化
4. **社會證明**：客戶見證（照片 + 成果）+ 成交案例 + 媒體
5. **服務流程**：諮詢 → 看對 → 議價 → 成交，各階段助哥怎麼幫
6. **誘餌區**：免費速查表 / 判斷清單領取
7. **FAQ**：解決最後猶豫（服務費、流程、保密）
8. **最終 CTA**：重複價值主張 + 加 LINE / 預約按鈕
9. ⚖️ 合規：成交數據與見證需屬實可查，發布前過小法
