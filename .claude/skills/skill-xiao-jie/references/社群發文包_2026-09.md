# 【第 3 天・10/02】換屋先買還是先賣

## A. LINE（連結放內文）

```
有在考慮換屋的，這篇寫給你。

「我應該先買還是先賣？」——這題我每個月都被問好幾次。多數人接著會問「哪個比較划算」，但這個問法本身就沒有答案。

因為兩條路賺賠的不是同一件事：
先買後賣，你扛的是「錢」的風險（可能一段時間背兩份貸款）
先賣後買，你扛的是「住」的風險（賣掉了但還沒買到，要租屋、搬兩次）

所以要問的不是哪個划算，是哪一種風險你扛得住。

# 【第 5 天・10/04】七期的地為什麼買不到

## A. LINE（連結放內文）

```
今天這篇寫土地，講一件很多人不知道的事。

有人問我：「七期怎麼都是商辦？住宅不是比較好賣嗎？」
也有人反過來問：「我買的房子，以後旁邊會不會蓋一堆住宅，把檔次拉下來？」

這兩題的答案是同一條：那塊地的分區，決定了它能蓋什麼。

七期核心一帶有一種分區叫「第四種新市政中心專用區」，業界簡稱新四 —— 容積率 650%，依現行規定不得作住宅使用，只能做飯店、商場、百貨和商辦。

第一層：有些地，依現行規定不能做住宅

七期核心一帶有一種分區叫「第四種新市政中心專用區」，業界簡稱「新四」。容積率 650%，依現行規定不得作住宅使用，只能規劃飯店、商場、百貨與商辦。

這條解釋了為什麼惠國段一帶全是商辦、飯店、百貨 —— 不是建商一致看好商辦，是他們沒有別的選擇。
