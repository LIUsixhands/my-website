## 🎯 這篇的設計邏輯（寫下次同類型貼文時照抄）

1. **鉤子用金額，不用百分比。**
   「差 8%」沒感覺，「200 坪差一千萬」才會被記住。**換算成實際金額是整篇最關鍵的一句。**
2. **先破除一個誤解。** 「十三期不是一個地方，是四個段」——
   讀者以為自己懂的事其實不懂，這會讓他繼續讀下去。
3. **「不用加好友、不用留資料」** 把推銷疑慮先拿掉，點擊率差很多。
4. **真正的價值不在貼文，在被轉發。**
   四段價差對同業、代銷、建商是有用的工具，他們會存、會轉。
   這才是曝光成長計畫第 3 步要的「別人想引用的東西」。

## ⚠️ 配圖的製作紀錄（含一次自我更正）

圖用 `card.html` → chromium 1080×1080 @2x 產出。字型 Noto Serif TC / Noto Sans TC。

**圖表形式選 dot plot 而非長條圖**：數值落在 64–70 的窄區間，長條圖必須從 0 起算
（截斷基線是長條圖的硬錯誤），但從 0 起算會讓四段看起來幾乎一樣，失去意義。
dot plot 不需要零基線，可誠實呈現區間差距。
