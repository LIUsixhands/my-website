# 二、內容行銷 SOP（房地產版）

內容行銷是助哥 IP 最重要的長期獲客引擎。目標：透過有價值的判斷型內容吸引七期 / 西屯南屯買賣方，建立信任，最終導流至 LINE OA → 帶看預約 / 委託。

---

## SOP 2-1：每月內容企劃與排程

每月底規劃下月完整內容行事曆，確保穩定產出。

### 流程步驟

| 步驟 | 執行內容 | 時間 | 產出物 |
|------|---------|------|--------|
| 1. 主題規劃 | 依下月重點（賞屋團 / 講座 / 物件主打）+ 房市議題 + 買賣方常見問題，列 4 個週主題 | 每月 25 日前 | 月度主題清單 |
| 2. 內容矩陣填充 | 每個週主題拆成：1 篇長文 + 3 篇社群短貼 + 1 支短影片 + 1 篇限動 | 每月 27 日前 | 內容行事曆 |
| 3. 素材預製 | 提前製作下週圖片、影片腳本、文案初稿，用 AI 加速 | 每週五下午 | 下週素材包 |
| 4. 排程發布 | 完成內容排入各平台排程 | 素材完成即排 | 排程確認 |
| 5. 月底覆盤 | 分析每篇互動數據，標 Top 5 / Bottom 5，歸納成功模式 | 每月最後一天 | 月度成效分析 |

### 內容主題靈感來源（房地產五方向）

1. **買賣方常見問題** → 教學型（「七期買房最常踩的 5 個雷」）
2. **房市新聞 / 政策** → 觀點型（「新青安對七期首購的實際影響」）
3. **成交 / 服務案例** → 故事型（「議價 9,380 萬：一筆廠房怎麼談下來的」）
4. **判斷力知識** → 知識型（「土地單價 × 地坪：自己算估價三步驟」）
5. **助哥日常 / 理念** → 人設型（「我為什麼說『不賣房子，賣判斷』」）

## SOP 2-2：社群貼文製作流程

從構思到發布的標準流程，確保每篇有策略、有品質、有追蹤。

### 流程步驟

| 步驟 | 執行內容 | 建議時間 | 工具 |
|------|---------|---------|------|
| 1. 確認目標 | 明確目標：品牌認知 / 互動 / 導流 / 轉化？目標不同寫法不同 | 2 分鐘 | — |
| 2. AI 初稿 | 用 Claude / ChatGPT 生 2-3 版文案，提供明確 Prompt | 10 分鐘 | Claude / ChatGPT |
| 3. 人工優化 | 選最佳版，加真實案例 / 實價數據 / 助哥觀點 / 口語修飾 | 15 分鐘 | 文件 |
| 4. 視覺製作 | 用 Canva 品牌模板做配圖 / 輪播 / 物件卡 | 15 分鐘 | Canva |
| 5. 品質檢查 | 逐項確認：錯字？品牌調性？CTA？Hashtag？連結？圖片？合規用詞？ | 5 分鐘 | 貼文檢查表 |
| 6. 排程 / 發布 | 排入工具或直接發布，記錄時間與平台 | 2 分鐘 | 排程工具 |
| 7. 互動回覆 | 發布後 2 小時內回覆留言，24 小時內追蹤數據 | 持續 | 各平台 |

### 社群貼文 AI Prompt 模板

> 你是助哥（七期房地產，房仲土仲）的行銷專員，受眾是七期 / 西屯南屯的首購與換屋族。請幫我寫一篇 Facebook 貼文，主題是 [主題]。要求：
> (1) 開頭用一個引起共鳴的購屋 / 賣房痛點問題
> (2) 中段用一個具體案例或實價登錄數據說明「怎麼判斷」
> (3) 結尾引導至 [CTA：加 LINE 領速查表 / 預約帶看]
> 語氣像懂行的朋友分享判斷，專業不浮誇。字數 150-250 字。避免「保證 / 最便宜 / 穩賺」等違規用詞。

### 最佳發文時段

| 平台 | 最佳時段 | 次佳時段 | 頻率 |
|------|---------|---------|------|
| Facebook | 週二~四 12:00-13:00 | 週一~五 20:00-21:00 | 每週 3-4 篇 |
| Instagram | 週二~五 11:00-13:00 | 週日 10:00-11:00 | 每週 3 篇 + 每日限動 |
| LINE OA | 週二、四 12:30 | 週五 18:00 | 每週 2 次推播 |

### 貼文品質檢查表

- ☐ 有明確單一目標（品牌 / 互動 / 導流 / 轉化）
- ☐ 開頭 2 行能讓人停止滑動
- ☐ 語氣符合品牌調性（專業友善，不像 AI 機器產出）
- ☐ 有具體案例或實價數據佐證（數據附來源）
- ☐ CTA 明確且只有一個主要 CTA
- ☐ 無錯字、無連結錯誤
- ☐ 配圖符合品牌視覺
- ☐ Hashtag 3-5 個（含品牌與在地 tag，如 #七期 #台中買房）
- ☐ ⚖️ 無違規用詞（保證增值 / 最便宜 / 穩賺），必要時過小法

## SOP 2-3：SEO 文章撰寫流程

每月產出 2+ 篇 SEO 長文，建立長期自然流量（派小文執行）。

### 流程步驟

| 步驟 | 執行內容 | 建議時間 | 工具 |
|------|---------|---------|------|
| 1. 關鍵字研究 | 找目標關鍵字（搜尋量 100-1000 / 月、競爭中低），列本月 2-3 個 | 1 小時 / 月 | Ubersuggest / Ahrefs |
| 2. 競品分析 | 搜尋目標字，分析前 5 名文章結構、字數、主題 | 30 分鐘 / 篇 | Google 搜尋 |
| 3. 大綱撰寫 | AI 生大綱，涵蓋搜尋意圖各面向，加助哥獨特判斷 / 案例 | 20 分鐘 | Claude |
| 4. 初稿撰寫 | AI 輔助寫初稿（1,500-3,000 字），分段、每段明確指令 | 1.5 小時 | Claude |
| 5. 人工優化 | 加真實案例、客戶故事、助哥觀點，優化標題與 Meta | 1 小時 | 文件 |
| 6. SEO 優化 | 標題含關鍵字、H2/H3 合理、內鏈 2+、圖片 Alt、字數 ≥1,500 | 20 分鐘 | SEO 檢查表 |
| 7. 發布追蹤 | 發布、提交 Search Console，30/60/90 天追蹤排名 | 10 分鐘 + 持續 | Search Console |

### SEO 檢查表

- ☐ 標題含目標關鍵字（如「七期 買房」），≤60 字元
- ☐ Meta Description 含關鍵字，150-160 字元
- ☐ H2/H3 結構清晰，至少 3 個 H2
- ☐ 目標關鍵字自然出現 5-10 次（不堆砌）
- ☐ 內部連結至少 2 個（連到物件頁 / 速查表 / 其他文章）
- ☐ 圖片都有 Alt 文字
- ☐ 字數 ≥1,500 字
- ☐ 有明確 CTA（加 LINE / 預約帶看 / 領速查表）

## SOP 2-4：電子報經營流程

每週發送電子報，持續培育潛在買賣方的興趣與信任。

### 流程步驟

| 步驟 | 執行內容 | 時間 | 工具 |
|------|---------|------|------|
| 1. 名單管理 | 每週整理新訂閱者，分群（來源：速查表 / 講座 / 官網 / 社群；身份：買方 / 屋主） | 每週一 | Email 平台 |
| 2. 內容規劃 | 定本週主題（與社群呼應不重複） | 每週二 | 內容行事曆 |
| 3. AI 撰稿 | AI 生初稿，結構：問候 → 市場觀察（300-500 字）→ 物件 / 資源 → CTA | 每週三上午 | Claude |
| 4. 人工編輯 | 優化語氣（像寫信給朋友）、個人化、確認連結 | 每週三下午 | Email 平台 |
| 5. 測試發送 | 發測試信給自己與助哥，確認排版、連結、圖片 | 每週四上午 | Email 平台 |
| 6. 正式發送 | 最佳時段（週四 12:30 或週五 10:00）發送 | 每週四 / 五 | Email 平台 |
| 7. 數據追蹤 | 48 小時後看開信率、點擊率、退訂率 | 發送後 48 小時 | 追蹤表 |

### 電子報 KPI 基準

| 指標 | 目標值 | 警戒線 |
|------|--------|--------|
| 開信率 | ≥ 35% | < 25% |
| 點擊率 | ≥ 5% | < 2% |
| 退訂率 | ≤ 0.5% / 期 | > 1% |

退訂率超過 1% 需檢討：推播太頻繁？內容偏離期待？太多銷售太少價值？

### 電子報 AI Prompt 模板

> 請幫我寫助哥的週電子報，主題 [主題]。
> 結構：(1) 一句親切問候 (2) [主題] 的市場觀察與判斷，300-500 字 (3) 推薦 1-2 個資源（速查表 / 物件 / 講座）(4) CTA 引導至 [加 LINE / 預約帶看]。
> 語氣像在地前輩寫信給朋友，溫暖有料、不說教。避免保證 / 穩賺等違規用詞。
