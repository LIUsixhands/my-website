# 預測紀錄檔（predictions.jsonl）欄位定義與驗證流程

這份紀錄是整個 skill「可驗證準確率」的基礎。目的不是自我感覺良好，而是誠實地量化：**我的判斷長期到底準不準？我標「高信心」時是不是真的比較準？** 沒有紀錄，「很準」永遠只是錯覺（人會選擇性記住猜對的、忘記猜錯的）。

檔案位置：專案根目錄 `predictions.jsonl`，每行一個 JSON 物件（JSON Lines 格式，方便一直往後追加）。

## 欄位定義

| 欄位 | 型別 | 說明 |
|------|------|------|
| `date` | string | 做出預測的日期，`YYYY-MM-DD` |
| `ticker` | string | 股票代號；產業/主題預測填代表標的或產業名 |
| `name` | string | 公司或產業名稱 |
| `market` | string | 固定 `TW` |
| `direction` | string | `看多` / `看空` / `中性偏多` / `中性偏空` / `區間` |
| `confidence` | string | `高` / `中` / `低` —— 你對這個判斷的信心 |
| `horizon` | string | 預期驗證的時間框架，如 `2週`、`1-3個月`、`半年` |
| `thesis` | string | 核心論點，一兩句話講清楚為什麼 |
| `entry_ref` | string | 進場參考條件（可為空） |
| `stop_ref` | string | 停損參考條件（可為空） |
| `target_ref` | string | 目標價/區間（可為空） |
| `scenarios` | object | `{"bull":0.4,"base":0.45,"bear":0.15}`，三者相加為 1 |
| `price_at_call` | number/null | 下判斷當時的參考價，方便日後算報酬（查得到就填） |
| `outcome` | string/null | 驗證結果，未驗證為 `null`；驗證後填 `命中`/`未命中`/`部分命中`/`未到期` |
| `verified_date` | string/null | 回填驗證的日期 |
| `note` | string | 驗證時的補充說明（可為空） |

## 一筆範例

```json
{"date":"2026-07-23","ticker":"3017","name":"奇鋐","market":"TW","direction":"看多","confidence":"中","horizon":"1-3個月","thesis":"AI伺服器散熱需求外溢，市場只盯大廠、低估中游散熱模組的訂單能見度","entry_ref":"回測季線不破","stop_ref":"跌破前低","target_ref":"+20%","scenarios":{"bull":0.45,"base":0.4,"bear":0.15},"price_at_call":820,"outcome":null,"verified_date":null,"note":""}
```

## 驗證流程（使用者說「回顧預測準不準」時）

1. 讀 `predictions.jsonl` 全部。
2. 篩出 `outcome` 為 `null` 且今天已超過其 `horizon` 推算的到期日的預測。
3. 對每一筆，用 SKILL.md 的 Step 0 查現價與後續發展，判定：
   - **命中**：走勢方向與論點相符（看多且確實漲、看空且確實跌）。
   - **未命中**：方向相反。
   - **部分命中**：方向對但幅度遠不如預期，或先對後錯。
   - **未到期**：時間框架還沒到，跳過不計。
4. 回填 `outcome`、`verified_date`、必要的 `note`。
5. 彙整並回報：
   - 整體命中率（排除未到期）。
   - **信心校準**：把預測按 `confidence` 分組，看「高信心」的命中率是否真的高於「中」與「低」。如果高信心反而不準，代表信心給太浮誇，要調整。
   - **方向偏誤**：是不是系統性偏多或偏空？看多的命中率 vs 看空的命中率差很多，代表有心理偏誤要修正。
   - 用這些發現，具體說一句「接下來下判斷時該怎麼調整」。

## 重要心態

- 紀錄的價值在**誠實**。驗證時不要幫過去的自己找藉口硬凹成「命中」——凹了，這份紀錄就失去校準能力，等於自欺。
- 樣本少的時候（例如少於 10 筆），命中率只能參考，不要過度解讀。重點是養成「每個判斷都留痕、都回頭對帳」的習慣。
- 這是一個複利的系統：紀錄越多，校準越準，判斷品質越高。
