# 台股產業鏈聯動框架（M1 產業鏈 X 光用）

這份是「思考鷹架」，不是標準答案。用它快速定位一檔個股在供應鏈的位置、以及該去盯哪個上游訊號。**代表公司會隨時間變動，實際分析時仍要用 Step 0 查證最新供應鏈關係與客戶名單**，不要把這裡的名字當永恆事實。

## 怎麼用這份地圖

1. 先把個股歸到某條鏈、某個環節（上/中/下游）。
2. 往「上游」找先行指標：上游的訂單/稼動率/資本支出，通常領先下游營收 1–2 季。
3. 往「終端」找需求源頭：終端品牌的出貨、財測、庫存，是整條鏈的需求方向盤。
4. 問一句：這條鏈裡「市場只盯著明星股、卻忽略了誰」？被忽略的受益者/受害者常是 alpha 所在。

---

## 鏈一：AI 伺服器 / 加速運算（近年主線）

終端需求源：雲端大廠資本支出（CSP capex）、NVIDIA/AMD 加速器出貨與財測。

```
上游：晶圓代工（先進製程、CoWoS 先進封裝）
  → 中游：ABF 載板、PCB、記憶體（HBM）、測試
  → 下游：伺服器代工/組裝、散熱、電源、機櫃、光通訊
```

盯訊號的順序：NVIDIA 財測與 CoWoS 產能 → 台積電先進封裝稼動 → 載板/散熱/電源接單 → 伺服器代工出貨。散熱、電源、光通訊常是「需求外溢」的受益環節，市場有時反應較慢。

## 鏈二：智慧型手機 / 消費電子

終端需求源：Apple 與 Android 品牌新機出貨、換機週期。

```
上游：晶圓代工、IC 設計
  → 中游：封測、鏡頭、面板、被動元件
  → 下游：組裝代工、品牌
```

盯訊號：品牌端出貨與砍單/追單傳聞 → 上游拉貨或庫存調整。旺季備貨（Q2–Q3）與淡季（Q1）節奏很固定，別把季節性當趨勢反轉。

## 鏈三：半導體設備與資本支出

終端需求源：全球晶圓廠擴產計畫、ASML EUV 出貨量。

```
ASML/應材 等設備出貨 → 晶圓廠資本支出 → 廠務工程、設備零組件、耗材
```

盯訊號：ASML 訂單與財測是整個半導體資本支出的領先風向球；設備廠的接單能見度領先廠務與耗材。

## 鏈四：電動車 / 車用電子

終端需求源：全球電動車銷量、車廠電動化進度。

```
上游：功率半導體（含第三代半導體）、電池材料
  → 中游：電池芯/模組、車用 IC、連接器、電控
  → 下游：整車、充電基礎設施
```

盯訊號：車廠銷量與價格戰 → 供應鏈稼動。政策補貼與充電網布建是中長線變數。

## 鏈五：傳產與景氣循環（鋼鐵、塑化、航運、金融）

這些對總體經濟、原物料價格、利率更敏感，供應鏈邏輯較弱，改盯：
- 航運：運價指數（如 SCFI/BDI）、艙位供需。
- 塑化：油價與價差（如乙烯–石油腦價差）。
- 鋼鐵：中國需求與出口報價。
- 金融：利率環境、利差、放款成長、資產品質。

## 台美連動的通用問法

- 分析台股個股時，永遠追問一句：**「它的美股客戶/終端，最近的財測與出貨數據透露了什麼？」**
- 分析美股趨勢時，反過來問：**「這個趨勢的台灣供應鏈，誰是受益者、誰是受害者，而且還沒被 price in？」**
- 留意時間差：美股終端財報/財測公布後，台股供應鏈的反應常有數天到數週的滯後，這個滯後窗口就是機會。
