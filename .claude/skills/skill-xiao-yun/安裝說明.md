## 安裝（macOS）

### 方法 A：解壓縮直接丟（推薦）

1. 解壓 `skill-xiao-yun.zip`
2. 把整個 `skill-xiao-yun` 資料夾拖到：
   ```
   ~/.claude/skills/
   ```
   （Finder 按 `Cmd + Shift + G`，貼上 `~/.claude/skills` 即可開啟）
3. 重開 Claude Code
4. 輸入「**小運**」測試

### 方法 B：終端機一行指令

```bash
unzip -o ~/Desktop/skill技能包/skill-xiao-yun.zip -d ~/.claude/skills/
```

## 安裝（Windows）

技能資料夾路徑改為：

```
C:\Users\<你的帳號>\.claude\skills\
```

其餘步驟相同。若找不到 `.claude` 資料夾，請在檔案總管開啟「顯示隱藏項目」。

## 怎麼用

### 情境 1：片子拍好了，要上架
```

要發 YouTube Shorts 和 IG Reels，
受眾是 40 歲上班族，目的是導流到講座報名頁。
```

→ 得到完整上架文案包（標題 ×3 / 封面大字 / 描述 / hashtag / 置頂留言 / CTA / 合規檢查）

### 情境 2：只想要標題

→ 三版標題各附「抓的是哪個心理」

```
小運，幫我排下個月的週更表
```
→ 先定四大內容支柱，再排格子

## 附贈工具：批次文案包生成器

量產時可用腳本，內建**字數檢查 + 合規紅線掃描**：

```bash
# 產一份範例 JSON 當起手式
python3 ~/.claude/skills/skill-xiao-yun/scripts/gen_copy_pack.py --sample > input.json

# 產出 Markdown 文案包
python3 ~/.claude/skills/skill-xiao-yun/scripts/gen_copy_pack.py input.json -o 文案包.md

# 只跑檢查（趕時間時用）
python3 ~/.claude/skills/skill-xiao-yun/scripts/gen_copy_pack.py input.json --check-only
```

需求：Python 3（macOS 內建，無需安裝套件）。

## ⚠️ 兩個必須知道的限制

1. **合規掃描只擋明著寫的違規詞**（保證賺／根治／最強…），**擋不住語意暗示**。
   例：「我朋友吃完就不痛了」不會被抓，但一樣是療效宣稱。
   👉 太赫茲、保健品、食療、投資類的稿子，**人工必須再看一遍**。

2. **平台字數與 hashtag 規則會變動**（TikTok 字數這兩年就改過）。
   表裡是通用值，重要投放前建議貼進後台實測一次有沒有被截斷。
