# 六平台規格與語感差異（小運速查）

> ⚠️ 平台規格會變動。表中數字為撰稿時的通用值，遇到重要投放前建議實測一次（貼進後台看有沒有被截斷）。
> **鐵律：一稿多發 ≠ 複製貼上。**

## 語感改寫指南

### YouTube Shorts
- **標題 = 搜尋詞**：受眾會 google 的字要進標題前半。
- 描述做 SEO：前 2 行寫重點＋關鍵字，中段放時間軸／延伸連結，末段放頻道固定資訊。
- 固定系列前綴養回訪（`頻道名 EP##｜`）。
- 縮圖／首幀是 CTR 主戰場，標題只是輔助。

### Instagram Reels
- 前 2 行就是全部：把最狠的一句放第一行，第二行留白。
- 大量換行、口語、可用 emoji 分段（但別成串亂灑）。
- 內文不能放連結 → CTA 一律導向「留言關鍵字」或「看限動」或「點 bio」。
- 收藏率是 IG 的隱藏權重 → 文案末尾加「先存起來，之後用得到」。

### TikTok
- 最短最快。一句話講完，不要寫小作文。
- 網感、梗、口語，別用書面語。
- Hashtag 少而精，混一個大流量 + 兩個垂類。
- **留言區是第二戰場**：預先在置頂留言埋爭議點或補充，衝互動。

### Facebook
- 說人話講故事，長文反而吃香（台灣 FB 受眾偏中高齡，願意讀）。
- 開頭 3 行必須自成一段完整鉤子。
- **連結放第一則留言**，內文放連結會被壓觸及。
- 適合「經驗分享體」：我遇到什麼 → 我怎麼解 → 你也可以。

### Threads
- 像在自言自語，不要有「行銷味」。
- 先丟一個觀點或提問，把影片放第二則串文。
- 一則 500 字，長內容拆 3-4 則串文，最後一則放 CTA。
- 反問句結尾最容易引出回覆。

### 小紅書
- 標題 ≤20 全形字，可帶 1-2 個 emoji（❗️🔥💡）。
- 筆記體：分點、粗體感、「姐妹們」「碼住」「親測」等社群語。
- 內文結構：痛點 → 我試了什麼 → 結論 → 分點乾貨 → tag。
- ⚠️ 用**簡體**發小紅書；若整包文案是繁體，需另出簡體版。
