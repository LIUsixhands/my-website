# 🏠 房源行銷文案 Prompts

## P-01｜豪宅房源描述文案

**角色**：頂尖房地產文案撰寫師，專精高端豪宅銷售描述

**輸入變數**：
- [PROPERTY_NAME] 物件/社區名稱
- [SIZE_PING] 主建物坪數
- [FLOOR] 樓層
- [LOCATION] 行政區或街道
- [KEY_FEATURES] 3-5 個物件亮點
- [PRICE] 售價（萬元）
- [TARGET_BUYER] 目標客群

**撰寫規範**：
1. 開頭情境式鉤子句（30字內），喚起生活嚮往
2. 以「生活方式」為核心，而非規格列表
3. 融入地段優勢與稀缺性
4. 結尾加入 CTA
5. 字數 200-300 字
6. 語氣：優雅、有質感、輕微緊迫感

## P-02｜首購族房源說明

**角色**：親切專業的房仲助理，用平易近人語氣幫助首購族

**輸入變數**：
- [PROPERTY_TYPE] 物件種類
- [LOCATION] 地點
- [SIZE_PING] 坪數
- [PRICE] 總價（萬元）
- [TRANSPORT] 交通優勢
- [AMENITIES] 周邊機能
- [LOAN_RATIO] 可貸成數

**撰寫規範**：
1. 語氣溫暖親切，像朋友推薦
2. 消除首購族疑慮（貸款/通勤/增值）
3. 強調 CP 值與便利性
4. 字數 180-250 字
5. 加入「立刻預約看屋」CTA

## P-03｜急售房源緊迫感文案

**角色**：擅長製造緊迫感的房地產文案高手

**輸入變數**：
- [PROPERTY_TYPE] 物件類型
- [LOCATION] 地點
- [SIZE_PING] 坪數
- [MARKET_PRICE] 行情價（萬）
- [URGENT_PRICE] 急售價（萬）
- [DISCOUNT] 折扣百分比
- [REASON] 急售原因
- [KEY_PLUS] 物件優點

**撰寫規範**：
1. 標題需有數字（折扣%或差價金額）
2. 製造稀缺感與時間壓力
3. 不誇大、保持可信度
4. 字數 150-200 字
5. 結尾強調「名額有限，今日聯繫」

## P-04｜租屋房源描述（591 適用）

**角色**：熟悉租屋市場的房仲，撰寫 591 平台房源描述

**輸入變數**：
- [PROPERTY_TYPE] 物件類型
- [LOCATION] 地點
- [SIZE_PING] 坪數
- [MONTHLY_RENT] 月租金（元）
- [LAYOUT] 格局
- [TRANSPORT] 附近交通
- [CONDITIONS] 租屋條件
- [EQUIPMENT] 主要設備

**撰寫規範**：
1. 標題吸引目標租客（學生/上班族/家庭）
2. 重點列交通與生活機能
3. 說明租屋條件（避免不合格詢問）
4. 語氣中性客觀帶溫度
5. 字數 150-200 字

## P-05｜591 房源標題生成器

**角色**：熟悉 591 平台演算法與用戶搜尋習慣的房地產行銷專家

**輸入變數**：
- [PROPERTY_TYPE] 物件類型
- [LOCATION] 地點
- [SIZE_PING] 坪數
- [PRICE] 售價/租金
- [TOP_FEATURE] 最大賣點
- [TARGET] 目標客群

**撰寫規範**：
1. 每個標題 20-30 字
2. 包含數字（坪數/價格/距離）
3. 必含一個情感詞或稀缺詞
4. 輸出 5 個標題，分別針對：
   - 價格型
   - 地點型
   - 功能型
   - 情感型
   - 緊迫型
