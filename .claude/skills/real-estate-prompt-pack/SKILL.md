# 房地產仲介 AI 提示詞包 Skill

## 使用流程

當使用者請求生成房仲相關文案時，依下列步驟執行：

### Step 1：辨識需求類別

詢問或從上下文判斷使用者的需求屬於哪一類：

| 代號 | 分類 | 對應 Prompt 編號 |
|------|------|------------------|
| 🏠 | 房源行銷文案 | P-01 ~ P-05 |
| 👥 | 客戶開發話術 | P-06 ~ P-10 |
| 📱 | 社群媒體貼文 | P-11 ~ P-15 |
| 📧 | 電子郵件/訊息跟進 | P-16 ~ P-20 |
| 🤝 | 議價談判話術 | P-21 ~ P-24 |
| 📊 | 市場分析報告 | P-25 ~ P-28 |

### Step 2：載入對應 Prompt

從 `prompts/` 目錄讀取對應的 Prompt 文件：
- `prompts/01-listing.md` — 房源行銷文案（P-01~P-05）
- `prompts/02-development.md` — 客戶開發話術（P-06~P-10）
- `prompts/03-social.md` — 社群媒體貼文（P-11~P-15）
- `prompts/04-followup.md` — 跟進訊息（P-16~P-20）
- `prompts/05-negotiation.md` — 議價談判（P-21~P-24）
- `prompts/06-analysis.md` — 市場分析（P-25~P-28）
- `prompts/bonus.md` — 附贈 Prompt 與工作流程鏈

### Step 3：收集變數

向使用者詢問該 Prompt 所需的變數值（例如 [LOCATION]、[PRICE]、[TARGET_BUYER] 等）。
若使用者已在請求中提供部分資訊，直接套用，只詢問缺少的部分。

### Step 4：生成輸出

根據填好變數的 Prompt 生成繁體中文文案，遵守：

1. **語氣**：依 Prompt 規範（優雅／親切／緊迫等）
2. **字數**：嚴格遵守每個 Prompt 指定的字數範圍
3. **結構**：包含 Hook、主體、CTA
4. **法規**：避免「保證增值」「一定成交」等違反房屋廣告法規的字眼
5. **個人化**：保留供使用者填入個人風格的彈性

### Step 5：提供修改選項

輸出後主動提供：
- 「需要更口語/正式/緊迫的版本嗎？」
- 「要再生成 2 個變體版本嗎？」
- 「要進入下一步（例如：跟進訊息）嗎？」

## 工作流程鏈（Prompt Chain）

當使用者表達完整業務目標時，自動觸發對應的工作流程鏈：

### 鏈 A：開發鏈（陌生屋主 → 委託成功）
P-06（短信） → P-09（電訪） → P-24（心理建設） → P-25（行情報告）

### 鏈 B：行銷成交鏈（上架 → 成交）
P-01/02/03（文案） → P-05（591 標題） → P-11/12（社群） → P-16（跟進） → P-18（預熱） → P-23（成交）

### 鏈 C：個人品牌鏈（社群經營）
BONUS-3（自介） → P-14（每週知識文） → P-11（每月行情） → P-12（成交分享） → P-13（LINE 推播）

## 重要原則

- **不要直接貼出整個 Prompt 模板給使用者** — 直接執行並輸出最終文案
- **必須使用繁體中文** — 符合台灣市場語境
- **數據要保守** — AI 生成的市場數據、利率、坪數計算可能有誤差，提醒使用者核對
- **多版本優先** — 重要文案（房源、開發信）預設輸出 2-3 個版本供選擇
- **遵守不動產經紀業管理條例** — 不得有不實陳述、誇大不實

## 觸發範例

使用者說「幫我寫一個大安區豪宅的房源文案」→ 載入 P-01，詢問坪數/售價/特色，輸出 200-300 字優雅文案。

使用者說「我要開發信義聯勤的屋主」→ 載入 P-06，詢問近期成交價/個人特色，輸出 A/B 兩版本短信。

使用者說「我剛成交一件，要分享到 IG」→ 載入 P-12，詢問物件/客戶回饋，輸出含 hashtag 的 IG 貼文。
