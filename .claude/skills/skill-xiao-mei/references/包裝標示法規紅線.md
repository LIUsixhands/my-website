# 包裝標示法規紅線（送印前逐項打勾）

> ⚠️ 法規會修正，各類商品另有中央主管機關公告事項。
> 本表供**設計配置與自我檢查**使用；最終適法性請客戶／法務／主管機關確認。
> 小美的原則：**沒有確認的項目，寧可標「待確認」也不出送印檔。**

---

## 一、食品（《食品安全衛生管理法》第 22 條）

有容器或外包裝之食品，應以**中文及通用符號明顯標示**下列事項：

- [ ] 1. **品名**
- [ ] 2. **內容物名稱**（混合二種以上，分別標明）
- [ ] 3. **淨重、容量或數量**
- [ ] 4. **食品添加物名稱**（混合二種以上者，應分別列出；甜味劑、防腐劑、抗氧化劑須標示用途名稱＋品名）
- [ ] 5. **製造廠商或國內負責廠商名稱、電話號碼及地址**（輸入食品應同時標示國內負責廠商資訊）
- [ ] 6. **原產地（國）**
- [ ] 7. **有效日期**
- [ ] 8. **營養標示**
- [ ] 9. **含基因改造食品原料**（如有）
- [ ] 10. **其他經中央主管機關公告之事項**（如過敏原標示、特定成分警語等，**依最新公告**）

**設計注意**
- 標示須**明顯易見**，不得被摺線、封口、提把、貼紙遮蔽。
- 有效日期／批號的**噴印區**要留淺色空白（≥ 30×10 mm）。
- 字級不可過小，**依相關規定與可讀性**設定；避免細字反白於深底。
- 散裝食品、直接供應飲食之場所另有規定。

### 🚫 絕對不可出現在食品包裝／文宣上
- 醫療效能字句：治療、療效、根治、抗癌、降三高、消炎、殺菌（人體）、改善病症、
  「提升免疫力」等易被認定為醫療效能或誇大之詞（食安法第 28 條）。
- 「無毒」「天然」「純」等易生誤解的絕對用語，若無依據一律不寫。
- 未取得認證的標章：有機、CAS、產銷履歷、地理標示、清真、原住民族相關標章。

### ✅ 可用的替代寫法（同樣好賣，但不違法）
| ❌ 不可寫 | ✅ 改寫 |
|:---|:---|
| 降血糖／降三高 | 低糖配方／每份含糖 X 公克 |
| 抗癌、排毒 | 以〇〇原料製成，日常飲食搭配 |
| 提升免疫力 | 富含〇〇（依營養標示可宣稱之營養素含量用語） |
| 純天然無添加 | 未添加防腐劑（**須確實未添加且可佐證**） |
| 治療失眠 | 睡前的一杯溫熱〇〇 |
| 有機（無驗證） | 友善耕作／無使用除草劑（須可佐證） |

## 二、化粧品（《化粧品衛生安全管理法》）

- [ ] 品名、用途、用法、保存方法
- [ ] 淨重／容量、全成分（依規定格式）
- [ ] 製造或輸入業者之名稱、地址、電話
- [ ] 製造日期及有效期間／保存期限（依規定擇一或併列）
- [ ] 批號
- [ ] 必要之警語與注意事項
- 🚫 不得為虛偽或誇大之宣傳，不得宣稱醫療效能（如：治療痘痘、去除皺紋至醫療程度、生髮療效等）。

## 三、酒（《菸酒管理法》）

- [ ] 品牌名稱、產品名稱、類別、酒精成分（%）、容量
- [ ] 製造業者名稱地址（進口者另標進口業者）、原產地
- [ ] 製造日期或保存期限（依規定）
- [ ] **警語：「飲酒過量，害人害己」**（依規定格式與明顯程度標示）
- 🚫 不得對未成年行銷；廣告受限制。

## 四、一般商品共通

- [ ] 商品標示法相關事項（商品名稱、生產或製造商名稱地址、原產地、主要成分或材料、數量、國曆或西曆製造日期、使用與保存方法及其他應注意事項）
- [ ] 條碼（EAN-13）：留白 ≥ 2.3mm，不跨摺線
- [ ] 回收標誌（依應回收廢棄物之規定）
- [ ] 進口品：中文標示不得小於外文標示、不得以貼紙遮蔽原有必要資訊

## 五、標章與補助字樣

- [ ] 所有標章**都有核准文件**才印（要客戶提供證明檔）
- [ ] 公部門補助案：**指導／主辦／協辦單位 logo 排序與補助字樣**依承辦提供之規定
- [ ] 使用他人商標（通路、聯名）須有授權書
