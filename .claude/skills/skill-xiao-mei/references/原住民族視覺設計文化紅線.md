# 原住民族視覺設計 文化紅線與工作流

> 這份文件的目的只有一個：**讓你做出來的東西，族人願意掛在部落活動中心的牆上。**
> 法規會變、實務見解會有差異，以下引述**僅供設計流程判斷使用**，
> 個案是否須取得同意、如何取得，請洽**部落／族群代表、原住民族委員會**與專業律師。

---

## 一、法源速覽（設計師需要知道的最小集合）

| 法規 | 與設計有關的重點 |
|:---|:---|
| 《原住民族傳統智慧創作保護條例》第 3 條 | 保護標的包含傳統之**宗教祭儀、音樂、舞蹈、歌曲、雕塑、編織、圖案、服飾、民俗技藝**及其他文化成果之表達 |
| 同條例第 4 條 | 智慧創作應**經主管機關認定並登記**始受本條例保護 |
| 同條例第 10 條 | 經認定屬特定原住民族或部落者，**專用權歸屬該族或該部落**；無法認定者歸屬全部原住民族 |
| 同條例第 13 條 | 專用權人以外之人欲利用，**應取得同意或授權**；**商業利用**並應支付使用報酬 |
| 同條例第 14 條 | 經授權之利用，應為**專用權標記**之註記 |
| 同條例（合理使用相關規定） | 個人非營利、學術研究等有其例外，**但商業設計案幾乎都不在例外內** |
| 《原住民族基本法》第 13 條 | 政府應保護、發展原住民族傳統生物多樣性知識及智慧創作 |
| 《著作權法》 | **當代族人藝術家的個別創作**受著作權保護，與傳統智慧創作是兩件事，兩邊都要處理 |
| 《民法》肖像權・個資法 | 族人照片、祭儀影像使用須有同意；未成年須法定代理人同意 |

**兩層授權都要拿：**
1. **傳統層** → 該族／部落（是否為登記在案之智慧創作、由誰代表同意）
2. **個人層** → 實際繪製／拍攝者（設計、插畫、攝影的著作財產權與授權範圍）

## 二、動工前必問七題（沒有全部答案不進入設計）

1. 這個案子服務的是**哪一族、哪個部落**？（族名＋部落族語名＋所在鄉鎮）
2. 主辦單位與**部落的關係**是什麼？（部落自辦／公所辦／協會辦／廠商標案）
3. 有沒有**部落窗口**可以確認視覺？（姓名、職稱、聯絡方式）
4. 活動的**族語名稱**正確拼寫是什麼？誰能確認？（族語老師／文化健康站／族語推廣人員）
5. 可用元素有哪些？**明確不可用**的有哪些？（請部落直接列）
6. 圖像素材從哪來？（部落既有素材／族人藝術家繪製／攝影師拍攝／AI 生成）各自的**授權文件**在哪？
7. 這次成果會被**商業利用**嗎？（販售、周邊、授權他人使用）→ 若會，授權書必須寫清楚範圍與期間。

→ 直接用 `templates/原民文化訪查表.json` 收集，回填後才開圖。

## 三、絕對不做的事（做了就是事故）

| ❌ 不做 | 為什麼 |
|:---|:---|
| 用 AI 生「原住民風圖騰／部落紋樣」 | 模型會混出泛太平洋／北美原民的四不像紋樣，交出去是冒犯也是侵權風險 |
| 把不同族的元素拼成一張圖 | 16 族是 16 個民族，不是一種風格 |
| 使用排灣／魯凱的**人頭紋、百步蛇紋、太陽紋**當裝飾 | 傳統上與**貴族階序**相關，屬身分象徵，非公共素材 |
| 使用達悟族**拼板舟船眼紋**、銀盔 | 船紋屬特定家族／船團；銀盔為重要文化物件，不得戲謔或商品化 |
| 使用泰雅／太魯閣／賽德克**紋面**影像做視覺花樣 | 紋面是身分與生命歷程的印記，不是圖案 |
| 把祭儀寫成「表演」「秀」「體驗包玩」 | 歲時祭儀是儀式；用詞錯誤會直接引發部落抗議 |
| 未經同意使用祭典現場照片 | 多數祭儀有攝影規範，部分區域／時段禁止攝影 |
| 用「山地」「山胞」「番」「土著」「原始」「野性」 | 歧視性用語 |
| 族語拼寫自行「簡化」，把 ' 或 ʉ 拿掉 | 那是字母不是裝飾，拿掉就是拼錯字 |
| 把族服穿在非族人模特兒身上拍宣傳照 | 文化挪用爭議極高，一律避免 |

## 四、可以做、而且做了會加分的事

1. **把主體讓給族人。** 主視覺的核心圖像交由**部落指定的族人藝術家**繪製，
   小美負責的是**版面、字體、資訊層級、印刷規格、應用延伸**——這是最安全也最專業的分工。
2. **族語與中文並列。** 活動名稱做族語（大）＋中文（次）並列，是最直接的尊重表達。
3. **地景與物產取代圖騰。** 山、海、溪、稻、小米、洛神、飛魚、月桃、藤編質感——
   這些是**地方感**而非**專屬紋樣**，風險低且辨識度高。
4. **色彩取自實地。** 從部落實拍照片取色（織品、山壁、屋瓦、作物），比套「原民配色」真實得多。
5. **署名與感謝。** 主視覺說明中列出**繪製者族名／漢名、部落、以及協力單位**，
   這一步常被省略，但它是「被看見」與「被拿走」的分界線。
6. **交件附《元素來源與授權清單》**（見 §6），案子結束三年後被問起也答得出來。

## 六、族語排版的技術地雷（最常出事、也最容易修）

1. **缺字（tofu 豆腐框）**：族語羅馬字含 `ʉ`（U+0289）、`'`（喉塞音，常用直立單引號 U+02BC 或 U+0027）、
   `ng`、帶符號母音等。**多數中文設計字型不含這些字符**，排上去就是空白或框框。
   → 族語文字建議使用 **Noto Sans／Noto Serif（Google Noto 系列）** 或 **思源黑體／思源宋體**（拉丁擴充較完整），
   並**送印前逐字跑缺字檢查**（`scripts/preflight.py --text`）。
2. **智慧引號自動替換**：文書軟體會把 `'` 換成 `’`，看起來像卻是不同字元。
   → 族語文字一律**從族語老師提供的純文字檔複製**，不要手打，不要用自動校正。
3. **大小寫**：族語專有名詞的大小寫由族語書寫系統決定，**不要為了設計把整句改全大寫**。
4. **斷行**：族語不可任意斷詞，長字寧可縮字級或換行，不要中間硬斷。
5. **繁體中文字型**：中文一律用 **Songti TC／PingFang TC** 等繁體字型，
   **不可用 Songti SC**（簡體字型缺繁體字會渲染成空白）。
