# 海報・DM・活動主視覺 設計 SOP

## 1. 動工前先答三題

1. **這張要印多大？貼在哪裡？看的人站多遠？**
   （A3 貼公布欄＝1 公尺內看；A1 貼牆＝3 公尺外看；布條＝10 公尺外看）
   → 觀看距離決定**最小字級**與**主標大小**，不是美感決定。
2. **看完要做什麼？**（報名／到場／掃 QR／打電話）→ 這是唯一的 CTA。
3. **一定要放什麼？**（主辦／指導／協辦 logo、補助字樣、法定標示、QR）
   → 公部門案的 logo 排序與字樣是**驗收項目**，先跟承辦確認。

## 2. 三階層資訊架構（海報只能有一個主角）

| 階層 | 內容 | 字級比 | 判斷 |
|:---|:---|:---|:---|
| **L1 主角** | 活動名稱／主視覺圖像 | 4 | 3 公尺外唯一看得到的東西 |
| **L2 決策資訊** | 日期・時間・地點 | 2 | 走近一步就要看到 |
| **L3 行動與細節** | 報名方式／QR／主辦單位／注意事項 | 1 | 拿起手機時才看 |

**檢查法**：把稿子縮到 10% 瞇眼看，若看不出主角 → 主標加大或減少元素，重做。

## 3. 版面骨架（四種安全結構，挑一個就好）

1. **上圖下字**：主視覺占上 60–70%，資訊帶在下方色塊——最穩，公部門最愛。
2. **滿版圖＋壓字**：圖要有留白區（天空、水面）給字；字下加半透明色塊或漸層確保可讀。
3. **左右分割**：左圖右字（或反之），適合 A4 DM 與橫式。
4. **中央對稱**：主標置中、上下對稱資訊——適合祭典、典禮、莊重場合。

**留白鐵律**：四邊留白 ≥ 成品短邊的 5%（A1 約 30mm），且**留白不是浪費，是主角的呼吸**。

## 4. 字體與顏色

- 中文主標：黑體（思源黑體 TC Heavy／PingFang TC Semibold）；文青／文化場合可用宋體（**Songti TC，不可用 SC**）。
- 字體家族**最多兩套**（一套標題一套內文），靠字重與字級拉層級，不靠換字體。
- 顏色主色 1 ＋ 輔色 1 ＋ 強調色 1，**不超過三色系**；強調色只給 CTA。
- 深底反白字：字級 ≥ 9pt 且用黑體；細筆畫字型不做反白。
- 對比度：文字與底色亮度差要夠（印刷會比螢幕暗一階，**設計時故意再拉開一點**）。

## 5. 一套 KV → 全媒材延伸表（交件時附這張）

| 應用 | 尺寸 | 重點 |
|:---|:---|:---|
| 主海報 | A1 594×841 | 完整版 |
| 場地海報 | A2／A3 | 縮小後字級重排，不是直接縮 |
| DM 傳單 | A5 雙面／A4 三摺 | 正面 KV，背面議程與交通 |
| 社群主圖 | 1200×1200／1080×1350 | 重新裁切構圖，不要直接塞海報 |
| FB 廣告素材 | 1080×1080／1080×1920 | 交給小廣；文字盡量精簡 |
| 直式布條 | 依現場（常見 90×270 cm） | 只留 L1＋L2，出血 20–50mm |
| 舞台背板 | 依現場 | 100–150 dpi；**中央勿放關鍵字**（會被講台與人擋住） |
| 識別證／貼紙／桌卡 | 依需求 | 同一色系與圖像元素 |
| 簡報封面 | 16:9 | 給小講延伸簡報 |

**延伸原則**：不是縮放，是**重排**。每個尺寸都要重新決定 L1/L2/L3 的取捨。

## 6. 原民活動主視覺的額外流程（必跑）

1. 先跑 `原住民族視覺設計文化紅線.md` 的**動工前必問七題**與**訪查表**。
2. 主要文化圖像**委由部落指定族人藝術家繪製**；小美做版面、字體、資訊層級與印刷。
3. 族語活動名稱**大於或等於**中文名稱，拼寫經族語老師二次確認。
4. 出稿後**送部落窗口確認**再送印；確認紀錄留檔（截圖／Email）。
5. 交件必附《元素來源與授權清單》。

## 7. 交件前檢查（逐項打勾）

- [ ] 主角清楚（10% 瞇眼測試過）
- [ ] 日期／時間／地點／報名方式**逐字唸過**
- [ ] QR Code 實測掃得開（列印尺寸下 ≥ 2×2 cm，四周留白）
- [ ] 主辦／指導／贊助 logo 齊全、排序正確、解析度足夠（**向量或 300dpi**）
- [ ] 出血 3mm、安全區 5–8mm、CMYK、字型外框化
- [ ] 缺字檢查通過（`scripts/preflight.py`）
- [ ] 附延伸尺寸表與規格書
- [ ] 原民案：授權清單與部落確認紀錄
