# 雜誌・刊物 編輯設計 SOP

> 雜誌不是「一堆好看的頁」，是**一套可以每期重複執行的規範**。
> 小美交的不只是這一期，是讓下一期只花三分之一時間的**樣式規範書**。

## 1. 開案先定五件事

| # | 決定 | 說明 |
|:---|:---|:---|
| 1 | **開本** | 菊 8 開 190×260、16 開 210×285、A4 210×297；決定後不可中途改 |
| 2 | **頁數與台數** | 騎馬釘／膠裝皆須 **4 的倍數**，一台常 8 或 16 頁；頁數先定，內容再塞 |
| 3 | **裝訂** | ≤ 48 頁騎馬釘；≥ 48 頁膠裝（膠裝內側多留 3–7mm） |
| 4 | **紙材** | 封面 200–250g 上膜；內頁雪銅／輕塗 80–120g（文字多可用道林護眼） |
| 5 | **色數** | 全彩／部分黑白（黑白台可省成本，但要**整台**規劃） |

## 2. 網格系統（先立網格，再談美感）

**版心設定（以 A4 210×297 為例）**

| 項目 | 建議值 |
|:---|:---|
| 天（上）| 20–25 mm |
| 地（下）| 25–30 mm（放頁碼與頁尾） |
| 內（訂口）| 20 mm（膠裝 23–27 mm） |
| 外（切口）| 15–18 mm |
| 欄數 | **12 欄**（彈性最高，可組 1/2/3/4 欄）或 6 欄 |
| 欄間 gutter | 4–5 mm |
| 基線格 baseline grid | 內文行距的整數倍（例 13pt），**所有文字對齊基線** |

**常用欄組合**：單欄（長文散文）、雙欄（一般報導）、三欄（新聞、短訊）、
主欄＋邊欄（圖說、註解、小專欄）。同一本刊物**最多三種**版型輪替。

## 3. 字級階層（定一次，全刊照用）

| 樣式 | 建議（中文） | 說明 |
|:---|:---|:---|
| 大標 H1 | 28–40 pt 黑體 Bold | 每篇一個 |
| 副標 H2 | 16–20 pt | 提示內容 |
| 引言 Lead | 12–14 pt，行距 1.8 | 與內文區隔 |
| 內文 Body | **9.5–11 pt**，行距 1.6–1.8 | 中文行距要比西文大 |
| 小標 H3 | 12–13 pt Bold | 段落分節 |
| 圖說 Caption | 8–9 pt，可用不同字體或灰階 | 一定要有 |
| 頁眉／頁碼 | 8–9 pt | 左右頁位置對稱 |

**字體**：中文最多兩套（例：標題思源黑體 TC／內文 Songti TC）；
⚠️ **一律用 TC 不用 SC**（SC 缺繁體字會渲染成空白，本院踩過）。

## 4. 固定頁面元素

- **封面**：刊名（固定位置與字體，每期不變）＋期數日期＋主打標題 1–3 條＋主圖。
  刊名是識別資產，**不要每期換設計**。
- **目錄**：頁碼、欄目名、篇名、作者；用於檢查落版是否正確。
- **版權頁**：發行單位、發行人、編輯團隊、地址電話、出版日期、ISSN（若有）、
  公部門刊物常需**GPN／經費來源／授權條款**——先問承辦。
- **頁眉頁尾**：左頁放刊名／期數，右頁放欄目名（或相反），固定不變。
- **欄目識別**：每個欄目一個色或一個標示，讀者翻頁能辨位。

## 5. 落版（Flat plan）— 每期最重要的一張表

| 頁碼 | 欄目 | 篇名 | 圖片數 | 狀態 |
|:--|:---|:---|:--|:--|
| 封面 | — | 主視覺 | 1 | ✅ |
| 2–3 | 編者的話／目錄 | — | 1 | ✅ |
| 4–9 | 封面故事 | 〇〇〇 | 6 | 待圖 |
| … | | | | |
| 封底裡・封底 | 廣告／宣導 | — | — | 待客戶 |

**鐵律**：
1. 頁數＝**4 的倍數**，不足用扉頁／筆記頁補。
2. **跨頁（見開）成對思考**：讀者一次看到的是左右兩頁，不是一頁。
3. 跨頁大圖**中間不要放人臉與關鍵文字**（膠裝會吃掉）。
4. 廣告頁位置先卡（封面裡／封底裡／封底最貴），再排內容。

## 6. 圖片處理

- 每張圖標註：來源、攝影者、授權、是否需付費、是否有肖像同意。
- 300 dpi 於實際刊出尺寸；直式圖不要硬拉成橫式。
- 去背圖與滿版圖不要同頁太多，會亂；一個跨頁**一個視覺主角**。
- 圖說一定要寫（人事時地），這是刊物的專業度分水嶺。

## 7. 交件（每期）

1. `內頁_送印.pdf`（單頁排列，非跨頁拼版；出血 3mm、裁切標記、字型內嵌）
2. `封面_送印.pdf`（含書背厚度計算：膠裝書背 mm ≈ 頁數 ÷ 2 × 紙厚係數，**以印廠計算為準**）
3. `落版單.md`
4. `樣式規範書.md`（網格、字級階層、色票、圖說格式）← **下一期的省時關鍵**
5. `圖片來源與授權清單.md`
