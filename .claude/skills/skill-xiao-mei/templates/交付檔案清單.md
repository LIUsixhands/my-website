# 交付檔案清單（每案交件時逐項打勾）

## 一、共通五件
- [ ] `成品_預覽.png`（RGB，給客戶手機看）
- [ ] `成品_送印.pdf`（含出血 3mm＋裁切標記；字型外框化或內嵌）
- [ ] `規格書.md`（尺寸／紙材／印刷／後加工／色彩／字型／圖片來源）
- [ ] `送印前檢查表.md`（跑 `scripts/preflight.py` 產生）
- [ ] `圖片來源與授權清單.md`

## 二、依案件類型加交
### 海報／DM
- [ ] 延伸尺寸表（A1／A2／A3／DM／社群／布條／背板）
- [ ] 社群版主圖（1080×1080、1080×1350、1080×1920）

### 雜誌／刊物
- [ ] `內頁_送印.pdf`（單頁排列，非跨頁拼版）
- [ ] `封面_送印.pdf`（含書背厚度，以印廠計算為準）
- [ ] `落版單.md`
- [ ] `樣式規範書.md`（網格／字級階層／色票／圖說格式）

### 包裝
- [ ] `刀模.svg` ＋ `刀模.pdf`
- [ ] `包裝_送印.pdf`（展開稿，刀模線分層不印）
- [ ] `3D預覽.png`
- [ ] `標示合規檢查表.md`（食安法／化粧品／酒品逐項）
- [ ] 印廠刀模已回傳確認
- [ ] 白樣已實摺驗證

### 原住民族案件（缺一不可）
- [ ] `元素來源與授權清單.md`（族別／出處／同意依據／繪製者）
- [ ] 部落確認紀錄（截圖或 Email）
- [ ] 族語拼寫確認紀錄（確認人與日期）
- [ ] 繪製者署名已出現在成品或說明中

## 三、交件時一併說明
- [ ] 已告知客戶：交付為 **PDF／PNG／SVG**，若需 `.ai`／`.indd` 可編輯原始檔須由設計師依規範書轉製
- [ ] 已告知客戶：色彩以**印廠打樣**為準
- [ ] 已提醒客戶：**電話／日期／地點／報名方式**四項請自行逐字複查一次
