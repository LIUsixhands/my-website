## 每筆案例的固定格式

1. **起點**：助哥一開始丟了什麼素材、說了哪句話
2. **流程**：每一步怎麼跟 Claude 說 → Claude 做了什麼 → 人要檢查什麼
3. **改版紀錄**：哪一版被打槍、為什麼、怎麼改（這段最有教學價值）
4. **踩坑清單**：學員最容易犯的錯
5. **可直接套用的開口句**：學員複製就能用
