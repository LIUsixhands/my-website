## 🔧 流程變更：不再等 Netlify 預覽綠燈

助哥 2026-10-04 採納建議，**關閉 Deploy Previews**（每個 PR 省一次建置，消耗直接砍半）。

因此既有流程中「開 Draft PR → **等 Netlify preview 綠燈** → 轉正式 → 合併」這一步**不再適用**，
預覽不會再出現，等它等於卡死。

**改用本機驗證取代**（品質不降，而且更嚴格）：

```
JSON-LD 皆可 json.loads
標籤閉合平衡、單一 <h1>
H1／<title>／og:title 三者互異
.meta 日期 == datePublished
無 markdown 殘留、無中英夾雜殘字
所有內部連結指向實際存在的檔案
Playwright 390px 與 1280px：scrollWidth == innerWidth、無溢出
需要時截圖目視確認版面
```

全部通過才合併。**不要再等 preview。**
