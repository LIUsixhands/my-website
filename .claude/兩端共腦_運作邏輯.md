# 兩端共腦運作邏輯

> 助哥指定固化（2026-05-26）：說明「Claude Code (this repo) ↔ 手機 claude.ai Project」如何共享記憶與資料。

---

## 🧠 兩個環境，兩個獨立的「我」

| 環境 | 名稱 | 角色 |
|:--|:--|:--|
| **Code 端** | Claude Code on web（my-website 程式庫）| 重型工作：分析、清洗、commit、出報告 |
| **手機端** | claude.ai Project（手機 App / 網頁）| 隨身協助：召喚員工、查行情、輕量對話 |

**事實**：兩邊對話**不互通**。手機聊的不會出現在 Code 端，反之亦然。

---

## 🔗 唯一的「共同記憶」＝ 程式庫檔案

```
      [手機 claude.ai Project]
              ↓
      重要結論寫成文字 / 截圖
              ↓
      ═══════════════════════
           [my-website repo]   ← 共腦
           git commit + push
      ═══════════════════════
              ↑
      Code 端產出 commit
              ↑
      [Claude Code 對話]
```

---

## 🔁 雙向同步機制

### Code 端 → 手機端
**何時觸發**：新建大樓行情卡、新估價報告、新員工、知識庫版本更新

**做什麼**：
1. Code 端 commit + push 後
2. 把更新的檔案**重新上傳**到 claude.ai Project 知識庫（覆蓋舊版）
3. 對應檔案：
   - `.claude/skills/skill-xiao-tun/references/七期行情_知識庫版.md`
   - `.claude/skills/skill-xiao-tun/references/七期範圍圖_v3.png`
   - `.claude/Sixhands StudioAI員工團隊_claude專案版.md`（員工總表）

### 手機端 → Code 端
**何時觸發**：手機聊出新數據、新策略、新成交、新洞察

**做什麼**：
1. 截圖或複製重要對話
2. 傳回 Code 端對話（這邊）
3. 由 Code 端的我整理 + commit 進 repo
4. 必要時再回上傳給手機（閉環）
