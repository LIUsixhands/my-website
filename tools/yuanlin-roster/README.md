# 員林交流道特定區｜地主同意書整合名冊 產製工具

把「土地登記第二類謄本」PDF 轉成同意書追蹤用的 Excel 名冊，可分批併入同一個檔案。

## ⚠️ 個資鐵律

- 謄本 PDF、解析出的 JSON、產出的 Excel **一律不入版控**（已由 `.gitignore` 擋掉）。
- 名冊只存本機／實體檔案，不上公開雲端連結、不寫進對外文案。

## 用法

```bash
pip install pdfplumber openpyxl

# 1) 抽取 PDF 文字（自動濾掉浮水印與頁緣防偽碼）
python3 extract_pdf.py <謄本PDF所在資料夾> clean.txt

# 2) 解析成結構化 JSON
python3 parse_deed.py clean.txt data.json

# 3) 產出／併入 Excel（第三個參數為區塊代號）
python3 build_roster.py data.json "員林交流道特定區_地主同意書整合名冊.xlsx" A區
```

第 3 步可重複執行：**已存在的 Excel 會被併檔而非覆蓋**，以
`段別|地號全碼|登記次序|統一編號` 為鍵值比對，人工填寫欄位
（同意書狀態／紙本收件日／印鑑證明／聯絡方式／上次接觸日／下次追蹤日／位置關鍵性／備註）
會原樣保留。

## Excel 結構

| 工作表 | 內容 |
|---|---|
| 說明與進度 | 資料來源、累計面積、門檻對照（A區 13.18ha、5 公頃門檻）、兩階段同意門檻、工作提醒 |
| 地主同意書總表 | 逐「地號 × 所有權人」一列，橘色標題為人工填寫欄 |
| 地號彙總 | 每地號面積、所有權人數、持分合計檢核、公私有別、同意進度公式 |
| 地主彙總 | 每位地主一列（＝同意書份數），含合計持分面積與涉及地號 |
| 他項權利 | 抵押權等，含權利人、擔保金額、共同擔保地號 |

## 內建檢核

- 各地號權利範圍加總須為 1，否則「持分合計檢核」欄顯示 ⚠（代表謄本未收齊或需複核）。
- 面積換算 1 坪 = 3.305785 ㎡。
- 面積為謄本登載值，實際面積以核定圖實地分割測量面積為準。
