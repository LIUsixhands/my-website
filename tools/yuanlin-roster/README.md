# 員林交流道特定區｜地主同意書整合名冊 產製工具

把「土地登記第二類謄本」PDF 轉成同意書追蹤用的 Excel 名冊，可分批併入同一個檔案。

## ⚠️ 個資鐵律

- 謄本 PDF、解析出的 JSON、產出的 Excel **一律不入版控**（已由 `.gitignore` 擋掉）。
- 名冊只存本機／實體檔案，不上公開雲端連結、不寫進對外文案。

## 用法

```bash
pip install pdfplumber openpyxl

# 1) 抽取 PDF 文字（自動濾掉浮水印、頁緣防偽碼與重複上傳的 PDF）
python3 extract_pdf.py <謄本PDF所在資料夾> clean.txt

# 2) 解析成結構化 JSON
python3 parse_deed.py clean.txt data.json

# 3) 產出／併入 Excel
python3 build_roster.py data.json "員林交流道特定區_A區地主同意書整合名冊.xlsx" A區

# 3b) 首次要把現場跑地主名單（全名／電話／地址／意願等級／拜訪摘要／承辦人）灌進來
python3 build_roster.py data.json "…名冊.xlsx" A區 --field 現場名單.xlsx
```

`--field` 只在首次或需要重新灌入外部名單時使用；之後人工填寫以產出的 Excel 為準。

第 3 步可重複執行：**已存在的 Excel 會被併檔而非覆蓋**，以
`段別|地號全碼|登記次序|統一編號` 為鍵值比對，人工填寫欄位
（同意書狀態／紙本收件日／印鑑證明／聯絡方式／上次接觸日／下次追蹤日／位置關鍵性／備註）
會原樣保留。

## Excel 結構

| 工作表 | 內容 |
|---|---|
| 說明與進度 | 使用方式、意願等級定義、累計面積、門檻對照、兩階段同意門檻、工作鐵律 |
| 拜訪名單（依地主） | **出勤主表**：一人一列，依合計持分面積排優先序，含全名／電話／地址／意願等級／拜訪階段／承辦人 |
| 地號×地主明細 | 逐「地號 × 所有權人」一列，含持分、地目、他項權利 |
| 地號彙總 | 每地號面積、所有權人數、持分合計檢核、公私有別、同意進度 |
| 拜訪紀錄 | 每次接觸一列（日期／承辦人／接觸方式／對象／內容／下次行動），整張人工登錄 |
| 他項權利 | 抵押權等，含權利人、擔保金額、共同擔保地號 |
| 核對與待辦 | 待調謄本地號、名單漏列地主、統一編號疑義、遮罩統編一碼多人 |

### 地主歸戶規則

遮罩統一編號**一碼可能對到多人**（實測有一組對到 5 位不同地主），因此歸戶鍵為
**統一編號 ＋ 謄本姓氏 ＋ 通訊地址群集**；地址一方為另一方前綴（地址遮罩、門牌寫法不同）
者視為同一人。地主代號（L001…）一經產生即固定，併檔不會重編。

## 內建檢核

- 各地號權利範圍加總須為 1，否則「持分合計檢核」欄顯示 ⚠（代表謄本未收齊或需複核）。
- 公同共有整群只計一次；持分面積為按人數均分之推估值，不是應有部分。
- 現場名單與謄本以「地號 × 統一編號」比對，首碼字母不同但數字相同者做模糊比對並列入待辦。
- 面積換算 1 坪 = 3.305785 ㎡。
- 面積為謄本登載值，實際面積以核定圖實地分割測量面積為準。
